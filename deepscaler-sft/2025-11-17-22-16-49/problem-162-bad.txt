To solve this problem, we can use the Pythagorean theorem. The Pythagorean theorem states that in a right triangle, the square of the length of the hypotenuse ($c$) is equal to the sum of the squares of the lengths of the other two legs ($a$ and $b$). Mathematically, it is expressed as:

\[ c = \sqrt{a^2 + b^2} \]

In this problem, the lengths of the legs are 20 inches and 21 inches. So, we can substitute \( a = 20 \) and \( b = 21 \) into the formula:

\[ c = \sqrt{20^2 + 21^2} \]

Let's compute this step-by-step using Python to ensure accuracy.
```python
import math

# Lengths of the legs
a = 20
b = 21

# Calculate the hypotenuse using the Pythagorean theorem
c = math.sqrt(a**2 + b**2)
print(c)
```
Code execution result: 29.0

Thus, the length of the hypotenuse is \(\boxed{29}\) inches. This is the final answer.
