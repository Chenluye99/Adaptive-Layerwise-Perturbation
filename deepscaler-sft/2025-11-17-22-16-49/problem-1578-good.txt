To solve this problem, we need to generate the first few rows of Pascal's triangle until we find the smallest three-digit number.

Pascal's triangle is constructed as follows:
- The first row (row 0) is [1].
- The second row (row 1) is [1, 1].
- Each subsequent row \( n \) is constructed such that each element is the sum of the two elements directly above it in the previous row (with the boundary conditions that the first and last elements of each row are 1).

We can generate Pascal's triangle up to a sufficient number of rows and then find the smallest three-digit number in that triangle. Let's write some Python code to accomplish this task.
```python
import itertools

def generate_pascals_triangle(n_rows):
    triangle = []
    for n in range(n_rows):
        row = [1] * (n + 1)
        for i in range(1, n):
            row[i] = triangle[n-1][i-1] + triangle[n-1][i]
        triangle.append(row)
    return triangle

# Generate Pascal's triangle with enough rows to get all three-digit numbers
pascals_triangle = generate_pascals_triangle(200)

# Find all three-digit numbers in the triangle
three_digit_numbers = [num for row in pascals_triangle for num in row if 100 <= num < 1000]

# Find the smallest three-digit number in Pascal's triangle
smallest_three_digit_number = min(three_digit_numbers)
print(smallest_three_digit_number)
```
