To solve this problem, we need to place trees in such a way that they are 5 feet apart from each other, and we need to find the maximum number of trees that can be placed on a rectangular plot of land with sides of 120 feet and 70 feet.

### Step-by-Step Solution:

1. **Placing Trees Along the Rectangular Plot:**
    - We can place trees along the perimeter of the rectangular plot such that no two trees are closer than 5 feet from each other.
    - To do this, we start by figuring out how many trees can be placed along the four sides of the rectangle.

2. **Placing Trees Along the Length (120 feet):**
    - For each length of 120 feet, the number of trees that can be placed is \(\left\lfloor \frac{120}{5} \right\rfloor + 1 = 25\).
    - So, for both lengths (each 120 feet), we can place \(2 \times 25 = 50\) trees along the two lengths.

3. **Placing Trees Along the Width (70 feet):**
    - For each width of 70 feet, the number of trees that can be placed is \(\left\lfloor \frac{70}{5} \right\rfloor + 1 = 15\).
    - So, for both widths (each 70 feet), we can place \(2 \times 15 = 30\) trees along the two widths.

4. **Adjusting for Corner Overcounting:**
    - When placing trees along the full perimeter, we will have overcounted the four corners since each corner tree would have been counted twice (once for each side it is adjacent to).
    - Therefore, we need to subtract 4 trees (one for each corner) to correct for this overcounting.

So, the total number of trees is \(50 + 30 - 4 = 76\).

```python
# To solve the problem programmatically, let's consider placing the trees in a grid pattern inside the rectangular plot, ensuring trees are at least 5 feet apart both horizontally and vertically.

def place_trees(length, width, distance_between_trees):
    rows = length // distance_between_trees
    cols = width // distance_between_trees
    if length % distance_between_trees != 0:
        rows += 1
    if width % distance_between_trees != 0:
        cols += 1
    return rows * cols

length = 120
width = 70
distance_between_trees = 5

# Place trees in a grid pattern ensuring no closer than 5 feet distance
num_trees = place_trees(length, width, distance_between_trees)
print(num_trees)
```
