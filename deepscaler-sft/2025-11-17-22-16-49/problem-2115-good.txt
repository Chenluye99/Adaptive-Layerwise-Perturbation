To solve this problem, we need to follow these steps:

1. **Generate the List of Numbers:**
    - We need to generate all three-digit numbers that have a ones digit of 3. So, the numbers range from 103 to 993 with a step of 10 (i.e., 103, 113, 123, ..., 993).

2. **Check Divisibility by 3:**
    - For each number in this list, we need to check if it is divisible by 3. A number is divisible by 3 if the sum of its digits is divisible by 3.

3. **Count Numbers That Meet the Condition:**
    - We will count how many of these numbers are divisible by 3.

4. **Calculate the Probability:**
    - The probability that a randomly chosen number from this list is divisible by 3 is the number of numbers divisible by 3 divided by the total number of three-digit numbers that end in 3.

Let's implement this step-by-step process in Python.
```python
# Step 1: Generate the list of three-digit numbers that have a ones digit of 3
three_digit_numbers_ending_in_3 = [num for num in range(103, 1000) if num % 10 == 3]

# Step 2 and 3: Check divisibility by 3 and count how many of these numbers are divisible by 3
count_divisible_by_3 = sum(1 for num in three_digit_numbers_ending_in_3 if num % 3 == 0)

# Step 4: Calculate the probability
total_numbers_ending_in_3 = len(three_digit_numbers_ending_in_3)
probability = count_divisible_by_3 / total_numbers_ending_in_3

# Return the result as a fraction
from fractions import Fraction
probability_fraction = Fraction(count_divisible_by_3, total_numbers_ending_in_3)

print(((total_numbers_ending_in_3, count_divisible_by_3, probability_fraction)))
```
Code execution result: (90, 30, Fraction(1, 3))

This means:
- There are 90 three-digit numbers that end in 3.
- Out of these 90 numbers, 30 are divisible by 3.
- Therefore, the probability that a randomly chosen three-digit number that ends in 3 is divisible by 3 is \(\frac{30}{90} = \frac{1}{3}\).

So, the final answer is \(\boxed{\frac{1}{3}}\).
