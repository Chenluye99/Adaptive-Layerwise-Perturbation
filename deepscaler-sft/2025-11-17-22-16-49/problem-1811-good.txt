To solve this problem, we need to determine for how many integers \( n \) between 1 and 11 (inclusive), the fraction \(\frac{n}{12}\) results in a repeating decimal.

A fraction in its simplest form has a repeating decimal if and only if the prime factorization of the denominator (after simplifying the fraction) contains any prime number other than 2 or 5. For the fraction \(\frac{n}{12}\), the denominator 12 can be factored as \( 2^2 \cdot 3 \). This means that \(\frac{n}{12}\) will have a repeating decimal if and only if 3 is a factor of the denominator after simplifying (i.e., we need to consider the greatest common divisor (GCD) of \( n \) and 12).

Let's iterate through each integer \( n \) from 1 to 11, simplify \(\frac{n}{12}\), and check if the resulting fraction has a repeating decimal.

We can use Python to perform this check accurately. We will check if the decimal representation of \(\frac{n}{12}\) is repeating by examining the prime factors of the denominator of the fraction in its simplest form. If the denominator, after simplification, contains a prime factor other than 2 or 5, then the decimal representation is repeating.

Let's implement this step-by-step in Python.
```python
import math

def is_repeating_decimal(n, d):
    # Simplify the fraction by finding the GCD of n and d
    gcd = math.gcd(n, d)
    n_simplified = n // gcd
    d_simplified = d // gcd
    
    # Get the prime factors of the denominator
    prime_factors = []
    for i in range(2, d_simplified + 1):
        while d_simplified % i == 0:
            prime_factors.append(i)
            d_simplified //= i
    
    # Check if the only prime factors of the denominator are 2 or 5
    for factor in prime_factors:
        if factor != 2 and factor != 5:
            return True
    return False

# Count how many of the fractions n/12, for n from 1 to 11, result in a repeating decimal
count_repeating = 0

for n in range(1, 12):
    if is_repeating_decimal(n, 12):
        count_repeating += 1

print(count_repeating)
```
