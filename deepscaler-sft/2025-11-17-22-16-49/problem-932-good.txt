To solve this problem, we need to find the smallest positive integer \( n \) such that:

1. \( n \) is a multiple of 75.
2. \( n \) has exactly 75 positive integral divisors.

First, let's start with some mathematical reasoning:

1. **Conditions for being a multiple of 75**:
    - Since \( 75 = 3 \times 5^2 \), the number \( n \) must be divisible by both 3 and \( 5^2 = 25 \), i.e., \( n \) must be divisible by 75.

2. **Conditions for having exactly 75 divisors**:
    - If the prime factorization of \( n \) is given by \( n = 2^{e_1} \times 3^{e_2} \times 5^{e_3} \times \cdots \times p_k^{e_k} \), then the number of divisors of \( n \) is \((e_1 + 1)(e_2 + 1)(e_3 + 1) \cdots (e_k + 1)\).
    - We need this product to be 75. The number 75 can be factored into:
      \[
      75 = 75 \times 1, \quad 75 = 25 \times 3, \quad 75 = 15 \times 5, \quad 75 = 5 \times 5 \times 3
      \]
    - This means we need to check which of these factorizations can correspond to the exponents \( e_1, e_2, e_3, \ldots, e_k \) in the prime factorization of \( n \) such that \( n \) is also a multiple of \( 75 = 3 \times 5^2 \).

We will use Python to iterate through possible values of \( n \), checking both conditions as we go along. We will start checking from the smallest multiples of 75 and move upwards until we find the appropriate \( n \).

Let's implement this step-by-step in Python:
```python
import sympy

def count_divisors(n):
    return len(sympy.divisors(n))

# Start checking from the smallest multiple of 75, which is 75 itself
multiple_of_75 = 75

while True:
    if count_divisors(multiple_of_75) == 75:
        break
    multiple_of_75 += 75

n = multiple_of_75
result = n // 75

print((n, result))
```
