To solve the problem, we need to find values for the letters A, B, C, D, E, F, and G that satisfy the equation $\overline{\mathrm{ABCD}} + \overline{\mathrm{EFG}} = 2020$, where each letter represents a different digit. 

1. **Representation of Numbers:**
    - $\overline{\mathrm{ABCD}}$ represents a 4-digit number, so $\overline{\mathrm{ABCD}} = 1000A + 100B + 10C + D$.
    - $\overline{\mathrm{EFG}}$ represents a 3-digit number, so $\overline{\mathrm{EFG}} = 100E + 10F + G$.
    - The equation becomes: $1000A + 100B + 10C + D + 100E + 10F + G = 2020$.

2. **Constraints:**
    - Each letter (A, B, C, D, E, F, G) represents a different digit, i.e., they are all unique and range from 0 to 9.
    - A cannot be 0 because $\overline{\mathrm{ABCD}}$ is a 4-digit number.

3. **Iterative Search:**
    - We can use a brute force approach to check all possible combinations of the digits 0 through 9 for the letters A, B, C, D, E, F, G, ensuring that each letter has a unique value.
    - For each combination, we check if the equation holds.

Let's implement this using Python.
```python
import itertools

# We need to find suitable digits for A, B, C, D, E, F, G such that the equation holds and all letters are different.
solution = None

for combo in itertools.permutations(range(10), 7):
    A, B, C, D, E, F, G = combo
    
    ABCD = 1000 * A + 100 * B + 10 * C + D
    EFG = 100 * E + 10 * F + G
    
    if ABCD + EFG == 2020:
        solution = (A, B, C, D, E, F, G)
        break

print((solution, sum(solution)))
```
