Let's start by solving the problem step-by-step using reasoning and then confirm it by implementing it in Python.

1. **Problem Understanding:**
    - There are 4 representatives from each of 4 companies, so there are a total of \(4 \times 4 = 16\) people at the convention.
    - Each person should shake hands with every other person except for the 3 other representatives from their own company.

2. **Calculations:**
    - First, compute the total possible handshakes if there were no restrictions. This would be the number of ways to choose 2 people out of 16, which is \(\binom{16}{2} = \frac{16 \times 15}{2} = 120\).
    - Next, we must subtract the handshakes that do not happen because representatives from the same company do not shake hands with each other. For each company, there are 4 representatives, and the number of handshakes that would occur among these 4 people is \(\binom{4}{2} = \frac{4 \times 3}{2} = 6\). Since there are 4 companies, the total number of handshakes that do not happen is \(4 \times 6 = 24\).

So, the total number of handshakes that take place is:
\[ 120 - 24 = 96 \]

3. **Implement in Python to Verify:**
Let's confirm this by using a more direct computational approach. We can iterate through all possible pairs of people and count only the handshakes that occur according to the problem's rule.

We will use Python to ensure our solution is accurate by coding it.
```python
# Create a list of all 16 people, labeling them by their company and representative number
num_companies = 4
num_representatives_per_company = 4

# Create a list of all people with a tuple (company, representative_number)
people = [(company, rep) for company in range(num_companies) for rep in range(num_representatives_per_company)]

# Function to check if two people should shake hands (i.e., they are not from the same company)
def should_shakeHands(person1, person2):
    return person1[0] != person2[0]

# Count handshakes
num_handshakes = 0

# Iterate through all pairs of people and count the valid handshakes
for i in range(len(people)):
    for j in range(i + 1, len(people)):
        if should_shakeHands(people[i], people[j]):
            num_handshakes += 1

print(num_handshakes)
```
Code execution result: 96

Thus, the Python code's result confirms our reasoning. Therefore, the number of handshakes is \(\boxed{96}\). This is our final answer.
