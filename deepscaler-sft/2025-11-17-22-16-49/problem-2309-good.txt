To solve this problem, we need to identify which row of Pascal's triangle contains the numbers 1 and 12. Each element in Pascal's triangle is a binomial coefficient, and the \(n\)-th row of Pascal's triangle contains the coefficients of the expansion of \((a + b)^n\).

1. **Identify the Row:**
    - The first element of the \(n\)-th row of Pascal's triangle is \(\binom{n}{0} = 1\).
    - The second element of the \(n\)-th row is \(\binom{n}{1} = n\).
    - We are given that the second element of this row is 12, so we set up the equation:
      \[
      \binom{n}{1} = n = 12
      \]
    - This means \(n = 12\). So, we are looking at the 12th row of Pascal's triangle (note that row indices start from 0, so the 12th row is row index 12).

2. **Generate the 12th Row of Pascal's Triangle:**
    - The \(k\)-th element of the \(n\)-th row of Pascal's triangle is given by \(\binom{n}{k} = \frac{n!}{k!(n-k)!}\).
    - We need to generate the 12th row of Pascal's triangle and find the fourth number in that row (index 3, since indexing starts from 0).

Let's write Python code to generate the 12th row of Pascal's triangle and get the fourth number.
```python
import math

# Get the 12th row of Pascal's triangle
n = 12
row = [math.comb(n, k) for k in range(n + 1)]

# The fourth number in the row is at index 3 (since indexing starts from 0)
fourth_number = row[3]
print(fourth_number)
```
Code execution result: 220

Thus, the fourth number in the row of Pascal's triangle that starts with 1 and then 12 is \(\boxed{220}\). This is the final answer.
