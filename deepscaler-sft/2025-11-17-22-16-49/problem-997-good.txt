f(x, y, z) = \frac{4z}{2x + y} + \frac{4x}{y + 2z} + \frac{y}{x + z}.

1. Define the function \( f(x, y, z) \).
2. Use an optimization routine to find the minimum value of the function with respect to \( x, y, \) and \( z \).

from scipy.optimize import minimize
