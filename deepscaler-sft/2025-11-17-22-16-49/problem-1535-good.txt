To solve this problem, we need to determine the range of the function \( m(x) = \sqrt{x + 5} + \sqrt{20 - x} \).

1. **Find the Domain of the Function:**
    - The expression \(\sqrt{x + 5}\) is defined when \(x + 5 \geq 0 \implies x \geq -5 \).
    - The expression \(\sqrt{20 - x}\) is defined when \(20 - x \geq 0 \implies x \leq 20 \).
    - Therefore, the domain of \( m(x) \) is \([-5, 20]\).

2. **Evaluate the Function at the Boundary Points:**
    - Evaluate \( m(x) \) at \( x = -5 \):
      \[
      m(-5) = \sqrt{-5 + 5} + \sqrt{20 - (-5)} = \sqrt{0} + \sqrt{25} = 0 + 5 = 5.
      \]
    - Evaluate \( m(x) \) at \( x = 20 \):
      \[
      m(20) = \sqrt{20 + 5} + \sqrt{20 - 20} = \sqrt{25} + \sqrt{0} = 5 + 0 = 5.
      \]

3. **Find the Maximum Value of the Function in the Domain:**
    - To find the maximum value, we take the derivative of \( m(x) \) and set it to zero:
      \[
      m(x) = \sqrt{x + 5} + \sqrt{20 - x}
      \]
      Taking the derivative:
      \[
      m'(x) = \frac{d}{dx} \left( \sqrt{x + 5} \right) + \frac{d}{dx} \left( \sqrt{20 - x} \right) = \frac{1}{2\sqrt{x + 5}} - \frac{1}{2\sqrt{20 - x}}.
      \]
      Set \( m'(x) = 0 \):
      \[
      \frac{1}{2\sqrt{x + 5}} = \frac{1}{2\sqrt{20 - x}} \implies \sqrt{x + 5} = \sqrt{20 - x} \implies x + 5 = 20 - x \implies 2x = 15 \implies x = \frac{15}{2}.
      \]
    - Evaluate \( m \left( \frac{15}{2} \right) \):
      \[
      m \left( \frac{15}{2} \right) = \sqrt{\frac{15}{2} + 5} + \sqrt{20 - \frac{15}{2}} = \sqrt{\frac{15}{2} + \frac{10}{2}} + \sqrt{\frac{40}{2} - \frac{15}{2}} = \sqrt{\frac{25}{2}} + \sqrt{\frac{25}{2}} = 2 \sqrt{\frac{25}{2}} = 2 \cdot \frac{5}{\sqrt{2}} = 2 \cdot \frac{5 \sqrt{2}}{2} = 5 \sqrt{2}.
      \]

4. **Conclusion:**
    - The function \( m(x) \) achieves its minimum value of 5 at both boundaries \( x = -5 \) and \( x = 20 \).
    - The function \( m(x) \) achieves its maximum value of \( 5 \sqrt{2} \) at \( x = \frac{15}{2} \).
    - Therefore, the range of \( m(x) \) is all values from 5 to \( 5 \sqrt{2} \), inclusive.
