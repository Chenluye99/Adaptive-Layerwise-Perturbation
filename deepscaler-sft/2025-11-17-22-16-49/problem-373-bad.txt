1. **Problem Understanding**:
    - We have 21 distinct skill-level competitors numbered from 1 to 21.
    - The tournament proceeds for 20 rounds, starting with a randomly chosen active player. In each round, an inactive player is chosen to play against the current active player, and the winner becomes the new active player, and the loser is eliminated.
    - Alice is the competitor with skill 11, and we need to find the expected number of matches she will play in this tournament.

2. **Key Insights**:
    - In each round, one of the 20 inactive players gets chosen to play against the current active player.
    - Alice will only get a chance to play if she is chosen to be the active player or if a player with a lower skill level than Alice is chosen to be the active player and then loses to her.
    - We need to calculate the probability that Alice is chosen as the active player or gets a chance to play in each of the rounds by losing to a higher-ranked player that is chosen as the active player.

3. **Model the Problem**:
    - Initialize a list of players with skills from 1 to 21.
    - Simulate the tournament multiple times to get an accurate expectation. Each simulation will proceed as follows:
        1. Start with a random player chosen as the initial active player.
        2. For each round, choose a random inactive player to play against the current active player.
        3. The player with the higher skill wins and becomes the new active player.
        4. The loser is eliminated, reducing the number of inactive players.
        5. Repeat for 20 rounds, and count how many times Alice plays in each simulation.
    - Run a sufficient number of simulations (e.g., 100,000) to get a good estimate of the expected number of matches Alice will play.

Let's implement this in Python.
```python
import numpy as np

def simulate_tournament(num_simulations=100000):
    num_players = 21
    alice_skill = 11
    alice_play_count = 0
    
    for _ in range(num_simulations):
        players = list(range(1, num_players + 1))
        active_player = np.random.choice(players)
        
        for _ in range(20):
            inactive_players = [player for player in players if player != active_player]
            chosen_inactive_player = np.random.choice(inactive_players)
            
            if players.index(chosen_inactive_player) < players.index(active_player):
                # Alice plays if chosen_inactive_player is replaced by Alice or Alice beats a lower skill player
                if chosen_inactive_player != alice_skill:
                    alice_play_count += 1
            players.remove(chosen_inactive_player)
            if chosen_inactive_player < active_player and players.index(alice_skill) < players.index(active_player):
                active_player = alice_skill
        
    expected_alice_play_count = alice_play_count / num_simulations
    return expected_alice_play_count

expected_number_of_matches = simulate_tournament()
print(expected_number_of_matches)
```
