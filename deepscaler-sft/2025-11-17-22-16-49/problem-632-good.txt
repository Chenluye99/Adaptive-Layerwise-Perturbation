### Part (1) Implementation
We will start by solving the equation \(\frac{1}{2} + \frac{2a}{2a+2} + \frac{3}{2a+2} = \frac{5}{3}\) for \(a\).
```python
import sympy as sp

# Define the equation
a = sp.symbols('a', positive=True, integer=True)
eq = sp.Eq(1/2 + 2*a/(2*a + 2) + 3/(2*a + 2), 5/3)

# Solve the equation
solution = sp.solve(eq, a)
```

### Part (2): Find the Probability that the Sum of the Scores Obtained is 5 When Drawing 3 Balls at Once

Now we substitute \( a = 2 \) back into the problem. This means we have:
- 3 red balls,
- 2 yellow balls,
- 1 blue ball,
- Giving a total of 6 balls.

We need to find the probability that the sum of the scores obtained from drawing 3 balls at once is 5.

We will generate all combinations of drawing 3 balls out of these 6 balls and then check how many of these combinations have a sum of scores equal to 5. Let's implement this step-by-step in Python.
```python
import itertools

# Define the balls
balls = [1]*3 + [2]*2 + [3]*1

# Find all combinations of drawing 3 balls at a time
combinations = list(itertools.combinations(balls, 3))

# Count the number of combinations where the sum of scores is 5
count_sum_5 = sum(1 for combo in combinations if sum(combo) == 5)

# Calculate the total number of ways to draw 3 balls out of 6
total_combinations = len(combinations)

# Calculate the probability
probability_sum_5 = count_sum_5 / total_combinations
print(probability_sum_5)
```

So, the probability that the sum of the scores obtained is 5 when drawing 3 balls at once is \(\boxed{0.3}\).
