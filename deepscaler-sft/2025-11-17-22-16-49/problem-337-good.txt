To solve this problem, we need to calculate the expected value of the rain in inches for a single day and then multiply that by the number of days (from Monday to Friday, which is 5 days).

The expected value of the rain in inches for a single day can be calculated using the probabilities and the corresponding amounts of rain:

\[E(\text{Rain per day}) = (0 \, \text{inches} \cdot 0.40) + (4 \, \text{inches} \cdot 0.25) + (10 \, \text{inches} \cdot 0.35)\]

Let's compute this step-by-step.

1. Calculate the expected value of the rain for a single day.
2. Multiply this expected value by 5 (the number of days from Monday to Friday) to get the total expected value of the rain from Monday to Friday.

Let's proceed with the Python code to ensure accuracy.
```python
# Probabilities and corresponding rain amounts
prob_sun = 0.40
prob_4_inches = 0.25
prob_10_inches = 0.35

rain_0_inches = 0
rain_4_inches = 4
rain_10_inches = 10

# Calculate expected rain for a single day
expected_rain_per_day = (rain_0_inches * prob_sun) + (rain_4_inches * prob_4_inches) + (rain_10_inches * prob_10_inches)

# Number of days from Monday to Friday
num_days = 5

# Calculate total expected rain from Monday to Friday
total_expected_rain = expected_rain_per_day * num_days
print(total_expected_rain)
```
Code execution result: 22.5

Thus, the expected value of the total number of inches of rain which will fall from Monday to Friday, rounded to the nearest tenth, is \(\boxed{22.5}\). This is our final answer.
