To solve this problem, we need to generate the 100th row of the given triangular array and then find the sum of the numbers in that row.

First, let's understand how the array is formed:
- The 0th row is [0].
- The 1st row is [1, 1].
- The 2nd row is [2, 2, 2].
- The 3rd row is [3, 4, 4, 3].
- And so on...

We can see that each number in the interior of the triangle is the sum of the two adjacent numbers from the previous row.

To generate the 100th row, we can follow these steps:
1. Initialize the 0th row with [0].
2. Generate each subsequent row based on the rule that each number in the interior of the triangle is the sum of the two adjacent numbers from the previous row.
3. Continue this process until we generate the 100th row.
4. Compute the sum of the numbers in the 100th row.

Let's implement this step-by-step in Python.
```python
# We'll start by initializing the first row and then generate each subsequent row up to the 100th row.

# Initialize the 0th row
triangle = [[0]]

# Generate rows up to the 100th row (i.e., 100 rows total)
for i in range(1, 101):
    row = [i]
    for j in range(1, i):
        row.append(triangle[i-1][j-1] + triangle[i-1][j])
    row.append(i)
    triangle.append(row)

# Get the 100th row (index 99 because list indices start from 0)
hundredth_row = triangle[99]

# Calculate the sum of the numbers in the 100th row
sum_of_100th_row = sum(hundredth_row)
print(sum_of_100th_row)
```
