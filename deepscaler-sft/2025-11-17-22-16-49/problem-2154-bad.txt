First, let's understand the problem.

1. **Properties of the Right Triangle Inscribed in a Circle**: A right triangle inscribed in a circle has its hypotenuse as the diameter of the circle. Given that the diameter of the circle is 100 units, the hypotenuse of the right triangle is also 100 units.
2. **Relationship Between the Sides of the Right Triangle**: For a right triangle with legs \(a\) and \(b\) and hypotenuse \(c = 100\), we have the equation from the Pythagorean theorem:
   \[
   a^2 + b^2 = 100^2 = 10000
   \]
3. **Area of the Right Triangle**: The area \(A\) of the right triangle is given by:
   \[
   A = \frac{1}{2} \cdot a \cdot b
   \]
   We need to maximize this area subject to the constraint \(a^2 + b^2 = 10000\).

To solve this, we can use the method of Lagrange multipliers or parameterize \(a\) and \(b\) using a trigonometric substitution. However, another common approach is to use Python to numerically solve this optimization problem.

Let's set up the problem in Python and solve it by iterating over possible values of \(a\) and \(b\) that satisfy the equation \(a^2 + b^2 = 10000\) and then computing the corresponding areas to find the maximum.
```python
import numpy as np

# Initialize variables to keep track of the maximum area and the corresponding sides
max_area = 0
best_a = 0
best_b = 0

# We need to check through possible values of a and b such that a^2 + b^2 = 10000
for a in range(1, 10000):
    b_squared = 10000 - a**2
    if b_squared > 0:
        b = int(np.sqrt(b_squared))
        if b * b == b_squared:
            area = 0.5 * a * b
            if area > max_area:
                max_area = area
                best_a, best_b = a, b

print(((max_area, best_a, best_b)))
```
Code execution result: (2400.0, 60, 80)

So, the maximum area of the right triangle that can be inscribed in the circle with a diameter of 100 units is \(2400.0\) square units, and this occurs when the legs of the triangle have lengths 60 and 80.
