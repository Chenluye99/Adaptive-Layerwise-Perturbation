To solve the problem, we need to find the largest subset of the integers from 1 to 100 such that no member of the subset is 3 times another member. We can implement this step-by-step using Python.

1. **Initialize the List of Numbers:**
   Create a list of integers from 1 to 100.
   
2. **Build the Subset:**
   We need to construct a subset such that for any two numbers \(a\) and \(b\) in the subset, it is not true that \(a = 3 \cdot b\). We can use a loop to check each number and add it to our subset if it does not violate this condition with any existing number in the subset.

Let's implement this in Python.
```python
numbers = list(range(1, 101))
subset = []

for num in numbers:
    can_add = True
    for x in subset:
        if num == 3 * x or x == 3 * num:
            can_add = False
            break
    if can_add:
        subset.append(num)

print((len(subset), subset[:10]))  # return the length of the subset and the first 10 elements for verification
```
