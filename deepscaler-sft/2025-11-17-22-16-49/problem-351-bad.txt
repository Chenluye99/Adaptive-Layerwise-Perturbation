First, let's observe the pattern in the sequence:

1. The sequence starts with ● (a solid circle).
2. The next circle is ○ (a hollow circle).
3. The next three circles are ●, ●, ● (three solid circles).

So, the complete pattern is: ●, ○, ●, ●, ●, ○, ●, ●, ●, ... and it repeats every 9 circles.

The full pattern of 9 circles is: ●, ○, ●, ●, ●, ○, ●, ●, ●.

To solve the problem, we need to determine how many times this pattern repeats in the first 2001 circles, and then count the number of hollow circles within these repetitions.

1. First, we need to find out how many complete patterns of 9 circles fit into 2001 circles.
2. Next, for each complete pattern, we can count how many of the circles are hollow.
3. Then, if there are any remaining circles after the complete patterns, we need to consider those as well.

Let's write the Python code to solve this problem step by step.
```python
# Define the pattern of 9 circles
pattern = ['●', '○', '●', '●', '●', '○', '●', '●', '●']

# Find how many complete patterns of 9 circles fit into 2001 circles
num_complete_patterns = 2001 // 9

# Find the number of circles remaining after these complete patterns
remaining_circles = 2001 % 9

# Count the number of hollow circles (○) in one complete pattern of 9 circles
hollow_in_pattern = [circle == '○' for circle in pattern].count(True)

# Total number of hollow circles from complete patterns
hollow_count_from_complete_patterns = num_complete_patterns * hollow_in_pattern

# Count the number of hollow circles in the remaining part of the sequence
hollow_count_in_remaining = [pattern[i] for i in range(remaining_circles) if pattern[i] == '○'].count('○')

# Get the final count of hollow circles in the first 2001 circles
total_hollow_circle_count = hollow_count_from_complete_patterns + hollow_count_in_remaining
print(total_hollow_circle_count)
```
