Let's denote the total capacity of the water tank by \( C \) gallons.

First, we express the amount of water in the tank at different states:

1. When the tank is 30% full, it contains \( 0.3C \) gallons.
2. When the tank is 20% empty, it means the tank is 80% full, so it contains \( 0.8C \) gallons.

According to the problem, when the tank is 30% full, it contains 27 gallons less than when it is 20% empty. We can set up the following equation based on this information:

\[ 0.3C = 0.8C - 27 \]

To solve for \( C \):

1. Rearrange the equation to isolate \( C \):
   \[
   0.8C - 0.3C = 27 \implies 0.5C = 27
   \]
2. Solve for \( C \):
   \[
   C = \frac{27}{0.5} = 54
   \]

So, the total capacity of the tank is 54 gallons. Let's verify this by coding it to ensure accuracy.
```python
from sympy import symbols, Eq, solve

# Define the variable
C = symbols('C')

# Set up the equation based on the problem statement
eq = Eq(0.3 * C, 0.8 * C - 27)

# Solve the equation
capacity = solve(eq, C)[0]
print(capacity)
```
Code execution result: 54.0000000000000

Thus, the total capacity of the water tank when it is full is \(\boxed{54}\) gallons. This solution has been verified by solving the equation both manually and through coding, ensuring its accuracy.
