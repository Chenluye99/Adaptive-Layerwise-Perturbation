First, we need to expand the left-hand side of the equation \((x + 2)(3x^2 - x + 5)\) and then compare it to the right-hand side \(Ax^3 + Bx^2 + Cx + D\). 

1. **Expand \((x + 2)(3x^2 - x + 5)\):**
   - We will distribute each term in \((x + 2)\) to each term in \((3x^2 - x + 5)\).

2. **Identify Coefficients:**
   - After expanding, we will collect like terms to get the polynomial in standard form, i.e., \(Ax^3 + Bx^2 + Cx + D\).
   - Then we will identify the coefficients \(A, B, C, D\).

3. **Sum the Coefficients:**
   - Finally, we will find the sum \(A + B + C + D\).

Let's start by expanding \((x + 2)(3x^2 - x + 5)\) using Python to ensure accuracy.
```python
import sympy as sp

# Define the variables
x = sp.symbols('x')

# Define the expression (x + 2)(3x^2 - x + 5)
expression = (x + 2) * (3 * x**2 - x + 5)

# Expand the expression
expanded_expression = sp.expand(expression)

print(expanded_expression)
```
Code execution result: 3*x**3 + 5*x**2 + 3*x + 10

So, after expanding, we get:

\[ 3x^3 + 5x^2 + 3x + 10 \]

From this, we can identify the coefficients as follows:
\[ A = 3, \, B = 5, \, C = 3, \, D = 10 \]

Now, we need to find the value of \( A + B + C + D \):

\[ A + B + C + D = 3 + 5 + 3 + 10 \]

Let's calculate this sum.
```python
# Assign the coefficients
A, B, C, D = 3, 5, 3, 10

# Calculate the sum
result = A + B + C + D
print(result)
```
Code execution result: 21

Thus, the value of \( A + B + C + D \) is \(\boxed{21}\). This is our final answer.
