To solve this problem, we will follow these steps:

1. Identify all two-digit prime numbers less than 50.
2. For each prime number, check if the number formed by reversing its digits is also a prime number.
3. If the condition in step 2 is satisfied, then the prime number is a palindromic prime.
4. Collect all such palindromic primes.
5. Compute the sum of these palindromic primes.

Let's implement this step-by-step process in Python to ensure the result is accurate.
```python
import sympy

# Find all two-digit prime numbers less than 50
two_digit_primes_less_than_50 = [num for num in range(10, 50) if sympy.isprime(num)]

palindromic_primes = []

# Check for each prime if the number formed by reversing its digits is also prime
for prime in two_digit_primes_less_than_50:
    reversed_num = int(str(prime)[::-1])
    if sympy.isprime(reversed_num):
        palindromic_primes.append(prime)

# Calculate the sum of all palindromic primes found
sum_of_palindromic_primes = sum(palindromic_primes)
print((sum_of_palindromic_primes, palindromic_primes))
```

So, the palindromic primes less than 50 are [11, 13, 17, 31, 37], and their sum is 109. 

Thus, the final answer is:
\(\boxed{109}\)
