To solve this problem, we need to find the smallest possible value of \( X \) such that \( X = \frac{T}{12} \) and \( T \) is a positive integer composed only of the digits 0 and 1. This means \( T \) is a number where every digit is either 0 or 1, such as 1, 10, 11, 100, 101, 110, 111, etc.

1. **Generating Numbers Composed of Digits 0 and 1:**
    - We can generate numbers that consist only of the digits 0 and 1.
    - We will check each of these numbers to see if it is divisible by 12.

2. **Checking Divisibility by 12:**
    - A number is divisible by 12 if and only if it is divisible by both 3 and 4.
    - For a number to be divisible by 3, the sum of its digits must be divisible by 3.
    - For a number to be divisible by 4, its last two digits must form a number that is divisible by 4.

3. **Finding the Smallest Possible Value of \( X \):**
    - We will iterate through numbers composed of 0s and 1s, check the divisibility condition, and if found divisible by 12, compute \( X = \frac{T}{12} \).
    - We will keep track of the smallest value of \( X \) that we find.

Let's implement this step-by-step using Python to ensure accuracy.
```python
import itertools

def find_smallest_X():
    n = 1
    while True:
        # Generate numbers composed only of 0s and 1s, up to n digits
        for combo in itertools.product('01', repeat=n):
            T = int(''.join(combo))
            if T > 0:  # We only consider positive integers
                if T % 12 == 0:
                    X = T // 12
                    return X, T
        n += 1

smallest_X, corresponding_T = find_smallest_X()
print((smallest_X, corresponding_T))
```
