First, let's identify the numbers that meet both conditions:

1. They must have a 2 in the units place.
2. They must be divisible by 4.

A number that has a 2 in the units place means its last digit is 2. Now, we need to check which of these numbers are also divisible by 4.

We can iterate through the numbers from 1 to 200, check if the number ends with 2, and then check if it is divisible by 4. If both conditions are satisfied, we will count that number.

Let's write some Python code to solve this step-by-step.
```python
count = 0

for num in range(1, 201):
    if str(num).endswith('2') and num % 4 == 0:
        count += 1

print(count)
```
Code execution result: 10

Thus, the number of numbers from 1 through 200 that have a 2 in the units place and are divisible by 4 is \(\boxed{10}\). This is our final answer.
