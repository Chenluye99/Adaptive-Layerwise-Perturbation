To solve the problem, we need to convert the rectangular coordinates $(x, y, z) = (0, -3 \sqrt{3}, 3)$ to spherical coordinates $(\rho, \theta, \phi)$. The formulas for the conversion are as follows:

1. **Radial distance** $\rho$:
   \[
   \rho = \sqrt{x^2 + y^2 + z^2}
   \]

2. **Azimuthal angle** $\theta$:
   \[
   \theta = \begin{cases} 
   \arctan\left(\frac{y}{x}\right) & \text{if } x > 0, \\
   \arctan\left(\frac{y}{x}\right) + \pi & \text{if } x < 0 \text{ and } y \ge 0, \\
   \arctan\left(\frac{y}{x}\right) - \pi & \text{if } x < 0 \text{ and } y < 0, \\
   \frac{\pi}{2} & \text{if } x = 0 \text{ and } y > 0, \\
   -\frac{\pi}{2} & \text{if } x = 0 \text{ and } y < 0, \\
   \text{undefined} & \text{if } x = 0 \text{ and } y = 0.
   \end{cases}
   \]
   In our case, $x = 0$ and $y = -3 \sqrt{3}$, so $\theta = \frac{3\pi}{2}$ (since $\arctan\left(\frac{-3 \sqrt{3}}{0}\right) = -\frac{\pi}{2}$, but we need to correct it since $y$ is negative and $x$ is $0$, so it is effectively $\frac{3\pi}{2}$ in the standard convention).

3. **Polar angle** $\phi$:
   \[
   \phi = \arccos\left(\frac{z}{\rho}\right)
   \]

Let's compute these step-by-step using Python to ensure accuracy.
```python
import sympy as sp

# Rectangular coordinates
x, y, z = 0, -3 * sp.sqrt(3), 3

# Calculate rho
rho = sp.sqrt(x**2 + y**2 + z**2)

# Calculate theta
# We need to take care of the special cases for theta when x is 0.
if x == 0:
    if y > 0:
        theta = sp.pi / 2
    elif y < 0:
        theta = 3 * sp.pi / 2
else:
    theta = sp.atan2(y, x)

# Calculate phi
phi = sp.acos(z / rho)

print(((rho, theta, phi)))
```
