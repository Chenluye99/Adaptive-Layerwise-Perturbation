To solve this problem, we need to follow these steps:

1. **Check if a number is prime**.
2. **Check if a number is a perfect cube**.
3. **Find the prime factors of a number** and check if they are all greater than 60 and if the number of prime factors is even.
4. **Find the smallest positive integer** that satisfies the above conditions: it should neither be prime nor a perfect cube, and it should have an even number of prime factors, all of which are greater than 60.

We'll implement this step-by-step using Python to ensure accuracy. Let's start by defining the functions needed to check primality, whether a number is a perfect cube, and to find and check the prime factors. Then, we will search for the smallest number that meets the criteria.
```python
import sympy

def is_prime(n):
    """Check if a number is prime."""
    return sympy.isprime(n)

def is_cube(n):
    """Check if a number is a perfect cube."""
    cube_root = round(n ** (1/3))
    return cube_root ** 3 == n

def get_prime_factors_greater_than_60(n):
    """Get the prime factors of a number and check if all them are greater than 60."""
    factors = []
    for i in range(2, n + 1):
        while n % i == 0:
            factors.append(i)
            n = n // i
    return factors

def has_even_number_of_prime_factors(factors):
    """Check if the number of prime factors is even."""
    return len(factors) % 2 == 0

def find_special_number():
    n = 2  # Start checking from the smallest positive integer
    while True:
        if not is_prime(n) and not is_cube(n):
            factors = get_prime_factors_greater_than_60(n)
            if all(factor > 60 for factor in factors) and has_even_number_of_prime_factors(factors):
                return n
        n += 1

special_number = find_special_number()
print(special_number)
```

Thus, the smallest positive integer that is neither prime nor a cube and that has an even number of prime factors, all greater than 60, is \(\boxed{3721}\). This is the final answer.
