The median of a set of five numbers is the third number in the ordered list. So, in this case, the median is \(0.1\).

Let's implement this step in Python to ensure correctness and print the final answer.
```python
# Assign the values of a and b
a = -100
b = 0.1

inv_b = 1 / b

# Create the set {0, 1, a, b, 1/b}
data_set = [0, 1, a, b, inv_b]

sorted_data_set = sorted(data_set)
```
