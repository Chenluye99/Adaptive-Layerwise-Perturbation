To solve the problem, we need to count the occurrences of the digits '4' and '8' in all the page numbers of a 488-page book, from page 1 to page 488, and then find the difference between the counts of '4' and '8'.

We'll write a Python script to iterate through each page number, convert it to a string, and then count how many times '4' and '8' appear in all of those page numbers combined. Finally, we'll find the difference between the counts of '4' and '8'.

Let's implement this step-by-step in code.
```python
# Initialize counters for the digits '4' and '8'
count_4 = 0
count_8 = 0

# Iterate through each page number from 1 to 488 and count occurrences of '4' and '8'
for page in range(1, 489):
    page_str = str(page)
    count_4 += page_str.count('4')
    count_8 += page_str.count('8')

# Calculate the difference between the counts of '4' and '8'
difference = count_4 - count_8
print(difference)
```
Code execution result: 90

Thus, the number of times '4' is printed is 90 more than the number of times '8' is printed. The final answer is:

\(\boxed{90}\)
