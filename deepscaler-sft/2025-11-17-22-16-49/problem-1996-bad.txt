To solve the problem, we need to follow these steps:

1. **Formulate the Equation:**
    We start with the given equation:
    \[
    x^2 - 4x - 14 = 3x + 16
    \]
    Rearrange it to standard quadratic form:
    \[
    x^2 - 4x - 14 - 3x - 16 = 0 \implies x^2 - 7x - 30 = 0
    \]

2. **Use Vieta's Formulas:**
    For a quadratic equation of the form \(ax^2 + bx + c = 0\), the sum of the solutions is given by \(-\frac{b}{a}\). In our equation, \(a = 1\), \(b = -7\), and \(c = -30\). So, the sum of the solutions is:
    \[
    -\frac{-7}{1} = 7
    \]

We can also confirm this by solving the quadratic equation \(x^2 - 7x - 30 = 0\) using Python to ensure the accuracy of our result.

Let's implement this in Python to solve the quadratic equation and get the solutions, then compute their sum directly.
```python
import sympy as sp

# Define the variable and the equation
x = sp.symbols('x')
equation = x**2 - 7*x - 30

# Solve the equation
solutions = sp.solve(equation, x)

# Get the sum of the solutions
sum_of_solutions = sum(solutions)
print(sum_of_solutions)
```
Code execution result: 7

Thus, the sum of the solutions of the quadratic equation \(x^2 - 7x - 30 = 0\) is \(\boxed{7}\). This confirms our earlier reasoning using Vieta's formulas.
