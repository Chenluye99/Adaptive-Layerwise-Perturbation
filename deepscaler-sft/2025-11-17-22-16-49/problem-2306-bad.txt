To solve the problem, we need to generate numbers and check if the sum of their digits equals 11. We then need to list these numbers in increasing order until we get to the 11th number in that list.

1. **Generate Numbers and Check Digit Sum:**
    - We'll start checking from 1 and go upwards.
    - For each number, we will calculate the sum of its digits.
    - If the sum of the digits of a number is 11, we will add that number to our list.

2. **Get the 11th Number:**
    - We will continue this process until we have at least 11 numbers in our list, and then return the 11th number from that list.

Let's implement this step-by-step in Python.
```python
def sum_of_digits(n):
    """Returns the sum of the digits of n."""
    return sum(int(digit) for digit in str(n))

# Initialize a list to store numbers whose digits sum up to 11
numbers_with_digit_sum_11 = []

# We will iterate through the positive integers and check the condition
num = 1
while len(numbers_with_digit_sum_11) < 11:
    if sum_of_digits(num) == 11:
        numbers_with_digit_sum_11.append(num)
    num += 1

# Get the 11th number (index 10) in the list
eleventh_number = numbers_with_digit_sum_11[10]
print(eleventh_number)
```
Code execution result: 137

Thus, the eleventh number in the list of all positive integers whose digits add up to 11, listed in increasing order, is \(\boxed{137}\). This is our final answer.
