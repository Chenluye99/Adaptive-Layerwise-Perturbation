To solve this problem, let's start by understanding what it means for a number to have an odd number of positive factors.

1. **Understanding the Problem:**
    - A number generally has an even number of factors because factors come in pairs, e.g., for 12, the factors are (1, 12), (2, 6), and (3, 4).
    - However, perfect squares are an exception because one of their factors is repeated (the square root of the number). For example, for 36, the factors are (1, 36), (2, 18), (3, 12), (4, 9), and (6, 6). Here, 6 is repeated, so the total number of distinct factors is odd.
    - Therefore, only perfect squares can have an odd number of positive factors.

2. **Identify Two-Digit Perfect Squares:**
    - We need to find the range of perfect squares that are two-digit numbers. The smallest two-digit number is 10, and the largest two-digit number is 99.
    - Find the smallest integer whose square is a two-digit number: \(\lceil \sqrt{10} \rceil = 4\) (because \(4^2 = 16\)).
    - Find the largest integer whose square is a two-digit number: \(\lfloor \sqrt{99} \rfloor = 9\) (because \(9^2 = 81\) and \(10^2 = 100\), which is a three-digit number).

3. **Enumerate the Relevant Range:**
    - So, we need to consider the squares of the integers from 4 to 9, because these are the integers whose squares are two-digit numbers.
    - We'll then list these squares to ensure they are indeed two-digit numbers and count them.

Let's implement this step-by-step reasoning in Python to make sure we get an accurate result.
```python
import math

# Initialize a counter for two-digit perfect squares
count = 0

# Loop through the numbers and check if their square is a two-digit number
for i in range(4, 10):  # Because 4^2 = 16 and 9^2 = 81, the range is 4 to 9
    square = i * i
    if 10 <= square <= 99:
        count += 1

print(count)
```
