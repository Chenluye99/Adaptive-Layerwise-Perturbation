To solve this problem, we will use the method of Lagrange multipliers to find the maximum value of the expression \(2ab \sqrt{2} + 2bc\) subject to the constraint \(a^2 + b^2 + c^2 = 1\).

We define:
\[ f(a, b, c) = 2ab \sqrt{2} + 2bc \]
and the constraint:
\[ g(a, b, c) = a^2 + b^2 + c^2 - 1 = 0. \]

The method of Lagrange multipliers involves setting up the following system of equations:
\[
\nabla f = \lambda \nabla g,
\]
where \(\nabla f\) is the gradient of \(f\) and \(\nabla g\) is the gradient of \(g\). The gradients are given by:
\[
\nabla f = \left( \frac{\partial f}{\partial a}, \frac{\partial f}{\partial b}, \frac{\partial f}{\partial c} \right) = \left( 2b \sqrt{2}, 2a \sqrt{2} + 2c, 2b \right)
\]
and
\[
\nabla g = \left( \frac{\partial g}{\partial a}, \frac{\partial g}{\partial b}, \frac{\partial g}{\partial c} \right) = \left( 2a, 2b, 2c \right).
\]

So, we set up the following equations:
\[
2b \sqrt{2} = \lambda \cdot 2a,
\]
\[
2a \sqrt{2} + 2c = \lambda \cdot 2b,
\]
\[
2b = \lambda \cdot 2c.
\]

From the third equation, we get:
\[
b = \lambda c.
\]

Substitute \(\lambda = \frac{b}{c}\) into the first equation:
\[
2b \sqrt{2} = \lambda \cdot 2a \implies 2b \sqrt{2} = \frac{b}{c} \cdot 2a \implies b \sqrt{2} = \frac{b}{c} \cdot a \implies \sqrt{2} = \frac{a}{c} \implies a = c \sqrt{2}.
\]

Substitute \(\lambda = \frac{b}{c}\) into the second equation:
\[
2a \sqrt{2} + 2c = \lambda \cdot 2b \implies 2a \sqrt{2} + 2c = \frac{b}{c} \cdot 2b \implies 2a \sqrt{2} + 2c = \frac{2b^2}{c}.
\]

We substitute \(a = c \sqrt{2}\) into the constraint equation \(a^2 + b^2 + c^2 = 1\):
\[
(c \sqrt{2})^2 + b^2 + c^2 = 1 \implies 2c^2 + b^2 + c^2 = 1 \implies 3c^2 + b^2 = 1.

```python
import sympy as sp

# Define the variables
a, b, c, lambd = sp.symbols('a b c lambd', real=True, positive=True)

# Define the function to maximize and the constraint
f = 2 * a * b * sp.sqrt(2) + 2 * b * c
g = a**2 + b**2 + c**2 - 1

# Set up the system of equations from the method of Lagrange multipliers
eq1 = sp.diff(f, a) - lambd * sp.diff(g, a)
eq2 = sp.diff(f, b) - lambd * sp.diff(g, b)
eq3 = sp.diff(f, c) - lambd * sp.diff(g, c)

# Solve the system of equations
solution = sp.solve([eq1, eq2, eq3, g], (a, b, c, lambd), dict=True)

# Find the maximum value of the function among the solutions
max_value = max(f.subs(sol) for sol in solution)
print(max_value)
```
