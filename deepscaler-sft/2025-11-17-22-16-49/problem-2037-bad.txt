First, let's start by understanding when the matrix \(\mathbf{A} - x \mathbf{I}\) is not invertible. A matrix is not invertible if and only if its determinant is zero. So, we want to find the values of \(x\) such that the determinant of \(\mathbf{A} - x \mathbf{I}\) is zero.

Given:
\[
\mathbf{A} = \begin{pmatrix} 1 & 5 \\ 1 & 3 \end{pmatrix}
\]

The identity matrix \(\mathbf{I}\) is:
\[
\mathbf{I} = \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix}
\]

So, \(\mathbf{A} - x \mathbf{I}\) is:
\[
\mathbf{A} - x \mathbf{I} = \begin{pmatrix} 1 & 5 \\ 1 & 3 \end{pmatrix} - x \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix} = \begin{pmatrix} 1 - x & 5 \\ 1 & 3 - x \end{pmatrix}
\]

The determinant of \(\mathbf{A} - x \mathbf{I}\) is:
\[
\text{det}(\mathbf{A} - x \mathbf{I}) = \begin{vmatrix} 1 - x & 5 \\ 1 & 3 - x \end{vmatrix} = (1 - x)(3 - x) - (5 \cdot 1) = (1 - x)(3 - x) - 5
\]

Let's compute \((1 - x)(3 - x) - 5\):
\[
(1 - x)(3 - x) = 3 - x - 3x + x^2 = x^2 - 4x + 3
\]
\[
(1 - x)(3 - x) - 5 = x^2 - 4x + 3 - 5 = x^2 - 4x - 2
\]

We need to find the values of \(x\) that make this determinant equal to zero:
\[
x^2 - 4x - 2 = 0
\]

This is a quadratic equation. We can solve it using the quadratic formula \(x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}\), where \(a = 1\), \(b = -4\), and \(c = -2\):
\[
x = \frac{-(-4) \pm \sqrt{(-4)^2 - 4 \cdot 1 \cdot (-2)}}{2 \cdot 1} = \frac{4 \pm \sqrt{16 + 8}}{2} = \frac{4 \pm \sqrt{24}}{2} = \frac{4 \pm 2 \sqrt{6}}{2} = 2 \pm \sqrt{6}
\]

So the solutions are:
\[
x = 2 + \sqrt{6}, \quad x = 2 - \sqrt{6}
\]

Let's confirm this by implementing it in Python.
```python
import sympy as sp

# Define the matrix A
A = sp.Matrix([[1, 5], [1, 3]])

# Define the variable x
x = sp.symbols('x')

# Compute A - xI
A_minus_xI = A - x * sp.eye(2)

# Find the determinant of A - xI
det_A_minus_xI = A_minus_xI.det()

# Solve for x when the determinant is 0
solutions = sp.solve(det_A_minus_xI, x)
print(solutions)
```
Code execution result: [2 - sqrt(6), 2 + sqrt(6)]

This confirms our analytical solution. Thus, the real numbers \(x\) such that the matrix \(\mathbf{A} - x \mathbf{I}\) is not invertible are:

\(\boxed{2 - \sqrt{6}, 2 + \sqrt{6}}\)
