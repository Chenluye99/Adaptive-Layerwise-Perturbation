To solve this problem, we need to determine how many ways we can distribute 5 indistinguishable balls into 3 distinguishable boxes. This is a classic combinatorial problem that can be solved using the "stars and bars" theorem.

The "stars and bars" theorem states that the number of ways to distribute \( n \) indistinguishable items (in this case, balls) into \( k \) distinguishable bins (in this case, boxes) is given by:

\[
\binom{n + k - 1}{k - 1}
\]

Here, \( n = 5 \) (balls) and \( k = 3 \) (boxes). So, we need to compute:

\[
\binom{5 + 3 - 1}{3 - 1} = \binom{7}{2}
\]

The combination \(\binom{7}{2}\) is calculated as follows:

\[
\binom{7}{2} = \frac{7!}{2!(7-2)!} = \frac{7!}{2! \cdot 5!} = \frac{7 \cdot 6}{2 \cdot 1} = 21
\]

Let's confirm this by implementing it in Python to ensure accuracy.
