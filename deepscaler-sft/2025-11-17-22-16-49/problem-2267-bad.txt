To solve this problem, we need to generate all possible ways to place 6 distinct beads into a 2 x 3 grid, and then account for the fact that rotations and reflections of the grid should not produce distinct arrangements.

### Step 1: Generate All Permutations of Bead Placement

First, let's label the positions in the 2 x 3 grid as follows:
\[
\begin{array}{|c|c|c|}
\hline
1 & 2 & 3 \\
\hline
4 & 5 & 6 \\
\hline
\end{array}
\]
There are 6! (720) ways to arrange 6 distinct beads in these 6 positions.

### Step 2: Generate All Possible Grid Configurations

For each of these 720 permutations, we need to consider the symmetries of the 2 x 3 grid. We should treat two grids as the same if one can be obtained from the other by rotating or reflecting.

### Step 3: Implement Symmetry Operations

The symmetry operations for a 2 x 3 grid that we need to consider include:

1. **Rotations**: The grid can only be rotated 180 degrees because rotating it 90 degrees or 270 degrees would not preserve the 2 x 3 shape.
2. **Reflections**: The grid can be reflected over both vertical and horizontal axes, and also over the two axes that bisect the grid diagonally (though these won't preserve the 2 x 3 structure and are not rotations or reflections that make sense for our purposes here).

### Step 4: Use Set to Track Unique Arrangements

We can use a set to keep track of unique arrangements by comparing each arrangement with all its rotated and reflected versions. If an arrangement is the same as a previously encountered arrangement under any of these operations, then it is not added to the set again.

Let's implement this step-by-step process in Python.
```python
import itertools

# Generate all permutations of 6 distinct beads placed in 6 positions of a 2x3 grid
bead_positions = list(range(6))
all_permutations = list(itertools.permutations(bead_positions))

# Function to get all symmetrical versions of a grid configuration (rotations and reflections)
def get_symmetrical_versions(grid_config):
    grid = list(grid_config)
    
    # Convert the grid configuration to a list representation of the 2x3 grid
    grid_2x3 = [grid[0], grid[1], grid[2], grid[3], grid[4], grid[5]]
    
    # Rotations
    rotated_90 = [grid_2x3[3], grid_2x3[0], grid_2x3[4], grid_2x3[1], grid_2x3[5], grid_2x3[2]]
    rotated_180 = [grid_2x3[5], grid_2x3[4], grid_2x3[3], grid_2x3[2], grid_2x3[1], grid_2x3[0]]
    rotated_270 = [grid_2x3[1], grid_2x3[5], grid_2x3[2], grid_2x3[4], grid_2x3[0], grid_2x3[3]]
    
    # Reflections
    reflected_vertically = [grid_2x3[2], grid_2x3[1], grid_2x3[0], grid_2x3[5], grid_2x3[4], grid_2x3[3]]
    reflected_horizontally = [grid_2x3[3], grid_2x3[4], grid_2x3[5], grid_2x3[0], grid_2x3[1], grid_2x3[2]]
    
    # Collect all symmetrical versions and the original grid configuration
    symmetrical_versions = [grid_2x3]
    if rotated_90 not in symmetrical_versions:
        symmetrical_versions.append(rotated_90)
    if rotated_180 not in symmetrical_versions:
        symmetrical_versions.append(rotated_180)
    if rotated_270 not in symmetrical_versions:
        symmetrical_versions.append(rotated_270)
    if reflected_vertically not in symmetrical_versions:
        symmetrical_versions.append(reflected_vertically)
    if reflected_horizontally not in symmetrical_versions:
        symmetrical_versions.append(reflected_horizontally)
    
    return symmetrical_versions

# Use a set to store unique arrangements after considering symmetries
unique_arrangements = set()

for perm in all_permutations:
    grid_config = list(perm)
    symmetrical_set = get_symmetrical_versions(grid_config)
    
    # Normalize to the lexicographically smallest representation of all symmetrical versions
    min_version = min(symmetrical_set)
    unique_arrangements.add(tuple(min_version))

# The number of unique arrangements is the size of the set
num_unique_arrangements = len(unique_arrangements)
print(num_unique_arrangements)
```
