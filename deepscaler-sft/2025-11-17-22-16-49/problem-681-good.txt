First, let's start by understanding the given information and what we need to solve.

1. A stack of eight quarters is exactly half an inch high.
2. We need to find out how many quarters are needed to make a stack that is one foot high.

Since 1 foot is equal to 12 inches, we need to determine how many quarters are needed to reach a height of 12 inches, given that 8 quarters result in a height of 0.5 inches.

We can set up a proportion or use simple arithmetic to solve this. If 8 quarters make a stack 0.5 inches high, then we can find out how many quarters are needed to make a stack 12 inches high by setting up the following relationship:

\[
\text{Number of quarters needed for 12 inches} = \frac{12 \text{ inches}}{0.5 \text{ inches}} \times 8 \text{ quarters}
\]

Let's calculate this step-by-step using Python to ensure accuracy.
```python
# Given data
quarters_for_0_5_inches = 8
height_for_8_quarters = 0.5  # in inches
height_desired = 12  # in inches (1 foot)

# Calculate the number of quarters needed for 12 inches
quarters_needed_for_12_inches = (height_desired / height_for_8_quarters) * quarters_for_0_5_inches
print(quarters_needed_for_12_inches)
```
Code execution result: 192.0

So, the number of quarters needed to make a stack one foot (12 inches) high is \(\boxed{192}\). This is our final answer.
