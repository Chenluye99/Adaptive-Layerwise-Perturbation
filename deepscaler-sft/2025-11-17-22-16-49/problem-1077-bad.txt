We need to keep track of the cumulative totals and check when these cumulative totals are equal. Let's write some Python code to get this result accurately.
```python
# Initialize the home run counts for McGwire and Sosa
mcgwire_home_runs = [1, 10, 16, 10, 8, 10, 15]
sosa_home_runs = [0, 6, 7, 20, 9, 13, 11]

# Calculate cumulative totals for each month
mcgwire_cumulative = []
sosa_cumulative = []

mcgwire_total, sosa_total = 0, 0

for i in range(len(mcgwire_home_runs)):
    mcgwire_total += mcgwire_home_runs[i]
    sosa_total += sosa_home_runs[i]
    
    mcgwire_cumulative.append(mcgwire_total)
    sosa_cumulative.append(sosa_total)
    
    if mcgwire_total == sosa_total:
        tied_month = i + 1  # Months are indexed from 1 to 7 (March to September)

print(tied_month)
```
