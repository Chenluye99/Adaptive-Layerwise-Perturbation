First, let's start by expressing both sides of the equation in the same base.

Given the equation:

\[ 3^{2x} = \sqrt{27} \]

1. **Express \(\sqrt{27}\) in terms of base 3:**

   We know that \( 27 = 3^3 \). Therefore, 

   \[ \sqrt{27} = \sqrt{3^3} = (3^3)^{1/2} = 3^{3/2}. \]

2. **Equate the Exponents:**

   Now our equation becomes:

   \[ 3^{2x} = 3^{3/2}. \]

   Since the bases are the same, we can set the exponents equal to each other:

   \[ 2x = \frac{3}{2}. \]

3. **Solve for \( x \):**

   To isolate \( x \), divide both sides by 2:

   \[ x = \frac{3}{2} \cdot \frac{1}{2} = \frac{3}{4}. \]

Let's confirm this result by coding it in Python to ensure accuracy.
```python
import sympy as sp

# Define the variable
x = sp.symbols('x')

# Define the equation
equation = 3**(2*x) - sp.sqrt(27)

# Solve the equation
solution = sp.solve(equation, x)
print(solution)
```
Code execution result: [3/4, (log(27)/4 + I*pi)/log(3)]

From the output, the solution \( \frac{3}{4} \) is clearly visible. The other solution involving \( \log(27) \) and \( \pi \) is a complex solution, but we are only interested in the real solution.

So, the solution to the equation \( 3^{2x} = \sqrt{27} \) is:

\[ \boxed{\frac{3}{4}} \]
