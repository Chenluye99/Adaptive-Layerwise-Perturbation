1. **Understand the problem:**

    - We have a point \((m, n)\) in the first quadrant.
    - This point is symmetric to another point with respect to the line \(x + y - 2 = 0\).
    - The symmetric point lies on the line \(2x + y + 3 = 0\).
    - We need to find the minimum value of \(\frac{1}{m} + \frac{8}{n}\).

2. **Setup and Step-by-Step Solution:**

    - **Step 1: Symmetry with respect to the line \(x + y - 2 = 0\):**
      - The line \(x + y - 2 = 0\) can be written as \(y = -x + 2\).
      - The midpoint of \((m, n)\) and its symmetric point \((m', n')\) must lie on this line. So, if the symmetric point is \((m', n')\), then the midpoint \(\left(\frac{m + m'}{2}, \frac{n + n'}{2}\right)\) must satisfy the equation \(x + y - 2 = 0\).
      - This gives us: \[\frac{m + m'}{2} + \frac{n + n'}{2} - 2 = 0 \implies m + m' + n + n' = 4 \implies m' + n' = 4 - m - n.\]

    - **Step 2: Perpendicular Slope Condition:**
      - The line connecting \((m, n)\) and \((m', n')\) is perpendicular to the line \(x + y - 2 = 0\), which has a slope of \(-1\). The slope of the line joining \((m, n)\) and \((m', n')\) is \(\frac{n' - n}{m' - m}\), and it should be 1 (the negative reciprocal of \(-1\)):
        \[\frac{n' - n}{m' - m} = 1 \implies n' - n = m' - m.\]

    - **Step 3: Solve the System of Equations:**
      - We now have three equations:
        1. \(m' + n' = 4 - m - n\),
        2. \(n' - n = m' - m\),
        3. The symmetric point \((m', n')\) lies on the line \(2x + y + 3 = 0\), so \(2m' + n' + 3 = 0\).

      - Let's solve these equations systematically. First, express \(n'\) from the second equation:
        \[n' = m' + m - n.\]

      - Substitute this into the first equation:
        \[m' + (m' + m - n) = 4 - m - n \implies 2m' + m - n = 4 - m - n \implies 2m' = 4 - 2m \implies m' = 2 - m.\]

      - Substitute \(m' = 2 - m\) into the expression for \(n'\):
        \[n' = (2 - m) + m - n = 2 - n.\]

      - Now, substitute \(m' = 2 - m\) and \(n' = 2 - n\) into the third equation:
        \[2(2 - m) + (2 - n) + 3 = 0 \implies 4 - 2m + 2 - n + 3 = 0 \implies 9 - 2m - n = 0 \implies 2m + n = 9.\]

    - **Step 4: Minimize \(\frac{1}{m} + \frac{8}{n}\):**
      - We need to minimize \(\frac{1}{m} + \frac{8}{n}\) subject to the constraint \(2m + n = 9\).

3. **Implementation in Python:**

Let's implement this step-by-step in Python using `sympy`.

```python
import sympy as sp

# Define variables
m, n = sp.symbols('m n', positive=True)

# Define the constraint equation
constraint = 2 * m + n - 9

# Define the expression to minimize
expression = 1 / m + 8 / n

# Use Lagrange multipliers to solve the optimization problem
λ = sp.symbols('λ')
L = expression + λ * constraint

# Take partial derivatives
partial_m = sp.diff(L, m)
partial_n = sp.diff(L, n)
partial_λ = sp.diff(L, λ)

# Solve the system of equations
solution = sp.solve([partial_m, partial_n, partial_λ], (m, n, λ))

# Extract the solution and compute the minimum value of the expression
min_value = min(expression.subs({m: sol[0], n: sol[1]}) for sol in solution if sol[0] > 0 and sol[1] > 0)

print(min_value)
```
Code execution result: 2

Thus, the minimum value of \(\frac{1}{m} + \frac{8}{n}\) is \(\boxed{2}\). This is the final answer.
