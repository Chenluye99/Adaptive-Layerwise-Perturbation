First, let's start by implementing and computing the values of \( F(n) \) for \( n \) starting from 0 using the given recurrence relation and initial conditions.

Given:
\[ F(0) = 0, \]
\[ F(1) = \frac{3}{2}, \]
\[ F(n) = \frac{5}{2} F(n - 1) - F(n - 2) \text{ for } n \ge 2. \]

We will write Python code to generate \( F(n) \) for various values of \( n \), specifically for \( n \) of the form \( 2^k \) because we need to find \( \sum_{n=0}^\infty \frac{1}{F(2^n)} \).

Let's start by implementing the code to get the values of \( F(2^0), F(2^1), F(2^2), \ldots \) and then compute the sum of the series.
```python
import sympy as sp

# Initialize a list to store F(n) values
F = [0] * 1000  # We will generate enough terms to ensure accuracy

# Set initial conditions
F[0] = 0
F[1] = sp.Rational(3, 2)

# Generate F(n) values up to a reasonable limit to capture F(2^n) values
for n in range(2, 1000):
    F[n] = (5/2) * F[n - 1] - F[n - 2]

# Get F(2^n) for n starting from 0 and compute the sum of 1 / F(2^n) until it converges reasonably well.
sum_series = 0
f_values = []

for i in range(30):  # We choose 30 because 2^30 is already a very high number (1073741824), and higher powers of 2 aren't needed for practical purposes in this context.
    current_n = 2 ** i
    if current_n < len(F):
        f_values.append(F[current_n])
    else:
        break

for f in f_values:
    if f != 0:  # To avoid division by zero
        sum_series += 1 / f

print(sum_series)
```
