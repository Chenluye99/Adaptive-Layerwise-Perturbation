To find the solution, let's start by framing the problem mathematically. We need to determine if there exist several consecutive integers that sum up to 2014, and if so, identify the smallest such integer.

### Step-by-Step Solution:

1. **Formulate the Problem Mathematically:**
    - Consider a sequence of \( n \) consecutive integers starting from an integer \( A \). The sequence would be \( A, A+1, A+2, \ldots, A+(n-1) \).
    - The sum of these \( n \) consecutive integers is given by:
      \[
      A + (A+1) + (A+2) + \cdots + (A + (n-1)) = nA + (0 + 1 + 2 + \cdots + (n-1)) = nA + \frac{(n-1)n}{2}
      \]
    - We know that this sum is equal to 2014, so we can set up the equation:
      \[
      nA + \frac{(n-1)n}{2} = 2014
      \]
    - Rearrange the equation to solve for \( A \):
      \[
      nA = 2014 - \frac{(n-1)n}{2}
      \]
      \[
      A = \frac{2014 - \frac{(n-1)n}{2}}{n} = \frac{2 \cdot 2014 - (n-1)n}{2n} = \frac{4028 - (n-1)n}{2n}
      \]
    - For \( A \) to be an integer, \(\frac{4028 - (n-1)n}{2n}\) must be an integer. This means that \( 4028 - (n-1)n \) must be divisible by \( 2n \).

2. **Iterate to Find Valid \( n \) and Corresponding \( A \):**
    - We need to iterate through possible values of \( n \) and check if \(\frac{4028 - (n-1)n}{2n}\) is an integer for each \( n \).
    - Once we find a valid \( n \), we compute the corresponding \( A \) and keep track of the smallest such \( A \).
