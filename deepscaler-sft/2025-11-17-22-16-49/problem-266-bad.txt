To solve the problem, let's start by considering the probabilities and constraints involved.

1. **Problem Understanding:**
    - We have three balls numbered 1, 2, and 3.
    - We draw a ball, record its number, and return it to the urn. This is repeated three times.
    - We need to find the probability that the ball numbered 2 was drawn all three times, given that the sum of the recorded numbers is 6.

2. **Step-by-Step Breakdown:**
    - First, let's enumerate all possible sequences of drawing the balls and record their numbers. Each draw can be one of 1, 2, or 3, so there are \(3^3 = 27\) possible outcomes for three draws.
    - We need to identify which of these outcomes have a sum of 6.
    - From these outcomes, we will then determine how many of them involve drawing the ball numbered 2 all three times.
    - Finally, we compute the probability by dividing the number of favorable outcomes by the number of outcomes that have a sum of 6.

3. **Formulating the Solution in Python:**
    - We can use Python to generate all possible sequences of three draws, compute their sums, and then find the desired probability.

Let's implement this step-by-step in Python.
```python
import itertools

# Generate all possible outcomes for three draws
outcomes = list(itertools.product([1, 2, 3], repeat=3))

# Find outcomes where the sum of the recorded numbers is 6
sum_6_outcomes = [outcome for outcome in outcomes if sum(outcome) == 6]

# Find outcomes where the ball numbered 2 was drawn all three times
sum_6_outcomes_with_2_all_three_times = [outcome for outcome in sum_6_outcomes if outcome == (2, 2, 2)]

# Calculate the probability
num_sum_6_outcomes = len(sum_6_outcomes)
num_sum_6_with_2_all_three_times = len(sum_6_outcomes_with_2_all_three_times)

probability = num_sum_6_with_2_all_three_times / num_sum_6_outcomes
print(probability)
```
Code execution result: 0.14285714285714285

Thus, the probability that the ball numbered 2 was drawn all three times, given that the sum of the numbers recorded is 6, is \(\boxed{0.14285714285714285}\). This value can also be represented as \(\frac{1}{7}\) in fractional form.
