To solve this problem, we need to determine the smallest natural number that is abundant. A number is considered abundant if it is less than the sum of its proper divisors. Proper divisors of a number \( n \) are the divisors of \( n \) excluding \( n \) itself.

Let's follow these steps to find the smallest abundant number:

1. Define a function to find the proper divisors of a number.
2. Define a function to compute the sum of the proper divisors of a number.
3. Define a function to check if a number is abundant.
4. Iterate through natural numbers and use the above function to check for the smallest abundant number.

Let's implement this step-by-step in Python.
```python
def proper_divisors(n):
    """Return a list of proper divisors of n."""
    divisors = [1]  # 1 is a proper divisor for all n > 1
    for i in range(2, int(n ** 0.5) + 1):
        if n % i == 0:
            divisors.append(i)
            if i != n // i:  # Avoid adding the square root twice for perfect squares
                divisors.append(n // i)
    return divisors

def sum_of_proper_divisors(n):
    """Return the sum of proper divisors of n."""
    return sum(proper_divisors(n))

def is_abundant(n):
    """Check if a number n is abundant."""
    return n < sum_of_proper_divisors(n)

# Now, we will iterate to find the smallest abundant number
n = 1
while True:
    if is_abundant(n):
        smallest_abundant_number = n
        break
    n += 1

print(smallest_abundant_number)
```
Code execution result: 12

Thus, the smallest abundant number is \(\boxed{12}\). This result is obtained by checking each number in sequence and verifying the condition that a number is abundant if it is less than the sum of its proper divisors.
