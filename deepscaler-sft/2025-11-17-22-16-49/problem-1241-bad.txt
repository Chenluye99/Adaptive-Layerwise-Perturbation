To solve this problem, we need to compute the average value of \( S \), where \( S \) is the number of adjacent boy-girl pairs in a row of 7 boys and 13 girls.

1. **Problem Understanding:**
    - We have 20 positions, 7 of which are occupied by boys and 13 by girls.
    - We need to consider all possible ways to arrange these 20 people and then find the average number of adjacent pairs where a boy is standing next to a girl.

2. **Mathematical Formulation:**
    - For each position from 1 to 19, we check if a boy is standing next to a girl.
    - We count how many such adjacent pairs exist for each arrangement and then take the average over all possible arrangements of 7 boys and 13 girls.

3. **Implementation in Python:**
    - Generate all permutations of the 20 positions.
    - For each permutation, count the number of adjacent boy-girl pairs.
    - Calculate the average of this count over all permutations.

Let's implement this step-by-step in Python to get the accurate result.
```python
import itertools

# Number of boys and girls
num_boys = 7
num_girls = 13

# Generate all permutations of a list containing 7 'B's and 13 'G's
people = ['B'] * num_boys + ['G'] * num_girls

# Initialize a list to store the value of S for each permutation
S_values = []

# Generate all unique permutations of the list and compute S for each
for perm in set(itertools.permutations(people)):
    count = 0
    n = len(perm)
    for i in range(n - 1):
        if (perm[i] == 'B' and perm[i + 1] == 'G') or (perm[i] == 'G' and perm[i + 1] == 'B'):
            count += 1
    S_values.append(count)

# Calculate the average value of S
average_S = sum(S_values) / len(S_values)
print(average_S)
```
