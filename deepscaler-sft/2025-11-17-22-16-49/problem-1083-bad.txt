To solve the problem, we need to evaluate \(\sin \left( \sin^{-1} \frac{3}{5} + \tan^{-1} 2 \right)\).

1. **Understand the Problem:**
    - \(\sin^{-1} \frac{3}{5}\) is an angle whose sine is \(\frac{3}{5}\).
    - \(\tan^{-1} 2\) is an angle whose tangent is 2.

    Let's call:
    - \(\alpha = \sin^{-1} \frac{3}{5}\), so \(\sin \alpha = \frac{3}{5}\).
    - \(\beta = \tan^{-1} 2\), so \(\tan \beta = 2\).

2. **Find \(\cos \alpha\) and \(\cos \beta\):**
    - Since \(\sin \alpha = \frac{3}{5}\), we can find \(\cos \alpha\) using the Pythagorean identity \(\sin^2 \alpha + \cos^2 \alpha = 1\):
      \[
      \cos^2 \alpha = 1 - \sin^2 \alpha = 1 - \left( \frac{3}{5} \right)^2 = 1 - \frac{9}{25} = \frac{16}{25} \implies \cos \alpha = \frac{4}{5}.
      \]
    - Since \(\tan \beta = 2\), we can consider a right triangle where the opposite side is 2 and the adjacent side is 1. The hypotenuse of this triangle is \(\sqrt{2^2 + 1^2} = \sqrt{5}\), so:
      \[
      \sin \beta = \frac{2}{\sqrt{5}}, \quad \cos \beta = \frac{1}{\sqrt{5}}.
      \]

3. **Use the Angle Addition Formula:**
    - We use the sine addition formula: 
      \[
      \sin(\alpha + \beta) = \sin \alpha \cos \beta + \cos \alpha \sin \beta.
      \]
    - Substituting the values we have:
      \[
      \sin \alpha = \frac{3}{5}, \quad \cos \alpha = \frac{4}{5}, \quad \sin \beta = \frac{2}{\sqrt{5}}, \quad \cos \beta = \frac{1}{\sqrt{5}}
      \]
      \[
      \sin(\alpha + \beta) = \frac{3}{5} \cdot \frac{1}{\sqrt{5}} + \frac{4}{5} \cdot \frac{2}{\sqrt{5}} = \frac{3}{5 \sqrt{5}} + \frac{8}{5 \sqrt{5}} = \frac{11}{5 \sqrt{5}} = \frac{11 \sqrt{5}}{25}.
      \]
