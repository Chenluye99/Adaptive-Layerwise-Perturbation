First, we need to generate the palindromes between 100 and 500. A number is a palindrome if it reads the same forward and backward.

1. **Generate Palindromes:**
    - A three-digit number is a palindrome if its first and last digits are the same.
    - So, we only need to check numbers of the form $\overline{aba}$, where $a$ and $b$ are digits, and the number is between 100 and 500.

2. **Check for Containing at Least One 5:**
    - Once we have generated the list of palindromes, we need to check each of these palindromes to see if they contain at least one "5".

3. **Count and Calculate Percentage:**
    - Count how many of these palindromes contain at least one "5".
    - Calculate the percentage of such palindromes out of the total palindromes found.

Let's implement this step-by-step process in Python.
```python
# Step 1: Generate the palindromes between 100 and 500
palindromes = []

for num in range(100, 500):
    str_num = str(num)
    if str_num == str_num[::-1]:
        palindromes.append(num)

# Step 2: Check which of these palindromes contain at least one "5"
palindromes_with_at_least_one_5 = [p for p in palindromes if '5' in str(p)]

# Step 3: Calculate the percentage
total_palindromes = len(palindromes)
palindromes_with_5 = len(palindromes_with_at_least_one_5)
percentage = (palindromes_with_5 / total_palindromes) * 100

print(percentage)
```
Code execution result: 10.0

Thus, the percentage of the palindromes between 100 and 500 that contain at least one 5 is \(\boxed{10.0}\). This is our final answer.
