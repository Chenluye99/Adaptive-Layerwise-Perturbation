To solve this problem, we need to check for each digit \( n \) (from 0 to 9) whether the three-digit number \( 14n \) (where \( n \) is the unit digit) is divisible by \( n \).

Let's break it down step-by-step:

1. **Form the Number:**
   For each digit \( n \), the number \( 14n \) can be represented as 140 + n (i.e., the number formed by 140 and appending the digit \( n \) at the end).

2. **Check Divisibility:**
   For each of these numbers, check if the number \( 140 + n \) is divisible by \( n \). This means that \( (140 + n) \% n == 0 \) should hold true.

3. **Count Valid Digits:**
   We need to count how many such digits \( n \) (from 1 to 9, because 0 cannot be a divisor for anything other than 0, and 140 + 0 = 140, which is not a three-digit number formed by 14n in the context of this problem where n is a unit digit) satisfy this condition.

Let's implement this step-by-step plan in Python to get the accurate result.
```python
# Initialize a counter to keep track of how many different digits n make 14n divisible by n
count = 0

# Check for each digit from 1 to 9 (0 is not considered because 140 is not a three-digit number formed by 14n where n is the unit digit)
for n in range(1, 10):
    num = 140 + n
    if num % n == 0:
        count += 1

print(count)
```
Code execution result: 5

Thus, the number of different digits \( n \) for which the three-digit number \( 14n \) is divisible by \( n \) is \(\boxed{5}\). This is our final answer.
