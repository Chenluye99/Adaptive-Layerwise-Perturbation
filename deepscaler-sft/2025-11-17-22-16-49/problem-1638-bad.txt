To solve this problem, we need to translate the given conditions into a system of congruences and solve for \( n \) such that \( n > 100 \).

1. **Set Up the Problem:**
    - If Zorn invades 13 planets at a time, there are 6 left. This can be written as:
      \[
      n \equiv 6 \pmod{13}
      \]
    - If Zorn invades 14 planets at a time, there are 5 left. This can be written as:
      \[
      n \equiv 5 \pmod{14}
      \]

2. **Solve the System of Congruences:**
    - We need to find the smallest integer \( n > 100 \) that satisfies both congruences.

3. **Implementation in Python:**

Let's implement this step-by-step in Python to ensure we get the accurate result.
```python
# We need to find the smallest n > 100 that satisfies both:
# n ≡ 6 (mod 13)
# n ≡ 5 (mod 14)

# We will iterate over numbers greater than 100 and check for these conditions.
def find_smallest_n():
    n = 101  # Start checking from 101 (since it's more than 100)
    while True:
        if n % 13 == 6 and n % 14 == 5:
            return n
        n += 1

smallest_n = find_smallest_n()
print(smallest_n)
```
Code execution result: 201

Thus, the smallest number of planets the solar system could have, given the conditions, is \(\boxed{201}\). This is the final answer.
