To convert rectangular coordinates $(x, y, z)$ to cylindrical coordinates $(r, \theta, z)$, we use the following formulas:
- $r = \sqrt{x^2 + y^2}$
- $\theta = \arctan2(y, x)$ (This function returns the angle in the correct quadrant)
- $z = z$ (The $z$ coordinate remains the same)

Given the rectangular coordinates $(-5, 0, -8)$, we can apply these formulas to get the cylindrical coordinates $(r, \theta, z)$.

Let's break it down step-by-step and use Python to compute this accurately.
```python
import math

# Given rectangular coordinates
x, y, z = -5, 0, -8

# Calculate r
r = math.sqrt(x**2 + y**2)

# Calculate θ using arctan2 to ensure it is in the correct quadrant
theta = math.atan2(y, x)

# Ensure θ is in the range [0, 2π)
if theta < 0:
    theta += 2 * math.pi

print(((r, theta, z)))
```
Code execution result: (5.0, 3.141592653589793, -8)

So, the cylindrical coordinates for the point $(-5, 0, -8)$ are \((5.0, 3.141592653589793, -8)\).
