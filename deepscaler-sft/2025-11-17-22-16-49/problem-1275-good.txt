Let's start by defining the matrix $\mathbf{A}$ and then computing $\mathbf{A}^2$ and $\mathbf{A}^3$. After that, we can set up the equation and solve for $p$, $q$, and $r$.

1. **Define the Matrix $\mathbf{A}$:**
   \[
   \mathbf{A} = \begin{pmatrix} 0 & 1 & 2 \\ 1 & 0 & 1 \\ 2 & 1 & 0 \end{pmatrix}
   \]

2. **Compute $\mathbf{A}^2$ and $\mathbf{A}^3$:**
   \[
   \mathbf{A}^2 = \mathbf{A} \cdot \mathbf{A}
   \]
   \[
   \mathbf{A}^3 = \mathbf{A} \cdot \mathbf{A}^2
   \]

3. **Set Up the Equation $\mathbf{A}^3 + p \mathbf{A}^2 + q \mathbf{A} + r \mathbf{I} = \mathbf{0}$:**
   We need to find constants $p$, $q$, and $r$ such that the above equation holds true. We can do this by setting up a system of equations by equating the corresponding matrix elements to 0.

Let's implement this step-by-step in Python.
```python
import sympy as sp

# Define the matrix A
A = sp.Matrix([
    [0, 1, 2],
    [1, 0, 1],
    [2, 1, 0]
])

# Compute A^2 and A^3
A2 = A * A
A3 = A * A2

# Define the identity matrix I and the zero matrix 0
I = sp.eye(3)
O = sp.zeros(3)

# Set up the equation A^3 + p * A^2 + q * A + r * I = O
p, q, r = sp.symbols('p q r')
lhs = A3 + p * A2 + q * A + r * I

# We want lhs to be the zero matrix, so we set up the system of equations by equating corresponding elements of lhs and O
eqns = [sp.Eq(lhs[i, j], 0) for i in range(3) for j in range(3)]

# Solve the system of equations
solution = sp.solve(eqns, (p, q, r))
print(solution)
```
