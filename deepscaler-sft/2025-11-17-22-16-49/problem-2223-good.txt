First, let's set up the constraints and equations in mathematical terms and then translate these into code:

1. Let's say George is getting \( n \) cents in change. 
2. If George receives the most quarters possible and the rest in pennies, and he needs 3 pennies to meet the amount, then the number of quarters he gets plus the 3 pennies equals \( n \). The maximum number of quarters he can get is \(\left\lfloor \frac{n}{25} \right\rfloor\), so if he gets \(\left\lfloor \frac{n}{25} \right\rfloor\) quarters, then the amount after getting those quarters would be \( n - 25 \cdot \left\lfloor \frac{n}{25} \right\rfloor \), and he gets 3 pennies to make up the rest to reach \( n \). This means:
   \[
   n = 25 \cdot \left\lfloor \frac{n}{25} \right\rfloor + 3
   \]

3. If George receives the most dimes possible and the rest in pennies, and he needs 8 pennies to meet the amount, then the number of dimes he gets plus the 8 pennies equals \( n \). The maximum number of dimes he can get is \(\left\lfloor \frac{n}{10} \right\rfloor\), so if he gets \(\left\lfloor \frac{n}{10} \right\rfloor\) dimes, then the amount after getting those dimes would be \( n - 10 \cdot \left\lfloor \frac{n}{10} \right\rfloor \), and he gets 8 pennies to make up the rest to reach \( n \). This means:
   \[
   n = 10 \cdot \left\lfloor \frac{n}{10} \right\rfloor + 8
   \]

We'll write a Python program to find all possible values of \( n \) that meet both conditions and are less than 100 (since change less than one dollar is from 0 to 99 cents). After finding such \( n \) values, we will compute the sum of these possible amounts of change.
```python
possible_amounts = []

for n in range(1, 100):
    quarters_count = n // 25
    if 25 * quarters_count + 3 == n:
        dimes_count = n // 10
        if 10 * dimes_count + 8 == n:
            possible_amounts.append(n)

result = sum(possible_amounts)
print((result, possible_amounts))
```
