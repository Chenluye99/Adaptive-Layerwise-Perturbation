def rotate_around_point(point, pivot, angle):
    x, y = point
    x0, y0 = pivot
    cos_theta = sp.cos(angle)
    sin_theta = sp.sin(angle)
    
    new_x = (x - x0) * cos_theta - (y - y0) * sin_theta + x0
    new_y = (x - x0) * sin_theta + (y - y0) * cos_theta + y0
    
    return (new_x, new_y)

Next, we will use the shoelace formula to find the area of quadrilateral \( KLMN \). The shoelace formula for a polygon with vertices \((x_1, y_1), (x_2, y_2), \ldots, (x_n, y_n)\) is given by:

\[
\text{Area} = \frac{1}{2} \left| \sum_{i=1}^{n-1} (x_i y_{i+1} - y_i x_{i+1}) + (x_n y_1 - y_n x_1) \right|
\]
