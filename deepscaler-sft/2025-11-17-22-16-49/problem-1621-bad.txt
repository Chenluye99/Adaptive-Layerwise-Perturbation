First, we need to identify all the divisors of 72. We then need to find all unordered sets (subsets) of these divisors and check if the subsets contain only composite numbers. Finally, we need to count such subsets, including the empty set.

**Step-by-Step Solution:**

1. **Find the Set of Divisors of 72:**
    - Determine all the divisors of 72. A number \(d\) is a divisor of 72 if \(72 \mod d == 0\).
    
2. **Identify Composite Numbers in the Set:**
    - Check which of these divisors are composite numbers. A composite number is a positive integer that has at least one positive divisor other than one or the number itself (i.e., it can be formed by multiplying two smaller positive integers).
    
3. **Generate All Subsets of the Set of Divisors:**
    - Generate all possible subsets of the set of divisors of 72.
    
4. **Filter Subsets to Only Include Those Containing Only Composite Numbers:**
    - Check each subset to ensure that all elements of the subset are composite numbers.
    
5. **Count Such Subsets:**
    - Count the number of subsets that satisfy the above condition, including the empty set.

Let's implement this step-by-step plan in Python to get the accurate result.
```python
import sympy

# Step 1: Find the set of divisors of 72
num = 72
divisors = [d for d in range(1, num + 1) if num % d == 0]

# Step 2: Identify composite numbers in the set of divisors
composite_numbers = [num for num in divisors if sympy.isprime(num) == False]

# Step 3: Generate all subsets of the set of divisors
import itertools

subsets = []
for r in range(len(divisors) + 1):
    subsets.extend(itertools.combinations(divisors, r))

# Step 4 and 5: Filter subsets and count those that contain only composite numbers
def contains_only_composite(subset):
    return all(num in composite_numbers for num in subset)

count_composite_only_subsets = sum(1 for subset in subsets if contains_only_composite(subset))

print(count_composite_only_subsets)
```
Code execution result: 1024

Thus, the number of subsets of the set of divisors of 72 that contain only composite numbers (including the empty set) is \(\boxed{1024}\). This completes the solution.
