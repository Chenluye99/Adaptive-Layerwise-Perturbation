\[
\prod_{n = 1}^{2004} \frac{n^2 + 2n - 1}{n^2 + n + \sqrt{2} - 2}.

We can write a Python script to compute this product step-by-step. We'll define a loop to iterate from 1 to 2004, compute each fraction, and multiply them together.

Let's implement this in Python.
```python
import numpy as np

# Initialize the product to 1
product = 1

# Loop through each n from 1 to 2004
for n in range(1, 2005):
    numerator = n**2 + 2 * n - 1
    denominator = n**2 + n + np.sqrt(2) - 2
    fraction = numerator / denominator
    product *= fraction

print(product)
```
