To solve the problem, we need to find the maximum value of the function \( y = -x^2 + 5 \) where \( x \) is a real number.

The function \( y = -x^2 + 5 \) is a quadratic function with a negative leading coefficient (-1), meaning it opens downward and its maximum value occurs at its vertex.

For a quadratic function of the form \( y = ax^2 + bx + c \), the vertex form gives the maximum (or minimum) value of \( y \). The x-coordinate of the vertex of a parabola given by \( y = ax^2 + bx + c \) is given by \( x = -\frac{b}{2a} \). 

For the function \( y = -x^2 + 5 \), we have \( a = -1 \), \( b = 0 \), and \( c = 5 \). 

Since \( b = 0 \), the x-coordinate of the vertex is:
\[ x = -\frac{0}{2 \cdot (-1)} = 0. \]

Substitute \( x = 0 \) back into the function to get the y-coordinate of the vertex, which is the maximum value of \( y \):
\[ y = -(0)^2 + 5 = 5. \]

Hence, the maximum value of \( y \) is 5. To verify this and ensure accuracy, we can use Python to evaluate this.
```python
import sympy as sp

# Define the variable and the function
x = sp.symbols('x')
y = -x**2 + 5

# Find the critical points by taking the derivative and setting it to zero
dy_dx = sp.diff(y, x)
critical_points = sp.solve(dy_dx, x)

# Evaluate the function at the critical points to find the maximum value
max_y = max(y.subs(x, point) for point in critical_points)

print(max_y)
```
Code execution result: 5

Thus, the maximum value of \( y \) is \(\boxed{5}\). This confirms our earlier reasoning and calculations.
