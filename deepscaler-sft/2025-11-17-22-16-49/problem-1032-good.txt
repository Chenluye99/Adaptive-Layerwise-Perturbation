To solve the given problem, we start by computing the sum \(\sum_{k=1}^{35} \sin 5k\).

First, recall that the sine function is periodic and we can use Python to compute this sum directly. Then, we need to express this sum in the form \(\tan \frac{m}{n}\) and find the values of \(m\) and \(n\) that satisfy the conditions stated in the problem.

Let's start by computing \(\sum_{k=1}^{35} \sin 5k\):

1. We will iterate through \(k\) from 1 to 35, compute \(\sin(5k)\) for each \(k\), and sum these values.
2. Once we have the sum, we need to find \(\frac{m}{n}\) such that \(\tan \frac{m}{n} = \text{computed sum}\).
3. We then ensure that \(m\) and \(n\) are relatively prime, and \(\frac{m}{n} < 90\).

Let's implement this step-by-step in Python.
```python
import math
from fractions import Fraction

# Calculate the sum of sin(5k) for k from 1 to 35
sum_sin = sum(math.sin(math.radians(5 * k)) for k in range(1, 36))

# Find m and n such that tan(m/n) = sum_sin
# We will iterate over possible values of m and n to find a match
# Start by finding the arctan of the sum_sin, and then convert it to a fraction to get m/n

angle = math.degrees(math.atan(sum_sin))
frac_approx = Fraction(angle).limit_denominator()

m, n = frac_approx.numerator, frac_approx.denominator

# Ensure m and n are relatively prime and m/n < 90
assert math.gcd(m, n) == 1, "m and n should be relatively prime"
assert m / n < 90, "m/n should be less than 90"

print((m, n, m + n))
```
