To solve this problem, we can systematically evaluate all possible ways to assign the sports (volleyball, basketball, and table tennis) to the 4 different gyms and then count only those assignments where no gym has more than 2 of the sports.

Let's define our steps clearly:

1. **Generate all Assignments:**
   We have 3 sports (volleyball, basketball, table tennis) and 4 gyms. Each sport can be assigned to any of the 4 gyms, so there are \(4^3 = 64\) ways to assign the 3 sports to the 4 gyms without any restrictions.

2. **Apply the Constraint:**
   We need to ensure that no gym has more than 2 sports. This means, if a gym gets 3 sports, it is not valid.

3. **Check Validity:**
   For each of the 64 assignments, we need to check if any gym has more than 2 sports assigned to it. If not, we count that assignment as valid.

Let's implement this step-by-step plan using Python to ensure accuracy.
```python
import itertools

# Number of gyms and sports
num_gyms = 4
num_sports = 3

# List of sports
sports = ['volleyball', 'basketball', 'table tennis']

# Generate all permutations of assigning 3 sports to 4 gyms
assignments = list(itertools.product(range(num_gyms), repeat=num_sports))

# Function to check if an assignment is valid (no gym gets more than 2 sports)
def is_valid_assignment(assignment):
    gym_count = [0] * num_gyms
    
    for sport_idx, gym in enumerate(assignment):
        gym_count[gym] += 1
    
    # Check if any gym has more than 2 sports
    for count in gym_count:
        if count > 2:
            return False
    return True

# Count valid assignments
valid_assignments_count = 0

for assignment in assignments:
    if is_valid_assignment(assignment):
        valid_assignments_count += 1

print(valid_assignments_count)
```
Code execution result: 60

Thus, the number of different ways to schedule the volleyball, basketball, and table tennis competitions in 4 different gyms, ensuring each sport is held in only one gym and no gym hosts more than 2 sports, is \(\boxed{60}\). This is the final answer.
