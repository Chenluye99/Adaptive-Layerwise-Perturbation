First, let's start by understanding and generating Pascal's Triangle. Each element of Pascal's Triangle can be described using binomial coefficients, such that the entry in the \(n\)-th row and \(k\)-th column is given by:

\[
C(n, k) = \frac{n!}{k!(n-k)!}
\]

We need to find a row in Pascal's Triangle where three consecutive binomial coefficients, say \(C(n, k-1)\), \(C(n, k)\), and \(C(n, k+1)\), are in the ratio \(3:4:5\). This means:

\[
\frac{C(n, k)}{C(n, k-1)} = \frac{4}{3} \quad \text{and} \quad \frac{C(n, k+1)}{C(n, k)} = \frac{5}{4}
\]

Using the formula for binomial coefficients, we have:

\[
C(n, k) = \frac{n!}{k!(n-k)!}
\]

So, we can write:

\[
\frac{C(n, k)}{C(n, k-1)} = \frac{\frac{n!}{k!(n-k)!}}{\frac{n!}{(k-1)!(n-k+1)!}} = \frac{(k-1)!(n-k+1)!}{k!(n-k)!} = \frac{(n-k+1)}{k}
\]

And similarly,

\[
\frac{C(n, k+1)}{C(n, k)} = \frac{\frac{n!}{(k+1)!(n-k-1)!}}{\frac{n!}{k!(n-k)!}} = \frac{k!(n-k)!}{(k+1)!(n-k-1)!} = \frac{(n-k)}{k+1}
\]

We need these ratios to be equal to \(\frac{4}{3}\) and \(\frac{5}{4}\) respectively, so we set up the following equations:

\[
\frac{n-k+1}{k} = \frac{4}{3}
\]

\[
\frac{n-k}{k+1} = \frac{5}{4}
