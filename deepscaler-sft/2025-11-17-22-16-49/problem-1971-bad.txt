To solve the given problem, we need to find the integers \( n \) that satisfy the equation:

\[ 1 + \left\lfloor \frac{100n}{101} \right\rfloor = \left\lceil \frac{99n}{100} \right\rceil. \]

We will iterate through a reasonable range of integers for \( n \) and check whether the equation holds for each \( n \). To determine if the equation is satisfied, we will use the following steps:

1. Compute \(\left\lfloor \frac{100n}{101} \right\rfloor\).
2. Compute \(\left\lceil \frac{99n}{100} \right\rceil\).
3. Check if the equation \( 1 + \left\lfloor \frac{100n}{101} \right\rfloor = \left\lceil \frac{99n}{100} \right\rceil \) holds.

We can use Python to perform these calculations efficiently. Let's implement this step-by-step in code.
```python
import math

count = 0

# We will test a reasonable range for n, say -10000 to 10000, which should cover all possible integer solutions.
for n in range(-10000, 10001):
    left_side = 1 + math.floor(100 * n / 101)
    right_side = math.ceil(99 * n / 100)
    
    if left_side == right_side:
        count += 1

print(count)
```
