Given:
\[ a \overline{b} = -1 + 5i. \]

We need to find the value of $\overline{a} b$.

Let's denote:
\[ a = a_1 + a_2 i \]
\[ b = b_1 + b_2 i \]

Then, the conjugates are:
\[ \overline{a} = a_1 - a_2 i \]
\[ \overline{b} = b_1 - b_2 i \]

Substitute these into the given equation:
\[ a \overline{b} = (a_1 + a_2 i)(b_1 - b_2 i). \]

Expanding the left-hand side:
\[ (a_1 + a_2 i)(b_1 - b_2 i) = a_1 b_1 - a_1 b_2 i + a_2 i b_1 - a_2 i b_2 i = a_1 b_1 - a_1 b_2 i + a_2 b_1 i + a_2 b_2 = (a_1 b_1 + a_2 b_2) + (a_2 b_1 - a_1 b_2) i. \]

We know that this is equal to $-1 + 5i$, so we get:
\[ a_1 b_1 + a_2 b_2 = -1, \]
\[ a_2 b_1 - a_1 b_2 = 5. \]

Now, we want to find $\overline{a} b$. Substitute the definitions of $\overline{a}$ and $b$:
\[ \overline{a} b = (a_1 - a_2 i)(b_1 + b_2 i). \]

Expanding the right-hand side:
\[ (a_1 - a_2 i)(b_1 + b_2 i) = a_1 b_1 + a_1 b_2 i - a_2 i b_1 - a_2 i b_2 i = a_1 b_1 + a_1 b_2 i - a_2 b_1 i + a_2 b_2 = (a_1 b_1 + a_2 b_2) + (a_1 b_2 - a_2 b_1) i. \]

We need to determine $a_1 b_2 - a_2 b_1$. Observe that if we take the conjugate of both sides of the original equation, we get:

\[ \overline{a \overline{b}} = \overline{-1 + 5i}. \]

The conjugate of a product is the product of the conjugates, so:
\[ \overline{a} \, b = \overline{-1 + 5i} = -1 - 5i. \]

Thus, we have:
\[ \overline{a} b = -1 - 5i. \]
