To solve the problem, we need to find all the lattice points \((x, y)\) that satisfy the equation \(x^2 - y^2 = 2000^2\). We can factorize the left-hand side of the equation as:

\[x^2 - y^2 = (x - y)(x + y) = 2000^2.\]

This means that we need to find pairs of integers \((a, b)\) such that:

\[a = x - y \quad \text{and} \quad b = x + y,\]

where \(ab = 2000^2\). From these definitions, we get:

\[x = \frac{a + b}{2} \quad \text{and} \quad y = \frac{b - a}{2}.\]

For \(x\) and \(y\) to be integers, both \(\frac{a + b}{2}\) and \(\frac{b - a}{2}\) need to be integers. Therefore, both \(a + b\) and \(b - a\) need to be even, which implies that \(a\) and \(b\) must either both be even or both be odd.

First, let's compute \(2000^2\):

\[2000^2 = 4000000.\]

Next, we need to iterate through all the factor pairs \((a, b)\) of 4000000 and check if both \(\frac{a + b}{2}\) and \(\frac{b - a}{2}\) are integers, and that these values of \(x\) and \(y\) are integers.

We can implement this in Python to get an accurate result.
```python
import sympy

# Calculate 2000^2
n = 2000 ** 2

# Find all factor pairs (a, b) such that a * b = 2000^2
factor_pairs = []
for a in range(1, n + 1):
    if n % a == 0:
        b = n // a
        factor_pairs.append((a, b))

count = 0

# Check each factor pair to see if it gives integer solutions for x and y
for a, b in factor_pairs:
    x = (a + b) / 2
    y = (b - a) / 2
    if x.is_integer() and y.is_integer():
        count += 1

print(count)
```
