To solve the problem, let's begin by analyzing the conditions given:

1. The quadratic equation \(ax^2 + 8x + c = 0\) has exactly one solution.
2. For a quadratic equation to have exactly one solution, its discriminant must be zero. The discriminant \(\Delta\) of the quadratic equation \(ax^2 + 8x + c = 0\) is given by:
   \[
   \Delta = 8^2 - 4 \cdot a \cdot c = 64 - 4ac
   \]
   Setting the discriminant to zero, we get:
   \[
   64 - 4ac = 0 \implies 4ac = 64 \implies ac = 16
   \]
3. We are also given that \(a + c = 10\).
4. We need to find the ordered pair \((a, c)\) such that \(a < c\).

Now we have the following system of equations:
\[
\begin{cases}
ac = 16, \\
a + c = 10.
\end{cases}
\]

We can solve this system of equations by substituting \(c = 10 - a\) from the second equation into the first equation:

\[
a(10 - a) = 16 \implies 10a - a^2 = 16 \implies a^2 - 10a + 16 = 0.
\]

We can solve the quadratic equation \(a^2 - 10a + 16 = 0\) using the quadratic formula \(a = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}\), where \(a = 1\), \(b = -10\), and \(c = 16\):

\[
a = \frac{-(-10) \pm \sqrt{(-10)^2 - 4 \cdot 1 \cdot 16}}{2 \cdot 1} = \frac{10 \pm \sqrt{100 - 64}}{2} = \frac{10 \pm \sqrt{36}}{2} = \frac{10 \pm 6}{2}.
\]

This gives us two solutions:
\[
a = \frac{10 + 6}{2} = 8, \quad \text{and} \quad a = \frac{10 - 6}{2} = 2.
\]

Now, substituting these values back into the equation \(a + c = 10\):

1. If \(a = 8\), then \(c = 10 - 8 = 2\).
2. If \(a = 2\), then \(c = 10 - 2 = 8\).

We need to make sure that \(a < c\). From the above solutions, we have:

- If \(a = 8\) and \(c = 2\), then \(a \not< c\) (since \(8 > 2\)).
- If \(a = 2\) and \(c = 8\), then \(a < c\) (since \(2 < 8\)).

So, the only solution that satisfies all conditions is \((a, c) = (2, 8)\).
