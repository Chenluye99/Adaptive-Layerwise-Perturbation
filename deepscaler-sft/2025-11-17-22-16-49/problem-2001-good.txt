To solve the given problem, we need to evaluate the sum

\[
\sum_{n = 1}^{9999} \frac{1}{(\sqrt{n} + \sqrt{n + 1})(\sqrt[4]{n} + \sqrt[4]{n + 1})}.
\]

We'll write a Python program to compute this sum by iterating through each value of \( n \) from 1 to 9999, calculating the expression for each \( n \), and then summing these values.

Let's start by implementing this in code.
```python
import numpy as np

# Initialize the sum
summation = 0

# Iterate from 1 to 9999
for n in range(1, 10000):
    term = 1 / ((np.sqrt(n) + np.sqrt(n + 1)) * (np.power(n, 1/4) + np.power(n + 1, 1/4)))
    summation += term

print(summation)
```
