To solve this problem, we need to compare the values of the given numbers to 1. We'll convert all the fractions to decimal form and then compare their distances from 1.

The numbers to compare are:
1. \(\frac{11}{10}\)
2. \(\frac{111}{100}\)
3. 1.101
4. \(\frac{1111}{1000}\)
5. 1.011

First, let's convert the fractions to decimal form:
1. \(\frac{11}{10} = 1.1\)
2. \(\frac{111}{100} = 1.11\)
3. 1.101 remains 1.101
4. \(\frac{1111}{1000} = 1.111\)
5. 1.011 remains 1.011

Now, we will calculate the absolute differences of each of these numbers from 1 and then determine which number is closest to 1.

Let's implement this in Python to get the precise result.
```python
# List of numbers to compare
numbers = [11 / 10, 111 / 100, 1.101, 1111 / 1000, 1.011]

# Calculate the absolute differences from 1
differences = [abs(num - 1) for num in numbers]

# Find the index of the minimum difference
min_diff_index = differences.index(min(differences))

# Get the corresponding number that has the minimum difference
closest_number = numbers[min_diff_index]
print(closest_number)
```
Code execution result: 1.011

Thus, the number that is closest to 1 is \(\boxed{1.011}\). This is confirmed by calculating the differences and identifying that 1.011 has the smallest difference from 1 among the given numbers.
