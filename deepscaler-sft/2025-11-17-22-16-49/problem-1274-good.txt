To solve this problem, we need to find all the odd integers between 500 and 700, and then compute their sum.

1. **Identify the Range**:
    - The first odd integer greater than or equal to 500 is 501.
    - The last odd integer less than or equal to 700 is 699.

2. **Generate the List of Odd Integers**:
    - We can generate a list of all the odd integers between 501 and 699.
    - Then, we can compute the sum of these odd integers.

We'll use Python to ensure the result is accurate. Let's implement this step-by-step in code.
```python
# Initialize a list to store the odd numbers between 500 and 700
odd_numbers = []

# Populate the list with all odd numbers in the given range
for num in range(501, 700):
    if num % 2 != 0:
        odd_numbers.append(num)

# Calculate the sum of the odd numbers
sum_of_odd_numbers = sum(odd_numbers)
print(sum_of_odd_numbers)
```
Code execution result: 60000

Thus, the sum of all the odd integers between 500 and 700 is \(\boxed{60000}\). This is our final answer.
