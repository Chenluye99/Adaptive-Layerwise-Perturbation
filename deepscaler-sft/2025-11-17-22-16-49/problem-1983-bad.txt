To solve this problem, we need to follow these steps:

1. **Choose the Host School:**
   - There are 3 schools, and we can choose any one of the 3 schools to host the meeting. So, there are 3 ways to choose the host school.

2. **Choose Representatives:**
   - The host school sends 2 representatives out of its 5 members. The number of ways to choose 2 representatives from 5 is given by the combination formula \( \binom{5}{2} \).
   - Each of the other two schools sends 1 representative out of its 5 members. The number of ways to choose 1 representative from 5 is given by the combination formula \( \binom{5}{1} \), and since there are 2 such schools, we need to do this twice.

3. **Combine All Choices:**
   - For each choice of the host school, we need to compute the ways to choose the representatives as described above, and then multiply the ways for each of the steps.

Let's calculate this step by step using Python to ensure accuracy.
```python
import sympy as sp
from math import comb

# Number of ways to choose the host school
num_ways_choose_host_school = 3

# Number of ways to choose 2 representatives from the host school
ways_to_choose_host_representatives = comb(5, 2)

# Number of ways to choose 1 representative from each of the other two schools
ways_to_choose_non_host_representatives = comb(5, 1) * comb(5, 1)

# Total ways to choose representatives for all schools
total_ways_to_choose_representatives = ways_to_choose_host_representatives * ways_to_choose_non_host_representatives * ways_to_choose_non_host_representatives

# Final answer is the product of the number of ways to choose the host school and the number of ways to choose the representatives
total_ways = num_ways_choose_host_school * total_ways_to_choose_representatives
print(total_ways)
```
