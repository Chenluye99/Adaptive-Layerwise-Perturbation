To solve this problem, we need to compute the probability that Joe will have all the letters 'P', 'R', 'O', 'B', 'L', 'E', 'M' after randomly selecting letters from the words "CAMP", "HERBS", and "GLOW".

1. **Identify the Letters Needed:**
   - We need the letters 'P', 'R', 'O', 'B', 'L', 'E', 'M'.
   - The word "CAMP" contains the letters 'C', 'A', 'M', 'P'.
   - The word "HERBS" contains the letters 'H', 'E', 'R', 'B', 'S'.
   - The word "GLOW" contains the letters 'G', 'L', 'O', 'W'.

2. **Extract the Relevant Letters:**
   - From "CAMP", we can only get 'P'.
   - From "HERBS", we can get 'R', 'E', 'B'.
   - From "GLOW", we can get 'L', 'O'.

3. **Formulate the Problem:**
   - We need 'P' from "CAMP".
   - We need 'R', 'B', and 'L' from "HERBS".
   - We need 'O' from "GLOW".

4. **Check All Possible Combinations:**
   - We need to ensure that Joe's selections of 2 letters from "CAMP", 4 letters from "HERBS", and 3 letters from "GLOW" will guarantee that he has 'P', 'R', 'O', 'B', 'L', 'E' and 'M'. However, since 'M' is not present in any of the words "CAMP", "HERBS", or "GLOW", it is impossible to get all the letters of the word "PROBLEM" from these words as they do not contain the letters 'P', 'R', 'O', 'B', 'L', 'E', 'M'.

Let's write some Python code to explicitly check all possible combinations and confirm the probability, even though it should logically be zero because 'M' is not present in any of the words "CAMP", "HERBS", or "GLOW". Nevertheless, let's confirm it programmatically.
```python
import itertools

# Define the words from which letters are chosen
word_CAMP = "CAMP"
word_HERBS = "HERBS"
word_GLOW = "GLOW"

# Get all possible ways of choosing 2 letters from "CAMP", 4 letters from "HERBS", and 3 letters from "GLOW"
combs_CAMP = list(itertools.combinations(word_CAMP, 2))
combs_HERBS = list(itertools.combinations(word_HERBS, 4))
combs_GLOW = list(itertools.combinations(word_GLOW, 3))

# Get the target letters
target_letters = set("PROBLEM")

# Initialize counter for successful outcomes and total outcomes
success_count = 0
total_count = len(combs_CAMP) * len(combs_HERBS) * len(combs_GLOW)

# Check each combination
for c1 in combs_CAMP:
    for c2 in combs_HERBS:
        for c3 in combs_GLOW:
            combined_set = set(c1 + c2 + c3)
            if target_letters.issubset(combined_set):
                success_count += 1

# Calculate the probability
probability = success_count / total_count
print(probability)
```
