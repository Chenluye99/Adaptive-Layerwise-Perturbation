To solve this problem, we need to make use of some properties of polygons.

1. **Properties of a Polygon:**
    - The sum of the interior angles of an \(n\)-sided polygon is given by the formula \((n-2) \cdot 180^\circ\).
    - If we know that the sum of all angles except one of a convex polygon is \(2190^\circ\), then the sum of all interior angles of the polygon minus one of those angles is \(2190^\circ\).
    - Let's call the missing angle \(\theta\). Then, we have:
      \[
      (n-2) \cdot 180^\circ - \theta = 2190^\circ
      \]
    - Rearrange this equation to solve for \(\theta\):
      \[
      \theta = (n-2) \cdot 180^\circ - 2190^\circ
      \]
    - Since \(\theta\) is an interior angle of a polygon, it must be between \(0^\circ\) and \(180^\circ\) (exclusive of the endpoints because it is a convex polygon).

2. **Set Up the Equation and Solve for \(n\):**
    - We can iterate over possible values of \(n\) and check when \(\theta\) falls within the valid range for an interior angle of a convex polygon. We know that \(3 \leq n \leq 16\) because a polygon must have at least 3 sides and the maximum possible number of sides can be guessed by checking that \((n-2) \cdot 180^\circ\) is reasonably close to 2190 when added back the missing angle.

We can set up a Python code to check this iteratively.
```python
# We will iterate over possible values of n and check for the conditions described above.

# Initialize a variable to hold the correct n
correct_n = None

# Iterate over possible values of n (starting from 3, because a polygon needs at least 3 sides)
for n in range(3, 100):  # Arbitrarily chosen upper bound, but a practical check could be up to a reasonable number of sides for polygons.
    total_sum_of_angles = (n - 2) * 180
    theta = total_sum_of_angles - 2190
    
    # Check if theta is a valid interior angle for a convex polygon (i.e., 0 < theta < 180)
    if 0 < theta < 180:
        correct_n = n
        break

print(correct_n)
```
