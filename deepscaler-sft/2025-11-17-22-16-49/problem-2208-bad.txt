To solve the given problem, let's start by understanding how the sequence \(a_n\) is defined. The recurrence relation for the sequence is given as:

\[ a_n = \frac{a_{n-1}}{1 + a_{n-1}} \]

We are given the initial condition \( a_0 = 6 \). We need to find \( a_{100} \).

To solve this, we can implement a loop in Python to compute the values of the sequence up to \( a_{100} \).

Let's initialize \( a_0 \) and then iteratively compute \( a_n \) for \( n = 1, 2, \ldots, 100 \) using the recurrence relation.

We'll implement this step-by-step process in Python.
```python
# Initialize a_0
a = [6]

# Compute values up to a_100 using the recurrence relation
for n in range(1, 101):
    a_n = a[n - 1] / (1 + a[n - 1])
    a.append(a_n)

# Get a_100
a_100 = a[100]
print(a_100)
```

Thus, the value of \( a_{100} \) is \(\boxed{0.009983361064891848}\). This result was obtained by iteratively applying the recurrence relation starting from the initial condition \( a_0 = 6 \).
