To solve this problem, we need to find the smallest positive integer \( T \) whose only digits are 0s and 1s, and when divided by 12, results in an integer. We can then find \(\frac{T}{12} = X \), and determine the minimum possible value of \( X \).

1. **Generate Numbers Consisting Only of 0s and 1s:**
   We will generate numbers composed only of the digits 0 and 1, and check if these numbers are divisible by 12.

2. **Check Divisibility by 12:**
   For each generated number, we check if it is divisible by 12. If it is, we compute \( X = \frac{T}{12} \) and keep track of the smallest possible value of \( X \).

We will use Python to implement this step-by-step process until we find the smallest possible value of \( X \).

Let's start by implementing this in Python.
```python
import itertools

def find_smallest_X():
    n = 1
    min_X = float("inf")
    
    while True:
        # Generate all numbers with up to 'n' digits consisting only of 0s and 1s
        for num_str in itertools.product('01', repeat=n):
            num_str = ''.join(num_str)
            if num_str[0] == '0':  # Skip numbers that start with 0, as they are not considered positive integers
                continue
            T = int(num_str)
            
            if T % 12 == 0:
                X = T // 12
                if X < min_X:
                    min_X = X
        
        if min_X != float("inf"):
            return min_X
        
        n += 1

smallest_X = find_smallest_X()
print(smallest_X)
```
Code execution result: 925

Thus, the smallest possible value of \( X \) is \(\boxed{925}\). This result was obtained by iterating through numbers composed only of the digits 0 and 1, checking for divisibility by 12, and computing \(\frac{T}{12}\) while keeping track of the minimum value of such results.
