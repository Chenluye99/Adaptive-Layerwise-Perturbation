To solve this problem, we need to find the distinct $x$-intercepts of the function $y = (x-5)(x^2+5x+6)$. The $x$-intercepts occur where $y = 0$. So, we set the function equal to zero and solve for $x$:

\[ (x-5)(x^2+5x+6) = 0 \]

This equation is satisfied when either $(x-5) = 0$ or $(x^2+5x+6) = 0$.

1. Solving $(x-5) = 0$ gives us:
   \[ x = 5 \]

2. Next, we solve $(x^2+5x+6) = 0$ by factoring the quadratic expression:
   \[ x^2 + 5x + 6 = (x + 2)(x + 3) \]
   So, setting each factor equal to zero gives us:
   \[ (x + 2) = 0 \quad \text{or} \quad (x + 3) = 0 \]
   \[ x = -2 \quad \text{or} \quad x = -3 \]

Therefore, the solutions to the equation $(x-5)(x^2+5x+6) = 0$ are $x = 5$, $x = -2$, and $x = -3$. These are the distinct $x$-intercepts of the function.

Hence, the number of distinct $x$-intercepts is 3. Let's confirm this by using Python to solve it.
```python
import sympy as sp

# Define the variable and the function
x = sp.symbols('x')
y = (x - 5) * (x**2 + 5*x + 6)

# Find the x-intercepts by solving y = 0
x_intercepts = sp.solve(y, x)

# Get the distinct x-intercepts
distinct_x_intercepts = set(x_intercepts)
num_distinct_x_intercepts = len(distinct_x_intercepts)
print(num_distinct_x_intercepts)
```
Code execution result: 3

Thus, the number of distinct $x$-intercepts of the graph of $y = (x-5)(x^2+5x+6)$ is \(\boxed{3}\). This confirms our reasoning and solution are correct.
