First, let's outline the constraints and requirements for the license plates:

1. The Rotokas alphabet is composed of the following 12 letters: A, E, G, I, K, O, P, R, S, T, U, V.
2. A license plate consists of 5 letters.
3. The first letter of the license plate must be either G or K.
4. The last letter of the license plate must be T.
5. The letter S cannot be used in the license plate.
6. No letter can repeat in the license plate.

Given these constraints, we will:

1. Generate all possible combinations of 5 letters from the Rotokas alphabet, ensuring that "S" is excluded.
2. Filter these combinations to ensure that the first letter is either G or K.
3. Further filter these combinations to ensure that the last letter is T.
4. Finally, ensure that no letter is repeated in the combination.

Let's implement this step-by-step in Python to find the accurate count of such license plates.
```python
import itertools

# Rotokas alphabet without 'S'
rotoka_alphabet = ['A', 'E', 'G', 'I', 'K', 'O', 'P', 'R', 'T', 'U', 'V']

# Initialize a counter for valid license plates
valid_license_plates_count = 0

# Generate all possible 5-letter combinations from the Rotokas alphabet without 'S'
for comb in itertools.permutations(rotoka_alphabet, 5):
    str_comb = ''.join(comb)
    
    # Check constraints
    if (str_comb[0] == 'G' or str_comb[0] == 'K') and str_comb[-1] == 'T':
        is_valid = True
        for letter in str_comb:
            if str_comb.count(letter) > 1:
                is_valid = False
                break
        
        if is_valid:
            valid_license_plates_count += 1

print(valid_license_plates_count)
```
