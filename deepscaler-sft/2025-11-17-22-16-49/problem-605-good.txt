Given two lists of intervals, write a function that returns a list of intervals representing the intersection of the corresponding intervals from each list. Each interval in the list is defined by a tuple $(start, end)$, where $start$ and $end$ are integers and $start < end$. The intervals in each list are sorted and do not overlap or touch (i.e., for any two intervals $(start_1, end_1)$ and $(start_2, end_2)$ in the same list, either $end_1 <= start_2$ or $end_2 <= start_1$).

For example, given the following two lists of intervals:

List 1: $[(0, 2), (5, 7), (9, 12)]$
List 2: $[(1, 3), (6, 8), (10, 13)]$

The function should return: $[(1, 2), (6, 7), (10, 12)]$, because these are the intersections of the corresponding intervals from each list.

Implement this function and verify its correctness with the provided test case.
To solve this problem, we can follow these steps:

1. **Initialize an Empty List:** We need to create an empty list that will store the resulting intersections.
2. **Iterate Over Corresponding Intervals:** We will iterate through the corresponding intervals from both lists simultaneously.
3. **Find Intersection of Each Pair of Intervals:** For each pair of intervals ((start1, end1) from List 1 and (start2, end2) from List 2), we will find their intersection, if any. The intersection of two intervals (start1, end1) and (start2, end2) will be ((max(start1, start2)), min(end1, end2)) if max(start1, start2) < min(end1, end2), otherwise, there is no intersection.
4. **Add Intersection to Result List:** We will add the intersection to our result list if an intersection is found.

Let's implement this step-by-step approach in Python:

1. We will define a function that takes two lists of intervals as input.
2. We will use two pointers or iterate over both lists simultaneously to compare and find intersections.
3. We will append the intersections to a result list if they exist.

Let's implement this in code and ensure it's working correctly with a test case.
```python
def interval_intersection(list1, list2):
    i, j = 0, 0
    result = []
    
    while i < len(list1) and j < len(list2):
        (start1, end1) = list1[i]
        (start2, end2) = list2[j]
        
        # Find the intersection of the two intervals
        start = max(start1, start2)
        end = min(end1, end2)
        
        if start < end:
            result.append((start, end))
        
        # Move to the next interval in the list that ends first
        if end1 < end2:
            i += 1
        elif end1 > end2:
            j += 1
        else:
            i += 1
            j += 1
    
    return result

# Test case
```
