To solve this problem, we need to evaluate the sum

\[ S = \sum_{n=0}^{668} (-1)^n \binom{2004}{3n}. \]

After computing this sum, we need to find the remainder when $S$ is divided by 1000. Let's break it down step-by-step:

1. **Compute the Sum:**
    - We will iterate over each term of the sum from \( n = 0 \) to \( n = 668 \).
    - For each term, compute \((-1)^n \binom{2004}{3n}\).
    - Accumulate these values to get the sum \( S \).

2. **Find the Remainder:**
    - Once we have the value of \( S \), we determine the remainder when \( S \) is divided by 1000 using the modulus operator (%).

Let's implement this in Python.
```python
import math

# Initialize the sum
S = 0

# Compute the sum
for n in range(669):
    term = (-1)**n * math.comb(2004, 3 * n)
    S += term

# Find the remainder when S is divided by 1000
remainder = S % 1000
print(remainder)
```
Code execution result: 6

Thus, the remainder obtained when \( S \) is divided by 1000 is \(\boxed{6}\). This is the final answer.
