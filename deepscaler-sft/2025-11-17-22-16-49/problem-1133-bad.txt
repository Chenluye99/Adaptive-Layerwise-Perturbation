To solve the problem, we need to find the roots of the quadratic equation \(2x^2 + 4x - 1 = 0\) and then compute the sum of the squares of these roots.

1. **Find the Roots of the Quadratic Equation:**
   Let the roots of the quadratic equation \(2x^2 + 4x - 1 = 0\) be \(r_1\) and \(r_2\). We can use Vieta's formulas to get the relationships between the coefficients of the quadratic equation and its roots:
   - The sum of the roots \(r_1 + r_2 = -\frac{b}{a} = -\frac{4}{2} = -2\).
   - The product of the roots \(r_1 \cdot r_2 = \frac{c}{a} = \frac{-1}{2} = -\frac{1}{2}\).

2. **Find the Sum of the Squares of the Roots:**
   We want to find \( r_1^2 + r_2^2 \). We can use the identity:
   \[
   r_1^2 + r_2^2 = (r_1 + r_2)^2 - 2 \cdot r_1 \cdot r_2
   \]
   Substituting the values from Vieta's formulas:
   \[
   r_1^2 + r_2^2 = (-2)^2 - 2 \cdot \left(-\frac{1}{2}\right) = 4 + 1 = 5
   \]

Let's confirm this by solving the quadratic equation directly using Python and computing the roots, then finding the sum of their squares.
```python
import sympy as sp

# Define the variable and the equation
x = sp.symbols('x')
equation = 2*x**2 + 4*x - 1

# Find the roots of the equation
roots = sp.solve(equation, x)

# Calculate the sum of the squares of the roots
sum_of_squares = roots[0]**2 + roots[1]**2
print(sum_of_squares)
```
Code execution result: (-1 + sqrt(6)/2)**2 + (-sqrt(6)/2 - 1)**2

This symbolic representation needs to be evaluated to get the numerical result. Let's proceed with evaluating this expression.
```python
import sympy as sp

# Define the variable and the equation
x = sp.symbols('x')
equation = 2*x**2 + 4*x - 1

# Find the roots of the equation
roots = sp.solve(equation, x)

# Calculate the sum of the squares of the roots and evaluate it to a numerical value
sum_of_squares_evaluated = roots[0]**2 + roots[1]**2
sum_of_squares_evaluated = sp.N(sum_of_squares_evaluated)  # Evaluate to a numerical value
print(sum_of_squares_evaluated)
```
Code execution result: 5.00000000000000

Thus, the sum of the squares of the solutions to the equation \(2x^2 + 4x - 1 = 0\) is \(\boxed{5}\). This confirms our earlier analytical solution.
