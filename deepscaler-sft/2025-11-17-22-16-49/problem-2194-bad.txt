To solve the problem, we need to determine how many positive integers less than 60 have an even number of positive divisors.

1. **Understanding the Problem:**
    - A number has an even number of divisors unless it is a perfect square. This is because divisors of a number generally come in pairs, except when the number is a perfect square (e.g., the square root of the number is only counted once, making the total count of divisors odd).
    - So, to solve the problem, we can:
        1. Find all numbers less than 60.
        2. For each number, find its divisors.
        3. Check whether the number of divisors is even.
        4. Count how many such numbers exist.

2. **Implementation Plan:**
    - We will write a Python function to find the number of divisors of a given number.
    - Then, we will iterate through all numbers from 1 to 59, and for each number, we will use the function to determine if it has an even number of divisors.
    - Finally, we will count and return the numbers that meet this condition.

Let's implement this step-by-step in Python:
```python
def count_divisors(n):
    """Return the number of divisors of n."""
    count = 0
    for i in range(1, n + 1):
        if n % i == 0:
            count += 1
    return count

# Now, we need to count how many numbers less than 60 have an even number of divisors
count_even_divisors = 0

for num in range(1, 60):
    if count_divisors(num) % 2 == 0:
        count_even_divisors += 1

print(count_even_divisors)
```
Code execution result: 52

Thus, the number of positive integers less than 60 that have an even number of positive divisors is \(\boxed{52}\). This is our final answer.
