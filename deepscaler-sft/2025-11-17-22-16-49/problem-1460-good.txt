To ensure the result is accurate, let's write a Python code to verify this by squaring all numbers from 0 to 999 (which should cover all possible units digits of perfect squares because beyond 999 the pattern will just repeat as only the last digit affects the units digit of a square) and then collect all distinct units digits of these perfect squares.
```python
def get_units_digits_of_perfect_squares(limit=1000):
    units_digits = set()
    
    for i in range(limit):
        square = i * i
        units_digit = square % 10
        units_digits.add(units_digit)
    
    return units_digits

units_digits = get_units_digits_of_perfect_squares()
distinct_units_digits_count = len(units_digits)
print((distinct_units_digits_count, units_digits))
```
