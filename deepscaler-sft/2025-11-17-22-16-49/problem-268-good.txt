First, let's start by understanding the problem.

1. **Single-digit base-\( b \) numbers:**
   The single-digit numbers in base \( b \) range from 0 to \( b-1 \). However, when we add them, we exclude 0 since we are only considering the non-zero single-digit numbers.

2. **Sum of single-digit base-\( b \) numbers (excluding 0):**
   The numbers we consider are 1 through \( b-1 \). We need to find the sum of these numbers and then compare it with the number \( 34_b \) which is given in base \( b \).

3. **Sum in base 10:**
   The sum of the numbers 1 through \( b-1 \) is the sum of the first \( b-1 \) positive integers, which is given by the formula:
   \[
   \text{Sum} = \frac{(b-1)b}{2}
   \]

4. **Convert \( 34_b \) to base 10:**
   The number \( 34_b \) in base \( b \) can be converted to base 10 as:
   \[
   34_b = 3 \cdot b + 4
   \]

5. **Set up the equation:**
   We equate the sum of the numbers 1 through \( b-1 \) to \( 3 \cdot b + 4 \):
   \[
   \frac{(b-1)b}{2} = 3b + 4
   \]

Let's solve this equation step-by-step by iterating through possible values of \( b \) because solving it directly symbolically might be complex and error-prone. We'll implement it in Python to find the correct value of \( b \).
```python
# We will iterate through possible values of b and check which one satisfies the equation

    for b in range(2, 100):  # We start from 2 because base must be greater than 1 and we pick an upper bound of 100 just for safety.
        lhs = (b - 1) * b / 2  # Left-hand side of the equation: Sum of numbers from 1 to b-1
        rhs = 3 * b + 4         # Right-hand side of the equation: 3b + 4
        
        if lhs == rhs:
            return b

base_b = find_base_b()
```
