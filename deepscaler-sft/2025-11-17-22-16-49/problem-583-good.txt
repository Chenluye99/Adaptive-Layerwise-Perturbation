To solve the problem, we need to add the two given vectors:

\[
\begin{pmatrix} 3 \\ -7 \end{pmatrix} + \begin{pmatrix} -6 \\ 11 \end{pmatrix}
\]

To add two vectors, we add their corresponding components. So, the resulting vector will be:

\[
\begin{pmatrix} 3 + (-6) \\ -7 + 11 \end{pmatrix} = \begin{pmatrix} 3 - 6 \\ -7 + 11 \end{pmatrix} = \begin{pmatrix} -3 \\ 4 \end{pmatrix}
\]

Let's confirm this by implementing it in Python.
```python
import numpy as np

# Define the vectors
vector1 = np.array([3, -7])
vector2 = np.array([-6, 11])

# Add the vectors
result = vector1 + vector2
print(result)
```
Code execution result: [-3  4]

Thus, the result of adding the vectors \(\begin{pmatrix} 3 \\ -7 \end{pmatrix}\) and \(\begin{pmatrix} -6 \\ 11 \end{pmatrix}\) is:

\(\boxed{\begin{pmatrix} -3 \\ 4 \end{pmatrix}}\)
