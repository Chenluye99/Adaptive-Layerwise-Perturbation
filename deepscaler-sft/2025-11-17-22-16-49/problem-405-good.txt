To solve this problem, let's consider the product \( 810 \times 811 \times 812 \times \cdots \times 2010 \) and compare it to \( 810^n \).

1. **Understand the Problem:**
    - We need to find the maximum value of \( n \) such that the expression \(\frac{810 \times 811 \times 812 \times \cdots \times 2010}{810^n}\) is an integer.
    - This means that the product \( 810 \times 811 \times 812 \times \cdots \times 2010 \) must be divisible by \( 810^n \).

2. **Prime Factorization:**
    - First, let's get the prime factorization of 810:
      \[
      810 = 2 \times 3^4 \times 5
      \]
    - To maximize \( n \), we need to determine how many times 810 can divide the product \( 810 \times 811 \times 812 \times \cdots \times 2010 \). This requires counting the powers of 2, 3, and 5 in the factorization of the product and then determining the greatest possible value of \( n \) that respects the prime factorization of 810.

3. **Counting the Powers of 2, 3, and 5 in the Product:**
    - We need to go through each number from 810 to 2010 and count the factors of 2, 3, and 5 in this range.
    - For each number, we will perform the following:
      - Count the number of factors of 2.
      - Count the number of factors of 3.
      - Count the number of factors of 5.

4. **Implementing in Python:**
    - We'll write a Python program to count the powers of 2, 3, and 5 in the product \( 810 \times 811 \times 812 \times \cdots \times 2010 \), and then find the limiting factor for \( n \) based on the prime factorization of 810.

Let's implement this step-by-step in Python.
```python
import sympy

# Initialize counters for the powers of 2, 3, and 5 in the range 810 to 2010
count_2 = 0
count_3 = 0
count_5 = 0

for num in range(810, 2011):
    factorization = sympy.factorint(num)
    for p, exp in factorization.items():
        if p == 2:
            count_2 += exp
        elif p == 3:
            count_3 += exp
        elif p == 5:
            count_5 += exp

# Get the prime factorization of 810
prime_factors_810 = sympy.factorint(810)
factor_2_in_810 = prime_factors_810.get(2, 0)
factor_3_in_810 = prime_factors_810.get(3, 0)
factor_5_in_810 = prime_factors_810.get(5, 0)

# Determine the limiting factor for n
max_n_from_2 = count_2 // factor_2_in_810
max_n_from_3 = count_3 // factor_3_in_810
max_n_from_5 = count_5 // factor_5_in_810

# The maximum value of n is the minimum of these three values because all factors of 810 (2, 3^4, 5) must be fully accounted for
max_n = min(max_n_from_2, max_n_from_3, max_n_from_5)
print(max_n)
```
Code execution result: 150

Thus, the maximum value of \( n \) such that \(\frac{810 \times 811 \times 812 \times \cdots \times 2010}{810^n}\) is an integer is \(\boxed{150}\). This is the final answer.
