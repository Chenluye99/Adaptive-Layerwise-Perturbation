To solve this problem, we need to determine the values of the constants \(a\) and \(b\) for the hyperbola given its properties.

1. **Properties of the Hyperbola:**
    - The foci of the hyperbola are at \((\pm 7, 0)\). For a hyperbola of the form \(\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1\), the foci are located at \((\pm c, 0)\) where \(c = \sqrt{a^2 + b^2}\). Given that the foci are at \((\pm 7, 0)\), we have \(c = 7\), so:
      \[
      c = \sqrt{a^2 + b^2} = 7 \implies a^2 + b^2 = 49.
      \]
    - The hyperbola passes through the point \((2, 12)\). Substituting this point into the equation of the hyperbola, we get:
      \[
      \frac{2^2}{a^2} - \frac{12^2}{b^2} = 1 \implies \frac{4}{a^2} - \frac{144}{b^2} = 1.
      \]

2. **Formulate the System of Equations:**
    - We now have a system of equations:
      \[
      \begin{cases}
      a^2 + b^2 = 49, \\
      \frac{4}{a^2} - \frac{144}{b^2} = 1.
      \end{cases}
      \]
    - We can solve this system of equations by using a substitution or solving iteratively.

Let's implement this step-by-step in Python to obtain accurate results.
```python
import sympy as sp

# Define variables
a, b = sp.symbols('a b', positive=True)

# Define the equations based on the problem statement
eq1 = a**2 + b**2 - 49
eq2 = 4/a**2 - 144/b**2 - 1

# Solve the system of equations
solution = sp.solve([eq1, eq2], (a, b))

print(solution)
```

So, the solution to the system of equations is \((a, b) = \left( \sqrt{7 - 4 \sqrt{3}} \cdot \sqrt{4 \sqrt{3} + 7}, 4 \sqrt{3} \right)\).
