To solve this problem, we need to find an integer \( x \) such that the sum of all its positive factors is 24 and one of its factors is 3.

We can follow these steps:

1. **Define a Function to Get All Factors of an Integer:**
   First, we need a function that will give us all the factors of a given integer \( x \).

2. **Check the Sum of the Factors:**
   For each integer, we get its factors and then check if the sum of these factors is 24.

3. **Check if 3 is a Factor:**
   We also need to ensure that 3 is one of the factors of the integer \( x \).

4. **Iterate and Find the Correct Integer:**
   We can test integers one by one until we find the correct value of \( x \).

Let's implement this step by step in Python.
```python
def get_factors(n):
    """Returns a list of all the factors of n."""
    factors = []
    for i in range(1, n + 1):
        if n % i == 0:
            factors.append(i)
    return factors

# Now, we will iterate through numbers and check the conditions as described

# We will check for values of x and see if they meet the criteria
for x in range(1, 1000):  # Arbitrarily chosen upper limit; can be adjusted if needed
    factors = get_factors(x)
    if sum(factors) == 24 and 3 in factors:
        result = x
        break

print(result)
```
