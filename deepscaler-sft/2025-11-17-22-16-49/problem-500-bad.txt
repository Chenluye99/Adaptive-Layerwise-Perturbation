To solve this problem, we need to find the number of valid sequences of length 19 where:

1. No two adjacent houses get mail on the same day (i.e., no two consecutive positions in the sequence can both be 1).
2. There are never more than two houses in a row that get no mail on the same day (i.e., the sequence should not contain "000" as a subsequence).

We will use a recursive approach to generate all possible sequences and then filter them based on these rules.

### Step-by-Step Plan:

1. **Define the Problem Constraints:**
    - Let `1` represent a house that gets mail on a given day.
    - Let `0` represent a house that does not get mail on a given day.
    - A valid sequence of length 19 must not contain "11" as a subsequence.
    - A valid sequence of length 19 must not contain "000" as a subsequence.

2. **Generate and Check Sequences:**
    - Generate all binary sequences of length 19.
    - Check each sequence to make sure it meets the conditions above.
    - Count how many such sequences exist.

3. **Implement in Python:**
    - We can use Python to implement this check efficiently.

Let's proceed with coding this solution.
```python
import itertools

# We need to check all binary sequences of length 19 and apply the conditions
count = 0

for seq in itertools.product([0, 1], repeat=19):
    seq_str = ''.join(map(str, seq))
    
    # Check if no two adjacent houses get mail on the same day
    if any(seq_str[i] == '1' and seq_str[i + 1] == '1' for i in range(17)):
        continue
    
    # Check if there are never more than two houses in a row that get no mail
    if '000' in seq_str:
        continue
    
    # If both conditions are satisfied, increment the count
    count += 1

print(count)
```
Code execution result: 465

Thus, the number of different patterns of mail delivery that are possible is \(\boxed{465}\). This is our final answer based on the constraints and the code implementation.
