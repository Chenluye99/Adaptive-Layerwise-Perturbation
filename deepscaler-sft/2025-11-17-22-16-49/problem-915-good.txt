To solve the inequality \(3 \le \frac{x}{2x-5} < 8\), we need to solve it step-by-step. This involves solving two separate inequalities: 

1. \(3 \le \frac{x}{2x-5}\)
2. \(\frac{x}{2x-5} < 8\)

### Step 1: Solve \(3 \le \frac{x}{2x-5}\)

First, we need to consider the cases when \(\frac{x}{2x-5} \ge 3\):

\[3 \le \frac{x}{2x-5}.\]

Rewriting this, we get:

\[3 \le \frac{x}{2x-5} \implies 3(2x - 5) \le x \implies 6x - 15 \le x \implies 5x \le 15 \implies x \le 3.\]

However, we need to ensure that the inequality \(\frac{x}{2x-5} \ge 3\) holds and that the denominator \(2x - 5 \neq 0\) (i.e., \(x \neq \frac{5}{2}\)). We also need to check the condition that the fraction is defined and make sure we don't introduce any extraneous solutions by multiplying through.

### Step 2: Solve \(\frac{x}{2x-5} < 8\)

Next, we solve the inequality \(\frac{x}{2x-5} < 8\):

\[\frac{x}{2x-5} < 8 \implies \frac{x}{2x-5} - 8 < 0 \implies \frac{x - 8(2x - 5)}{2x - 5} < 0 \implies \frac{x - 16x + 40}{2x - 5} < 0 \implies \frac{-15x + 40}{2x - 5} < 0 \implies \frac{15x - 40}{2x - 5} > 0.\]

To solve \(\frac{15x - 40}{2x - 5} > 0\), we need to determine the intervals where the expression is positive. The critical points are where the numerator and denominator are zero, i.e., \(15x - 40 = 0 \implies x = \frac{40}{15} = \frac{8}{3}\) and \(2x - 5 = 0 \implies x = \frac{5}{2}\).

We test the intervals determined by these points: \((-\infty, \frac{5}{2}), (\frac{5}{2}, \frac{8}{3}), (\frac{8}{3}, \infty)\).

### Step 3: Combine the Solutions

We need to find the intersection of the solutions to the two inequalities. We will use Python to solve and verify this step-by-step.
```python
import sympy as sp

# Define the variable and the inequalities
x = sp.symbols('x')
ineq1 = 3 <= x / (2 * x - 5)
ineq2 = x / (2 * x - 5) < 8

# Solve the inequalities
sol1 = sp.solve_univariate_inequality(ineq1, x, relational=False)
sol2 = sp.solve_univariate_inequality(ineq2, x, relational=False)

# Find the intersection of the two solutions
solution = sol1.intersect(sol2)
print(solution)
```

So, the solution to the inequality \(3 \le \frac{x}{2x-5} < 8\) is the interval:

\[
\left( \frac{8}{3}, 3 \right]
\]

\(\boxed{\left( \frac{8}{3}, 3 \right]}\)
