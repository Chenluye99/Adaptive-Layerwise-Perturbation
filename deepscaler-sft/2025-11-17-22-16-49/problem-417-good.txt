To solve for the length of \(AB\) in the given right triangle, we will use trigonometric properties and relationships in the triangle.

### Step-by-Step Solution:

1. **Understand the Problem:**
    - We have a right triangle \( \triangle ABC \) with \( \angle BAC = 30^\circ \).
    - \( AC = 18 \).
    - We need to find the length of \( AB \).

2. **Apply Trigonometry:**
    - In a right triangle, \(\tan(\theta) = \frac{\text{opposite}}{\text{adjacent}}\).
    - For \(\angle BAC = 30^\circ\), \(\tan(30^\circ) = \frac{AC}{AB} = \frac{1}{\sqrt{3}}\).
    - So, \(\frac{18}{AB} = \frac{1}{\sqrt{3}} \).

3. **Solve for \( AB \):**
    - Rearrange the equation to solve for \( AB \):
      \[
      AB = 18 \cdot \sqrt{3}
      \]

Let's confirm this by coding the solution to ensure accuracy.
```python
import sympy as sp

# We declare the variables and set up the equation based on the trigonometric relationship
AC = 18
theta = 30  # angle in degrees

# Convert the angle to radians because the trigonometric functions in sympy (and typically in math libraries) use radians
theta_rad = sp.rad(theta)

# Use the tangent function which is opposite / adjacent, in this case, AC / AB = tan(30°)
tan_30 = sp.tan(theta_rad)

# Set up the equation: AC / AB = tan(30°) and solve for AB
AB = AC / tan_30
print(AB)
```
Code execution result: 18*sqrt(3)

Thus, the length of \( AB \) is \(\boxed{18 \sqrt{3}}\). This is our final answer, derived both through reasoning and confirmed by the computation.
