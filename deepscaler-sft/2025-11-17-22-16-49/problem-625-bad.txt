First, we need to determine the remainders when 2018 is divided by each integer from 1 to 1000. The maximum possible remainder for any division is one less than the divisor. So, for each divisor \(d\) in the range from 1 to 1000, we calculate the remainder when 2018 is divided by \(d\), and then keep track of the maximum remainder observed and the divisor that gives this maximum remainder.

We will use Python to carry out this process because it allows us to quickly iterate over the range and find the solution.
```python
# Initialize variables to keep track of the maximum remainder and corresponding divisor
max_remainder = 0
max_divisor = 0

# Loop through each number from 1 to 1000 and get the remainder when 2018 is divided by that number
for d in range(1, 1001):
    remainder = 2018 % d
    if remainder > max_remainder:
        max_remainder = remainder
        max_divisor = d

print((max_remainder, max_divisor))
```
Code execution result: (672, 673)

This means that the maximum remainder obtained when 2018 is divided by an integer between 1 and 1000 is 672, and this remainder is achieved when 2018 is divided by 673.

Thus, the biggest remainder among the thousand remainders is \(\boxed{672}\).
