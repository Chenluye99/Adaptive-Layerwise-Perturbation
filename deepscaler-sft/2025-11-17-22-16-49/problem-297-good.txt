To solve this problem, we need to find the number of 6-digit numbers whose digits are in non-decreasing order, and where 0 cannot be the leading digit. This is equivalent to finding the number of ways to choose 6 digits from the multiset {1, 2, 3, 4, 5, 6, 7, 8, 9} (since 0 is not allowed in the leading position and we need 6 digits).

One efficient way to solve this is by using the "stars and bars" theorem from combinatorics, but it's more straightforward here to use Python to generate and count all valid 6-digit numbers that meet the criteria.

### Steps:

1. **Generate 6-digit numbers**: We will generate all 6-digit numbers, from 100000 to 999999.
2. **Check if digits are in non-decreasing order**: For each number, we will check if its digits, when sorted, remain the same as the original number's digits. This means the digits are in non-decreasing order.
3. **Count valid numbers**: We will count how many such numbers satisfy the condition.

Let's write the Python code to solve this step-by-step.
```python
count = 0

# Loop through all 6-digit numbers
for num in range(100000, 1000000):
    num_str = str(num)
    digits = [int(d) for d in num_str]
    
    # Check if the digits are in non-decreasing order
    if all(digits[i] <= digits[i + 1] for i in range(len(digits) - 1)):
        count += 1

print(count)
```
