Let's denote the number of jellybeans Alex buys by \( n \). The conditions given in the problem can be formulated as follows:

1. Alex wants to buy at least 100 jellybeans, so \( n \geq 100 \).
2. After dividing the jellybeans evenly among 13 people, there should be 11 jellybeans left over. Mathematically, this can be expressed as:
   \[
   n \equiv 11 \pmod{13}
   \]
   This means that when \( n \) is divided by 13, the remainder is 11.

Combining these conditions, we need to find the smallest integer \( n \) that satisfies both \( n \geq 100 \) and \( n \equiv 11 \pmod{13} \).

We can iterate through numbers starting from 100 and check for each number whether it satisfies both conditions. We will use Python to solve this problem by implementing a loop and checking the conditions iteratively.
```python
# Initialize the starting point
n = 100

# Loop until we find the correct number of jellybeans
while True:
    if n % 13 == 11:
        break
    n += 1

print(n)
```
Code execution result: 102

So, the smallest number of jellybeans Alex should buy to meet all of the conditions of the problem is \(\boxed{102}\). This solution was found by iterating from 100 and checking for the condition \( n \equiv 11 \pmod{13} \). When we find that 102 meets this condition, we can be sure that 102 is the correct answer.
