1. Generate all 3-digit numbers.
2. Check which of these numbers are palindromes.
3. From the list of palindromes, check which ones are multiples of 3.
4. Count how many such numbers exist.

Let's implement this step-by-step in Python.
```python
# Step 1: Generate 3-digit numbers and check which of them are palindromes
palindromes = []

for num in range(100, 1000):
    str_num = str(num)
    if str_num == str_num[::-1]:
        palindromes.append(num)

# Step 2: Check which of these palindromes are multiples of 3
palindromes_multiple_of_3 = [num for num in palindromes if num % 3 == 0]

# Step 3: Get the count of such numbers
count_palindromes_multiple_of_3 = len(palindromes_multiple_of_3)

print(count_palindromes_multiple_of_3)
```
