To determine how many diagonals a regular octagon has, we can use a general mathematical formula for finding the number of diagonals in any \( n \)-sided polygon. The formula is:

\[
\text{Number of diagonals} = \frac{n(n-3)}{2}
\]

where \( n \) is the number of sides (or vertices) of the polygon. For an octagon, \( n = 8 \).

Let's substitute \( n = 8 \) into the formula:

\[
\text{Number of diagonals} = \frac{8(8-3)}{2} = \frac{8 \cdot 5}{2} = \frac{40}{2} = 20
\]

We can also verify this by using Python to ensure the result is accurate. We'll write a Python function to confirm this.
```python
# Function to calculate the number of diagonals in an n-sided polygon
def count_diagonals(n):
    return n * (n - 3) // 2

# Calculate the number of diagonals in an octagon (8-sided polygon)
num_diagonals = count_diagonals(8)
print(num_diagonals)
```
Code execution result: 20

Thus, the number of diagonals in a regular octagon is \(\boxed{20}\). This confirms our earlier calculation to be accurate.
