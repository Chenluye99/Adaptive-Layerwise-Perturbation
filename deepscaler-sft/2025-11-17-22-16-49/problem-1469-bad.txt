 To solve this problem, let's start by understanding the conditions for forming a regular $n$-pointed star:

1. **Conditions for Forming a Regular Star Polygon:**
    - A regular $n$-pointed star is formed by connecting every $k$-th point out of $n$ points placed equally around a circle, where $k$ and $n$ are integers, and $1 < k < \frac{n}{2}$.
    - The connecting path must ensure that the resulting figure does not degenerate into a simple polygon (like a polygon or a star with fewer points by connecting different $k$ values).
    - The value of $k$ must be chosen such that the star is a regular star and not a polygon (which would happen if $k = 1$ or $k = \frac{n}{2}$ or any value that would result in a figure that connects all points sequentially or reverses the connection).

2. **Non-Similar Stars Condition:**
    - Two regular $n$-pointed stars are considered the same (or similar) if they can be transformed into each other by rotations or reflections. In terms of the connecting step $k$, two stars are similar if they use the same $k$ or its corresponding complementary $n - k$. This means that if a star is formed by connecting every $k$-th point, there is no other distinct star formed by connecting every $(n - k)$-th point because it would just be a reflection or a rotation of the original star.

3. **Finding Valid $k$ Values:**
    - For a given $n$, we need to find all valid $k$ values such that $\gcd(k, n) = 1$ and $1 < k < \frac{n}{2}$. This means $k$ and $n$ are coprime (no common divisors other than 1) and $k$ must be less than half of $n$ to ensure the star does not degenerate and properly connect to form the star polygon.
    - We can then count the number of such valid $k$ values, because each unique valid $k$ leads to a unique (non-similar) regular $n$-pointed star.

Let's implement this reasoning in Python to get the answer for $n = 1000$.
```python
import math

def count_non_similar_stars(n):
    count = 0
    for k in range(2, n // 2):
        if math.gcd(k, n) == 1:
            count += 1
    return count

# Get the count for 1000-pointed stars
num_non_similar_stars_1000 = count_non_similar_stars(1000)
print(num_non_similar_stars_1000)
```
