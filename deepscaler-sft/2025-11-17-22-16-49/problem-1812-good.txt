First, let's start by finding all the positive whole number divisors of 210. Then, we will sum these divisors.

To find the divisors of 210, we need to check which numbers from 1 to 210 divide 210 without leaving a remainder. After getting the list of all such divisors, we will compute their sum.

Let's implement this step-by-step in Python.
```python
# Initialize the number
n = 210

# Find all divisors of 210
divisors = [i for i in range(1, n + 1) if n % i == 0]

# Calculate the sum of the divisors
sum_of_divisors = sum(divisors)
print((sum_of_divisors, divisors))
```
