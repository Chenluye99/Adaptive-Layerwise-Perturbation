Combining all of these, the full data set is:

Let's proceed by implementing the following steps in Python:
1. Create a list of all the numbers extracted from the stem-and-leaf plot.
2. Find the median of the data set.
3. Find the mode of the data set.
4. Compute the positive difference between the median and the mode.

### Step 1: Create the Data List
We'll create a list based on the given stem-and-leaf plot.

### Step 2: Find the Median
The median is the middle value of a sorted data set. For an odd number of observations, it's the middle number, and for an even number of observations, it's the average of the two middle numbers.

### Step 3: Find the Mode
The mode is the value that appears most frequently in the data set.

### Step 4: Compute the Positive Difference
Finally, we compute the positive difference between the median and the mode.

Let's implement this in Python.
```python
import numpy as np
from scipy import stats

# Step 1: Create the data list from the stem-and-leaf plot
data = [
    12, 13, 14, 15, 15,
    22, 22, 22,
    31, 31, 38, 39,
    40, 41, 42, 43,
    52, 58, 59
]

# Step 2: Find the median
median = np.median(data)

# Step 3: Find the mode
mode = stats.mode(data)[0][0]

# Step 4: Compute the positive difference between the median and the mode
positive_difference = abs(median - mode)

print(((median, mode, positive_difference)))
```
Code execution result: IndexError: invalid index to scalar variable.
It seems there is an error because `stats.mode` returns an object that includes both the mode and its count, and we need to access it properly.

We can resolve this issue by using `collections.Counter` to get the most common element directly. Let's correct and adjust our code to get the mode correctly and then proceed to compute the positive difference between the median and the mode.
```python
import numpy as np
from collections import Counter

# Step 1: Create the data list from the stem-and-leaf plot
data = [
    12, 13, 14, 15, 15,
    22, 22, 22,
    31, 31, 38, 39,
    40, 41, 42, 43,
    52, 58, 59
]

# Step 2: Find the median
median = np.median(data)

# Step 3: Find the mode
# Count the occurrences of each number in the data set
count_dict = Counter(data)
mode = max(count_dict, key=count_dict.get)

# Step 4: Compute the positive difference between the median and the mode
positive_difference = abs(median - mode)

print(((median, mode, positive_difference)))
```
Code execution result: (31.0, 22, 9.0)

So, the median of the data set is \(31.0\) and the mode of the data set is \(22\). The positive difference between the median and the mode is:

\(\boxed{9}\)
