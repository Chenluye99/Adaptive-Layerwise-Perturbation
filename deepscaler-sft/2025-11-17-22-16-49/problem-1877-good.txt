First, let's denote the lengths of the legs of triangle \( \triangle XOY \) as \( OX = a \) and \( OY = b \). The midpoints of the legs \( OX \) and \( OY \) are \( M \) and \( N \), respectively. Therefore, we have:
- \( OM = \frac{a}{2} \)
- \( ON = \frac{b}{2} \)

Given that \( XN = 19 \) and \( YM = 22 \), we can use the Pythagorean theorem in triangles \( \triangle XNO \) and \( \triangle YMO \) to form the following equations:
\[ XN = \sqrt{a^2 + \left( \frac{b}{2} \right)^2} = 19 \]
\[ YM = \sqrt{b^2 + \left( \frac{a}{2} \right)^2} = 22 \]

So we get:
\[ a^2 + \frac{b^2}{4} = 19^2 = 361 \tag{1} \]
\[ b^2 + \frac{a^2}{4} = 22^2 = 484 \tag{2} \]

We need to solve these two equations to find \( a \) and \( b \). After obtaining \( a \) and \( b \), we can find the length of \( XY \) using the Pythagorean theorem in \( \triangle XOY \):
\[ XY = \sqrt{a^2 + b^2} \]

Let's solve the system of equations (1) and (2) using Python.
```python
import sympy as sp

# Define the variables
a, b = sp.symbols('a b', positive=True)

# Define the equations
eq1 = sp.Eq(a**2 + (b**2) / 4, 361)
eq2 = sp.Eq(b**2 + (a**2) / 4, 484)

# Solve the system of equations
solution = sp.solve((eq1, eq2), (a, b))

print(solution)
```
Code execution result: [(16, 2*sqrt(105))]

From solving the system of equations, we get the solutions \( a = 16 \) and \( b = 2 \sqrt{105} \).

Now, we can find the length of \( XY \) using the Pythagorean theorem:
\[ XY = \sqrt{a^2 + b^2} = \sqrt{16^2 + (2 \sqrt{105})^2} = \sqrt{256 + 4 \cdot 105} = \sqrt{256 + 420} = \sqrt{676} = 26 \]

Thus, the length of \( XY \) is \(\boxed{26}\). This is our final answer.
