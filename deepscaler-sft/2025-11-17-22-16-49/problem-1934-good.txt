To solve the problem, we need to find the last two digits of the sum of the factorials of numbers from 5 to 100 that increase by 5 each time (i.e., 5!, 10!, 15!, ..., 100!).

To determine the last two digits of a number, we need to find that number modulo 100. We can calculate each factorial in the range and then sum them up, taking the modulo 100 at each step to keep the numbers manageable.

Let's implement this in Python:

1. Initialize a variable to store the sum.
2. Iterate over the numbers from 5 to 100 in steps of 5.
3. For each number, calculate its factorial.
4. Add the factorial to the sum and take the result modulo 100.
5. After summing all factorials in the range, the result will be the last two digits of the sum of 5! + 10! + 15! + ... + 100!.

Let's write the code to solve this step-by-step:
```python
import math

# Initialize the sum
factorial_sum = 0

# Calculate the sum of the specified factorials and take modulo 100 at each step
for i in range(5, 101, 5):
    factorial = math.factorial(i)
    factorial_sum = (factorial_sum + factorial) % 100

print(factorial_sum)
```
Code execution result: 20

Thus, the last two digits of the sum \( 5! + 10! + 15! + \cdots + 100! \) are \(\boxed{20}\). This is our final answer.
