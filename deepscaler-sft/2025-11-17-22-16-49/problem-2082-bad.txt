First, we need to understand the composition and counting of a standard domino set where both squares of a domino have integers from 0 to 9.

1. **Generating the Set of Dominoes:**
    - A standard domino set composed of tiles with integers from 0 to 9 will have every possible pairing of the numbers 0 through 9.
    - Each number from 0 to 9 will pair with every number from 0 to 9, and order does not matter because (a, b) is the same as (b, a) for a domino.

2. **Forming the Set:**
    - The pairs will range from (0, 0), (0, 1), (0, 2), ..., (0, 9), (1, 1), (1, 2), ..., (1, 9), ..., (9, 9).
    - To avoid repetition and ensure that each distinct pair is considered only once, (a, b) is considered the same as (b, a).

3. **Counting the Dominoes:**
    - We will create a list or a set to store all distinct dominoes.
    - This set will include pairs such as (0, 0), (0, 1), (0, 2), ..., (9, 9).

4. **Identifying Doubles:**
    - A double is a domino with the same integer on both squares, such as (0, 0), (1, 1), (2, 2), ..., (9, 9).

5. **Counting Doubles:**
    - To count the number of doubles, we check which of the pairs have the same number on both sides.

6. **Calculating Probability:**
    - The probability that a randomly selected domino is a double is the number of doubles divided by the total number of dominoes.

Let's go ahead and write Python to get the exact numbers and probability.
```python
# Generate all unique dominoes with numbers from 0 to 9
dominoes = []
for i in range(10):
    for j in range(10):
        dominoes.append((min(i, j), max(i, j)))

# Count the total number of dominoes
total_dominoes = len(dominoes)

# Find all the 'double' dominoes (where both numbers on the domino are the same)
doubles = [(i, i) for i in range(10)]

# Count the number of 'double' dominoes
num_doubles = len(doubles)

# Calculate the probability
probability = num_doubles / total_dominoes

print(((total_dominoes, num_doubles, probability)))
```
Code execution result: (100, 10, 0.1)

This means there are 100 total dominoes, 10 of which are doubles, giving a probability of \(\frac{10}{100} = \frac{1}{10}\).

Thus, the probability that a randomly selected domino from this set is a double is \(\boxed{\frac{1}{10}}\). This is our final answer.
