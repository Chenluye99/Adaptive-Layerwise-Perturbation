First, let's set up the problem.

1. **Define the Objective Function:**
   The function we want to minimize is:
   \[
   f(x, y, z) = \frac{x^2 + y^2}{x + y} + \frac{x^2 + z^2}{x + z} + \frac{y^2 + z^2}{y + z}
   \]

2. **Define the Constraint:**
   The constraint is that \(x + y + z = 6\). We can express this as \(g(x, y, z) = x + y + z - 6 = 0\).

3. **Set Up and Solve the Optimization Problem:**
   Use SciPy's `minimize` function to solve this constrained optimization problem. We will need to ensure that \(x, y, z > 0\), so we set bounds for \(x, y, z\) as `(0, None)`.

```python
import numpy as np
from scipy.optimize import minimize

# Define the objective function
def objective(vars):
    x, y, z = vars
    return (x**2 + y**2) / (x + y) + (x**2 + z**2) / (x + z) + (y**2 + z**2) / (y + z)

# Define the constraint function
def constraint(vars):
    return vars[0] + vars[1] + vars[2] - 6

# Initial guess for x, y, z
initial_guess = [1, 1, 4]

# Define bounds for x, y, z (they must be positive)
bounds = [(0, None), (0, None), (0, None)]

# Define constraints in the form required by `minimize`
con = {'type': 'eq', 'fun': constraint}

# Perform the minimization
solution = minimize(objective, initial_guess, method='SLSQP', bounds=bounds, constraints=[con])

print((solution.x, solution.fun))
```
