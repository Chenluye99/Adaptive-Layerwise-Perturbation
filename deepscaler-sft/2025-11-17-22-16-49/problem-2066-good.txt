To solve the problem, we need to find the common positive divisors of 840, 960, and 1200. We can break this problem down into the following steps:

1. **Find the Divisors of Each Number:**
   - Get the list of all positive divisors for 840.
   - Get the list of all positive divisors for 960.
   - Get the list of all positive divisors for 1200.

2. **Find the Common Divisors:**
   - Find the intersection of the lists of divisors from steps 1a, 1b, and 1c. The intersection will give us the common positive divisors of 840, 960, and 1200.

3. **Count the Common Divisors:**
   - Count the number of elements in the intersection list to get the final answer.

Let's implement this step-by-step plan in Python.
```python
# Step 1: Find the divisors of each number

def get_divisors(n):
    """Return a list of all positive divisors of n."""
    divisors = []
    for i in range(1, n + 1):
        if n % i == 0:
            divisors.append(i)
    return divisors

# Get the divisors for 840, 960, and 1200
divisors_840 = get_divisors(840)
divisors_960 = get_divisors(960)
divisors_1200 = get_divisors(1200)

# Step 2: Find the common divisors
common_divisors = set(divisors_840).intersection(divisors_960, divisors_1200)

# Step 3: Count the common divisors
num_common_divisors = len(common_divisors)

print(num_common_divisors)
```
Code execution result: 16

Thus, the number of positive divisors that 840, 960, and 1200 have in common is \(\boxed{16}\). This is our final answer.
