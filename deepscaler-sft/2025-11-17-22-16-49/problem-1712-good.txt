To solve this system of linear equations, we can use the ` sympy` library in Python. We'll define the variables and the equations, and then solve for the variables \(x\) and \(y\).

The system of equations is:
\[
\begin{align*}
2x - 3y &= -5, \\
5x - 2y &= 4.
\end{align*}
\]

Here is the step-by-step code to solve it:

1. Import `sympy`.
2. Define the variables \(x\) and \(y\).
3. Define the equations.
4. Use `solve` to get the solution for the system of equations.
5. Print the solution.

Let's implement this in Python:
```python
import sympy as sp

# Define the variables
x, y = sp.symbols('x y')

# Define the equations
eq1 = 2*x - 3*y + 5
eq2 = 5*x - 2*y - 4

# Solve the system of equations
solution = sp.solve((eq1, eq2), (x, y))
print(solution)
```
Code execution result: {x: 2, y: 3}

So, the solution to the system of equations is \( (x, y) = (2, 3) \).

We can verify this solution by substituting \( x = 2 \) and \( y = 3 \) back into the original equations to ensure that they are satisfied:

1. For the first equation: \( 2(2) - 3(3) = 4 - 9 = -5 \), which is correct.
2. For the second equation: \( 5(2) - 2(3) = 10 - 6 = 4 \), which is also correct.

Since both equations are satisfied, the solution is correct. Therefore, the final answer is:

\(\boxed{(2, 3)}\)
