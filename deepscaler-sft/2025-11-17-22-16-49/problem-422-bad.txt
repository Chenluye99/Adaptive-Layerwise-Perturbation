### Part 1: Find Angle \( B \)

Given the equation \( c \sin \frac{A + C}{2} = b \sin C \), we can use trigonometric identities and properties of triangles. We know that in any triangle, \( A + B + C = \pi \). So, \( \frac{A + C}{2} = \frac{\pi - B}{2} \).

Thus, the equation becomes:
\[ c \sin \left( \frac{\pi - B}{2} \right) = b \sin C. \]
Since \(\sin \left( \frac{\pi - B}{2} \right) = \cos \frac{B}{2}\), the equation can be rewritten as:
\[ c \cos \frac{B}{2} = b \sin C. \]

Using the Law of Sines, we know that \(\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R\) (where \( R \) is the circumradius of the triangle), so \( c = 2R \sin C \) and \( b = 2R \sin B \). Substituting these into the equation, we get:
\[ 2R \sin C \cdot \cos \frac{B}{2} = 2R \sin B \cdot \sin C. \]
Since \(\sin C \neq 0\) (because \( C \) is an angle in a triangle), we can cancel \(\sin C\) from both sides:
\[ \sin B = \cos \frac{B}{2}. \]

We know that \(\cos \frac{B}{2} = \sin \left( \frac{\pi}{2} - \frac{B}{2} \right)\), so we can set:
\[ \sin B = \sin \left( \frac{\pi}{2} - \frac{B}{2} \right). \]

This implies:
\[ B = \frac{\pi}{2} - \frac{B}{2} + 2k\pi \quad \text{or} \quad B = \pi - \left( \frac{\pi}{2} - \frac{B}{2} \right) + 2k\pi. \]

Considering the range of angles in a triangle (0 to \(\pi\)), the only feasible solution is:
\[ B = \frac{\pi}{2} - \frac{B}{2}, \]
which simplifies to:
\[ \frac{3B}{2} = \frac{\pi}{2}, \]
\[ 3B = \pi, \]
\[ B = \frac{\pi}{3}. \]

We also know that in \(\triangle ABC\), by the Law of Cosines, we have:
