To solve this problem, let's start by understanding the sequence and how it is generated. The sequence starts with 1,000,000 and each subsequent term is obtained by dividing the previous term by 2. We want to find out when this sequence becomes non-integer, and then identify the last integer in this sequence.

Let's generate the sequence and check when a term is no longer an integer by repeatedly dividing by 2. We will use Python to ensure accuracy. 

We'll start with the initial value of 1,000,000 and keep dividing by 2 and check if the result is an integer until we find the last integer in this sequence.
```python
# Initialize the starting value of the sequence
num = 1_000_000

# Create a list to store the sequence
sequence = [num]

# Generate the sequence by repeatedly dividing by 2 and check for integers
while True:
    num = num / 2
    if num % 1 != 0:  # Check if the number is no longer an integer
        break
    sequence.append(int(num))

# The last integer in the sequence is the last element in the list `sequence`
last_integer = sequence[-1]
print(last_integer)
```
Code execution result: 15625

Thus, the last integer in the sequence is \(\boxed{15625}\). This is the correct answer obtained through the process of repeatedly dividing 1,000,000 by 2 and ensuring that each term is an integer until a non-integer is encountered.
