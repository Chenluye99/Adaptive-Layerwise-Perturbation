To solve this problem, we need to use the properties of the angles in a quadrilateral. The sum of the interior angles of a quadrilateral is always \(360^\circ\). Let the measures of \(\angle A, \angle B, \angle C, \angle D\) be denoted as \(A, B, C, D\) respectively.

Given the relationships between the angles:
\[
A = 2B = 3C = 4D,
\]
we can express \(B, C, D\) in terms of \(A\):

1. From \(A = 2B\), we get:
\[
B = \frac{A}{2}.
\]

2. From \(A = 3C\), we get:
\[
C = \frac{A}{3}.
\]

3. From \(A = 4D\), we get:
\[
D = \frac{A}{4}.
\]

Since the sum of the angles in a quadrilateral is \(360^\circ\), we have:
\[
A + B + C + D = 360.
\]

Substitute the expressions for \(B, C, D\) in terms of \(A\) into this equation:
\[
A + \frac{A}{2} + \frac{A}{3} + \frac{A}{4} = 360.
\]

To solve for \(A\), we need to find a common denominator for the fractions. The least common multiple of 2, 3, and 4 is 12, so we rewrite the equation with a common denominator:
\[
A + \frac{6A}{12} + \frac{4A}{12} + \frac{3A}{12} = 360.
\]

Combine the terms on the left side:
\[
A + \frac{6A + 4A + 3A}{12} = 360,
\]
\[
A + \frac{13A}{12} = 360.
\]

Combine the left side into a single fraction:
\[
\frac{12A}{12} + \frac{13A}{12} = 360,
\]
\[
\frac{25A}{12} = 360.
\]

Multiply both sides by 12 to clear the fraction:
\[
25A = 360 \cdot 12,
\]
\[
25A = 4320.
\]

Solve for \(A\):
\[
A = \frac{4320}{25},
\]
\[
A = 172.8.
\]

Rounded to the nearest whole number, we get:
\[
A \approx 173.
\]

Let's confirm this by implementing it in Python to ensure accuracy.
```python
from sympy import symbols, Eq, solve

# Define the variable
A = symbols('A')

# Define the equation based on the relationships and the sum of angles in a quadrilateral
eq = Eq(A + A/2 + A/3 + A/4, 360)

# Solve for A
solution = solve(eq, A)[0]

# Get the solution rounded to the nearest whole number
angle_A_rounded = round(solution)

```
