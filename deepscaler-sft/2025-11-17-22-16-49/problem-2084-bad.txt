\[ c = \sqrt{a^2 + b^2}. \]
So, we want to maximize:
\[ \frac{a + b}{\sqrt{a^2 + b^2}}. \]

To proceed, we can use a parameterization for the right triangle. Without loss of generality, we can set \(a = r \cos \theta\) and \(b = r \sin \theta\) for some \(r > 0\) and \(\theta \in [0, \frac{\pi}{2}]\). Then, the hypotenuse \(c\) is:
\[ c = r \sqrt{\cos^2 \theta + \sin^2 \theta} = r. \]
This means the expression we want to maximize is:
\[ \frac{a + b}{c} = \frac{r \cos \theta + r \sin \theta}{r} = \cos \theta + \sin \theta. \]

To find the maximum value of \(\cos \theta + \sin \theta\), we can use the trigonometric identity:
\[ \cos \theta + \sin \theta = \sqrt{2} \left( \frac{1}{\sqrt{2}} \cos \theta + \frac{1}{\sqrt{2}} \sin \theta \right) = \sqrt{2} \cos \left( \theta - \frac{\pi}{4} \right). \]

This maximum is achieved when \(\cos \left( \theta - \frac{\pi}{4} \right) = 1\), which means \(\theta - \frac{\pi}{4} = 0\) or \(\theta = \frac{\pi}{4}\).
