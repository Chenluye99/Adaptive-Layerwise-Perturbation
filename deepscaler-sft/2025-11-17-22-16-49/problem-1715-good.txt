To solve this problem, we need to follow these steps:

1. **Find all two-digit prime numbers less than 40.**
    - The two-digit prime numbers less than 40 are: 11, 13, 17, 19, 23, 29, 31, 37.

2. **Generate all possible four-digit house numbers.**
    - Each of the two-digit primes found in the previous step can be represented as "AB" and "CD". For a house number "ABCD", both "AB" and "CD" must be one of the two-digit prime numbers less than 40.

3. **Check the conditions.**
    - We need to check if a combination of "AB" and "CD" forms a valid four-digit number "ABCD" where none of the digits "A", "B", "C", "D" are zero.
    - We also need to ensure that "AB" and "CD" are distinct primes (i.e., they should be different even if they have the same digits).

4. **Count the valid house numbers.**
    - We'll iterate through all combinations of the two-digit primes, form the four-digit number, and check if it meets all the conditions. If it does, we count it as a valid house number.

Let's implement this step by step using Python.
```python
import sympy

# Find all two-digit prime numbers less than 40
two_digit_primes = [num for num in range(10, 40) if sympy.isprime(num)]

# Initialize a set to store unique four-digit house numbers that meet the conditions
house_numbers = set()

# Check all combinations of the two-digit primes and form the four-digit number
for prime1 in two_digit_primes:
    for prime2 in two_digit_primes:
        if prime1 != prime2:  # Ensure they are different primes
            str_num1 = f"{prime1:02d}"
            str_num2 = f"{prime2:02d}"
            
            # Combine to form a four-digit number "ABCD"
            house_number = int(str_num1 + str_num2)
            
            # Check that the house number contains no zeroes
            if '0' not in str(house_number):
                house_numbers.add(house_number)

# Get the count of unique valid house numbers
num_possible_house_numbers = len(house_numbers)
print(num_possible_house_numbers)
```
