To find the area of the trapezoid, we start with the formula for the area of a trapezoid:

\[
\text{Area} = \frac{1}{2} \times (\text{Base}_1 + \text{Base}_2) \times \text{Height}
\]

Given:
- One base of the trapezoid, \(\text{Base}_1\), is equal to twice the height, so \(\text{Base}_1 = 2x\).
- The other base of the trapezoid, \(\text{Base}_2\), is three times the height, so \(\text{Base}_2 = 3x\).
- The height of the trapezoid is \(x\).

Now, substitute these values into the formula for the area of the trapezoid:

\[
\text{Area} = \frac{1}{2} \times (2x + 3x) \times x = \frac{1}{2} \times 5x \times x = \frac{1}{2} \times 5x^2 = \frac{5x^2}{2}
\]

So, the expression for the area of the trapezoid in terms of the height \(x\) is \(\frac{5x^2}{2}\).

Let's confirm this by coding it out to ensure the result is accurate.
```python
# Function to calculate the area of the trapezoid
def trapezoid_area(height):
    base1 = 2 * height
    base2 = 3 * height
    return 0.5 * (base1 + base2) * height

# To get the expression in terms of x, we can use a symbolic computation library like SymPy.
import sympy as sp

# Define the variable
x = sp.symbols('x')

# Calculate the area symbolically
area = trapezoid_area(x)
print(area)
```
Code execution result: 2.5*x**2

Thus, the expression for the area of the trapezoid as a common fraction in terms of the height \(x\) is \(\boxed{\frac{5x^2}{2}}\). This confirms our solution is accurate.
