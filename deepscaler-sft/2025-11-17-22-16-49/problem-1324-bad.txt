To calculate the area of the shaded region, we can use the Shoelace formula (also known as Gauss's area formula for polygons). This formula is useful for finding the area of a polygon when given the coordinates of its vertices.

The formula is as follows:

\[
\text{Area} = \frac{1}{2} \left| \sum_{i=1}^{n-1}(x_i y_{i+1} - y_i x_{i+1}) + (x_n y_1 - y_n x_1) \right|
\]

For our polygon with vertices \((0, 0)\), \((0, 2)\), \((3, 2)\), \((3, 3)\), \((7, 3)\), \((7, 4)\), \((12, 4)\), and \((12, 0)\), we can apply this formula.

Let's implement this in Python using the listed vertices.
```python
# List the vertices of the shaded region
vertices = [
    (0, 0),
    (0, 2),
    (3, 2),
    (3, 3),
    (7, 3),
    (7, 4),
    (12, 4),
    (12, 0)
]

# Implementing the Shoelace formula
def shoelace_formula(vertices):
    n = len(vertices)
    sum1 = sum(vertices[i][0] * vertices[(i + 1) % n][1] for i in range(n))
    sum2 = sum(vertices[i][1] * vertices[(i + 1) % n][0] for i in range(n))
    area = abs(sum1 - sum2) / 2
    return area

# Calculate the area
area = shoelace_formula(vertices)
print(area)
```
