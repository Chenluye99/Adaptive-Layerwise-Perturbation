To solve for the residue of \(-998 \pmod{28}\), we need to find an equivalent positive integer between 0 and 27 that represents the same remainder when \(-998\) is divided by 28.

Mathematically, the residue of a number \(a \mod m\) is given by finding the remainder when \(a\) is divided by \(m\). For \(-998 \mod 28\), we can use the following approach:

1. Compute the quotient of \(-998\) divided by \(28\).
2. Use the quotient and the modulus to get the equivalent positive remainder.

We can use Python to compute this directly with the modulus operator `%`, which gives the remainder of a division operation. Let's proceed with this step-by-step process in Python.
```python
# Calculate -998 % 28 to get the residue
residue = -998 % 28
print(residue)
```
Code execution result: 10

Thus, the residue of \(-998 \pmod{28}\) is \(\boxed{10}\). This is our final answer, and it falls within the required range \([0, 1, 2, \ldots, 27]\).
