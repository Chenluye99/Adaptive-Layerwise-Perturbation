To solve this problem, we need to find a number \( n \) that meets the following conditions:

1. \( n < 500 \)
2. When \( n \) is divided by 23, the remainder is 22, so \( n \equiv 22 \pmod{23} \).
3. When \( n \) is divided by 21, the remainder is 14, so \( n \equiv 14 \pmod{21} \).

We can iterate through all numbers less than 500 and check which number satisfies both of these congruences.

Let's write the Python code to solve this step-by-step.
```python
# We will iterate through all numbers less than 500 and check the conditions.

for n in range(500):
    if n % 23 == 22 and n % 21 == 14:
        result = n

print(result)
```
Code execution result: 413

Thus, the number of people in the incoming freshman class is \(\boxed{413}\). This is the value that satisfies all the given conditions.
