To solve the problem, we start with the given conditions for the triangle \( \triangle ABC \):

1. \( b^2 = ac \)
2. \( a^2 - c^2 = ac - bc \)

We need to find the value of \(\frac{c}{b \sin B}\).

First, let's manipulate the second equation:

\[ a^2 - c^2 = ac - bc \]

We can factorize and rearrange this equation:

\[ a^2 - c^2 = (a - c)c - b(c - 0) \]
\[ (a - c)(a + c) = c(a - c) - b(c - 0) \]

Assuming \( a \neq c \), we can divide both sides by \( a - c \):

\[ a + c = c - \frac{b(c - 0)}{a - c} \]

However, a simpler approach is to solve the equation directly. Notice that if we assume \( a = c \), then the equation automatically holds as:

\[ a^2 - c^2 = 0 = ac - bc \]

This seems like a potential solution, but let's explore it more rigorously with Python to ensure there are no other possibilities and solve for angles and sides.

We can use the Law of Cosines and Law of Sines in conjunction with the given conditions. The Law of Sines states:

\[ \frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R \]

where \( R \) is the circumradius of the triangle.

From the given condition \( b^2 = ac \), and substituting \( a = c \) into the second equation \( a^2 - c^2 = ac - bc \), we get:

\[ a^2 - a^2 = a \cdot a - a \cdot c \implies 0 = a^2 - ac \implies a(a - c) = 0 \]

This implies that either \( a = 0 \) or \( a = c \). Since \( a = 0 \) is not valid for a triangle, we have \( a = c \).

Substitute \( a = c \) back into \( b^2 = ac \):

\[ b^2 = a \cdot a = a^2 \implies b = a = c \]

So, the triangle is equilateral, meaning \( a = b = c \) and \(\angle A = \angle B = \angle C = 60^\circ \).

For an equilateral triangle, \(\sin B = \sin 60^\circ = \frac{\sqrt{3}}{2}\). Therefore:

\[ \frac{c}{b \sin B} = \frac{a}{a \cdot \frac{\sqrt{3}}{2}} = \frac{1}{\frac{\sqrt{3}}{2}} = \frac{2}{\sqrt{3}} = \frac{2 \sqrt{3}}{3} \]
