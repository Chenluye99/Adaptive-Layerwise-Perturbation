To solve the given problem, we start by solving the equation:

\[
\frac{4x - 12}{x^2 + 2x - 15} = x + 2.
\]

First, factorize the numerator and the denominator:

- The numerator \(4x - 12\) can be factored as \(4(x - 3)\).
- The denominator \(x^2 + 2x - 15\) can be factored as \((x + 5)(x - 3)\).

So, the equation becomes:

\[
\frac{4(x - 3)}{(x + 5)(x - 3)} = x + 2.
\]

We can cancel the common factor of \(x - 3\) from the numerator and the denominator, but we need to note that \(x \neq 3\) because if \(x = 3\), the denominator would be zero, making the original expression undefined. Thus, we get:

\[
\frac{4}{x + 5} = x + 2.
\]

Next, we solve this equation by cross-multiplying:

\[
4 = (x + 2)(x + 5).
\]

Expanding the right-hand side, we get:

\[
4 = x^2 + 7x + 10.
\]

Rearrange this equation to form a standard quadratic equation:

\[
x^2 + 7x + 10 - 4 = 0 \implies x^2 + 7x + 6 = 0.
\]

We can factorize \(x^2 + 7x + 6\) as:

\[
(x + 6)(x + 1) = 0.
\]

So, the solutions to this equation are:

\[
x = -6 \quad \text{or} \quad x = -1.
\]

These are the potential solutions to our original equation, but we must ensure they do not make any part of the original expression undefined. We previously noted that \(x = 3\) makes the original expression undefined because it makes the denominator zero. Checking our solutions, neither \(-6\) nor \(-1\) is equal to 3, so both are valid solutions. 

Thus, the distinct solutions to the equation are \(p = -1\) and \(q = -6\). Since we are asked to find \(p - q\) with \(p > q\), we have:

\[
p - q = -1 - (-6) = -1 + 6 = 5.
\]

Let's verify this by coding the solution to ensure accuracy.
```python
import sympy as sp

# Define the variable and the equation
x = sp.symbols('x')
equation = (4 * x - 12) / (x**2 + 2 * x - 15) - (x + 2)

# Solve the equation
solutions = sp.solve(equation, x)

# Filter out any extraneous solutions if necessary (though in this case, we should be good as discussed)
print(solutions)
```

This confirms that the solutions to the equation are \( x = -6 \) and \( x = -1 \). As discussed, these are the distinct solutions and they are correct. Therefore, with \( p = -1 \) and \( q = -6 \), the value of \( p - q \) is:

\[
p - q = -1 - (-6) = -1 + 6 = 5.
\]

Thus, the final answer is \(\boxed{5}\). This is our solution, verified through both analytical steps and computational methods.
