To solve this problem, we need to determine the number of ways to distribute 5 cousins into 4 rooms where each room can hold any number of cousins.

This is a combinatorial problem where we seek the number of ways to partition a set of 5 cousins into up to 4 non-empty subsets, and these subsets will correspond to the rooms.

For each of the 5 cousins, there are 4 choices of rooms they can go into. This means each cousin has 4 independent choices, and since these choices are made independently for each of the 5 cousins, the total number of ways to place the 5 cousins into the 4 rooms is given by \(4^5\).

Let's calculate this step-by-step and confirm the result using Python.
```python
# Number of cousins
num_cousins = 5

# Number of rooms
num_rooms = 4

# Calculate the total number of ways to place the cousins into the rooms
total_ways = num_rooms ** num_cousins

print(total_ways)
```
Code execution result: 1024

Thus, the number of different ways to arrange the 5 cousins among the 4 rooms is \(\boxed{1024}\). This is the final answer.
