To solve the problem of finding the least common multiple (LCM) of 36 and 132, we can utilize Python's math library, which provides a function called `math.lcm` (available in Python 3.9 and onwards). If you're using an earlier version of Python, you can use the `math.gcd` function along with a custom implementation to compute the LCM. The relationship between the GCD (Greatest Common Divisor) and LCM of two numbers \(a\) and \(b\) is given by:

\[
\text{LCM}(a, b) = \frac{|a \cdot b|}{\text{GCD}(a, b)}
\]

Let's implement this step-by-step. For clarity and correctness, I'll demonstrate it below using Python 3.9+ with the `math.lcm` function. If needed, I can also provide the implementation using GCD as well.

First, let's import the necessary module and use `math.lcm` directly:
```python
import math

# Given numbers
a = 36
b = 132

# Calculate the LCM using math.lcm function
lcm_result = math.lcm(a, b)
print(lcm_result)
```
Code execution result: 396

Thus, the least common multiple (LCM) of 36 and 132 is \(\boxed{396}\). This concludes the solution based on the `math.lcm` function available in Python 3.9 and onwards. If you need the GCD-based implementation for earlier Python versions or further clarity, let me know!
