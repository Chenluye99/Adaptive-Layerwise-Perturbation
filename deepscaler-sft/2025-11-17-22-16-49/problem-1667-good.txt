The task is to find the chromatic number of this graph, i.e., the minimum number of colors needed to color the graph so that no two adjacent nodes (tiles) share the same color.

Let's implement this step-by-step:

1. **Model the Problem:**
   We need to model the tessellation as a graph where each tile is a node and an edge is drawn between any two nodes that share a side.

2. **Graph Representation:**

3. **Formulate the Graph:**

Let's create a Python script to solve this problem:

```python
import networkx as nx

# Create a function to generate the graph representing the tessellation
def generate_tessellation_graph(num_tiles):
    G = nx.Graph()
    
    # Add nodes representing each tile in the tessellation
    nodes = []
    for i in range(num_tiles):
        nodes.append(i)
    
    G.add_nodes_from(nodes)
    
    # Add edges to the graph based on which tiles share a side
    for i in range(num_tiles - 1):
        G.add_edge(i, i + 1)
    
    return G

# Now, we'll use a reasonable number of tiles to model and then determine the chromatic number of this graph.
num_tiles = 10  # You can increase this number if needed, but 10 should be a good start to capture the periodic pattern in the tessellation.

graph = generate_tessellation_graph(num_tiles)

# Find the chromatic number of the graph
chromatic_number = nx.coloring.greedy_color(graph, strategy="largest_first")
num_colors_needed = max(chromatic_number.values()) + 1

print(num_colors_needed)
```
