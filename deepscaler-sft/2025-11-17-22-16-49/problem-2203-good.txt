To solve for \(\sin 120^\circ\), we can use the properties of trigonometric functions. Specifically, we know that \(120^\circ\) is an angle in the second quadrant. The reference angle for \(120^\circ\) is \(180^\circ - 120^\circ = 60^\circ\). Trigonometrically, in the second quadrant, the sine function is positive, so \(\sin 120^\circ = \sin 60^\circ\).

We know from trigonometric values of special angles that \(\sin 60^\circ = \frac{\sqrt{3}}{2}\). Therefore, \(\sin 120^\circ = \frac{\sqrt{3}}{2}\).

Let's confirm this by using Python to compute it directly.
```python
import math

# Convert degrees to radians because math.sin function expects the angle in radians
angle_degrees = 120
angle_radians = math.radians(angle_degrees)

# Compute the sine of 120 degrees
sin_120 = math.sin(angle_radians)
print(sin_120)
```
Code execution result: 0.8660254037844387

We know that \(\frac{\sqrt{3}}{2} \approx 0.8660254037844386\), so the result from the Python code confirms our analytical solution.

Thus, the final answer is:
\(\boxed{\frac{\sqrt{3}}{2}}\)
