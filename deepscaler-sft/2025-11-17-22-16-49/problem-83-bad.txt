To solve this problem, we need to find all four-digit numbers \( abcd \) such that:

1. \( a \neq 0 \) (so that \( ab, bc, cd \) are two-digit numbers).
2. The three two-digit integers \( ab, bc, cd \) form an increasing arithmetic sequence. This means that the difference between consecutive terms in the sequence is the same, i.e., \( bc - ab = cd - bc \).

Mathematically, if the two-digit numbers are represented as integers, then:
\[ bc = 10b + c \]
\[ ab = 10a + b \]
\[ cd = 10c + d \]
So, the condition \( bc - ab = cd - bc \) translates to:
\[ (10b + c) - (10a + b) = (10c + d) - (10b + c) \]
Simplifying the left and right sides, we get:
\[ 9b - 10a + c = 9c - 10b + d \]
Rearranging terms, we get:
\[ 9b + 10b + c - c = 9c + d + 10a \]
\[ 19b = 9c + d + 10a \]
So, we have:
\[ 19b = 9c + d + 10a \]
This equation must hold for \( a, b, c, d \) being digits (with \( a \) ranging from 1 to 9 and \( b, c, d \) ranging from 0 to 9).

We will iterate over all possible values of \( a, b, c, d \) and check if this equation holds, and also ensure that \( ab < bc < cd \).

Let's write the Python code to find all such four-digit numbers:
```python
count = 0

for a in range(1, 10):
    for b in range(0, 10):
        for c in range(0, 10):
            for d in range(0, 10):
                ab = 10 * a + b
                bc = 10 * b + c
                cd = 10 * c + d
                
                if ab < bc < cd:
                    if 19 * b == 9 * c + d + 10 * a:
                        count += 1

print(count)
```
