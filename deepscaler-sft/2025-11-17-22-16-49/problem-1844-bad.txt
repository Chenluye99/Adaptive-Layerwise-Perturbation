First, let's determine the cost per dozen for the apples. Anna Lisa bought two dozen apples for \$15.60, so the cost per dozen can be calculated as:

\[
\text{Cost per dozen} = \frac{15.60}{2}
\]

Once we have the cost per dozen, we can find out how much three dozen apples would cost by multiplying the cost per dozen by 3:

\[
\text{Cost of three dozen apples} = \text{Cost per dozen} \times 3
\]

Let's calculate this step-by-step using Python to ensure accuracy.
```python
# Given data
cost_for_two_dozens = 15.60
number_of_dozens_bought = 2

# Calculate the cost per dozen
cost_per_dozen = cost_for_two_dozens / number_of_dozens_bought

# Calculate the cost for three dozen apples
number_of_dozens_required = 3
cost_for_three_dozens = cost_per_dozen * number_of_dozens_required
print(cost_for_three_dozens)
```
