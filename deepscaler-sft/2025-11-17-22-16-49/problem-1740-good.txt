First, let's start by understanding the problem. We want to convert the number \(0.72\overline{6}\) (where 6 is repeating) into a fraction.

1. Let's denote the number by \( x \):
   \[
   x = 0.72\overline{6}
   \]

2. To eliminate the repeating part, we can manipulate \( x \) by multiplying it by appropriate powers of 10. First, multiply \( x \) by 100 to shift the decimal point two places to the right (to get rid of the non-repeating part up to the start of the repeating part):
   \[
   100x = 72.\overline{6}
   \]
   
3. Next, we multiply \( x \) by 1000 to shift the decimal point three places to the right (to get a point where we can easily subtract and eliminate the repeating part):
   \[
   1000x = 726.\overline{6}
   \]
   
4. Now, we can subtract the first equation from the second to eliminate the repeating part:
   \[
   1000x - 100x = 726.\overline{6} - 72.\overline{6}
   \]
   \[
   900x = 654
   \]
   \[
   x = \frac{654}{900}
   \]

5. We can simplify the fraction \(\frac{654}{900}\) by finding the greatest common divisor (GCD) of 654 and 900. Let's calculate the GCD and simplify the fraction using Python.
```python
import math

# Define the numerator and the denominator
numerator = 654
denominator = 900

# Find the greatest common divisor (GCD)
gcd = math.gcd(numerator, denominator)

# Simplify the fraction
simplified_numerator = numerator // gcd
simplified_denominator = denominator // gcd

simplified_fraction = (simplified_numerator, simplified_denominator)
print(simplified_fraction)
```
