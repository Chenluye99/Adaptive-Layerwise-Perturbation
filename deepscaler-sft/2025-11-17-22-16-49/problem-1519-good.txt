To determine the values of \( k \) so that the domain of the function
\[ b(x) = \frac{kx^2 + 2x - 5}{-5x^2 + 2x + k} \]
is the set of all real numbers, we need to ensure that the denominator of the function is never zero for any real number \( x \). In other words, the quadratic equation \(-5x^2 + 2x + k = 0\) should have no real roots.

A quadratic equation \( ax^2 + bx + c = 0 \) has no real roots if its discriminant is less than zero. The discriminant \(\Delta\) of a quadratic equation \( ax^2 + bx + c = 0 \) is given by:
\[ \Delta = b^2 - 4ac \]

For the quadratic equation \(-5x^2 + 2x + k = 0\), we have:
\[ a = -5, \quad b = 2, \quad c = k \]

So, the discriminant of \(-5x^2 + 2x + k = 0\) is:
\[ \Delta = 2^2 - 4(-5)k = 4 + 20k \]

For the quadratic equation to have no real roots, we need:
\[ \Delta < 0 \]
\[ 4 + 20k < 0 \]
\[ 20k < -4 \]
\[ k < -\frac{1}{5} \]

Thus, the values of \( k \) that ensure the domain of \( b(x) \) is all real numbers are \( k < -\frac{1}{5} \). We will confirm this by coding a small check in Python to ensure correctness.
```python
import sympy as sp

# Define the variable and the quadratic equation
x, k = sp.symbols('x k')
quadratic_eq = -5 * x**2 + 2 * x + k

# Find the discriminant of the quadratic equation
discriminant = sp.discriminant(quadratic_eq, x)

# Solve the inequality discriminant < 0
solution = sp.solve(discriminant < 0, k)
print(solution)
```
