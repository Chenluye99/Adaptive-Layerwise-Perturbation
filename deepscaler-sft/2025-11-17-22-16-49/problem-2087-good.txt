First, let's express the problem mathematically. 

We want to determine how many positive integers \( n \) make the sum of the first \( n \) positive integers, which is given by the formula:
\[ S = \frac{n(n + 1)}{2} \]
divisible evenly by \( 6n \). This means that:
\[ \frac{6n}{\frac{n(n + 1)}{2}} = \frac{12n}{n(n + 1)} = \frac{12}{n + 1} \]
must be an integer. This implies that \( n + 1 \) must be a divisor of 12.

We start by listing the divisors of 12, which are: 1, 2, 3, 4, 6, 12. For each divisor \( d \), we set \( n + 1 = d \), and solve for \( n \):
\[ n = d - 1. \]

Therefore, \( n \) must be one of the values \( 0, 1, 2, 3, 5, 11 \). Since \( n \) is a positive integer, we exclude 0, leaving us with: 1, 2, 3, 5, 11. We need to check if these values of \( n \) actually satisfy our original condition.

We will use Python to verify this.
```python
# We will iterate through the positive integers and check the condition for each n
count = 0

for n in range(1, 1000):  # We choose an upper limit of 1000 to be reasonably sure we capture all possibilities
    sum_first_n = n * (n + 1) // 2
    if 6 * n % sum_first_n == 0:
        count += 1

print(count)
```
Code execution result: 5

Thus, the number of positive integers \( n \) that satisfy the condition is \(\boxed{5}\). This is confirmed by checking each value of \( n \) up to a reasonable upper limit (in this case, 1000) and verifying that the condition holds for 5 distinct values of \( n \).
