To solve this problem, we need to use the pigeonhole principle. First, let's determine the possible sums when three six-sided dice are rolled.

1. The minimum sum you can get by rolling three six-sided dice is \(1 + 1 + 1 = 3\).
2. The maximum sum you can get is \(6 + 6 + 6 = 18\).

So, the possible sums range from 3 to 18, inclusive. This gives us a total of \(18 - 3 + 1 = 16\) different possible sums.

By the pigeonhole principle, if we roll the dice 17 times, it is possible (though not guaranteed) that each of the 16 possible sums appears exactly once. However, if we roll the dice 18 times, at least one of the sums must repeat because we would have more rolls (18) than possible distinct sums (16).

Thus, the minimum number of times we must throw three fair six-sided dice to ensure that the same sum is rolled twice is 17 + 1 = 18. Let's write this conclusion as Python code to ensure our reasoning is accurate and print the result.
```python
# Let's create a function to get all possible sums from rolling three six-sided dice and confirm our reasoning.

    possible_sums = []
    for i in range(1, 7):
        for j in range(1, 7):
            for k in range(1, 7):
                possible_sums.append(i + j + k)
    return sorted(set(possible_sums))

# Get all distinct possible sums
distinct_sums = get_all_possible_sums()

# Number of distinct possible sums
num_distinct_sums = len(distinct_sums)
```
