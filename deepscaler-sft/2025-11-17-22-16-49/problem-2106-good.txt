To solve the problem, we need to determine how many solutions the equation $\sin x = \sin nx$ has on the interval $[0, \pi]$ for an integer $n > 1$. Then, we will sum these counts from $n=2$ to $n=2007$.

### Step-by-Step Solution:

1. **Understand the Equation $\sin x = \sin nx$:**
    - The equation $\sin x = \sin nx$ holds if and only if $nx = x + 2k\pi$ or $nx = \pi - x + 2k\pi$ for some integer $k$.
    - Simplifying the first case: $nx = x + 2k\pi \implies (n-1)x = 2k\pi \implies x = \frac{2k\pi}{n-1}$.
    - Simplifying the second case: $nx = \pi - x + 2k\pi \implies (n+1)x = (2k+1)\pi \implies x = \frac{(2k+1)\pi}{n+1}$.

2. **Find Solutions in the Interval $[0, \pi]$:**
    - For $x = \frac{2k\pi}{n-1}$, we need $0 \leq \frac{2k\pi}{n-1} \leq \pi$, which simplifies to $0 \leq \frac{2k}{n-1} \leq 1$ and thus $0 \leq k \leq \frac{n-1}{2}$.
    - For $x = \frac{(2k+1)\pi}{n+1}$, we need $0 \leq \frac{(2k+1)\pi}{n+1} \leq \pi$, which simplifies to $0 \leq \frac{2k+1}{n+1} \leq 1$ and thus $0 \leq 2k+1 \leq n+1$, which means $0 \leq k \leq \frac{n}{2}$.

3. **Count the Solutions for Each $n$:**
    - For each $n$, we need to count all valid integers $k$ that fit into the ranges determined above.
    - We can use Python to iterate through each $n$ from 2 to 2007, compute the valid $k$ values for both cases, and sum the counts to get $F(n)$.

4. **Sum $F(n)$ from $n=2$ to $n=2007$:**
    - Once we have the function to determine $F(n)$, we can sum it up for all $n$ from 2 to 2007.

Let's implement this step-by-step in Python:
```python
import numpy as np

def count_solutions(n):
    count = 0
    
    # Count solutions of the form x = 2kπ / (n - 1)
    for k in range((n - 1) // 2 + 1):
        x = (2 * k * np.pi) / (n - 1)
        if 0 <= x <= np.pi:
            count += 1
    
    # Count solutions of the form x = (2k + 1)π / (n + 1)
    for k in range((n) // 2 + 1):
        x = ((2 * k + 1) * np.pi) / (n + 1)
        if 0 <= x <= np.pi:
            count += 1
    
    return count

# Now, compute the sum of F(n) for n from 2 to 2007
F_n_sum = sum(count_solutions(n) for n in range(2, 2008))
```
