To solve this problem, let's start with setting up the system of equations:

\[
\begin{align*}
2ax + 2y &= b, \\
5x + y &= -3.
\end{align*}
\]

We need to determine the values of \(a\) and \(b\) such that this system has infinitely many solutions. For a system of linear equations to have infinitely many solutions, the equations must be dependent, meaning one equation is a scalar multiple of the other.

First, let's express the system in a more comparable form. We can solve the second equation for \(y\):

\[ y = -3 - 5x. \]

Next, substitute this expression for \(y\) into the first equation:

\[ 2ax + 2(-3 - 5x) = b. \]

Simplifying the left side, we get:

\[ 2ax - 6 - 10x = b, \]
\[ 2ax - 10x - 6 = b, \]
\[ (2a - 10)x - 6 = b. \]

For this equation to hold for all \(x\), the coefficient of \(x\) must be zero (otherwise, it would not be true for all values of \(x\)), and the constant term must also match up. Therefore, we get two conditions:

1. \(2a - 10 = 0\),
2. \(-6 = b\).

First, solve the first condition for \(a\):

\[ 2a - 10 = 0, \]
\[ 2a = 10, \]
\[ a = 5. \]

Next, the second condition gives us:

\[ b = -6. \]

So, the ordered pair \((a, b)\) that makes the system have infinitely many solutions is \((5, -6)\).

Let's verify this solution by plugging \(a = 5\) and \(b = -6\) back into the original system and check if it results in dependent equations.

The system becomes:

\[
\begin{align*}
2(5)x + 2y &= -6, \\
5x + y &= -3,
\end{align*}
\]

which simplifies to:

\[
\begin{align*}
10x + 2y &= -6, \\
5x + y &= -3.
\end{align*}
\]

We can see that the first equation is exactly 2 times the second equation:

\[ 10x + 2y = 2(5x + y) = 2(-6) = -12/2 = -6. \]

This confirms that the two equations are indeed dependent, meaning they represent the same line, and thus the system has infinitely many solutions when \((a, b) = (5, -6)\).

So, the final answer is \(\boxed{(5, -6)}\). Let's confirm this by coding the solution as well.

import sympy as sp

# Define the variables
a, b, x, y = sp.symbols('a b x y')

# Define the system of equations
eq1 = 2*a*x + 2*y - b

# Find the conditions for the system to have infinitely many solutions, i.e., the system should be consistent and dependent
solution = sp.solve([sp.diff(eq1, x), sp.diff(eq1, y), sp.Eq(eq1, 0), sp.Eq(eq2, 0)], (a, b))
