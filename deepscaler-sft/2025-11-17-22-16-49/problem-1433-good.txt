To solve the problem, we need to convert the weight Alice wants to buy from pounds to kilograms. 

1. Alice wants to buy 3 pounds of veal.
2. We know that 1 kilogram is equal to 2.20 pounds.
3. To find out how many kilograms correspond to 3 pounds, we can use the conversion factor:

\[
\text{Weight in kg} = \frac{\text{Weight in pounds}}{\text{Pounds per kilogram}}
\]

Substituting the given values:

\[
\text{Weight in kg} = \frac{3 \text{ pounds}}{2.20 \text{ pounds/kg}}
\]

Let's calculate this using Python to ensure accuracy, and we'll round the result to the nearest hundredth.
```python
# Given values
weight_in_pounds = 3
pounds_per_kilogram = 2.20

# Convert weight from pounds to kilograms
weight_in_kilograms = weight_in_pounds / pounds_per_kilogram

# Round the result to the nearest hundredth
weight_in_kilograms_rounded = round(weight_in_kilograms, 2)
print(weight_in_kilograms_rounded)
```
Code execution result: 1.36

Thus, Alice should buy \(\boxed{1.36}\) kilograms of veal. This is the final answer.
