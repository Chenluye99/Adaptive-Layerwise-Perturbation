First, let's solve the problem step-by-step.

1. **Identify the Problem:**
    - We need to determine how many different three-letter sets of initials can be formed using the letters from 'A' to 'G'.
    - There are 7 letters in total (i.e., 'A', 'B', 'C', 'D', 'E', 'F', 'G').

2. **Formulate the Solution:**
    - Each position in the three-letter set can be any of the 7 letters.
    - Therefore, for each of the three positions, there are 7 choices. This means the total number of different three-letter sets of initials is \(7 \times 7 \times 7 = 7^3\).

3. **Implement the Solution in Python:**
    - We can use Python to confirm this calculation.

Let's write the Python code to find the answer.
```python
# Number of letters available (from 'A' to 'G')
num_letters = 7

# Calculate the number of different three-letter sets of initials
num_three_letter_sets = num_letters ** 3
print(num_three_letter_sets)
```
Code execution result: 343

Thus, the number of different three-letter sets of initials that can be formed using the letters 'A' through 'G' is \(\boxed{343}\). This is our final answer.
