To solve this problem, we need to distribute the total profit of $26,000 among the four partners according to the given ratio 2:3:3:5. 

1. **Understand the Ratio and Total Parts:**
    - The ratio is 2:3:3:5.
    - This means that the total number of parts the profit is divided into is \(2 + 3 + 3 + 5 = 13\).
    - Each part of the ratio would be equal to \(\frac{26000}{13}\).

2. **Calculate Each Partner's Share:**
    - The first partner gets \(2 \times \frac{26000}{13}\).
    - The second partner gets \(3 \times \frac{26000}{13}\).
    - The third partner gets \(3 \times \frac{26000}{13}\).
    - The fourth partner gets \(5 \times \frac{26000}{13}\).

3. **Determine the Largest Share:**
    - We need to compare these values and identify the largest one.

Let's implement this step-by-step calculation in Python to ensure accuracy.
```python
# Given data
total_profit = 26000
ratio = [2, 3, 3, 5]

# Calculate the value of one part of the ratio
value_per_part = total_profit / sum(ratio)

# Calculate each partner's share
shares = [part * value_per_part for part in ratio]

# Find the maximum share
max_share = max(shares)
print(max_share)
```
Code execution result: 10000.0

Thus, the largest number of dollars received by any of the four partners is \(\boxed{10000}\). This is obtained by computing that the fourth partner, who receives 5 parts of the ratio, gets \(5 \times \frac{26000}{13} = 10000\) dollars.
