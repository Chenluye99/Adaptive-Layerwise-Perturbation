To solve the given problem, we need to find the largest constant \( c > 0 \) such that for every positive integer \( n \ge 2 \), there always exists a positive divisor \( d \) of \( n \) satisfying:

1. \( d \le \sqrt{n} \)
2. \( \tau(d) \ge c \sqrt{\tau(n)} \)

where \(\tau(n)\) is the number of divisors of \(n\).

### Steps to solve the problem:

1. **Define the Function \(\tau(n)\):**
   The function \(\tau(n)\) returns the number of divisors of \(n\). We can define this function in Python to use later.

2. **Check for the Condition:**
   For each positive integer \( n \ge 2 \), we need to check if there exists a divisor \( d \) of \( n \) that satisfies both conditions. We will iterate through all divisors of \( n \) and check if they meet the conditions.

3. **Determine the Largest Possible \( c \):**
   We will test different values of \( c \) starting from 1, and reduce it if necessary, checking if for every \( n \), we can always find a suitable divisor \( d \).

### Implementation in Python

Let's start by defining the function to compute \(\tau(n)\), and then check for the condition for various values of \( c \). We'll start with a reasonable guess for \( c \) and iterate to find the largest possible value that works for all \( n \ge 2 \).

First, let's define \(\tau(n)\) and a function to check for the conditions on \( c \).
```python
import math

def number_of_divisors(n):
    count = 0
    for i in range(1, int(math.sqrt(n)) + 1):
        if n % i == 0:
            if i * i == n:
                count += 1
            else:
                count += 2
    return count

def find_largest_c():
    # We will start checking from c = 0.99 and go downwards until we find the largest possible c.
    c = 0.99
    while True:
        works = True
        for n in range(2, 1000000):  # Check for a sufficiently large range of n
            tau_n = number_of_divisors(n)
            if tau_n == 0:
                continue  # Skip if n has no divisors, which shouldn't happen for n >= 2
            
            found = False
            for d in range(1, int(math.sqrt(n)) + 1):
                if n % d == 0:
                    tau_d = number_of_divisors(d)
                    if tau_d >= c * math.sqrt(tau_n):
                        found = True
                        break
            
            if not found:
                works = False
                break
        
        if works:
            # If we found that for this c, all tested n up to 1,000,000 satisfy the condition, let's check with a slightly smaller c
            c_test = (c + 0.98) / 2
            works_with_new_c = True
            for n in range(2, 1000000):
                tau_n = number_of_divisors(n)
                if tau_n == 0:
                    continue
                
                found = False
                for d in range(1, int(math.sqrt(n)) + 1):
                    if n % d == 0:
                        tau_d = number_of_divisors(d)
                        if tau_d >= c_test * math.sqrt(tau_n):
                            found = True
                            break
                
                if not found:
                    works_with_new_c = False
                    break
            
            if works_with_new_c:
                return c
            else:
                c = c_test
        else:
            return c - 0.0001  # Return the previous value of c as the largest that works

largest_c = find_largest_c()
print(largest_c)
```
