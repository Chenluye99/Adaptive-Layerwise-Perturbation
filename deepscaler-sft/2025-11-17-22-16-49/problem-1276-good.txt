### Step-by-Step Solution:

1. **Understand the Problem:**
    - We need to find the largest \(\lambda\) such that \(\lambda xy + yz \le \frac{\sqrt{5}}{2}\) holds for all \(x, y, z\) that satisfy \(x^2 + y^2 + z^2 = 1\).
    - To solve this, we can search for critical values of \(\lambda\) by testing some boundary conditions or specific values of \(x, y, z\) under the constraint \(x^2 + y^2 + z^2 = 1\).

2. **Formulate a Plan:**
    - We will use symbolic computation with Python and SymPy to solve this problem.
    - We can use Lagrange multipliers to solve the constrained optimization problem: find the maximum value of \(\lambda xy + yz\) under the constraint \(x^2 + y^2 + z^2 = 1\), and then ensure that the maximum value is less than or equal to \(\frac{\sqrt{5}}{2}\).

3. **Implementation in Python with SymPy:**
    - Set up the Lagrange function: \(\mathcal{L} = \lambda xy + yz + \mu (1 - x^2 - y^2 - z^2)\).
    - Take the partial derivatives of \(\mathcal{L}\) with respect to \(x, y, z, \mu\) and set them to zero to get the critical points.

Let's implement this step-by-step in Python using SymPy.

```python
import sympy as sp

# Define the variables
x, y, z, lam, mu = sp.symbols('x y z lam mu', real=True, positive=True)

# Define the function to maximize and the constraint
f = lam * x * y + y * z
g = x**2 + y**2 + z**2 - 1

# Set up the Lagrange function
L = f - mu * g

# Take the partial derivatives of L with respect to x, y, z, and mu, and set them to 0
partial_x = sp.diff(L, x)
partial_y = sp.diff(L, y)
partial_z = sp.diff(L, z)
partial_mu = sp.diff(L, mu)

# Solve the system of equations given by setting the partial derivatives to 0
solutions = sp.solve([partial_x, partial_y, partial_z, partial_mu], (x, y, z, mu), dict=True)

# Find the critical points and evaluate the expression lam * x * y + y * z at these points
max_value = 0
for sol in solutions:
    if all(val >= 0 for val in sol.values()):  # Ensure that x, y, z are non-negative
        xy_value = sol[x] * sol[y]
        yz_value = sol[y] * sol[z]
        expr_value = lam * xy_value + yz_value
        if expr_value > max_value:
            max_value = expr_value

# We know that this maximum value must be less than or equal to sqrt(5)/2. So, we solve for lambda in the equation max_value = sqrt(5)/2.
lambda_max = sp.solve(max_value - sp.sqrt(5) / 2, lam)[0]
print(lambda_max)
```
