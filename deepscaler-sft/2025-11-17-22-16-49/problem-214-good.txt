To solve the problem, we need to find the slope of the tangent line to the curve \( y = \frac{1}{2}x^2 + 2 \) at the point \((-1, \frac{5}{2})\).

1. **Find the Derivative:**
   The slope of the tangent line to a curve at a given point is given by the derivative of the function evaluated at that point. The derivative of \( y = \frac{1}{2}x^2 + 2 \) is:
   \[
   \frac{dy}{dx} = \frac{d}{dx}\left(\frac{1}{2}x^2 + 2\right) = x
   \]

2. **Evaluate the Derivative at the Point:**
   To get the slope of the tangent line at the point \((-1, \frac{5}{2})\), we substitute \( x = -1 \) into the derivative:
   \[
   \left. \frac{dy}{dx} \right|_{x = -1} = -1
   \]

3. **Find the Angle of the Tangent Line:**
   The slope of a line is the tangent of the angle it makes with the positive \(x\)-axis. So, if the slope of the tangent line is \( m \), then the angle of inclination \(\theta\) is given by:
   \[
   \tan(\theta) = m
   \]
   Since the slope of the tangent line at the point \((-1, \frac{5}{2})\) is \(-1\), we have:
   \[
   \tan(\theta) = -1
   \]
   Therefore, the angle \(\theta\) is:
   \[
   \theta = \arctan(-1)
   \]
   We know that \(\arctan(-1) = -\frac{\pi}{4}\) or \(\frac{3\pi}{4}\) depending on the context. However, angles for tangent lines are usually taken from the positive \(x\)-axis, where angles are measured in the standard position, and typically we use the angle in the range \([0, \pi)\). So we take \(\theta = \frac{3\pi}{4}\).

Let's confirm this by implementing it in Python using sympy:

```python
import sympy as sp

# Define the variables and function
x = sp.symbols('x')
y = (1/2)*x**2 + 2

# Find the derivative of the function
dy_dx = sp.diff(y, x)

# Evaluate the derivative at the point x = -1
slope_at_point = dy_dx.subs(x, -1)

# Find the angle of inclination
angle = sp.atan(slope_at_point)

print(angle)
```
Code execution result: -0.785398163397448

The result \(-0.785398163397448\) is equivalent to \(-\frac{\pi}{4}\). However, as mentioned, angles of inclination are usually preferred to be in the standard range \([0, \pi)\).

To get the corresponding angle in the range \([0, \pi)\), we add \(\pi\) to \(-\frac{\pi}{4}\):

\[
\theta = \pi - \frac{\pi}{4} = \frac{4\pi}{4} - \frac{\pi}{4} = \frac{3\pi}{4}
\]

Thus, the angle of the tangent line to the curve \( y = \frac{1}{2}x^2 + 2 \) at the point \((-1, \frac{5}{2})\) is \(\frac{3\pi}{4}\).

So, the final answer is:
\(\boxed{\frac{3\pi}{4}}\)
