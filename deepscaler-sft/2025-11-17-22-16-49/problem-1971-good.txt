To solve this problem, we need to find the integers \( n \) that satisfy the equation:

\[ 1 + \left\lfloor \frac{100n}{101} \right\rfloor = \left\lceil \frac{99n}{100} \right\rceil. \]

Let's break it down step-by-step:

1. **Set Up the Equation:**
    - The left side of the equation is \( 1 + \left\lfloor \frac{100n}{101} \right\rfloor \).
    - The right side of the equation is \( \left\lceil \frac{99n}{100} \right\rceil \).

2. **Understand the Floor and Ceiling Functions:**
    - The expression \( \left\lfloor \frac{100n}{101} \right\rfloor \) gives the greatest integer less than or equal to \( \frac{100n}{101} \).
    - The expression \( \left\lceil \frac{99n}{100} \right\rceil \) gives the smallest integer greater than or equal to \( \frac{99n}{100} \).

3. **Set Up the Inequalities:**
    - Let \( k = \left\lfloor \frac{100n}{101} \right\rfloor \). Then, the left side of the equation becomes \( 1 + k \).
    - For \( k = \left\lfloor \frac{100n}{101} \right\rfloor \), we have:
      \[
      k \leq \frac{100n}{101} < k + 1.
      \]
      Multiplying through by 101, we get:
      \[
      101k \leq 100n < 101(k + 1).
      \]
      Which simplifies to:
      \[
      101k \leq 100n < 101k + 101.
      \]
    - For \( \left\lceil \frac{99n}{100} \right\rceil = 1 + k \), we have:
      \[
      1 + k - 1 < \frac{99n}{100} \leq 1 + k.
      \]
      This simplifies to:
      \[
      k < \frac{99n}{100} \leq k + 1.
      \]
      Multiplying through by 100, we get:
      \[
      100k < 99n \leq 100(k + 1).
      \]
      Which simplifies to:
      \[
      100k < 99n \leq 100k + 100.
      \]

4. **Set Up a Loop to Check for Valid Integers:**
    - We need to check for integers \( n \) that satisfy both sets of inequalities for some integer \( k \).
    - We will iterate through a reasonable range of \( n \) values and check for each \( n \) if the equation holds.

Let's implement this step-by-step check in Python to get the correct answer.
```python
import math

count = 0

# We will check for a reasonable range of n values, say from -100000 to 100000, to ensure we capture all possible solutions.
for n in range(-100000, 100001):
    left_side = 1 + math.floor(100 * n / 101)
    right_side = math.ceil(99 * n / 100)
    
    if left_side == right_side:
        count += 1

print(count)
```
