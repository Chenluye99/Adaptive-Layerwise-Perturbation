To solve this problem, we need to use the concept of volume and density. 

1. **Determine the Density of Silver:**
    - First, let's calculate the volume of a two-inch cube. The volume \( V_{2} \) of a cube with side length 2 inches is:
      \[
      V_{2} = 2^3 = 8 \text{ cubic inches}
      \]
    - This two-inch cube weighs 3 pounds and is worth \$200.
    - Next, let's find the value per cubic inch of silver. To do this, we first need to figure out the weight per cubic inch (density, in terms of weight) and then calculate the value per cubic inch based on its worth.

2. **Find the Volume of a Three-Inch Cube:**
    - The volume \( V_{3} \) of a cube with side length 3 inches is:
      \[
      V_{3} = 3^3 = 27 \text{ cubic inches}
      \]

3. **Relate the Value of the Cubes:**
    - Since the value of silver is directly proportional to its volume (assuming the density and value per unit volume of silver is the same in both cases), we can determine the value of a three-inch cube of silver by using the ratio of their volumes.
    - The ratio of the volumes of the three-inch cube to the two-inch cube is:
      \[
      \frac{V_{3}}{V_{2}} = \frac{27}{8}
      \]
    - Therefore, the value of the three-inch cube of silver will be:
      \[
      \text{Value of 3-inch cube} = \text{Value of 2-inch cube} \times \frac{27}{8}
      \]
    - Substituting the value of the 2-inch cube, which is \$200, we get:
      \[
      \text{Value of 3-inch cube} = 200 \times \frac{27}{8}
      \]

4. **Compute the Final Value and Round to the Nearest Dollar:**
    - We will compute this value and then round it to the nearest dollar.

Let's perform this calculation using Python for accuracy.
```python
# Given data
value_of_2_inch_cube = 200  # dollars
volume_2_inch_cube = 2 ** 3  # cubic inches
volume_3_inch_cube = 3 ** 3  # cubic inches

# Calculate the value of the 3-inch cube of silver
value_of_3_inch_cube = value_of_2_inch_cube * (volume_3_inch_cube / volume_2_inch_cube)

# Round the result to the nearest dollar
value_of_3_inch_cube_rounded = round(value_of_3_inch_cube)

```
