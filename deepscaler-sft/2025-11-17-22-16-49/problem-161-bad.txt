1. **Problem Understanding:**
    - We have a \(4 \times 4\) grid where each cell contains one dwarf.
    - There are both liars and knights among the dwarves.
    - Each dwarf makes the statement: "Among my neighbors (by edge), there are an equal number of liars and knights".
    - Neighbors are defined as horizontally or vertically adjacent cells.

2. **Formulating the Rules:**
    - Knights always tell the truth.
    - Liars always lie.
    - For a dwarf to be telling the truth, the number of liars and knights among its neighbors must be equal.
    - For a dwarf to be lying, the number of liars and knights among its neighbors must not be equal.

3. **Consideration of Possible Configurations:**
    - Each cell in a \(4 \times 4\) grid has up to 4 neighbors (top, bottom, left, right). The number of neighbors can be 2, 3, or 4 (corners or edges will have fewer).
    - For a dwarf to truthfully say that there are an equal number of liars and knights among its neighbors, it needs to have an even number of neighbors (2, 4, 6) for the equality to be meaningful and assessable.
    - Thus, the only possible configurations for the numbers of liars and knights for a truthful dwarf would logically be 2 neighbors if there are 4 neighbors in total (i.e., 2 liars and 2 knights).

4. **Constraint Check:**
    - We need to ensure that our configuration contains both liars and knights, and it satisfies the above conditions for all dwarves.

5. **Implementation via Python:**
    - We can employ a brute force approach or reason logically to place dwarves into the grid and check the conditions.
    - Let's use Python to help us check potential configurations and validate our solution.

### Step-by-step Implementation in Python

We'll use a system where we place dwarves in a \(4 \times 4\) grid and evaluate each configuration to see which valid configurations meet the condition of the problem statement. We'll use 0 to denote knights and 1 to denote liars, then check each configuration programmatically.

Let's start coding.
```python
import itertools

def count_neighbors(grid, i, j):
    """
    Returns the number of liars and knights in the 4-directional neighbors of the cell at (i, j).
    """
    n_rows, n_cols = 4, 4
    neighbors = []
    
    # Add the neighbors of (i, j)
    for x, y in [(i-1, j), (i+1, j), (i, j-1), (i, j+1)]:
        if 0 <= x < n_rows and 0 <= y < n_cols:
            neighbors.append(grid[x][y])
    
    return neighbors

def evaluate_configuration(grid):
    """
    Checks if the given grid configuration is valid according to the problem's conditions.
    """
    n_rows, n_cols = 4, 4
    
    # Evaluate each cell to see if its statement holds true.
    for i in range(n_rows):
        for j in range(n_cols):
            neighbors = count_neighbors(grid, i, j)
            
            # Count liars and knights among the neighbors
            num_liars = sum(1 for neighbor in neighbors if neighbor == 1)
            num_knights = sum(1 for neighbor in neighbors if neighbor == 0)
            
            if len(neighbors) == 0:
                continue  # Skip the case where the dwarf has no neighbors (this shouldn't happen in a 4x4 grid with each cell containing a dwarf).
            
            if (len(neighbors) % 2 == 0) and (num_liars != num_knights):
                return False
            elif (len(neighbors) % 2 != 0) and (num_liars == num_knights):
                return False
    
    return True

def find_solution():
    # We will try different combinations and check for validity
    for num_knights in range(1, 17):  # Reasonably, numbers of knights can range from 1 to 16 (as 0 or 16 would mean no liars or no knights, respectively, which is not allowed).
        num_liars = 16 - num_knights  # knights + liars should sum up to 16 (since there are 16 cells in a 4x4 grid).
        for comb in itertools.product([0, 1], repeat=16):
            grid = [list(comb[n:n+4]) for n in range(0, 16, 4)]
            if sum(1 for row in grid for cell in row if cell == 0) == num_knights and sum(1 for row in grid for cell in row if cell == 1) == num_liars:
                if evaluate_configuration(grid):
                    return num_liars  # Return the number of liars if a valid configuration is found.

num_liars = find_solution()
print(num_liars)
```
