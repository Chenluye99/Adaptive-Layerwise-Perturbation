To solve this problem, we need to find out for how many integer values of \(a\), the quadratic equation \(x^2 + ax + 12a = 0\) has integer solutions for \(x\).

Let's start by using the fact that if \(x_1\) and \(x_2\) are the integer solutions to the equation, then by Vieta's formulas, we have:
1. \(x_1 + x_2 = -a\)
2. \(x_1 \cdot x_2 = 12a\)

From the second equation, we can express \(a\) as:
\[ a = \frac{x_1 \cdot x_2}{12} \]

Substituting this into the first equation, we get:
\[ x_1 + x_2 = -\frac{x_1 \cdot x_2}{12} \]

Rearrange this equation to get:
\[ 12(x_1 + x_2) = -x_1 \cdot x_2 \]
\[ x_1 \cdot x_2 + 12(x_1 + x_2) = 0 \]
\[ x_1 \cdot x_2 + 12x_1 + 12x_2 = 0 \]
\[ x_1 \cdot x_2 + 12x_1 + 12x_2 + 144 = 144 \]
\[ (x_1 + 12)(x_2 + 12) = 144 \]

We need to find all pairs of integers \((x_1 + 12, x_2 + 12)\) that multiply to give 144. Then, for each pair, we can get \((x_1, x_2)\), and subsequently compute \(a = - (x_1 + x_2)\) and check if it is an integer.

Let's list out all pairs of factors of 144 and derive \((x_1, x_2)\) from them, then compute \(a\) for each valid pair. Finally, we will count the distinct integer values of \(a\).

We will implement this using Python to ensure accuracy.
```python
import itertools

# List all possible factor pairs (p, q) such that p * q = 144
factor_pairs = []
for i in range(1, 145):
    if 144 % i == 0:
        factor_pairs.append((i, 144 // i))
        factor_pairs.append((-i, -144 // i))

# Initialize a set to store distinct values of 'a'
a_values = set()

for p, q in factor_pairs:
    x1 = p - 12
    x2 = q - 12
    
    # Calculate 'a' from the equations x1 + x2 = -a and x1 * x2 = 12a
    a = - (x1 + x2)
    if x1 * x2 == 12 * a:
        a_values.add(a)

# Get the number of distinct integer values of 'a'
num_distinct_a = len(a_values)
print(num_distinct_a)
```
