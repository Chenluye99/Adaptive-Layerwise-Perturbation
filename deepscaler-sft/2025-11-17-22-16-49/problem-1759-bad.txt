We need to find the smallest whole number \( x \) that satisfies the following conditions:

1. \( x \equiv 1 \pmod{4} \)
2. \( x \equiv 1 \pmod{3} \)
3. \( x \equiv 2 \pmod{5} \)

We can iterate through the whole numbers and check for these conditions. We will start from 1 and check each number until we find the correct one.

Let's write some Python code to solve this step-by-step.
```python
def find_number():
    x = 1
    while True:
        if (x % 4 == 1) and (x % 3 == 1) and (x % 5 == 2):
            return x
        x += 1

result = find_number()
print(result)
```
Code execution result: 37

Thus, the smallest whole number that satisfies all the conditions is \(\boxed{37}\). This is our final answer.
