To solve this problem, we need to find the lengths of the legs of the right triangle given that the hypotenuse is 39 units and the lengths of the sides are integers.

We know that for a right triangle with legs of lengths \(a\) and \(b\) and hypotenuse of length \(c\), the Pythagorean theorem holds:

\[ a^2 + b^2 = c^2 \]

In this case, the hypotenuse \( c = 39 \). So we need to find integers \( a \) and \( b \) such that:

\[ a^2 + b^2 = 39^2 = 1521 \]

We also need to ensure that \( a \) and \( b \) are integers and that \( a \leq b \) (so that \( a \) is the shorter leg).

We can iterate through all possible integer values for \( a \) and solve for \( b \) to check if it is an integer and forms a valid right triangle with the given hypotenuse.

Let's write some Python code to solve this problem.
```python
import math

# Length of the hypotenuse
c = 39

# Initialize a variable to store the length of the shorter leg
shorter_leg = None

# Iterate through all possible values for 'a' (the shorter leg)
for a in range(1, c):
    # Calculate the corresponding value for b using the Pythagorean theorem
    b_squared = c**2 - a**2
    b = math.isqrt(b_squared)
    
    # Check if b is an integer and if it satisfies the Pythagorean theorem
    if b_squared == b**2:
        if a <= b:
            shorter_leg = a
            break

print(shorter_leg)
```
