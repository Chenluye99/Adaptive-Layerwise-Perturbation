To solve this problem, we need to generate all possible ways to split the digits {2, 4, 6, 8} into two 2-digit numbers. Then, we need to compute the differences between these pairs of 2-digit numbers and find the smallest possible difference.

We can break this problem down into the following steps:

1. Generate all permutations of the list [2, 4, 6, 8].
2. For each permutation, split the permutation into two 2-digit numbers in all possible ways (i.e., the first 2 digits form the first 2-digit number and the last 2 digits form the second 2-digit number, or vice versa).
3. Compute the difference between these two 2-digit numbers.
4. Track the smallest difference encountered.

Let's implement this step-by-step plan in Python to ensure accuracy.
```python
import itertools

# Digits to use
digits = [2, 4, 6, 8]

# Initialize a variable to keep track of the minimum difference found
min_difference = float("inf")

# Generate all permutations of the list [2, 4, 6, 8]
for perm in list(itertools.permutations(digits)):
    num1 = perm[0] * 10 + perm[1]
    num2 = perm[2] * 10 + perm[3]
    
    # Calculate the absolute difference between the two 2-digit numbers
    difference = abs(num1 - num2)
    
    # Update min_difference if the current difference is smaller
    if difference < min_difference:
        min_difference = difference

print(min_difference)
```
Code execution result: 14

Thus, the smallest possible difference between the two 2-digit numbers formed by using the digits 2, 4, 6, and 8 each once is \(\boxed{14}\). This is the final answer.
