To solve for the sum of the solutions of the equation \((3x + 5)(2x - 9) = 0\), we first need to find the roots of the equation.

1. Set each factor equal to zero and solve for \( x \):
   - For \( 3x + 5 = 0 \):
     \[
     3x + 5 = 0 \implies 3x = -5 \implies x = -\frac{5}{3}
     \]
   - For \( 2x - 9 = 0 \):
     \[
     2x - 9 = 0 \implies 2x = 9 \implies x = \frac{9}{2}
     \]

2. The solutions (or roots) to the equation \((3x + 5)(2x - 9) = 0\) are \( x = -\frac{5}{3} \) and \( x = \frac{9}{2} \).

3. To find the sum of these solutions, we add them together:
   \[
   -\frac{5}{3} + \frac{9}{2}
   \]

To perform the addition, we need a common denominator. The least common denominator of 3 and 2 is 6. We rewrite each fraction with this common denominator:

\[
-\frac{5}{3} = -\frac{5 \cdot 2}{3 \cdot 2} = -\frac{10}{6}
\]
\[
\frac{9}{2} = \frac{9 \cdot 3}{2 \cdot 3} = \frac{27}{6}
\]

Now we can add these fractions:

\[
-\frac{10}{6} + \frac{27}{6} = \frac{-10 + 27}{6} = \frac{17}{6}
\]

Thus, the sum of the solutions is \(\frac{17}{6}\). Let's confirm this with Python to ensure the result is accurate.
```python
from sympy import symbols, Eq, solve

# Define the variable and equation
x = symbols('x')
equation = (3 * x + 5) * (2 * x - 9)

# Solve the equation (3x + 5)(2x - 9) = 0
solutions = solve(Eq(equation, 0), x)

# Calculate the sum of the solutions
sum_of_solutions = sum(solutions)
print(sum_of_solutions)
```
