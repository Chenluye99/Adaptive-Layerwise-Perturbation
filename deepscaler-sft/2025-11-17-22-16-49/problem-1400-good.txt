To determine the complex number \( c \) around which the function \( f(z) \) rotates, we need to find the fixed point of the function. A fixed point of a function \( f \) is a point \( c \) such that \( f(c) = c \).

So, we want to solve the equation:
\[ f(c) = c \]

First, substitute \( c \) into the function \( f(z) \):
\[ f(c) = \frac{(-1 + i \sqrt{3}) c + (-2 \sqrt{3} - 18i)}{2} \]

Setting \( f(c) = c \), we have:
\[ \frac{(-1 + i \sqrt{3}) c + (-2 \sqrt{3} - 18i)}{2} = c \]

Multiply both sides by 2 to clear the fraction:
\[ (-1 + i \sqrt{3}) c + (-2 \sqrt{3} - 18i) = 2c \]

Rearrange the equation to isolate \( c \):
\[ (-1 + i \sqrt{3}) c - 2c = 2 \sqrt{3} + 18i \]
\[ (-1 + i \sqrt{3} - 2) c = 2 \sqrt{3} + 18i \]
\[ (-3 + i \sqrt{3}) c = 2 \sqrt{3} + 18i \]

Now, solve for \( c \) by dividing both sides by \(-3 + i \sqrt{3}\):
\[ c = \frac{2 \sqrt{3} + 18i}{-3 + i \sqrt{3}} \]

To simplify this, we will multiply the numerator and the denominator by the complex conjugate of the denominator, \(-3 - i \sqrt{3}\):
\[ c = \frac{(2 \sqrt{3} + 18i)(-3 - i \sqrt{3})}{(-3 + i \sqrt{3})(-3 - i \sqrt{3})} \]

First, compute the denominator:
\[ (-3 + i \sqrt{3})(-3 - i \sqrt{3}) = (-3)^2 - (i \sqrt{3})^2 = 9 - (-3) = 9 + 3 = 12 \]

Next, compute the numerator:
\[ (2 \sqrt{3} + 18i)(-3 - i \sqrt{3}) = 2 \sqrt{3} \cdot (-3) + 2 \sqrt{3} \cdot (-i \sqrt{3}) + 18i \cdot (-3) + 18i \cdot (-i \sqrt{3}) \]
\[ = -6 \sqrt{3} - 2i \cdot 3 - 54i - 18i^2 \sqrt{3} \]
\[ = -6 \sqrt{3} - 6i - 54i - 18(-1) \sqrt{3} \]
\[ = -6 \sqrt{3} - 60i + 18 \sqrt{3} \]
\[ = 12 \sqrt{3} - 60i \]

So, we have:
\[ c = \frac{12 \sqrt{3} - 60i}{12} = \frac{12 (\sqrt{3} - 5i)}{12} = \sqrt{3} - 5i \]

So the fixed point, and therefore the center of rotation, is:
\[ c = \sqrt{3} - 5i \]

Let's verify this by coding the solution in Python to ensure the accuracy.
```python
import sympy as sp

# Define the variables
z = sp.symbols('z', complex=True)
c = sp.symbols('c', complex=True)

# Define the function f(z)
f = ((-1 + 1j * sp.sqrt(3)) * z + (-2 * sp.sqrt(3) - 18j)) / 2

# Set up the equation f(c) = c
equation = sp.Eq(f.subs(z, c), c)

# Solve for c
solution = sp.solve(equation, c)[0]
print(solution)
```
