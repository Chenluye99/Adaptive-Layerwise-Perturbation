To solve this problem, let's break it down into steps.

1. **Define the Function \( p(x) \):**
   - First, we need a function to check if a number is prime.
   - The function \( p(x) \) should check if \(\lfloor x \rfloor\) (the greatest integer less than or equal to \( x \)) is prime.
     - If \(\lfloor x \rfloor\) is prime, then \( p(x) = x + 1 \).
     - If \(\lfloor x \rfloor\) is not prime, we need to find the greatest prime factor of \(\lfloor x \rfloor\) and set \( y \) to that prime factor. Then, we calculate \( p(y) + (x + 1 - \lfloor x \rfloor) \).

2. **Implement the Function:**
   - We will implement the above logic in Python and compute the values of \( p(x) \) for \( x \) in the interval \([2, 10]\).
   - We will then determine the range of values taken by \( p(x) \) and express it in interval notation.

Let's implement this step-by-step in Python.
```python
import sympy

def is_prime(n):
    """Check if a number is prime."""
    return sympy.isprime(n)

def greatest_prime_factor(n):
    """Find the greatest prime factor of n."""
    factors = []
    candidate = 2
    while candidate * candidate <= n:
        while n % candidate == 0:
            n //= candidate
            factors.append(candidate)
        candidate += 1
    if n > 1:
        factors.append(n)
    return max(factors)

def p(x):
    """Define the function p(x) as per the problem statement."""
    floor_x = int(x)
    
    if is_prime(floor_x):
        return x + 1
    else:
        y = greatest_prime_factor(floor_x)
        return p(y) + (x + 1 - floor_x)

# Compute values of p(x) for x in the range [2, 10]
p_values = []
for x in [2 + i / 1000 for i in range(0, 8001)]:  # Using high precision to get a good approximation of continuous values
    p_values.append(p(x))

# Get the minimum and maximum values of p(x) to determine the range
min_p = min(p_values)
max_p = max(p_values)

print(((min_p, max_p)))
```
