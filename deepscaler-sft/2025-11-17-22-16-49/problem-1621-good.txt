First, we start by identifying all the divisors of 72. To do this, we check all numbers from 1 to 72 to see which ones divide 72 without leaving a remainder.

Next, we identify which of those divisors are composite numbers. A composite number is a positive integer that has at least one positive divisor other than one or the number itself in question, meaning it has more than two distinct positive divisors.

Then, we need to generate all subsets of the set of divisors of 72 and check which of these subsets contain only composite numbers. Finally, we need to count such subsets, including the empty set.

Let's go ahead and implement this step by step in Python.
```python
import itertools

# Step 1: Find all divisors of 72
number = 72
divisors = [i for i in range(1, number + 1) if number % i == 0]

# Step 2: Identify composite numbers in the list of divisors
def is_composite(n):
    if n < 2:
        return False
    for i in range(2, int(n ** 0.5) + 1):
        if n % i == 0:
            return True
    return False

composite_divisors = [d for d in divisors if is_composite(d)]

# Step 3: Generate all subsets of the set of composite divisors and count those that contain only composite numbers
count = 0

# Generating all subsets of the set of composite divisors
for r in range(len(composite_divisors) + 1):
    for subset in itertools.combinations(composite_divisors, r):
        count += 1  # Each subset is valid and we're counting all possible subsets including the empty set

print(count)
```
Code execution result: 512

Thus, the number of subsets of the set of divisors of 72 that contain only composite numbers, including the empty set, is \(\boxed{512}\). This is our final answer.
