To solve the problem, we start with the equation given in the problem:

\[ x + y + xy = 119 \]

We need to find integers \( x \) and \( y \) that satisfy this equation with the condition \( x > y > 0 \).

We can iterate through possible values of \( y \) and, for each value of \( y \), solve for \( x \) to see if it results in an integer solution that satisfies the equation and the condition \( x > y \). 

Rearrange the equation to express \( x \) in terms of \( y \):

\[ x + y + xy = 119 \implies x(1 + y) + y = 119 \implies x(1 + y) = 119 - y \]

So,

\[ x = \frac{119 - y}{1 + y} \]

For \( x \) to be an integer, \(\frac{119 - y}{1 + y}\) must be an integer. Therefore, \( 119 - y \) must be divisible by \( 1 + y \).

We can set up a loop to check for all possible values of \( y \) from 1 to 118 (since both \( x \) and \( y \) are positive integers and \( x > y \), reasonable bounds can be set based on the equation structure). For each \( y \), we check if \(\frac{119 - y}{1 + y}\) is an integer, and if it is, we check if the resulting \( x \) is greater than \( y \).

Let's implement this in Python to find the correct solution.
```python
# We will iterate through possible values of y and check for corresponding x
solution = None

for y in range(1, 119):
    if (119 - y) % (1 + y) == 0:
        x = (119 - y) // (1 + y)
        if x > y:
            solution = (x, y)
            break

print(solution)
```
