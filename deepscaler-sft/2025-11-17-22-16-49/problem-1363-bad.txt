To solve the problem, we need to:

1. Generate all three-digit integers less than 500.
2. For each number, check if it has at least two digits that are the same.
3. Count how many such numbers exist.

Let's implement this step-by-step in Python.
```python
count = 0

for num in range(100, 500):
    num_str = str(num)
    
    # Check if there are at least two same digits in the number
    if len(set(num_str)) < 3:
        count += 1

print(count)
```
Code execution result: 112

Thus, the number of positive three-digit integers less than 500 that have at least two digits that are the same is \(\boxed{112}\). This is our final answer.
