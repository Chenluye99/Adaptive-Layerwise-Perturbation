Emma is using her square unit tiles to form different shaped rectangular figures. To find the least number of tiles Emma could have, we need to determine the smallest number \( n \) such that there are exactly ten different pairs of factors \((a, b)\) where \( a \times b = n \). Each pair \((a, b)\) represents a unique rectangular shape that uses all of her tiles, considering that a rectangle with dimensions \( a \times b \) is the same as a rectangle with dimensions \( b \times a \).

To find this, we need to check for each integer \( n \) and determine its number of distinct factor pairs. If \( n \) has exactly ten unique factor pairs, then that's the number of different rectangular shapes that can be formed using \( n \) tiles. We will iterate through integers, check their factor pairs, and stop once we find the smallest integer that meets the condition of having exactly ten different rectangular shapes.

Let's implement this in Python and iterate to get the answer.
```python
import sympy

def count_factor_pairs(n):
    count = 0
    for i in range(1, n + 1):
        if n % i == 0:
            count += 1
    return count

# We will start checking from 1 and go upwards until we find the smallest n that has exactly 10 factor pairs.
n = 1
while True:
    if count_factor_pairs(n) == 10:
        result = n
        break
    n += 1

print(result)
```
Code execution result: 48

Thus, the least number of tiles Emma could have is \(\boxed{48}\). This is the smallest number that can be formed by exactly ten different rectangular dimensions where order of dimensions does not matter (i.e., a 1 by 48 rectangle is the same as a 48 by 1 rectangle, and we only count it once).
