First, let's define the variables for the lengths of the legs of the right triangle. Let's call the length of the shorter leg \( a \) and the length of the longer leg \( b \). According to the problem, we have the following relationships:

1. The longer leg is 1 foot shorter than twice the length of the shorter leg:
\[ b = 2a - 1 \]

2. The area of the triangle is 60 square feet. The area of a right triangle is given by:
\[ \text{Area} = \frac{1}{2} \times a \times b = 60 \]
Substituting the expression for \( b \) into the area formula, we get:
\[ \frac{1}{2} \times a \times (2a - 1) = 60 \]
Multiplying both sides by 2 gives:
\[ a \cdot (2a - 1) = 120 \]
This simplifies to the quadratic equation:
\[ 2a^2 - a - 120 = 0 \]

We can solve this quadratic equation using the quadratic formula \( a = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} \), where \( a = 2 \), \( b = -1 \), and \( c = -120 \):
\[ a = \frac{-(-1) \pm \sqrt{(-1)^2 - 4 \cdot 2 \cdot (-120)}}{2 \cdot 2} = \frac{1 \pm \sqrt{1 + 960}}{4} = \frac{1 \pm \sqrt{961}}{4} = \frac{1 \pm 31}{4} \]
This gives us two solutions:
\[ a = \frac{32}{4} = 8 \]
\[ a = \frac{-30}{4} = -\frac{15}{2} \]
Since lengths must be positive, we have:
\[ a = 8 \]
Substituting \( a = 8 \) back into the equation for \( b \):
\[ b = 2(8) - 1 = 16 - 1 = 15 \]
So, the lengths of the legs of the triangle are \( a = 8 \) and \( b = 15 \). 

To find the length of the hypotenuse \( c \), we use the Pythagorean theorem:
\[ c = \sqrt{a^2 + b^2} = \sqrt{8^2 + 15^2} = \sqrt{64 + 225} = \sqrt{289} = 17 \]

Thus, the length of the hypotenuse is \( 17 \) feet. Let's verify this by coding the solution in Python to ensure accuracy.
```python
import sympy as sp

# Define the variables
a = sp.symbols('a', positive=True)

# Set up the equation 2a^2 - a - 120 = 0
equation = 2 * a**2 - a - 120

# Solve the equation
solution = sp.solve(equation, a)

# Get the valid solution (positive length)
a_val = [sol for sol in solution if sol > 0][0]

# Calculate corresponding b value
b_val = 2 * a_val - 1

# Calculate the hypotenuse
c_val = sp.sqrt(a_val**2 + b_val**2)
print(c_val)
```
Code execution result: 17

Thus, the length of the hypotenuse is \(\boxed{17}\). This confirms our solution is accurate.
