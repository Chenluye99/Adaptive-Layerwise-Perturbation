To solve this problem, we need to write a Python program that performs the following steps:

1. **Define a function to compute the digit sum of a number**.
2. **Define a function to compute the quotient when a number is divided by the sum of its digits**.
3. **Iterate through a reasonable range of natural numbers (starting from 10, since we need at least a two-digit number) and compute the quotient for each**.
4. **Keep track of the maximum and minimum quotients encountered, as well as the corresponding numbers**.

Let's implement this step-by-step in Python.
```python
import itertools

def digit_sum(n):
    """Compute the digit sum of n."""
    return sum(int(digit) for digit in str(n))

def find_max_min_quotients():
    max_quotient = 0
    min_quotient = float("inf")
    number_with_max_quotient = 0
    number_with_min_quotient = 0
    
    # We'll consider the range from 10 to 1000 as an initial exploration, meaning numbers with at most 3 digits.
    for num in range(10, 1000):
        sum_of_digits = digit_sum(num)
        if sum_of_digits != 0:  # To avoid division by zero
            quotient = num / sum_of_digits
            
            if quotient > max_quotient:
                max_quotient = quotient
                number_with_max_quotient = num
                
            if quotient < min_quotient:
                min_quotient = quotient
                number_with_min_quotient = num
    
    return max_quotient, number_with_max_quotient, min_quotient, number_with_min_quotient

max_quotient, num_max_quotient, min_quotient, num_min_quotient = find_max_min_quotients()
print(((max_quotient, num_max_quotient, min_quotient, num_min_quotient)))
```
