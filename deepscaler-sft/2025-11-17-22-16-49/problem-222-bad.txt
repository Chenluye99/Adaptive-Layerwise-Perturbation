To solve the given problem, let's start by finding the vectors \(\overrightarrow{AB}\) and \(\overrightarrow{OC}\).

1. **Given Vectors:**
    - \(\overrightarrow{OA} = (1, -2)\)
    - \(\overrightarrow{OB} = (4, -1)\)
    - \(\overrightarrow{OC} = (m, m+1)\)

2. **Find \(\overrightarrow{AB}\):**
    \[
    \overrightarrow{AB} = \overrightarrow{OB} - \overrightarrow{OA} = (4 - 1, -1 - (-2)) = (3, 1)
    \]

3. **Condition for \(\overrightarrow{AB} \parallel \overrightarrow{OC}\):**
    - Two vectors \(\overrightarrow{AB} = (3, 1)\) and \(\overrightarrow{OC} = (m, m+1)\) are parallel if and only if their components are proportional, i.e., \(\frac{3}{m} = \frac{1}{m+1}\).
    - This gives us the equation: \(3(m + 1) = 1 \cdot m \) which simplifies to \(3m + 3 = m\).
    - Rearrange to get: \(3m - m = -3 \implies 2m = -3 \implies m = -\frac{3}{2}\).

4. **Condition for \(\triangle ABC\) to be a Right-Angled Triangle:**
    - For \(\triangle ABC\) to be a right-angled triangle, one of the following dot products must be zero:
      - \(\overrightarrow{AB} \cdot \overrightarrow{BC} = 0\)
      - \(\overrightarrow{BC} \cdot \overrightarrow{CA} = 0\)
      - \(\overrightarrow{CA} \cdot \overrightarrow{AB} = 0\)
    - First, let's find \(\overrightarrow{BC}\) and \(\overrightarrow{CA}\):
      - \(\overrightarrow{BC} = \overrightarrow{OC} - \overrightarrow{OB} = (m - 4, m + 1 - (-1)) = (m - 4, m + 2)\)
      - \(\overrightarrow{CA} = \overrightarrow{OA} - \overrightarrow{OC} = (1 - m, -2 - (m + 1)) = (1 - m, -3 - m)\)
    - We now need to check the dot products of these vectors.

# Condition for parallel vectors: 3 / m = 1 / (m + 1) => 3 * (m + 1) = m
parallel_condition = 3 * (m + 1) - m
m_parallel = sp.solve(parallel_condition, m)[0]

# (2) Find m such that triangle ABC is a right-angled triangle
BC = OC - OB
CA = OA - OC

# Check for right-angled conditions:

# 2. BC . CA = 0
