To solve this problem, we need to use the properties of parabolas and their symmetry. Let's start with understanding the problem step-by-step.

1. **Understand the Problem**:
    - We have a parabola given by the equation \( y = x^2 - 5x + 2 \).
    - This parabola is symmetric about the point \((3, 2)\) with another parabola given by the equation \( y = ax^2 + bx + c \).
    - For a parabola, the symmetry about a point means that if \((x_0, y_0)\) is the point of symmetry, then for any point \((x, y)\) on the parabola, the point symmetric to \((x, y)\) about \((x_0, y_0)\) must also lie on the parabola.
    - For a parabola of the form \( y = mx^2 + nx + p \), the point of symmetry (also known as the vertex) is \(\left( -\frac{n}{2m}, m \left(-\frac{n}{2m}\right)^2 + n \left(-\frac{n}{2m}\right) + p \right)\).

2. **Find the Vertex of the Original Parabola**:
    - For the parabola \( y = x^2 - 5x + 2 \), the vertex can be found using the formula for the vertex of a parabola \( y = ax^2 + bx + c \), which is \(\left( -\frac{b}{2a}, f\left( -\frac{b}{2a} \right) \right)\).
    - Here, \( a = 1 \), \( b = -5 \), and \( c = 2 \), so the x-coordinate of the vertex is \( -\frac{-5}{2 \cdot 1} = \frac{5}{2} \).
    - Substituting \( x = \frac{5}{2} \) into the equation \( y = x^2 - 5x + 2 \):
      \[
      y = \left( \frac{5}{2} \right)^2 - 5 \left( \frac{5}{2} \right) + 2 = \frac{25}{4} - \frac{25}{2} + 2 = \frac{25}{4} - \frac{50}{4} + \frac{8}{4} = \frac{25 - 50 + 8}{4} = \frac{-17}{4}
      \]
    - So, the vertex of the parabola \( y = x^2 - 5x + 2 \) is \(\left( \frac{5}{2}, \frac{-17}{4} \right)\).

3. **Symmetry about the Point (3, 2)**:
    - We need the parabola \( y = ax^2 + bx + c \) to be symmetric about the point \((3, 2)\) and match the original parabola when transformed.
    - If a point \((x, y)\) on the original parabola \( y = x^2 - 5x + 2 \) is reflected about the point \((3, 2)\), the reflected point \((x', y')\) will be such that \((3, 2)\) is the midpoint of \((x, y)\) and \((x', y')\):
      \[
      \left( \frac{x + x'}{2}, \frac{y + y'}{2} \right) = (3, 2)
      \]
      This gives us:
      \[
      \frac{x + x'}{2} = 3 \implies x + x' = 6 \implies x' = 6 - x
      \]
      \[
      \frac{y + y'}{2} = 2 \implies y + y' = 4 \implies y' = 4 - y
      \]
    - Substituting \( x' = 6 - x \) into the equation of the original parabola to get the corresponding \( y' \):
      \[
      y = x^2 - 5x + 2
      \]
      The point \((x', y')\) after reflection must lie on the new parabola \( y = ax^2 + bx + c \):
      \[
      y' = a(6 - x)^2 + b(6 - x) + c
      \]
      Since \((x, y)\) and \((x', y')\) are corresponding points and the reflected points of each other about the point of symmetry \((3, 2)\):
      \[
      4 - (x^2 - 5x + 2) = a(6 - x)^2 + b(6 - x) + c
      \]
      Simplifying, we get:
      \[
      4 - x^2 + 5x - 2 = a(6 - x)^2 + b(6 - x) + c \implies 2 + 5x - x^2 = a(6 - x)^2 + b(6 - x) + c
      \]
    - To find \(a\), \(b\), and \(c\), we compare coefficients after expanding and matching with the left-hand side. We can substitute different values of \(x\) and form a system of equations or directly compare the coefficients, but considering the symmetry and properties, it is common to assume the vertex form and transformation might simplify this.

4. **Find the New Parabola's Vertex**:
    - The vertex of the new parabola must be \((3, 2)\) because it is symmetric about this point, so we can write the new parabola in vertex form then convert it to the standard form.
    - A parabola that is symmetric about the point \((3, 2)\) and matches our conditions can be assumed to be of the form:
      \[
      y - 2 = k ( (x - 3)^2 )
      \]
      We need to match it to a standard quadratic form of \( y = ax^2 + bx + c \) and match coefficients. But because of the problem's constraints, a simple way is to check if a vertically or horizontally transformed version of our original parabola fits, or use numerical methods to solve. 

To solve this precisely, let's use Python to solve this system of equations. We will find the coefficients \(a\), \(b\), and \(c\) by matching the original and the new parabolas considering their symmetry and then compute \(3a + 3c + b\).
```python
import sympy as sp

# Define variables
a, b, c, x = sp.symbols('a b c x')

# Original parabola equation
original_parabola = x**2 - 5*x + 2

# New parabola equation
new_parabola = a*x**2 + b*x + c

# Find the point (x', y') which is the reflection of (x, y) about (3, 2)
reflection_x = 6 - x
reflection_y = 4 - (x**2 - 5*x + 2)

# Set up the equation for the new parabola that should pass through (x', reflection_y)
eq = sp.Eq(reflection_y, new_parabola.subs(x, reflection_x))

# Solve for a, b, c by comparing coefficients after expanding the equation
solution = sp.solve(sp.collect(sp.expand(eq.lhs - eq.rhs), x), (a, b, c))

print(solution)
```
