Given the following equations:

1. \( a^2 + b^2 + c^2 = 25 \)
2. \( x^2 + y^2 + z^2 = 36 \)
3. \( ax + by + cz = 30 \)

We need to compute \(\frac{a + b + c}{x + y + z}\).

One mathematical insight here is to use the Cauchy-Schwarz inequality in the form:

\[
(a^2 + b^2 + c^2)(x^2 + y^2 + z^2) \geq (ax + by + cz)^2
\]

Substitute the given values into the inequality:

\[
25 \cdot 36 \geq 30^2
\]

\[
900 \geq 900
\]

The equality case of the Cauchy-Schwarz inequality holds if and only if there exists a constant \( k \) such that:

\[
\frac{a}{x} = \frac{b}{y} = \frac{c}{z} = k
\]

This means we can write:

\[
a = kx, \quad b = ky, \quad c = kz
\]

Substitute these into the first equation:

\[
a^2 + b^2 + c^2 = (kx)^2 + (ky)^2 + (kz)^2 = k^2 (x^2 + y^2 + z^2) = 25
\]

We know that \( x^2 + y^2 + z^2 = 36 \), so:

\[
k^2 \cdot 36 = 25 \implies k^2 = \frac{25}{36} \implies k = \frac{5}{6}
\]

Now, substitute \( k = \frac{5}{6} \) back into the expressions for \( a, b, \) and \( c \):

\[
a = \frac{5}{6} x, \quad b = \frac{5}{6} y, \quad c = \frac{5}{6} z
\]

We need to compute \(\frac{a + b + c}{x + y + z}\):

\[
a + b + c = \frac{5}{6} x + \frac{5}{6} y + \frac{5}{6} z = \frac{5}{6} (x + y + z)
\]

Thus,

\[
\frac{a + b + c}{x + y + z} = \frac{\frac{5}{6} (x + y + z)}{x + y + z} = \frac{5}{6}
\]

So, the answer is \(\frac{5}{6}\). We will now confirm this result using Python to ensure accuracy by solving it numerically if necessary.
