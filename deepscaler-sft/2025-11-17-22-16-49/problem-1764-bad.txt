We are given two pieces of information about the variables \(x\) and \(y\):

1. The sum of the two numbers is 399:
   \[
   x + y = 399
   \]
2. The value of the fraction \(\frac{x}{y}\) is 0.9:
   \[
   \frac{x}{y} = 0.9 \implies x = 0.9y \implies x = \frac{9}{10}y
   \]

We can substitute the expression for \(x\) from the second equation into the first equation:

\[
\frac{9}{10}y + y = 399
\]

Combining the terms on the left side, we get:

\[
\frac{9}{10}y + \frac{10}{10}y = 399 \implies \frac{19}{10}y = 399
\]

Next, solve for \(y\):

\[
y = 399 \cdot \frac{10}{19}
\]

Once we have \(y\), we can substitute it back into the equation \( x = \frac{9}{10}y \) to find \(x\):

\[
x = \frac{9}{10} \cdot 399 \cdot \frac{10}{19} = \frac{9}{19} \cdot 399
\]

After getting the values for \(x\) and \(y\), we then need to find the value of \( y - x \). Let's calculate this step-by-step using Python to ensure accuracy.
```python
from sympy import symbols, Eq, solve

# Define variables
x, y = symbols('x y')

# Create equations based on the problem statement
eq1 = Eq(x + y, 399)
eq2 = Eq(x / y, 0.9)

# Solve the system of equations
solution = solve((eq1, eq2), (x, y))

# Extract the values of x and y
x_val = solution[x]
y_val = solution[y]

# Find the value of y - x
result = y_val - x_val
print(result)
```
