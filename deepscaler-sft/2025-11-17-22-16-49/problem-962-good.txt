To solve this problem, we need to generate all possible three-digit numbers using the digits {1, 2, 3, 4, 5} such that:

1. The number is even.
2. The number is less than 500.
3. Digits can be used more than once.

Let's break it down step-by-step:

1. **Generate All Possible Three-Digit Numbers:**
   We need to form all three-digit numbers using the digits {1, 2, 3, 4, 5}, where each digit can be repeated.
   
2. **Check Conditions:**
   - The number must be even, so its last digit must be either 2 or 4.
   - The number must be less than 500, so its first digit must be either 1, 2, 3, or 4.

3. **Count Valid Numbers:**
   We need to count how many of these numbers satisfy both conditions above.

We will use Python to implement this systematically.
```python
import itertools

# Digits to use
digits = [1, 2, 3, 4, 5]

# Initialize a counter for valid numbers
valid_count = 0

# Generate all possible three-digit numbers using the digits {1, 2, 3, 4, 5}
for num in itertools.product(digits, repeat=3):
    number = int(''.join(map(str, num)))
    
    # Check if the number is even and less than 500
    if number % 2 == 0 and number < 500:
        valid_count += 1

print(valid_count)
```
Code execution result: 40

Thus, the number of even three-digit numbers less than 500 that can be formed using the digits 1, 2, 3, 4, 5 (with repetition allowed) is \(\boxed{40}\). This is our final answer.
