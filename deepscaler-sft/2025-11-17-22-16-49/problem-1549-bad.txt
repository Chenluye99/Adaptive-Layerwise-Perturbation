To solve this problem, we need to ensure that the slopes of segments \(AB\) and \(XY\) are equal, because two lines are parallel if and only if their slopes are equal.

First, let's calculate the slope of segment \(AB\). The slope \(m\) of a line passing through two points \((x_1, y_1)\) and \((x_2, y_2)\) is given by:
\[
m = \frac{y_2 - y_1}{x_2 - x_1}
\]

For segment \(AB\) with points \(A(-4, 0)\) and \(B(0, -4)\):
\[
m_{AB} = \frac{-4 - 0}{0 - (-4)} = \frac{-4}{4} = -1
\]

For segment \(XY\) with points \(X(0, 8)\) and \(Y(14, k)\):
\[
m_{XY} = \frac{k - 8}{14 - 0} = \frac{k - 8}{14}
\]

Since segments \(AB\) and \(XY\) are parallel, their slopes must be equal:
\[
m_{AB} = m_{XY} \implies -1 = \frac{k - 8}{14}
\]

Now, let's solve this equation for \(k\):
\[
-1 = \frac{k - 8}{14} \implies -1 \cdot 14 = k - 8 \implies -14 = k - 8 \implies k = -14 + 8 \implies k = -6
\]

Thus, the value of \(k\) is \(-6\). Let's confirm this by implementing it in Python.
```python
from sympy import symbols, Eq, solve

# Define the variables
k = symbols('k')

# Define the equation based on the slopes being equal
m_AB = -1
m_XY = (k - 8) / 14

# Set up the equation m_AB = m_XY
equation = Eq(m_AB, m_XY)

# Solve for k
k_solution = solve(equation, k)[0]
print(k_solution)
```
Code execution result: -6

Thus, the value of \( k \) that makes segment \( AB \) parallel to segment \( XY \) is \(\boxed{-6}\). This confirms our solution is correct.
