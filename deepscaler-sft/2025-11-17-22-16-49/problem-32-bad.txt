To solve this problem, we need to place the numbers 1, 2, 3, 4, 2, 6, 7, and 8 at the vertices of a cube and check for the condition that the sum of the numbers on any given face of the cube is at least 10. Our goal is to find the assignment that gives the minimum possible sum of the numbers on each face.

A cube has 6 faces, and each face is a square formed by 4 vertices of the cube. We can label the vertices of a cube with the numbers 1, 2, 3, 4, 2, 6, 7, and 8, and then check all possible assignments to ensure that the condition is satisfied and compute the sum of the numbers on each face for each assignment.

To begin, let's establish the adjacency relationships of the cube's vertices. For simplicity, let's number the vertices of the cube from 0 to 7 and then assign the numbers to these vertices. The faces of the cube can be defined by sets of 4 vertices each, and we will need to check all permutations of placing the 8 numbers at these 8 vertices.

We'll use Python to check all permutations and find the configuration that meets the condition and gives the minimum possible sum of the numbers on each face. Let's implement this step-by-step.

First, we need to define functions that will evaluate the sums of the numbers on each face of the cube for a given permutation of the numbers at the vertices, and then check if these sums are all at least 10. We also need a way to compute the sum of the numbers on each face for a given configuration and find the minimum possible maximum sum of the numbers on any face.

Let's use the following steps in our Python code:

1. Generate all permutations of placing the numbers 1, 2, 3, 4, 2, 6, 7, 8 at the 8 vertices of the cube.
2. For each permutation, compute the sum of the numbers on each of the 6 faces of the cube.
3. Check if all face sums are at least 10.
4. If the condition is satisfied, compute the maximum sum of the numbers on any face for that permutation and store the minimum of these maximum sums across all valid configurations.

Let's implement this step-by-step in Python.
```python
import itertools

# Define the 6 faces of a cube in terms of the indices of its vertices.
# We label the vertices of the cube with indices 0 through 7.
# The faces of the cube can be defined as follows (each face is a set of 4 vertex indices):
faces = [
    [0, 1, 2, 3],  # Front face
    [4, 5, 6, 7],  # Back face
    [0, 1, 4, 5],  # Left face
    [2, 3, 6, 7],  # Right face
    [0, 2, 4, 6],  # Bottom face
    [1, 3, 5, 7]   # Top face
]

# The numbers to place at the vertices of the cube.
numbers = [1, 2, 3, 4, 2, 6, 7, 8]

# Initialize a variable to store the minimum maximum face sum found.
min_max_face_sum = float("inf")

# Check all permutations of placing the numbers at the 8 vertices.
for perm in set(itertools.permutations(numbers)):
    face_sums = []
    
    for face in faces:
        face_sum = sum(perm[i] for i in face)
        face_sums.append(face_sum)
    
    # Check if all face sums are at least 10.
    if all(face_sum >= 10 for face_sum in face_sums):
        # Find the maximum sum among the faces for this permutation.
        max_face_sum = max(face_sums)
        # Update the minimum maximum face sum if the current one is smaller.
        if max_face_sum < min_max_face_sum:
            min_max_face_sum = max_face_sum

print(min_max_face_sum)
```
