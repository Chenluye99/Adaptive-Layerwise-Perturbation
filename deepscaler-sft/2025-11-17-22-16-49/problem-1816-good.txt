First, we need to find all two-digit integers where one of the digits is three times the other. Then, we need to sum those numbers.

Let's iterate through all the two-digit integers (from 10 to 99) and check for each number if one of its digits is three times the other. If this condition is met, we add that number to our sum.

We can do this programmatically by checking each two-digit number. For each number, we can separate it into its tens and units digits, and then check if one of the digits is three times the other. If it is, we include that number in our sum.
```python
# Initialize a variable to keep track of the sum
sum_of_numbers = 0

# Iterate through all two-digit integers
for num in range(10, 100):
    tens = num // 10
    units = num % 10
    
    # Check if one of the digits is three times the other
    if (tens == 3 * units) or (units == 3 * tens):
        sum_of_numbers += num

print(sum_of_numbers)
```
