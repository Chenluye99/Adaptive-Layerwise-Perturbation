### Part (a)

1. **Definition of a five-digit palindromic number**:
    - A five-digit number is palindromic if it reads the same forward and backward. So, a five-digit palindromic number has the form \(abcba\), where \(a, b, c\) are digits, and \(a \neq 0\) because it is a five-digit number.

2. **Condition for divisibility by 5**:
    - A number is divisible by 5 if its last digit is either 0 or 5. In our five-digit palindromic number \(abcba\), the last digit is \(a\), so \(a\) must be either 0 or 5. But since \(a\) is the first digit of a five-digit number, it cannot be 0 (otherwise it would be a four-digit number). Therefore, \(a\) must be 5.

3. **Form of the number**:
    - So, the number has the form \(5bc55\). We can choose any digits for \(b\) and \(c\) (where \(0 \leq b, c \leq 9\)) to form different palindromic numbers that are divisible by 5.

Let's provide an example of such a number. We can choose \(b = 2\) and \(c = 3\) to get the number 52325. We can confirm that 52325 is a five-digit palindromic number and it ends with 5, hence it is divisible by 5.

### Part (b)

1. **Generating all five-digit palindromic numbers**:
    - We generate all five-digit palindromic numbers of the form \(abcba\) and check which of these numbers are divisible by 5.

2. **Counting the numbers**:
    - For each combination of \(a, b, c\) (where \(a\) ranges from 1 to 9 and \(b, c\) range from 0 to 9), we form the number, check if it's divisible by 5, and count how many such numbers exist.

Let's implement this step-by-step in Python to get the accurate count.
```python
# We'll initialize a counter for the number of five-digit palindromic numbers that are divisible by 5.

count = 0

# We'll iterate through all five-digit numbers and check if the number is palindromic and divisible by 5.
for num in range(10000, 100000):
    str_num = str(num)
    if str_num == str_num[::-1]:  # Check if the number is palindromic
        if num % 5 == 0:  # Check if the number is divisible by 5
            count += 1

print(count)
```

So, the number of five-digit palindromic numbers that are divisible by 5 is \(\boxed{100}\).
