First, let's solve this problem step-by-step. We need to determine the probability that both quitters come from the same tribe out of the 16 players who have an equal chance of quitting.

1. **Total Number of Ways to Choose 2 Quitters from 16 Players:**
   - There are 16 ways to choose the first quitter and 15 ways to choose the second quitter. Since the order of choosing doesn't matter, the number of ways to choose 2 quitters from 16 players is given by the combination formula \( \binom{16}{2} \):
     \[
     \binom{16}{2} = \frac{16 \times 15}{2 \times 1} = 120
     \]

2. **Number of Ways to Choose 2 Quitters from the Same Tribe:**
   - Each tribe has 8 players, so the number of ways to choose 2 quitters from one tribe is given by \( \binom{8}{2} \):
     \[
     \binom{8}{2} = \frac{8 \times 7}{2 \times 1} = 28
     \]
   - Since there are two tribes, the total number of ways to choose 2 quitters from the same tribe (either tribe) is:
     \[
     28 + 28 = 56
     \]

3. **Probability Calculation:**
   - The probability that both quitters come from the same tribe is the ratio of the number of ways to choose 2 quitters from the same tribe to the total number of ways to choose 2 quitters from 16 players:
     \[
     P(\text{Both from same tribe}) = \frac{56}{120} = \frac{7}{15}
     \]

Let's confirm this with Python code to ensure that our reasoning and calculations are accurate.
```python
import itertools

# We have 16 people, 8 in each tribe
players = list(range(16))
tribe1 = players[:8]
tribe2 = players[8:16]

# Find all possible ways to choose 2 quitters from 16 players
ways_to_choose_2_quitters = list(itertools.combinations(players, 2))

# Count the number of ways where both quitters are from the same tribe
same_tribe_count = 0

for quitter_1, quitter_2 in ways_to_choose_2_quitters:
    if (quitter_1 in tribe1 and quitter_2 in tribe1) or (quitter_1 in tribe2 and quitter_2 in tribe2):
        same_tribe_count += 1

# Total ways to choose 2 quitters from 16 players is 120 (as calculated above)
total_ways = len(ways_to_choose_2_quitters)

# Probability that both quitters are from the same tribe
probability_same_tribe = same_tribe_count / total_ways
print(probability_same_tribe)
```
