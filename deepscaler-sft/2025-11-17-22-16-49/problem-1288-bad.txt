To solve the given equation \((x - p)(x - q) = (r - p)(r - q)\), let's start by substituting \(x = r\) and verifying it is a solution, as given in the problem. Then we'll find the other solution.

1. Substitute \(x = r\) into the equation to verify:

   \[
   (r - p)(r - q) = (r - p)(r - q)
   \]

   This is clearly true, so \(x = r\) is indeed one solution to the equation.

2. To find the other solution, expand and simplify the original equation \((x - p)(x - q) = (r - p)(r - q)\):

   \[
   (x - p)(x - q) = x^2 - (p + q)x + pq
   \]
   \[
   (r - p)(r - q) = r^2 - (p + q)r + pq
   \]

   So, the equation becomes:

   \[
   x^2 - (p + q)x + pq = r^2 - (p + q)r + pq
   \]

   Simplifying by canceling out \(pq\) from both sides, we get:

   \[
   x^2 - (p + q)x = r^2 - (p + q)r
   \]

   Rearrange this equation to bring all terms to one side:

   \[
   x^2 - (p + q)x - r^2 + (p + q)r = 0
   \]

   This is a quadratic equation of the form \(x^2 - (p + q)x - r^2 + (p + q)r = 0\). We know one of its solutions is \(x = r\). To find the other solution, we can use the fact that for a quadratic equation \(ax^2 + bx + c = 0\), the sum of the roots is given by \(-b/a\) and the product of the roots is given by \(c/a\). For our quadratic equation \(x^2 - (p + q)x - r^2 + (p + q)r = 0\):

   - The sum of the roots is \(p + q\).
   - Let the roots be \(r\) and \(s\). Then, by the sum of the roots formula, we have:
     \[
     r + s = p + q
     \]
   - Therefore, the other solution \(s\) can be found as:
     \[
     s = p + q - r
     \]

Let's verify this by coding the solution in Python to ensure accuracy.
```python
import sympy as sp

# Define the variables
x = sp.symbols('x')
p, q, r = sp.symbols('p q r')

# Define the equation (x - p)(x - q) = (r - p)(r - q)
lhs = (x - p) * (x - q)
rhs = (r - p) * (r - q)
equation = sp.Eq(lhs, rhs)

# Solve the equation for x
solutions = sp.solve(equation, x)

print(solutions)
```
