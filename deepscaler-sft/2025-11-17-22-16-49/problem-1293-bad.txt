To solve the problem, we need to determine when the three planets X, Y, and Z will all be in the same position relative to the sun again for the first time. This means we need to find the smallest positive number of days after which the rotations of all three planets will have completed an integer number of rotations such that they all line up again.

The periods of rotation for the planets are:
- Planet X: 360 days,
- Planet Y: 450 days,
- Planet Z: 540 days.

To find the minimum number of days after which the planets will again be in the same positions, we need to compute the Least Common Multiple (LCM) of these periods. The LCM of a set of integers is the smallest number that is a multiple of each of the integers in the set.

The formula to compute the LCM of two numbers \(a\) and \(b\) is given by:
\[
\text{LCM}(a, b) = \frac{|a \cdot b|}{\text{GCD}(a, b)}
\]
where GCD is the Greatest Common Divisor. To find the LCM of three numbers, we can use this formula iteratively.

Let's use Python to compute this.
```python
import math

# Function to compute LCM of two numbers
def lcm(a, b):
    return abs(a * b) // math.gcd(a, b)

# Periods of rotation for the planets
period_x = 360
period_y = 450
period_z = 540

# Compute LCM of the three periods
lcm_xy = lcm(period_x, period_y)
lcm_xyz = lcm(lcm_xy, period_z)

print(lcm_xyz)
```
Code execution result: 5400

Thus, the minimum positive number of days before planets X, Y, and Z will be all in the exact same locations again is \(\boxed{5400}\). This is the answer we were seeking.
