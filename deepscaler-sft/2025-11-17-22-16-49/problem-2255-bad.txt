To solve this problem, we need to understand the context and then write Python code that will solve it step-by-step.

1. **Understand the Problem:**
    - We have three different students whose names we can denote as \( A \), \( B \), and \( C \). Without loss of generality, let's assume \( A \), \( B \), and \( C \) are the students such that \( A < B < C \) alphabetically.
    - We want to find the probability that when these three students line up, they are in alphabetical order, i.e., \( A \) is in front, followed by \( B \), and then \( C \).

2. **Formulate Possible Outcomes:**
    - The three students can arrange themselves in \( 3! = 6 \) different ways. The six permutations of the three students are:
      \[
      [A, B, C], [A, C, B], [B, A, C], [B, C, A], [C, A, B], [C, B, A]
      \]

3. **Determine Favorable Outcomes:**
    - Out of these six permutations, only one of them is in alphabetical order: \([A, B, C]\).
    - Thus, there is exactly 1 favorable outcome out of 6 possible outcomes.

4. **Calculate the Probability:**
    - The probability that the students are in alphabetical order is \(\frac{1}{6}\).

Now, let's confirm this by writing Python code to simulate all permutations and count how many of those permutations are in alphabetical order.
```python
import itertools

# Define the three students
students = ['A', 'B', 'C']

# Get all permutations of the three students
permutations = list(itertools.permutations(students))

# Count the number of permutations that are in alphabetical order
alphabetical_count = sum(1 for perm in permutations if list(perm) == sorted(perm))

# Total number of permutations
total_permutations = len(permutations)

# Calculate the probability
probability = alphabetical_count / total_permutations
print(probability)
```
Code execution result: 0.16666666666666666

This result can be expressed as the fraction \(\frac{1}{6}\).

So, the probability that the three students will be in alphabetical order when they line up is \(\boxed{\frac{1}{6}}\). This confirms our earlier reasoning and calculations.
