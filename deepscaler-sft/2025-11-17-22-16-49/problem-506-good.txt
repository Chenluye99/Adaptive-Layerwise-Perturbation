To solve this problem, let's start by expressing the complex number \( z \) as \( z = a + bi \), where \( a \) and \( b \) are real numbers. Then, we substitute this into the equation \( z^2 = 4z - 19 + 8i \).

First, compute \( z^2 \):
\[
z^2 = (a + bi)^2 = a^2 + 2abi + (bi)^2 = a^2 + 2abi - b^2 = (a^2 - b^2) + 2abi.
\]
Next, compute \( 4z - 19 + 8i \):
\[
4z - 19 + 8i = 4(a + bi) - 19 + 8i = 4a + 4bi - 19 + 8i = (4a - 19) + (4b + 8)i.
\]
Now, we set the real and imaginary parts equal to each other:
\[
(a^2 - b^2) + 2abi = (4a - 19) + (4b + 8)i.
\]
This gives us two separate equations by comparing the real and imaginary parts:
\[
\begin{cases}
a^2 - b^2 = 4a - 19, \\
2ab = 4b + 8.
\end{cases}
\]

Let's solve the second equation \( 2ab = 4b + 8 \) first:
\[
2ab = 4b + 8 \implies 2ab - 4b = 8 \implies 2b(a - 2) = 8 \implies b(a - 2) = 4.
\]
So, we have:
\[
b(a - 2) = 4.
\]
This means that \( b \) and \( (a - 2) \) are integer pairs that multiply to 4. The possible pairs \((b, a - 2)\) are \((1, 4)\), \((-1, -4)\), \((2, 2)\), \((-2, -2)\), \((4, 1)\), and \((-4, -1)\). We will check each of these pairs to see which values of \( a \) and \( b \) also satisfy the first equation \( a^2 - b^2 = 4a - 19 \).

Additionally, we know that \( |z| \) is an integer, so:
\[
|z| = \sqrt{a^2 + b^2} \text{ is an integer}.
\]
We will implement this step-by-step check in Python to ensure accuracy.
```python
import sympy as sp

# Define the variables
a, b = sp.symbols('a b', real=True)

# Define the equations
eq1 = a**2 - b**2 - 4*a + 19
eq2 = 2*a*b - 4*b - 8

# Solve the system of equations
solutions = []
for b_val in [1, -1, 2, -2, 4, -4]:
    a_val = sp.solve(eq2.subs(b, b_val), a)
    for a_sol in a_val:
        if a_sol.is_real:
            if eq1.subs({a: a_sol, b: b_val}) == 0:
                solutions.append((a_sol, b_val))

# Calculate |z| for each solution and check if it is an integer
integer_solutions = []
for sol in solutions:
    a_sol, b_sol = sol
    abs_z = sp.sqrt(a_sol**2 + b_sol**2)
    if abs_z == int(abs_z):
        integer_solutions.append(sol)

print(integer_solutions)
```
