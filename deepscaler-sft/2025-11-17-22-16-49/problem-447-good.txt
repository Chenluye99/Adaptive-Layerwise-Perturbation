2. **Computational Steps**:
    - For each number \( n \) from 1 to 150, extract its digits.
    - For each digit, check if it is even or odd and then add it to the corresponding sum, \( E(n) \) or \( O(n) \).

```python
def even_odd_sums_up_to_150():
    total_sum = 0

    for n in range(1, 151):
        str_n = str(n)
        even_sum = 0
        odd_sum = 0
        
        for digit in str_n:

            if digit % 2 == 0:
                even_sum += digit
            else:
```
