Let's start by analyzing the functional equation given: 

\[ f(4xy) = 2y[f(x + y) + f(x - y)] \]

We are also given that \( f(5) = 3 \). We need to find \( f(2015) \).

### Step-by-Step Solution:

1. **Substitute Specific Values for \( x \) and \( y \):**

   - **Step 1: Substitute \( y = 0 \):**
     \[
     f(4x \cdot 0) = 2 \cdot 0 \cdot [f(x + 0) + f(x - 0)] \implies f(0) = 0
     \]
     So, we have \( f(0) = 0 \).

   - **Step 2: Substitute \( x = 0 \):**
     \[
     f(4 \cdot 0 \cdot y) = 2y [f(0 + y) + f(0 - y)] \implies f(0) = 2y [f(y) + f(-y)]
     \]
     Since \( f(0) = 0 \), we get:
     \[
     0 = 2y [f(y) + f(-y)] \implies f(y) + f(-y) = 0 \implies f(-y) = -f(y)
     \]
     This means \( f \) is an odd function.

   - **Step 3: Further Exploration with Other Values:**

     Let's substitute \( y = x \):
     \[
     f(4x^2) = 2x [f(x + x) + f(x - x)] \implies f(4x^2) = 2x [f(2x) + f(0)] \implies f(4x^2) = 2x [f(2x)]
     \]
     Since \( f(0) = 0 \), this simplifies to:
     \[
     f(4x^2) = 2x f(2x)
     \]

     Now, let's substitute \( y = -x \):
     \[
     f(4x \cdot (-x)) = 2 (-x) [f(x - x) + f(x + x)] \implies f(-4x^2) = -2x [f(0) + f(2x)] \implies f(-4x^2) = -2x [0 + f(2x)] \implies f(-4x^2) = -2x f(2x)
     \]
     Since \( f \) is an odd function, \( f(-4x^2) = -f(4x^2) \):
     \[
     -f(4x^2) = -2x f(2x) \implies f(4x^2) = 2x f(2x)
     \]
     This is consistent with our previous result.
