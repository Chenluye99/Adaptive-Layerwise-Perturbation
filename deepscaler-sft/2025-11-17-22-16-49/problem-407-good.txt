To solve this problem, we need to use the information given to form a system of equations, and then solve for the unknowns $a$ and $b$.

1. **Understand the Problem:**
    - The function is given as $f(x) = x^3 + ax^2 + bx + a^2$.
    - We are told that $f(x)$ has an extremum at $x = 1$ and that the value of the function at this extremum is 10. An extremum means that the first derivative of $f(x)$ with respect to $x$ is zero at $x = 1$.
    - First, compute the first derivative of $f(x)$:
      \[
      f'(x) = \frac{d}{dx}(x^3 + ax^2 + bx + a^2) = 3x^2 + 2ax + b
      \]
    - Since there is an extremum at $x = 1$, we have:
      \[
      f'(1) = 3(1)^2 + 2a(1) + b = 0 \implies 3 + 2a + b = 0 \implies 2a + b = -3 \quad \text{(Equation 1)}
      \]
    - We are also given that the value of the function at $x = 1$ is 10:
      \[
      f(1) = (1)^3 + a(1)^2 + b(1) + a^2 = 10 \implies 1 + a + b + a^2 = 10 \implies a + b + a^2 = 9 \quad \text{(Equation 2)}
      \]

2. **Set Up and Solve the System of Equations:**
    - We now have two equations:
      \[
      \begin{cases}
      2a + b = -3 \\
      a + b + a^2 = 9
      \end{cases}
      \]
    - We can solve this system of equations step-by-step using Python to get the values of $a$ and $b$.
```python
import sympy as sp

# Define variables
a, b = sp.symbols('a b')

# Define the equations
eq1 = 2 * a + b + 3
eq2 = a + b + a**2 - 9

# Solve the system of equations
solution = sp.solve((eq1, eq2), (a, b))
print(solution)
```
Code execution result: [(-3, 3), (4, -11)]

So, we get two solutions for the system of equations: \((-3, 3)\) and \((4, -11)\). 

3. **Verify Both Solutions:**
   - We need to verify that both solutions are valid by checking if they lead to a proper extremum condition by evaluating the second derivative of the function at \(x = 1\). For a correct extremum, the second derivative at \(x = 1\) must be non-zero.
   - Compute the second derivative of $f(x)$:
     \[
     f''(x) = \frac{d}{dx}(3x^2 + 2ax + b) = 6x + 2a
     \]
   - Evaluate the second derivative at \(x = 1\):
     \[
     f''(1) = 6(1) + 2a = 6 + 2a
     \]
   - We need to ensure that \( f''(1) \neq 0 \), which means \( 6 + 2a \neq 0 \) or \( a \neq -3 \).

Let's check both solutions:

- For \((a, b) = (-3, 3)\):
  \[
  f''(1) = 6 + 2(-3) = 6 - 6 = 0
  \]
  This means that when \( a = -3 \) and \( b = 3 \), the second derivative at \( x = 1 \) is zero, so it is not a proper extremum. Thus, this solution is invalid.

- For \((a, b) = (4, -11)\):
  \[
  f''(1) = 6 + 2(4) = 6 + 8 = 14 \neq 0
  \]
  This means that when \( a = 4 \) and \( b = -11 \), the second derivative at \( x = 1 \) is non-zero, so it is a proper extremum. Thus, this solution is valid.
