To solve the given problem, we need to find all positive integers \( n \) that satisfy the equation \(\mathop{\text{lcm}}[n, 100] = \gcd(n, 100) + 450\).

We can use the following properties of \(\text{lcm}\) and \(\gcd\):

1. \(\text{lcm}[a, b] \times \gcd[a, b] = a \times b\).
2. For \( n \) and 100, let \(\gcd(n, 100) = d \). This means that \( n = dk \) and \( 100 = dm \) for some integers \( k \) and \( m \) such that \(\gcd(k, m) = 1\).

From these, we get:
\[ \text{lcm}[n, 100] = \frac{n \cdot 100}{d} = \frac{dk \cdot 100}{d} = 100k. \]

So, the equation \(\text{lcm}[n, 100] = \gcd(n, 100) + 450\) becomes:
\[ 100k = d + 450. \]

Since \( d = \gcd(n, 100) \), \( d \) must be a divisor of 100. The divisors of 100 are: 1, 2, 4, 5, 10, 20, 25, 50, 100.

We can iterate through each of these divisors and check if the corresponding \( k \) and \( n \) are integers and if \(\gcd(n, 100) = d \).

Let's implement this step-by-step in Python to get the correct answer.
```python
import math

# Initialize a list to store values of n that satisfy the equation
valid_n = []

# We need to check for all positive integers n such that the equation holds
# We will check a reasonable range for n, say from 1 to 10000, as values outside this range are unlikely to satisfy the equation.
for n in range(1, 10001):
    lcm_n_100 = (n * 100) // math.gcd(n, 100)
    gcd_n_100 = math.gcd(n, 100)
    
    if lcm_n_100 == gcd_n_100 + 450:
        valid_n.append(n)

# Get the sum of all such valid n
sum_of_valid_n = sum(valid_n)
print((sum_of_valid_n, valid_n))
```
