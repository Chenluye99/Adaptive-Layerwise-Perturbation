To solve this problem, we need to perform the partial fraction decomposition of the given expression \(\frac{x^2 - 19}{x^3 - 2x^2 - 5x + 6}\).

1. **Factor the Denominator:**
   First, we need to factor the denominator \(x^3 - 2x^2 - 5x + 6\). By polynomial factorization or through testing possible roots, we can find that:
   \[
   x^3 - 2x^2 - 5x + 6 = (x - 1)(x + 2)(x - 3)
   \]

2. **Set Up the Partial Fraction Decomposition:**
   We want to decompose \(\frac{x^2 - 19}{x^3 - 2x^2 - 5x + 6}\) into the form:
   \[
   \frac{x^2 - 19}{(x - 1)(x + 2)(x - 3)} = \frac{A}{x - 1} + \frac{B}{x + 2} + \frac{C}{x - 3}
   \]
   Combining the right-hand side over a common denominator, we get:
   \[
   \frac{A(x + 2)(x - 3) + B(x - 1)(x - 3) + C(x - 1)(x + 2)}{(x - 1)(x + 2)(x - 3)} = \frac{x^2 - 19}{(x - 1)(x + 2)(x - 3)}
   \]
   This implies:
   \[
   A(x + 2)(x - 3) + B(x - 1)(x - 3) + C(x - 1)(x + 2) = x^2 - 19
   \]

3. **Find the Coefficients \(A\), \(B\), and \(C\):**
   To find \(A\), \(B\), and \(C\), we can substitute specific values of \(x\) that will simplify the equation.

   - **Substitute \(x = 1\):**
     \[
     A(1 + 2)(1 - 3) + B(1 - 1)(1 - 3) + C(1 - 1)(1 + 2) = 1^2 - 19 \implies A(3)(-2) = -18 \implies -6A = -18 \implies A = 3
     \]

   - **Substitute \(x = -2\):**
     \[
     A(-2 + 2)(-2 - 3) + B(-2 - 1)(-2 - 3) + C(-2 - 1)(-2 + 2) = (-2)^2 - 19 \implies B(-3)(-5) = -15 \implies 15B = -15 \implies B = -1
     \]

   - **Substitute \(x = 3\):**
     \[
     A(3 + 2)(3 - 3) + B(3 - 1)(3 - 3) + C(3 - 1)(3 + 2) = 3^2 - 19 \implies C(2)(5) = -10 \implies 10C = -10 \implies C = -1
     \]

4. **Formulate the Product \(ABC\):**
   Having found that \(A = 3\), \(B = -1\), and \(C = -1\), the product \(ABC\) is:
   \[
   ABC = 3 \cdot (-1) \cdot (-1) = 3
   \]
