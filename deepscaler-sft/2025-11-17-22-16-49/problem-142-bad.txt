To solve the problem, we need to place the numbers 1 through 9 in a 3x3 grid such that any two consecutive numbers are in adjacent squares (sharing an edge), and the numbers in the four corners add up to 18. We then need to determine what the number in the center of the grid is.

Let's start by setting up the grid and iterating through all possible permutations of the numbers 1 to 9 to find a valid configuration. We'll then check if the configuration meets all the conditions mentioned in the problem.

We can use Python to check all possible permutations of placing the numbers 1 through 9 in a 3x3 grid and then verify if the given constraints are satisfied. Finally, from the valid configurations, we will determine the number in the center of the grid.

Let's implement this step-by-step in Python.
```python
import itertools

# 3x3 grid representation
grid = [[0 for _ in range(3)] for _ in range(3)]

# Function to check if two numbers are in adjacent squares
def are_adjacent(pos1, pos2):
    (x1, y1) = pos1
    (x2, y2) = pos2
    return abs(x1 - x2) + abs(y1 - y2) == 1

# Function to place numbers in the grid and check constraints
def find_center_number():
    for perm in itertools.permutations(range(1, 10)):
        for i in range(3):
            for j in range(3):
                grid[i][j] = perm[i * 3 + j]
        
        # Check if consecutive numbers are adjacent
        for i in range(8):
            num1 = grid[i // 3][i % 3]
            num2 = grid[(i + 1) // 3][(i + 1) % 3]
            if abs(num1 - num2) == 1 and not are_adjacent((i // 3, i % 3), ((i + 1) // 3, (i + 1) % 3)):
                break
        else:
            # Check if the numbers in the four corners add up to 18
            corners_sum = grid[0][0] + grid[0][2] + grid[2][0] + grid[2][2]
            if corners_sum == 18:
                center_number = grid[1][1]
                return center_number

center_number = find_center_number()
print(center_number)
```
