First, let's start by understanding the problem. We need to find the greatest possible sum of the digits in the base-eight (octal) representation of a positive integer that is less than 1728.

1. **Convert 1728 to Base Eight:**
   - First, we note that \( 1728_{10} \) is the upper limit. We'll convert 1728 to its base-eight representation to understand the range we are dealing with.
   - To convert 1728 to base-eight, we repeatedly divide 1728 by 8 and keep track of the remainders.

2. **Generate and Evaluate Numbers:**
   - We need to consider numbers less than 1728 and convert them to base-eight.
   - For each number, compute the sum of its digits in the base-eight representation.
   - Find the maximum sum of the digits obtained from this process.

3. **Implementation in Python:**
   - We can write a Python function to convert a number to its base-eight representation and then calculate the sum of its digits.
   - We can then iterate through all numbers from 1 to 1727, calculate the sum of the digits of their base-eight representation, and keep track of the maximum sum encountered.

Let's implement this step-by-step in Python to ensure accuracy.
```python
def to_octal_digits_sum(n):
    """Convert a number to its base-eight representation and return the sum of its digits."""
    if n == 0:
        return 0
    
    octalrepresentation = []
    while n > 0:
        octalrepresentation.append(n % 8)
        n = n // 8
    
    return sum(octalrepresentation)

max_sum = 0
best_number = 0

for i in range(1, 1728):
    digit_sum = to_octal_digits_sum(i)
    if digit_sum > max_sum:
        max_sum = digit_sum
        best_number = i

print(((max_sum, best_number)))
```
