To solve the problem, we need to find the lengths of the sides of the quadrilateral formed by the points \(A, B, C, D\). The distance between two points \((x_1, y_1)\) and \((x_2, y_2)\) is given by the formula:

\[ \text{Distance} = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2} \]

We need to compute the distances for each of the sides \(AB, BC, CD, DA\):

1. Distance \(AB\):
\[ AB = \sqrt{(2 - 0)^2 + (5 - 1)^2} = \sqrt{2^2 + 4^2} = \sqrt{4 + 16} = \sqrt{20} = 2\sqrt{5} \]

2. Distance \(BC\):
\[ BC = \sqrt{(5 - 2)^2 + (2 - 5)^2} = \sqrt{3^2 + (-3)^2} = \sqrt{9 + 9} = \sqrt{18} = 3\sqrt{2} \]

3. Distance \(CD\):
\[ CD = \sqrt{(7 - 5)^2 + (0 - 2)^2} = \sqrt{2^2 + (-2)^2} = \sqrt{4 + 4} = \sqrt{8} = 2\sqrt{2} \]

4. Distance \(DA\):
\[ DA = \sqrt{(7 - 0)^2 + (0 - 1)^2} = \sqrt{7^2 + (-1)^2} = \sqrt{49 + 1} = \sqrt{50} = 5\sqrt{2} \]

The perimeter of the quadrilateral \(ABCD\) is the sum of these distances:
\[ \text{Perimeter} = AB + BC + CD + DA = 2\sqrt{5} + 3\sqrt{2} + 2\sqrt{2} + 5\sqrt{2} = 2\sqrt{5} + (3 + 2 + 5)\sqrt{2} = 2\sqrt{5} + 10\sqrt{2} \]

So, the perimeter is in the form \(a\sqrt{2} + b\sqrt{5}\), where \(a = 10\) and \(b = 2\). The sum of \(a\) and \(b\) is:
