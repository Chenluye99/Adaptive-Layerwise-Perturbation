First, let's recall some trigonometric identities and properties in a triangle:

1. We know that in any triangle \(ABC\), the angles \(A, B, C\) satisfy the identity:
   \[
   A + B + C = \pi
   \]
   This means:
   \[
   C = \pi - (A + B)
   \]
2. Using the cosine angle sum identity, we have:
   \[
   \cos C = \cos(\pi - (A + B)) = -\cos(A + B)
   \]
   And further, using the angle addition formula for cosine:
   \[
   \cos(A + B) = \cos A \cos B - \sin A \sin B
   \]
3. We are given:
   \[
   \sin A = \frac{3}{5}
   \]
   We can find \(\cos A\) using the Pythagorean identity:
   \[
   \sin^2 A + \cos^2 A = 1 \implies \left(\frac{3}{5}\right)^2 + \cos^2 A = 1 \implies \frac{9}{25} + \cos^2 A = 1 \implies \cos^2 A = \frac{16}{25} \implies \cos A = \pm \frac{4}{5}
   \]
   Since \(A\) is an angle in a triangle, \(\cos A\) must be positive:
   \[
   \cos A = \frac{4}{5}
   \]

4. Next, we are also given:
   \[
   \cos B = \frac{5}{13}
   \]
   Using the Pythagorean identity to find \(\sin B\):
   \[
   \sin^2 B + \cos^2 B = 1 \implies \sin^2 B + \left(\frac{5}{13}\right)^2 = 1 \implies \sin^2 B + \frac{25}{169} = 1 \implies \sin^2 B = 1 - \frac{25}{169} = \frac{144}{169} \implies \sin B = \pm \frac{12}{13}
   \]
   Since \(B\) is an angle in a triangle, \(\sin B\) must be positive:
   \[
   \sin B = \frac{12}{13}
   \]

5. Now, substituting \(\cos A, \sin A, \cos B, \sin B\) into the formula for \(\cos(A + B)\):
   \[
   \cos(A + B) = \cos A \cos B - \sin A \sin B = \frac{4}{5} \cdot \frac{5}{13} - \frac{3}{5} \cdot \frac{12}{13} = \frac{20}{65} - \frac{36}{65} = \frac{20 - 36}{65} = \frac{-16}{65}
   \]
   So,
   \[
   \cos C = -\cos(A + B) = - \left( \frac{-16}{65} \right) = \frac{16}{65}
   \]
