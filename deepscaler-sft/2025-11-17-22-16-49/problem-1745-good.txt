To solve the problem, we need to determine how many different negative values of \( x \) make \(\sqrt{x + 150}\) a positive integer.

1. **Set Up the Equation:**
    - Let \(\sqrt{x + 150} = k\), where \( k \) is a positive integer.
    - Squaring both sides, we get \( x + 150 = k^2 \).
    - Rearrange this equation to solve for \( x \):
      \[
      x = k^2 - 150
      \]
    - We need \( x \) to be negative, so:
      \[
      k^2 - 150 < 0 \implies k^2 < 150
      \]

2. **Find the Range for \( k \):**
    - We need to find the largest integer \( k \) such that \( k^2 < 150 \).
    - The square root of 150 is approximately 12.247, so the largest integer \( k \) can be is 12.
    - The smallest positive integer \( k \) can be is 1, because \( k \) is a positive integer.

3. **Iterate Through Possible Values of \( k \):**
    - We need to check each integer value of \( k \) from 1 to 12 to see if it gives a valid negative \( x \).
    - For each \( k \) in this range, compute \( x = k^2 - 150 \) and check if \( x \) is indeed negative.

4. **Implement This in Python to Get the Final Count:**
    - We will iterate through the values of \( k \) from 1 to 12, compute \( x \) for each, and count how many such \( x \) are negative.

Let's implement this step-by-step in Python to ensure accuracy.
```python
import sympy as sp

# Initialize a counter for the number of valid negative x values
count = 0
```
