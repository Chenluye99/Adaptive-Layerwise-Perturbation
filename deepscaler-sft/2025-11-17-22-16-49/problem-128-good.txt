To solve this problem, we need to understand how Pascal's triangle works. Each element in Pascal's triangle is a binomial coefficient, and the \(n\)-th row of Pascal's triangle contains the coefficients of the expansion of \((a + b)^n\). The elements of the \(n\)-th row are given by \(\binom{n}{k}\) for \(k = 0, 1, 2, \ldots, n\).

The 20th row of Pascal's triangle corresponds to the coefficients of \((a + b)^{20}\), so the elements are \(\binom{20}{0}, \binom{20}{1}, \binom{20}{2}, \ldots, \binom{20}{20}\). The fifth element in this row corresponds to \(\binom{20}{4}\) and the sixth element corresponds to \(\binom{20}{5}\). We need to find the sum of these two values.

Let's use Python to calculate these binomial coefficients and get the result.
```python
import math

# Calculate the 5th and 6th elements in the 20th row of Pascal's triangle
fifth_element = math.comb(20, 4)
sixth_element = math.comb(20, 5)

# Calculate their sum
result = fifth_element + sixth_element
print(result)
```
Code execution result: 20349

Thus, the sum of the fifth and sixth elements in Row 20 of Pascal's triangle is \(\boxed{20349}\). This completes our solution.
