To solve the problem, we need to find the value of \( x^2 + \frac{1}{x^2} \) given that \( x + \frac{1}{x} = 6 \).

We can start by squaring both sides of the equation \( x + \frac{1}{x} = 6 \):

\[
\left( x + \frac{1}{x} \right)^2 = 6^2
\]

This expands to:

\[
x^2 + 2 \cdot x \cdot \frac{1}{x} + \frac{1}{x^2} = 36
\]

This simplifies to:

\[
x^2 + 2 + \frac{1}{x^2} = 36
\]

By subtracting 2 from both sides, we get:

\[
x^2 + \frac{1}{x^2} = 34
\]

Thus, the value of \( x^2 + \frac{1}{x^2} \) is 34. Let's confirm this by coding the solution in Python.
```python
# Given value
lhs = 6

# Calculate x^2 + 1/x^2 using the relation derived above
x_plus_1_over_x = lhs
x_squared_plus_1_over_x_squared = x_plus_1_over_x ** 2 - 2

print(x_squared_plus_1_over_x_squared)
```
Code execution result: 34
