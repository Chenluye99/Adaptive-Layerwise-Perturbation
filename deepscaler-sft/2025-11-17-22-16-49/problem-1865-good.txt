First, let's outline the problem and set up the equations we need to solve it.

1. **Problem Understanding:**
    - We have a circle with its center on the x-axis. Let the center of the circle be \((a, 0)\) and the radius of the circle be \(r\).
    - The points \((0, 4)\) and \((1, 3)\) lie on this circle, so their distances from the center \((a, 0)\) are both equal to the radius \(r\).

2. **Formulate Equations:**
    - The equation for the distance from the center \((a, 0)\) to the point \((0, 4)\) is:
      \[
      \sqrt{(0 - a)^2 + (4 - 0)^2} = r \implies \sqrt{a^2 + 4^2} = r \implies \sqrt{a^2 + 16} = r
      \]
    - The equation for the distance from the center \((a, 0)\) to the point \((1, 3)\) is:
      \[
      \sqrt{(1 - a)^2 + (3 - 0)^2} = r \implies \sqrt{(1 - a)^2 + 3^2} = r \implies \sqrt{(1 - a)^2 + 9} = r
      \]

3. **Set Up the System of Equations:**
    - We now have two equations:
      \[
      \sqrt{a^2 + 16} = r
      \]
      \[
      \sqrt{(1 - a)^2 + 9} = r
      \]
    - We can set the expressions inside the square roots equal to each other because they both equal \(r^2\):
      \[
      a^2 + 16 = (1 - a)^2 + 9
      \]

4. **Solve for \(a\):**
    - Expand and simplify the equation:
      \[
      a^2 + 16 = (1 - a)^2 + 9 \implies a^2 + 16 = 1 - 2a + a^2 + 9 \implies 16 = 10 - 2a \implies 6 = -2a \implies a = -3
      \]

5. **Find the Radius \(r\):**
    - Substitute \(a = -3\) back into one of the original equations to solve for \(r\). We can use \(\sqrt{a^2 + 16} = r\):
      \[
      r = \sqrt{(-3)^2 + 16} = \sqrt{9 + 16} = \sqrt{25} = 5
      \]

Let's confirm this by coding the solution to ensure accuracy.
```python
import sympy as sp

# Define the variables
a, r = sp.symbols('a r')

# Set up the equations based on the distances from the center (a, 0) to the points (0, 4) and (1, 3)
eq1 = sp.Eq(sp.sqrt(a**2 + 4**2), r)
eq2 = sp.Eq(sp.sqrt((1 - a)**2 + 3**2), r)

# Solve the system of equations
solution = sp.solve((eq1, eq2), (a, r))

print(solution)
```
Code execution result: [(-3, 5)]

This confirms that the solution to the system of equations is \( a = -3 \) and \( r = 5 \).

Thus, the radius of the circle is \(\boxed{5}\). This is our final answer.
