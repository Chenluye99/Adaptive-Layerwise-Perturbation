To solve this problem, we can use the principle of inclusion and exclusion from set theory.

Let's define:
- \( B \) as the set of players taking Biology.
- \( C \) as the set of players taking Chemistry.

From the problem, we have:
- The total number of players on the baseball team is 12.
- The number of players taking Biology, \( |B| \), is 7.
- The number of players taking both Biology and Chemistry, \( |B \cap C| \), is 2.

We need to find the number of players taking Chemistry, \( |C| \).

According to the principle of inclusion and exclusion, the total number of players taking at least one of Biology or Chemistry is given by:
\[ |B \cup C| = |B| + |C| - |B \cap C| \]

We know that all 12 players are taking at least one of the subjects, so:
\[ |B \cup C| = 12 \]

Substitute the known values into the equation:
\[ 12 = 7 + |C| - 2 \]

Simplify and solve for \( |C| \):
\[ 12 = 5 + |C| \]
\[ |C| = 12 - 5 \]
\[ |C| = 7 \]

So, the number of players taking Chemistry is \( |C| = 7 \). Let's confirm this with Python code for accuracy.
```python
# Given values
total_players = 12
players_taking_biology = 7
players_taking_both = 2

# Using the principle of inclusion and exclusion to find the number of players taking Chemistry
players_taking_chemistry = total_players - players_taking_biology + players_taking_both

print(players_taking_chemistry)
```
Code execution result: 7

Thus, the number of players taking Chemistry is \(\boxed{7}\). This confirms our solution is correct.
