To solve this problem, let's start with the understanding that \( f \) is a linear function. A linear function can be written in the form:

\[ f(x) = mx + c \]

where \( m \) is the slope and \( c \) is the y-intercept.

We are given that:

\[ f(6) - f(2) = 12 \]

Substitute the linear function form into this equation:

\[ f(6) = 6m + c \]
\[ f(2) = 2m + c \]

So,

\[ f(6) - f(2) = (6m + c) - (2m + c) = 4m = 12 \]

From this, we can solve for \( m \):

\[ 4m = 12 \implies m = 3 \]

Now we need to find \( f(12) - f(2) \). Substitute \( m = 3 \) back into the expressions for \( f(12) \) and \( f(2) \):

\[ f(12) = 12m + c \]
\[ f(2) = 2m + c \]

Thus,

\[ f(12) - f(2) = (12m + c) - (2m + c) = 10m \]

Since we know that \( m = 3 \):

\[ f(12) - f(2) = 10 \cdot 3 = 30 \]

Let's confirm this step-by-step solution using Python code to ensure accuracy.
```python
# Let's define a linear function f(x) = mx + c and verify our solution.
import sympy as sp

# Define the variables
m, c = sp.symbols('m c')

# Set up the equation based on the given condition f(6) - f(2) = 12
f_6 = 6 * m + c
f_2 = 2 * m + c
condition = sp.Eq(f_6 - f_2, 12)

# Solve for m
solution = sp.solve(condition, m)[0]

# Now substitute m back to find f(12) - f(2)
f_12 = 12 * solution + c
f_2 = 2 * solution + c

result = f_12 - f_2
print(result)
```
Code execution result: 30

Thus, the final answer is \(\boxed{30}\). This confirms our solution is accurate.
