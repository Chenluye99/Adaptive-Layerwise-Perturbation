1. When the soldiers are divided into groups of 4, they divide successfully, so the number of soldiers, let's call it \( n \), must be divisible by 4: \( n \mod 4 = 0 \).
2. When the soldiers are divided into groups of 3, 2 soldiers are left without a group: \( n \mod 3 = 2 \).
3. When the soldiers are divided into groups of 11, 5 soldiers are left without a group: \( n \mod 11 = 5 \).
4. The number of soldiers is estimated to be about two hundred, so \( 200 > n > 0 \).

We need to find a number that satisfies all these constraints. We'll iterate over the possible values for \( n \) and check which value meets all of these conditions. We'll use Python to do this efficiently.
```python
# We will iterate through numbers in the range 1 to 200 and check each condition for every number.
# The conditions are:
# 1. \( n \mod 4 == 0 \)
# 2. \( n \mod 3 == 2 \)
# 3. \( n \mod 11 == 5 \)

regiment_size = []

# Iterate over possible values for the number of soldiers, checking each condition

    if (n % 4 == 0) and (n % 3 == 2) and (n % 11 == 5):
        regiment_size.append(n)

print(regiment_size)
```
