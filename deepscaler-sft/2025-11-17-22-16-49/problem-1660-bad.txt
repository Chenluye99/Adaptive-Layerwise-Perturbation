First, let's start by analyzing the function \( f(x) = \frac{2x^2 - 5x - 7}{x^2 - 4x + 1} \).

1. **Find the Horizontal Asymptote:**
    - For a rational function, the horizontal asymptote is determined by the degrees of the numerator and denominator polynomials.
    - In this case, both the numerator and denominator are quadratic polynomials (degree 2), so the horizontal asymptote is given by the ratio of the leading coefficients of the numerator and the denominator.
    - The leading coefficient of the numerator \(2x^2 - 5x - 7\) is 2, and the leading coefficient of the denominator \(x^2 - 4x + 1\) is 1.
    - Therefore, the horizontal asymptote is \( y = \frac{2}{1} = 2 \).

2. **Crossing the Horizontal Asymptote:**
    - To find where the function \( f(x) \) crosses its horizontal asymptote \( y = 2 \), we set \( f(x) = 2 \):
      \[
      \frac{2x^2 - 5x - 7}{x^2 - 4x + 1} = 2
      \]
    - We solve this equation to find the value of \( x \):
      \[
      2x^2 - 5x - 7 = 2(x^2 - 4x + 1)
      \]
      \[
      2x^2 - 5x - 7 = 2x^2 - 8x + 2
      \]
    - By simplifying the equation, we get:
      \[
      2x^2 - 5x - 7 = 2x^2 - 8x + 2 \implies -5x - 7 = -8x + 2 \implies 3x = 9 \implies x = 3
      \]

3. **Verification:**
    - We need to verify that this value of \( x \) makes \( f(x) = 2 \):
      \[
      f(3) = \frac{2(3)^2 - 5(3) - 7}{(3)^2 - 4(3) + 1} = \frac{2 \cdot 9 - 15 - 7}{9 - 12 + 1} = \frac{18 - 15 - 7}{9 - 12 + 1} = \frac{-4}{-2} = 2
      \]
    - Therefore, the function \( f(x) \) crosses its horizontal asymptote at \( x = 3 \).

Let's confirm this by implementing it in Python to ensure accuracy.
```python
import sympy as sp

# Define the variables and the function
x = sp.symbols('x')
f = (2*x**2 - 5*x - 7) / (x**2 - 4*x + 1)

# Set up the equation to find where f(x) = 2
equation = sp.Eq(f, 2)

# Solve for x
solution = sp.solve(equation, x)
print(solution)
```
Code execution result: [3]

This confirms that the solution is correct. Therefore, the value of \( x \) at which the function \( f(x) = \frac{2x^2 - 5x - 7}{x^2 - 4x + 1} \) crosses its horizontal asymptote is \(\boxed{3}\).
