First, we will recall that the transformation from rectangular (Cartesian) coordinates $(x, y, z)$ to cylindrical coordinates $(r, \theta, z)$ is given by the following formulas:

\[
r = \sqrt{x^2 + y^2}
\]
\[
\theta = \begin{cases}
\arctan\left(\frac{y}{x}\right) & \text{if } x > 0 \\
\arctan\left(\frac{y}{x}\right) + \pi & \text{if } x < 0 \text{ and } y \ge 0 \\
\arctan\left(\frac{y}{x}\right) - \pi & \text{if } x < 0 \text{ and } y < 0 \\
\frac{\pi}{2} & \text{if } x = 0 \text{ and } y > 0 \\
-\frac{\pi}{2} & \text{if } x = 0 \text{ and } y < 0 \\
\text{undefined} & \text{if } x = 0 \text{ and } y = 0
\end{cases}
\]
\[
z = z
\]

Given the rectangular coordinates $( -5, 0, -8 )$, we can substitute $x = -5$, $y = 0$, and $z = -8$ into these formulas.

1. Calculate \( r \):

\[
r = \sqrt{(-5)^2 + 0^2} = \sqrt{25} = 5
\]

2. Calculate \( \theta \):

Since $x = -5$ and $y = 0$, we need to pay attention to the correct quadrant or origin placement. The \(\arctan\left(\frac{y}{x}\right)\) would be undefined directly because \(\frac{0}{-5} = 0\), but we know that when $x < 0$ and $y = 0$, $\theta = \pi$ because the point lies on the negative x-axis. 

So, we have:

\[
\theta = \pi
\]

3. The coordinate $z$ remains the same:

\[
z = -8
\]

Hence, the cylindrical coordinates are \((5, \pi, -8)\). Let's confirm this with Python to ensure accuracy.
```python
import numpy as np

# Given rectangular coordinates
x, y, z = -5, 0, -8

# Calculate r
r = np.sqrt(x**2 + y**2)

# Calculate theta, making sure to handle the case where x = 0 properly
theta = np.arctan2(y, x)

# Ensure theta is in the range [0, 2 * np.pi)
if theta < 0:
    theta += 2 * np.pi

print(((r, theta, z)))
```
Code execution result: (5.0, 3.141592653589793, -8)

Thus, the cylindrical coordinates for the point $(-5, 0, -8)$ are \(\boxed{(5, \pi, -8)}\). This confirms our earlier reasoning and calculations.
