To solve this problem, we need to iterate through all the natural numbers from 1 to 600 and check each number to see if it contains the digit '5'. We will count how many of these numbers contain the digit '5' at least once.

Let's write the Python code to perform this task.
```python
# Initialize a counter to keep track of the numbers containing the digit '5'
count = 0

# Iterate through all the numbers from 1 to 600
for num in range(1, 601):
    if '5' in str(num):
        count += 1

print(count)
```
Code execution result: 195

Thus, the number of natural numbers from 1 to 600 that contain the digit '5' at least once is \(\boxed{195}\). This is our final answer.
