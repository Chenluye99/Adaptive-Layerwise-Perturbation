To solve the problem, we need to find the sum of the infinite series \(\sum_{n = 1}^\infty \frac{1}{n(n + 2)}\).

### Step-by-Step Solution:

1. **Understand the Series:**
   We need to decompose the term \(\frac{1}{n(n + 2)}\) into partial fractions. Using partial fraction decomposition, we get:
   \[
   \frac{1}{n(n + 2)} = \frac{A}{n} + \frac{B}{n + 2}
   \]
   To find \(A\) and \(B\), we solve:
   \[
   1 = A(n + 2) + Bn
   \]
   By comparing coefficients, we get:
   \[
   A + B = 0 \quad \text{(coefficient of } n)
   \]
   \[
   2A = 1 \quad \text{(constant term)}
   \]
   Solving these, we obtain:
   \[
   2A = 1 \implies A = \frac{1}{2}
   \]
   \[
   A + B = 0 \implies \frac{1}{2} + B = 0 \implies B = -\frac{1}{2}
   \]
   Therefore:
   \[
   \frac{1}{n(n + 2)} = \frac{1/2}{n} - \frac{1/2}{n + 2} = \frac{1}{2} \left( \frac{1}{n} - \frac{1}{n + 2} \right)
   \]

2. **Rewrite the Series:**
   Substituting this back into the series, we get:
   \[
   \sum_{n = 1}^\infty \frac{1}{n(n + 2)} = \sum_{n = 1}^\infty \frac{1}{2} \left( \frac{1}{n} - \frac{1}{n + 2} \right) = \frac{1}{2} \sum_{n = 1}^\infty \left( \frac{1}{n} - \frac{1}{n + 2} \right)
   \]

3. **Observe the Telescoping Nature:**
   The series \(\sum_{n = 1}^\infty \left( \frac{1}{n} - \frac{1}{n + 2} \right)\) is a telescoping series. When we write out the first few terms, we see:
   \[
   \left( \frac{1}{1} - \frac{1}{3} \right) + \left( \frac{1}{2} - \frac{1}{4} \right) + \left( \frac{1}{3} - \frac{1}{5} \right) + \left( \frac{1}{4} - \frac{1}{6} \right) + \cdots
   \]
   We see that most terms cancel out, leaving us with:
   \[
   1 + \frac{1}{2} - \lim_{N \to \infty} \left( \frac{1}{N + 1} + \frac{1}{N + 2} \right)
   \]
   As \(N \to \infty\), \(\frac{1}{N + 1} \to 0\) and \(\frac{1}{N + 2} \to 0\), so the tail of the series goes to 0. Therefore, the sum of the series is:
   \[
   1 + \frac{1}{2} = \frac{3}{2}
   \]
   Hence:
   \[
   \sum_{n = 1}^\infty \frac{1}{n(n + 2)} = \frac{1}{2} \cdot \frac{3}{2} = \frac{3}{4}
   \]
