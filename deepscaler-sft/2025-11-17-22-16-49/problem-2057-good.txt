First, let's start by recalling that in an equilateral triangle, all three sides are of equal length. Given the vertices of the triangle \((0,0)\), \((a,11)\), and \((b,37)\), we can denote the distances between these points and set them equal to each other because it is an equilateral triangle.

1. **Calculate the Distances:**

   - The distance between \((0,0)\) and \((a,11)\) is:
     \[
     d_1 = \sqrt{(a - 0)^2 + (11 - 0)^2} = \sqrt{a^2 + 11^2} = \sqrt{a^2 + 121}
     \]
   - The distance between \((0,0)\) and \((b,37)\) is:
     \[
     d_2 = \sqrt{(b - 0)^2 + (37 - 0)^2} = \sqrt{b^2 + 37^2} = \sqrt{b^2 + 1369}
     \]
   - The distance between \((a,11)\) and \((b,37)\) is:
     \[
     d_3 = \sqrt{(b - a)^2 + (37 - 11)^2} = \sqrt{(b - a)^2 + 26^2} = \sqrt{(b - a)^2 + 676}
     \]

2. **Set Up the Equations:**

   Since it is an equilateral triangle, we have:
   \[
   d_1 = d_2 = d_3
   \]

   Therefore, we can set up the following equations by equating the distances:
   \[
   \sqrt{a^2 + 121} = \sqrt{b^2 + 1369}
   \]
   \[
   \sqrt{a^2 + 121} = \sqrt{(b - a)^2 + 676}
   \]

3. **Square Both Sides of the Equations:**

   Squaring both sides of the first equation, we get:
   \[
   a^2 + 121 = b^2 + 1369
   \]
   Rearrange this equation to:
   \[
   a^2 - b^2 = 1369 - 121 \implies a^2 - b^2 = 1248 \implies (a - b)(a + b) = 1248 \quad \text{(Equation 1)}
   \]

   For the second equation, we get:
   \[
   a^2 + 121 = (b - a)^2 + 676
   \]
   Rearrange this equation to:
   \[
   a^2 + 121 = b^2 - 2ab + a^2 + 676 \implies 121 = b^2 - 2ab + 676 \implies b^2 - 2ab = 121 - 676 \implies b^2 - 2ab = -555 \implies 2ab - b^2 = 555 \quad \text{(Equation 2)}
   \]

4. **Solve the System of Equations:**

   We now have two equations:
   \[
   (a - b)(a + b) = 1248 \quad \text{(Equation 1)}
   \]
   \[
   2ab - b^2 = 555 \quad \text{(Equation 2)}
   \]

   We can solve these equations step-by-step using a systematic approach with Python to get the precise values for \(a\) and \(b\), and then find \(ab\).
```python
import sympy as sp

# Define the variables
a, b = sp.symbols('a b', real=True, positive=True)

# Define the equations based on the distances being equal
eq1 = sp.Eq(sp.sqrt(a**2 + 121), sp.sqrt(b**2 + 1369))
eq2 = sp.Eq(sp.sqrt(a**2 + 121), sp.sqrt((b - a)**2 + 676))

# Solve the system of equations
solution = sp.solve((eq1, eq2), (a, b))

print(solution)
```
Code execution result: [(21*sqrt(3), 5*sqrt(3))]

So, we have the solutions \( a = 21 \sqrt{3} \) and \( b = 5 \sqrt{3} \). Now, to find the value of \( ab \):

\[
ab = (21 \sqrt{3}) \cdot (5 \sqrt{3}) = 21 \cdot 5 \cdot (\sqrt{3} \cdot \sqrt{3}) = 105 \cdot 3 = 315
\]

Thus, the value of \( ab \) is \(\boxed{315}\). This is our final answer.
