To solve this problem, we need to follow these steps:

1. Define the polynomial \( P(x) = 1 - \frac{1}{3}x + \frac{1}{6}x^2 \).
2. Define the polynomial \( Q(x) = P(x)P(x^3)P(x^5)P(x^7)P(x^9) \).
3. Expand \( Q(x) \) to get it in the form \(\sum_{i=0}^{50} a_i x^i \).
4. Compute \(\sum_{i=0}^{50} |a_i|\).

Let's implement this step-by-step using Python and the SymPy library.

```python
import sympy as sp

# Define the variable
x = sp.symbols('x')

# Define P(x)
P = 1 - (1/3)*x + (1/6)*x**2

# Define Q(x) as the product of P(x), P(x^3), P(x^5), P(x^7), P(x^9)
Q = P * P.subs(x, x**3) * P.subs(x, x**5) * P.subs(x, x**7) * P.subs(x, x**9)

# Expand Q(x)
Q_expanded = sp.expand(Q)

# Get the coefficients of Q(x)
coefficients = [Q_expanded.coeff(x, i) for i in range(51)]

# Compute the sum of the absolute values of the coefficients
sum_abs_coefficients = sum([abs(coeff) for coeff in coefficients])

print(sum_abs_coefficients)
```
