Given the equations:

1. \( a^2 + b^2 + c^2 = 25 \)
2. \( x^2 + y^2 + z^2 = 36 \)
3. \( ax + by + cz = 30 \)

We are asked to find \(\frac{a + b + c}{x + y + z}\).

To solve this, we can use the Cauchy-Schwarz inequality, which states that for any two sets of real numbers, the following holds:

\[
(a_1^2 + a_2^2 + a_3^2)(b_1^2 + b_2^2 + b_3^2) \geq (a_1 b_1 + a_2 b_2 + a_3 b_3)^2
\]

Applying this to our variables:

\[
(a^2 + b^2 + c^2)(x^2 + y^2 + z^2) \geq (ax + by + cz)^2
\]

Substituting the given values:

\[
(25)(36) \geq (30)^2
\]

\[
900 \geq 900
\]

This shows that equality holds in the Cauchy-Schwarz inequality, which means that the vectors \((a, b, c)\) and \((x, y, z)\) are linearly dependent. That is, there exists a constant \( k \) such that:

\[
a = kx, \quad b = ky, \quad c = kz
\]

Substitute these into the first equation \( a^2 + b^2 + c^2 = 25 \):

\[
(kx)^2 + (ky)^2 + (kz)^2 = 25
\]

\[
k^2 (x^2 + y^2 + z^2) = 25
\]

We know from the second equation that \( x^2 + y^2 + z^2 = 36 \), so:

\[
k^2 \cdot 36 = 25
\]

\[
k^2 = \frac{25}{36}
\]

\[
k = \frac{5}{6}
\]

With \( k = \frac{5}{6} \), we have:

\[
a = \frac{5}{6} x, \quad b = \frac{5}{6} y, \quad c = \frac{5}{6} z
\]

We need to find \(\frac{a + b + c}{x + y + z}\):

\[
a + b + c = \frac{5}{6} x + \frac{5}{6} y + \frac{5}{6} z = \frac{5}{6} (x + y + z)
\]

Thus:

\[
\frac{a + b + c}{x + y + z} = \frac{\frac{5}{6} (x + y + z)}{x + y + z} = \frac{5}{6}
\]
