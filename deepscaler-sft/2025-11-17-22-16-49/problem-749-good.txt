To solve the problem, we need to check all integers between 200 and 300, compute the sum of the digits of each integer, and then count how many of these integers have a digit sum equal to 15.

Let's implement this step-by-step in Python.
```python
# Initialize a counter
count = 0

# Check each number from 200 to 299
for num in range(200, 300):
    # Calculate the sum of the digits of the number
    digit_sum = sum(int(digit) for digit in str(num))
    
    # Check if the sum of the digits is equal to 15
    if digit_sum == 15:
        count += 1

print(count)
```
Code execution result: 6

Thus, the number of integers between 200 and 300 that have the sum of their digits equal to 15 is \(\boxed{6}\). This is our final answer.
