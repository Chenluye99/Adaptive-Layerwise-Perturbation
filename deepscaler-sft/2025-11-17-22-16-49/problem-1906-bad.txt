To solve this problem, we need to use properties of quadratic equations and their roots. 

1. **Properties of a Quadratic Equation:**
    - For the quadratic equation \(x^2 + bx + c = 0\), the roots are given by the quadratic formula:
      \[
      x = \frac{-b \pm \sqrt{b^2 - 4c}}{2}
      \]
    - Let the roots be \(\alpha\) and \(\beta\). By Vieta's formulas, we know:
      \[
      \alpha + \beta = -b
      \]
      \[
      \alpha \cdot \beta = c
      \]
    - The difference of the roots is:
      \[
      |\alpha - \beta| = \left| \frac{-b + \sqrt{b^2 - 4c}}{2} - \frac{-b - \sqrt{b^2 - 4c}}{2} \right| = \left| \frac{2 \sqrt{b^2 - 4c}}{2} \right| = |\sqrt{b^2 - 4c}|
      \]
    - According to the problem, the difference of the roots is given as \(|b - 2c|\). Therefore, we have:
      \[
      |\sqrt{b^2 - 4c}| = |b - 2c|
      \]

2. **Setting Up Equations:**
    - This equation \( |\sqrt{b^2 - 4c}| = |b - 2c| \) means we need to consider two cases because of the absolute values:
      1. \(\sqrt{b^2 - 4c} = b - 2c\)
      2. \(\sqrt{b^2 - 4c} = -(b - 2c)\)

3. **Case 1: \(\sqrt{b^2 - 4c} = b - 2c \)**
    - Square both sides to eliminate the square root:
      \[
      b^2 - 4c = (b - 2c)^2
      \]
    - Expand the right side:
      \[
      b^2 - 4c = b^2 - 4bc + 4c^2
      \]
    - Cancel out \( b^2 \) from both sides:
      \[
      -4c = -4bc + 4c^2
      \]
    - Rearrange the equation:
      \[
      4c^2 - 4bc + 4c = 0
      \]
    - Divide through by 4:
      \[
      c^2 - bc + c = 0
      \]
    - Factorize:
      \[
      c(c - b + 1) = 0
      \]
    - This gives two solutions:
      \[
      c = 0 \quad \text{or} \quad c = b - 1
      \]
    - Since we are given that \( c \neq 0 \), we have:
      \[
      c = b - 1
      \]

4. **Case 2: \(\sqrt{b^2 - 4c} = -(b - 2c) \)**
    - Square both sides to eliminate the square root:
      \[
      b^2 - 4c = (-(b - 2c))^2 = (b - 2c)^2
      \]
    - This is the same as the equation in Case 1, so it leads to the same factorized equation:
      \[
      c(c - b + 1) = 0
      \]
    - Again, this gives the solutions:
      \[
      c = 0 \quad \text{or} \quad c = b - 1
      \]
    - And since \( c \neq 0 \), we get:
      \[
      c = b - 1
      \]

Hence, both cases lead to the same solution, \( c = b - 1 \). So, the value of \( c \) in terms of \( b \) is:

\[
c = b - 1
\]
