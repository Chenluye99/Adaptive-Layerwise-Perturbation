Let's implement this step by step using Python.

### Step 1: Find the roots of the polynomial equation
We start by solving the polynomial equation \(x^3 - 9x^2 + 11x - 1 = 0\) to find the roots \(a, b, c\).

### Step 2: Compute \(s = \sqrt{a} + \sqrt{b} + \sqrt{c}\)
Once we have the roots, we can compute \(s = \sqrt{a} + \sqrt{b} + \sqrt{c}\).

### Step 3: Compute \(s^4 - 18s^2 - 8s\)
Then, we substitute \(s\) into the expression \(s^4 - 18s^2 - 8s\) and compute the result.

Let's implement this in Python.
```python
import numpy as np

# Find the roots of the polynomial equation x^3 - 9x^2 + 11x - 1 = 0
coefficients = [1, -9, 11, -1]
roots = np.roots(coefficients)

# Assign the roots to a, b, c
a, b, c = roots

# Calculate s = sqrt(a) + sqrt(b) + sqrt(c)
s = np.sqrt(a) + np.sqrt(b) + np.sqrt(c)

# Calculate the expression s^4 - 18s^2 - 8s
result = s**4 - 18 * s**2 - 8 * s
print(result)
```
