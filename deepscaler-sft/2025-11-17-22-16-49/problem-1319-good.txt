First, let's start by visualizing the problem. We have a right triangle \(ABC\) with \(\angle A = 90^\circ\), so \(AB\) and \(AC\) are the legs and \(BC\) is the hypotenuse. We are given that \(AB = 5\) and \(BC = 8\). We need to find \(\sin B\).

To find \(\sin B\), we need to determine the length of \(AC\). We can use the Pythagorean theorem for this:

\[ BC^2 = AB^2 + AC^2 \]

Substituting the known values:

\[ 8^2 = 5^2 + AC^2 \]
\[ 64 = 25 + AC^2 \]
\[ AC^2 = 64 - 25 \]
\[ AC^2 = 39 \]
\[ AC = \sqrt{39} \]

Now, \(\sin B\) is defined as the ratio of the length of the opposite side to \(\angle B\) to the hypotenuse. In this triangle, the side opposite to \(\angle B\) is \(AC\) and the hypotenuse is \(BC\):

\[ \sin B = \frac{AC}{BC} = \frac{\sqrt{39}}{8} \]

Let's confirm this by coding the solution in Python.
```python
import sympy as sp

# Given values
AB = 5
BC = 8

# Calculate AC using the Pythagorean theorem
AC = sp.sqrt(BC**2 - AB**2)

# Calculate sin(B)
sin_B = AC / BC
print(sin_B)
```
Code execution result: sqrt(39)/8

Thus, the value of \(\sin B\) is \(\frac{\sqrt{39}}{8}\).

So, the final answer is:

\(\boxed{\frac{\sqrt{39}}{8}}\)
