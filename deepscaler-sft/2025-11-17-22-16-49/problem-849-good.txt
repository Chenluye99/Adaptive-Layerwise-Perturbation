First, let's start by understanding the problem:

1. We need to find rectangles on a 6x6 grid that have an area of 3 square units.
2. Each rectangle is defined by picking two horizontal and two vertical grid lines from the 7 available horizontal and 7 available vertical grid lines (since a 6x6 grid has 7 lines between its 6 rows and 6 columns).

To solve this, let's enumerate all possible pairs of horizontal and vertical grid lines and then check if the formed rectangle has an area of 3 square units. The area of a rectangle formed by these lines will be given by \((y2 - y1) \cdot (x2 - x1) = 3\), where \((x1, y1)\) and \((x2, y2)\) are the coordinates of the chosen lines.

Here, both \((y2 - y1)\) and \((x2 - x1)\) need to be integer lengths and must be such that the product is 3. The possible factor pairs of 3 are \((1, 3)\) and \((3, 1)\). This means the dimensions of the rectangle can be 1 unit by 3 units or 3 units by 1 unit.

Let's iterate through all combinations of choosing 2 horizontal and 2 vertical lines and check if the area of the formed rectangle is 3.

1. We'll use nested loops to consider all possible ways to choose 2 lines out of 7 for both the horizontal and vertical lines.
2. For each combination, we'll calculate the length and width of the rectangle as the differences between the chosen line indices.
3. We'll then check if the product of these lengths equals 3 and, if it does, we'll count that as a valid rectangle.

Let's implement this step-by-step process in Python to ensure accuracy.
```python
import itertools

# We have 7 lines in each direction to choose from (0 to 6 in indices, so 7 lines)
num_lines = 7

count = 0

# Iterate over all combinations of choosing 2 lines from the 7 available lines in both the horizontal and vertical directions.
for y1, y2 in itertools.combinations(range(num_lines), 2):
    for x1, x2 in itertools.combinations(range(num_lines), 2):
        width = abs(x2 - x1)
        height = abs(y2 - y1)
        if width * height == 3:
            count += 1

print(count)
```
