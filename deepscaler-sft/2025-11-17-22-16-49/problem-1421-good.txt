To solve the problem, we need to find all possible triangles with integer side lengths such that the perimeter is 15. For three integers \(a\), \(b\), and \(c\) to form a triangle, the following conditions must be satisfied:

1. The triangle inequality theorem: For any three sides \(a\), \(b\), and \(c\) of a triangle, the following must hold:
   \[
   a + b > c, \quad a + c > b, \quad b + c > a
   \]
2. The sides must be integers.
3. The perimeter of the triangle must be 15, i.e.,
   \[
   a + b + c = 15
   \]

To find all such triangles, we will iterate through all possible integer values for \(a\), \(b\), and \(c\) and check the conditions above. We also need to ensure that the triangles are non-congruent, meaning that the sets \((a, b, c)\) should be considered distinct only if they consist of different ordered triplets or if they differ in terms of permutation but are considered the same triangle if they have the same side lengths, i.e., \((a, b, c)\), \((a, c, b)\), \((b, a, c)\), etc., are considered the same.

Let's write the Python code to solve this step-by-step.
```python
# Initialize a set to store unique sets of side lengths representing non-congruent triangles
non_congruent_triangles = set()

# We need to check all combinations of (a, b, c) such that a, b, c are integers, and a + b + c = 15.
for a in range(1, 15):
    for b in range(a, 15 - a):
        c = 15 - a - b
        if b <= c and a + b + c == 15 and a + b > c and a + c > b and b + c > a:
            # Add the sorted tuple (to handle permutations considered as the same triangle) to the set
            non_congruent_triangles.add(tuple(sorted((a, b, c))))

# The number of non-congruent triangles found
num_non_congruent_triangles = len(non_congruent_triangles)
print(num_non_congruent_triangles)
```

Thus, the number of non-congruent triangles with only integer side lengths that have a perimeter of 15 units is \(\boxed{7}\). This completes the solution.
