First, let's start by using the Angle Bisector Theorem, which states that the angle bisector of an angle in a triangle divides the opposite side into segments that are proportional to the other two sides of the triangle.

For triangle \(XYZ\), with \(XY = 5\), \(YZ = 12\), and \(XZ = 13\), if \(YM\) is the angle bisector from vertex \(Y\), then it divides \(XZ\) into points \(XM\) and \(MZ\) such that:
\[
\frac{XM}{MZ} = \frac{XY}{YZ} = \frac{5}{12}
\]
Let \(XM = 5k\) and \(MZ = 12k\). Since \(XZ = XM + MZ = 13\), we can set up the following equation:
\[
5k + 12k = 13 \implies 17k = 13 \implies k = \frac{13}{17}
\]
So,
\[
XM = 5k = 5 \cdot \frac{13}{17} = \frac{65}{17}
\]
\[
MZ = 12k = 12 \cdot \frac{13}{17} = \frac{156}{17}
\]

Now, we need to find the length of \(YM\). To do this, we can use Stewart's Theorem, which states that in any triangle \(ABC\) with a cevian \(AD\) to side \(BC\):
\[
AB^2 \cdot DC + AC^2 \cdot BD - BC (AD^2 + BD \cdot DC) = 0
\]
For our triangle \(XYZ\) and the cevian \(YM\) (where \(M\) is on \(XZ\)):
\[
XY^2 \cdot MZ + YZ^2 \cdot XM - XZ (YM^2 + XM \cdot MZ) = 0
\]
Substituting the values we have:
\[
5^2 \cdot \frac{156}{17} + 12^2 \cdot \frac{65}{17} - 13 (YM^2 + \frac{65}{17} \cdot \frac{156}{17}) = 0
\]
Let's denote \(YM = m \sqrt{2}\), and solve this equation step by step using Python to get an accurate result.

from sympy import symbols, Eq, solve

# Assign variables
YM = symbols('YM', positive=True)

# Values from the triangle side lengths
XY = 5
YZ = 12
XZ = 13
XM = 65 / 17
MZ = 156 / 17

# Set up equation using Stewart's Theorem
stewart_eq = Eq(XY**2 * MZ + YZ**2 * XM - XZ * (YM**2 + XM * MZ), 0)

# Solve for YM
YM_solution = solve(stewart_eq, YM)[0]

# We know that YM = m * sqrt(2), so we need to express YM in that form and solve for m
m = YM_solution / (2 ** 0.5)

print((YM_solution, m))
