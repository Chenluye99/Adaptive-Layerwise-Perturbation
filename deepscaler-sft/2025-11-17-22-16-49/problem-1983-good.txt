To solve this problem, we need to determine the number of ways to satisfy both conditions of the problem.

1. **Choose the Host School:**
   There are 3 schools, so there are 3 ways to choose the host school.

2. **Choose Representatives:**
   - Once the host school is chosen, we need to choose 2 representatives out of the 5 members from the host school. The number of ways to choose 2 representatives out of 5 is given by the combination formula \( \binom{5}{2} \):
     \[
     \binom{5}{2} = \frac{5!}{2!(5-2)!} = \frac{5!}{2! \cdot 3!} = \frac{5 \cdot 4}{2 \cdot 1} = 10.
     \]
   - Each of the other two schools needs to choose 1 representative out of their 5 members. The number of ways to choose 1 representative from each of these schools is \( \binom{5}{1} = 5 \) for each school. Therefore, for the two schools, the number of ways to choose 1 representative from each school is \( 5 \times 5 = 25 \).

3. **Combine Choices:**
   - For each choice of the host school, we have 10 ways to choose 2 representatives from the host school, and we have 25 ways to choose 1 representative from each of the other two schools.
   - Therefore, for each choice of the host school, the number of ways to choose the representatives is \( 10 \times 25 = 250 \).
   - Since there are 3 ways to choose the host school, the total number of ways to arrange the meeting is \( 3 \times 250 = 750 \).

Let's confirm this with Python to ensure accuracy.
```python
import math

# Number of ways to choose the host school
num_ways_choose_host_school = 3

# Number of ways to choose 2 representatives from the host school (5 members choose 2)
num_ways_choose_representatives_host_school = math.comb(5, 2)

# Number of ways to choose 1 representative from each of the other two schools (5 members choose 1)
num_ways_choose_representative_from_other_school = math.comb(5, 1)
num_ways_choose_representatives_other_schools = num_ways_choose_representative_from_other_school ** 2

# Total ways for choosing the representatives for all schools combined, for a chosen host school
num_ways_to_choose_representatives_for_host = num_ways_choose_representatives_host_school * num_ways_choose_representatives_other_schools

# Total ways considering all possible hosts
num_total_ways = num_ways_choose_host_school * num_ways_to_choose_representatives_for_host
print(num_total_ways)
```
Code execution result: 750
