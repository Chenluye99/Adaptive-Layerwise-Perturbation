First, let's start with the properties and equation of the hyperbola. The standard form of a hyperbola centered at the origin with foci at \((\pm 7, 0)\) is given by:

\[
\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1
\]

For a hyperbola of this form, the relationship between \(a\), \(b\), and the distance from the center to the foci is given by:

\[
c^2 = a^2 + b^2
\]

where \(c\) is the distance from the center to each focus. In this problem, the foci are at \((\pm 7, 0)\), so \(c = 7\). Therefore, we have:

\[
7^2 = a^2 + b^2 \implies 49 = a^2 + b^2
\]

We also know that the hyperbola passes through the point \((2, 12)\). Substituting this point into the equation of the hyperbola, we get:

\[
\frac{2^2}{a^2} - \frac{12^2}{b^2} = 1 \implies \frac{4}{a^2} - \frac{144}{b^2} = 1
\]

Now, we have a system of equations:

1. \(49 = a^2 + b^2\)
2. \(\frac{4}{a^2} - \frac{144}{b^2} = 1\)

We can solve this system of equations step-by-step. First, let's express \(b^2\) in terms of \(a^2\) from the first equation:

\[
b^2 = 49 - a^2
\]

Next, substitute this expression for \(b^2\) into the second equation:

\[
\frac{4}{a^2} - \frac{144}{49 - a^2} = 1
\]

We can solve this equation iteratively or symbolically using Python to find the values of \(a^2\) and subsequently \(b^2\). Let's implement this in Python to get accurate results.
```python
import sympy as sp

# Define the variables
a, b = sp.symbols('a b', positive=True)

# Define the equations based on the problem statement
eq1 = sp.Eq(a**2 + b**2, 49)
eq2 = sp.Eq(4/a**2 - 144/b**2, 1)

# Solve the system of equations
solution = sp.solve((eq1, eq2), (a, b))

print(solution)
```
