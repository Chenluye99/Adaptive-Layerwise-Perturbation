To solve this problem, we need to find the smallest whole number of hours greater than 4 such that the number of hours is "clock equivalent" to its square number of hours on a 12-hour clock. Two numbers are "clock equivalent" if their difference is a multiple of 12.

Let's denote the number of hours by \( n \). We need to check if \( n \) is clock equivalent to \( n^2 \), i.e., if \((n^2 - n) \mod 12 = 0\).

We'll start checking from \( n = 5 \) and go upwards until we find such an \( n \). We will use a Python program to do this check efficiently.
```python
def find_least_clock_equivalent():
    n = 5  # Start checking from the first number greater than 4
    while True:
        if (n**2 - n) % 12 == 0:
            return n
        n += 1

result = find_least_clock_equivalent()
print(result)
```
Code execution result: 9

Thus, the least whole number of hours that is greater than 4 hours and is "clock equivalent" to its square number of hours is \(\boxed{9}\). This is verified by checking that \((9^2 - 9) \mod 12 = 0\), ensuring the answer is correct.
