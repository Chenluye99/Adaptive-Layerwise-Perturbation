To solve the problem, let's start by determining the number of each type of marble in the box.

1. **Determine the number of each type of marble:**
    - Silver marbles: 25% of 180
    - Gold marbles: 20% of 180
    - Bronze marbles: 15% of 180
    - Sapphire marbles: 10% of 180
    - Ruby marbles: 10% of 180
    - Diamond marbles: The remainder after accounting for silver, gold, bronze, sapphire, and ruby marbles

2. **Calculate these values using Python.**

3. **Remove 10% of the gold marbles and update the total number of marbles.**

Let's start by performing these calculations in Python.
```python
# Initial number of marbles
total_marbles = 180

# Calculate the number of each type of marble
silver_marbles = 0.25 * total_marbles
gold_marbles = 0.20 * total_marbles
bronze_marbles = 0.15 * total_marbles
sapphire_marbles = 0.10 * total_marbles
ruby_marbles = 0.10 * total_marbles

# Calculate the number of diamond marbles (the remainder)
diamond_marbles = total_marbles - (silver_marbles + gold_marbles + bronze_marbles + sapphire_marbles + ruby_marbles)

# Remove 10% of the gold marbles
gold_marbles_removed = 0.10 * gold_marbles
gold_marbles_left = gold_marbles - gold_marbles_removed

# Calculate the new total number of marbles after removing 10% of the gold marbles
marbles_left_in_box = silver_marbles + gold_marbles_left + bronze_marbles + sapphire_marbles + ruby_marbles + diamond_marbles

print(marbles_left_in_box)
```
Code execution result: 176.4

Since the number of marbles must be an integer, we will round 176.4 to 176 because the number of marbles can only be a whole number. 

So, the number of marbles left in the box after removing 10% of the gold marbles is \(\boxed{176}\).
