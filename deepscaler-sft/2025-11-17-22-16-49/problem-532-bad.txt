1. **Generate the Odd Integers:**
    - We generate all odd integers from 3 to 199.
2. **Check for Square-Free Property:**
    - For each odd integer, check if it is divisible by the square of any prime number less than or equal to \(\sqrt{199}\). If it is divisible by the square of any such prime, then it is not square-free.
3. **Count the Square-Free Integers:**
    - Count how many of these odd integers are square-free.

import sympy

Let's proceed by implementing this check manually. We will generate a list of prime numbers up to \(\sqrt{199}\) and then check if the number is divisible by the square of any of these primes. If it is, then the number is not square-free. Otherwise, it is square-free.

We'll implement this step-by-step in the code below.
```python
import math

def is_square_free(n):
    # Check divisibility by the squares of primes up to sqrt(n)
    for p in range(2, int(math.sqrt(n)) + 1):
        if n % (p * p) == 0:
            return False
    return True

# Generate all odd integers from 3 to 199
odd_integers = [num for num in range(3, 200, 2)]

# Count how many of these odd integers are square-free
square_free_count = sum(1 for num in odd_integers if is_square_free(num))

print(square_free_count)
```
