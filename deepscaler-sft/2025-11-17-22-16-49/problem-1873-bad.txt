To solve this problem, we need to find all the ordered triples \((x, y, z)\) that satisfy the following system of equations:

\[
\begin{cases}
x + y - z = 0, \\
xz - xy + yz = 27, \\
xyz = 54.
\end{cases}
\]

First, we can express \(z\) from the first equation:

\[ z = x + y. \]

Next, we substitute this expression for \(z\) into the other two equations. Substituting \(z = x + y\) into the second equation, we get:

\[ x(x + y) - xy + y(x + y) = 27, \]
\[ x^2 + xy - xy + yx + y^2 = 27, \]
\[ x^2 + y^2 + yx = 27. \]

Substituting \(z = x + y\) into the third equation, we get:

\[ xy(x + y) = 54. \]

So, we now have a system of two equations in terms of \(x\) and \(y\):

\[
\begin{cases}
x^2 + y^2 + xy = 27, \\
xy(x + y) = 54.
\end{cases}
\]

Let's introduce new variables to simplify the system. Set \( s = x + y \) and \( p = xy \). Then, we can rewrite the equations as:

\[
\begin{cases}
x^2 + y^2 + xy = 27, \\
p \cdot s = 54.
\end{cases}
\]

We know that \( x^2 + y^2 = (x + y)^2 - 2xy = s^2 - 2p \), so we substitute this into the first equation:

\[ s^2 - 2p + p = 27, \]
\[ s^2 - p = 27. \]

So, we now have the following system of equations in terms of \( s \) and \( p \):

\[
\begin{cases}
s^2 - p = 27, \\
ps = 54.
\end{cases}
\]

We can solve the second equation for \( p \):

\[ p = \frac{54}{s}. \]

Substitute this into the first equation:

\[ s^2 - \frac{54}{s} = 27. \]

Multiply through by \( s \) to clear the fraction:

\[ s^3 - 27s - 54 = 0. \]

We need to find the roots of this polynomial equation. We can use Python to solve this polynomial equation and then determine corresponding values for \( p \), and subsequently for \( x \) and \( y \).
```python
import sympy as sp

# Define the variable
s = sp.symbols('s', real=True, positive=True)

# Define the polynomial equation
equation = s**3 - 27*s - 54

# Find the roots of the polynomial equation
roots = sp.solve(equation, s)

print(roots)
```
