To solve the problem of finding the largest three-digit integer whose digits are distinct and form a geometric sequence, we need to follow these steps:

1. **Define what it means for digits to form a geometric sequence:**
    - For three digits \(a, b, c\) to be in a geometric sequence, the ratio between consecutive terms must be the same, i.e., \(\frac{b}{a} = \frac{c}{b}\). This can be rewritten as \(b^2 = ac\).

2. **Set up constraints for a three-digit number:**
    - A three-digit number ranges from 100 to 999.
    - The digits of the number must be distinct.
    - The digits must satisfy the geometric sequence condition, i.e., if the digits are \(a, b, c\), then \(b^2 = ac\).

3. **Iterate through all three-digit numbers and check the conditions:**
    - For each number, extract its digits.
    - Check if the digits are distinct.
    - Check if the digits form a geometric sequence.
    - Keep track of the largest number that meets these conditions.

Let's implement this step-by-step plan in Python to ensure accuracy.
```python
# Initialize a variable to keep track of the largest three-digit number that meets the conditions
largest_number = 0

# Function to check if three digits form a geometric sequence
def is_geometric_sequence(a, b, c):
    return b * b == a * c

# Iterate through all three-digit numbers
for num in range(999, 99, -1):
    str_num = str(num)
    a, b, c = int(str_num[0]), int(str_num[1]), int(str_num[2])
    
    # Check if all digits are distinct
    if len(set([a, b, c])) == 3:
        # Check if the digits form a geometric sequence
        if is_geometric_sequence(a, b, c):
            largest_number = num
            break

print(largest_number)
```
