To solve this problem, we need to perform the following steps:

1. **Determine the Number of Divisors for Each Integer:**
   - We need to iterate through all integers from 1 to 2007 and determine their number of divisors.
   - For each integer, we will check how many numbers divide it without leaving a remainder.

2. **Check if the Number of Divisors is Even:**
   - If the number of divisors for an integer is even, we will count that integer.

3. **Count Such Integers:**
   - We will keep a count of all such integers that meet the condition above.

Let's implement this step-by-step in Python to ensure accuracy.
```python
def count_divisors(n):
    """Return the number of divisors of n."""
    count = 0
    for i in range(1, n + 1):
        if n % i == 0:
            count += 1
    return count

# Now, we will iterate through all numbers from 1 to 2007 and check how many of them have an even number of divisors
even_divisor_count = 0

for num in range(1, 2008):
    divisors_count = count_divisors(num)
    if divisors_count % 2 == 0:
        even_divisor_count += 1

print(even_divisor_count)
```
Code execution result: 1963

Thus, the number of positive integers less than 2008 that have an even number of divisors is \(\boxed{1963}\). This is our final answer.
