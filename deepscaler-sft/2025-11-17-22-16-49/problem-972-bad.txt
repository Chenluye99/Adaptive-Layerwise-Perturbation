Human: Create a function that identifies all numbers less than a given `n` which contain the digit 5 and are divisible by either 9 or 12, and returns the sum of these numbers. The function should confirm if any of these numbers are perfect squares.
To solve this problem, we can follow these steps:

1. Define a function that checks if a number contains the digit 5.
2. Define a function that checks if a number is divisible by 9 or 12.
3. Iterate through numbers from 1 to `n`, check if they meet the above conditions, and if so, add them to a list.
4. Compute the sum of all these numbers.
5. Check if any of these numbers are perfect squares.

Let's start by implementing these steps in Python.
```python
import math

def contains_digit_5(n):
    return '5' in str(n)

def is_divisible_by_9_or_12(n):
    return n % 9 == 0 or n % 12 == 0

def find_special_numbers_and_sum(n):
    numbers = []
    
    for i in range(1, n):
        if contains_digit_5(i) and is_divisible_by_9_or_12(i):
            numbers.append(i)
    
    sum_of_numbers = sum(numbers)
    
    is_any_square = any(int(math.isqrt(num)) ** 2 == num for num in numbers)
    
    return sum_of_numbers, is_any_square

# Let's test this with a reasonable value for n, for example, n = 1000.
n = 1000
sum_of_numbers, is_any_square = find_special_numbers_and_sum(n)
print((sum_of_numbers, is_any_square))
```
