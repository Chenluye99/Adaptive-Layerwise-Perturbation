To solve this problem, we need to check for each number in the set $\{1, 2, 3, 4, 5, 6\}$ if it is a primitive root modulo 7. A number $a$ is a primitive root modulo $p$ if the set $\{a, a^2, a^3, \ldots, a^{p-1}\}$ contains every integer from 1 to $p-1$ exactly once when reduced modulo $p$.

For $p = 7$, we need to check if the set $\{a, a^2, a^3, a^4, a^5, a^6\}$ contains all the integers from 1 to 6 exactly once when taken modulo 7.

Let's write some Python code to check for each number in the set and then find the sum of all numbers that are primitive roots modulo 7.
```python
import sympy

# Initialize the set of numbers to check
numbers_to_check = [1, 2, 3, 4, 5, 6]
p = 7

# Find primitive roots for p=7
primitive_roots = []

for a in numbers_to_check:
    residues = [pow(a, k, p) for k in range(1, p)]
    if len(set(residues)) == p - 1:
        primitive_roots.append(a)

# Get the sum of all primitive roots found
sum_of_primitive_roots = sum(primitive_roots)
print((sum_of_primitive_roots, primitive_roots))
```
Code execution result: (8, [3, 5])

The code has identified that the numbers 3 and 5 are the primitive roots of 7. The sum of these primitive roots is:

\[ 3 + 5 = 8 \]

Thus, the sum of all integers in the set $\{1, 2, 3, 4, 5, 6\}$ that are primitive roots $\pmod 7$ is \(\boxed{8}\).
