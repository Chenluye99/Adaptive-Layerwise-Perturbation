To solve this problem, we need to implement the function \( f \) according to the given rules and then compute \( f(84) \).

1. **Understand the Function Definition:**
    - If \( n \geq 1000 \), then \( f(n) = n - 3 \).
    - If \( n < 1000 \), then \( f(n) = f(f(n + 5)) \).

2. **Implement the Function:**
    - We will create a Python function that implements this logic.
    - If \( n \geq 1000 \), we simply return \( n - 3 \).
    - If \( n < 1000 \), we need to recursively call the function to get \( f(n + 5) \), and then call the function again with that result to get \( f(f(n + 5)) \).

3. **Compute \( f(84) \):**
    - We start with \( n = 84 \) and follow the rules above until we get a result.

Let's implement this step-by-step in Python:
```python
def f(n):
    if n >= 1000:
        return n - 3
    else:
        return f(f(n + 5))

# Now let's find f(84)
result = f(84)
print(result)
```
Code execution result: 997

Thus, the value of \( f(84) \) is \(\boxed{997}\). This is the final answer after iterating and following the function definition until we obtained the result.
