First, let's start by understanding the problem.

1. **Initial Ratio and Count of Flowers:**
    - The ratio of irises to roses in Nikki's garden is 2:5.
    - Currently, Nikki has 25 roses.
    - To find the initial number of irises, we use the ratio. If the ratio of irises to roses is 2:5, then for every 5 roses, there are 2 irises. So, if there are 25 roses, the number of irises can be calculated as follows:
      \[
      \text{Initial number of irises} = \frac{2}{5} \times 25 = 10
      \]

2. **Adding More Flowers:**
    - Nikki plans to add 20 more roses, so the new total number of roses will be:
      \[
      25 + 20 = 45
      \]
    - To maintain the same ratio of 2:5 after adding the roses, we need to find out how many irises are required for 45 roses. If the new number of irises is \( I \), then the ratio should still be 2:5, so:
      \[
      \frac{I}{45} = \frac{2}{5}
      \]
      Solving for \( I \):
      \[
      I = \frac{2}{5} \times 45 = 18
      \]
    - This is the total number of irises needed to maintain the ratio after adding the 20 roses. But we need to determine how many more irises she will need to add to her current 10 irises to get to 18 irises.

3. **Finding Additional Irises Required:**
    - The additional irises needed will be:
      \[
      18 - 10 = 8
      \]
    - The total number of irises after adding the necessary irises will be:
      \[
      10 + 8 = 18
      \]

Now, let's implement this step-by-step reasoning in Python to ensure accuracy.
```python
# Initial given values
initial_roses = 25
additional_roses = 20
ratio_iris_to_roses = (2, 5)

# Calculate the initial number of irises based on the ratio
initial_irises = (ratio_iris_to_roses[0] / ratio_iris_to_roses[1]) * initial_roses

# Calculate the new total number of roses after adding more roses
new_total_roses = initial_roses + additional_roses

# Calculate the new total number of irises needed to maintain the same ratio
new_total_irises_needed = (ratio_iris_to_roses[0] / ratio_iris_to_roses[1]) * new_total_roses

# Calculate the additional irises needed to be added
additional_irises_needed = new_total_irises_needed - initial_irises

# Get the final total number of irises after adding the necessary irises
final_total_irises = initial_irises + additional_irises_needed

print(final_total_irises)
```
