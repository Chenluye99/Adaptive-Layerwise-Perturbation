Let's denote the number of lollipops Joann ate on the first day as \( x \).

According to the problem, each subsequent day, Joann eats six more lollipops than the previous day. This means:

- On the first day, she ate \( x \) lollipops.
- On the second day, she ate \( x + 6 \) lollipops.
- On the third day, she ate \( x + 12 \) lollipops.
- On the fourth day, she ate \( x + 18 \) lollipops.
- On the fifth day, she ate \( x + 24 \) lollipops.

The total number of lollipops eaten over the five days is 100. We can set up the following equation based on this information:

\[ x + (x + 6) + (x + 12) + (x + 18) + (x + 24) = 100 \]

Combining like terms, we get:

\[ 5x + 60 = 100 \]

To solve for \( x \), we can follow these steps:

1. Subtract 60 from both sides of the equation:
\[ 5x = 40 \]
2. Divide both sides of the equation by 5:
\[ x = 8 \]

Now that we have the value of \( x \), we can determine how many lollipops Joann ate on the third day. As mentioned earlier, on the third day, she ate \( x + 12 \) lollipops. Substituting \( x = 8 \) into this expression, we get:

\[ x + 12 = 8 + 12 = 20 \]

So, Joann ate 20 lollipops on the third day. We will verify this by coding the solution to ensure the accuracy.
```python
# We will use the equation and solve it programmatically to validate our result.
from sympy import symbols, Eq, solve

# Define the variable
x = symbols('x')

# Set up the equation based on the problem statement
equation = Eq(x + (x + 6) + (x + 12) + (x + 18) + (x + 24), 100)

# Solve the equation
solution = solve(equation, x)[0]

# Calculate the number of lollipops eaten on the third day
lollipops_third_day = solution + 12
print(lollipops_third_day)
```
Code execution result: 20

Thus, the number of lollipops Joann ate on the third day is \(\boxed{20}\). This confirms that our solution is accurate.
