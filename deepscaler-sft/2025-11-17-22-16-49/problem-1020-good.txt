To solve the problem, we need to find the discriminant of the quadratic equation \(3x^2 - 7x - 12\).

The discriminant \(\Delta\) of a quadratic equation of the form \(ax^2 + bx + c = 0\) is given by the formula:

\[
\Delta = b^2 - 4ac
\]

For the given quadratic equation \(3x^2 - 7x - 12\), we can identify the coefficients as follows:
- \(a = 3\)
- \(b = -7\)
- \(c = -12\)

Substitute these values into the discriminant formula:

\[
\Delta = (-7)^2 - 4 \cdot 3 \cdot (-12)
\]

Let's compute this step-by-step using Python to ensure accuracy.
```python
import sympy as sp

# Coefficients of the quadratic equation 3x^2 - 7x - 12
a = 3
b = -7
c = -12

# Calculate the discriminant
discriminant = b**2 - 4 * a * c
print(discriminant)
```
