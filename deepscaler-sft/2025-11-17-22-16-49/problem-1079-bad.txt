To ensure that the function \( f(x) \) is continuous at \( x = 3 \), the left-hand limit, right-hand limit, and the function value at \( x = 3 \) must all be equal. 

The function \( f(x) \) is defined as:
\[
f(x) =
\begin{cases}
3x^2 + 2 & \text{if } x \le 3, \\
ax - 1 & \text{if } x > 3.
\end{cases}
\]

1. **Evaluate \( f(3) \):**
   Using the first part of the piecewise function, we get:
   \[
   f(3) = 3(3)^2 + 2 = 3 \cdot 9 + 2 = 27 + 2 = 29.
   \]

2. **Set up the Condition for Continuity at \( x = 3 \):**
   For \( f(x) \) to be continuous at \( x = 3 \), the limit of \( f(x) \) as \( x \) approaches 3 from the right must be equal to \( f(3) \):
   \[
   \lim_{{x \to 3^+}} f(x) = ax - 1 \quad \text{when } x > 3,
   \]
   so we need:
   \[
   \lim_{{x \to 3^+}} (ax - 1) = 29.
   \]
   Substituting \( x = 3 \) into the second part of the piecewise function, we get:
   \[
   a \cdot 3 - 1 = 29.
   \]

3. **Solve for \( a \):**
   \[
   3a - 1 = 29 \implies 3a = 30 \implies a = 10.
   \]

Let's confirm this by coding it in Python to ensure the accuracy of the result.
```python
import sympy as sp

# Define the variable and the function pieces
x = sp.symbols('x')
f_left = 3 * x**2 + 2
f_right = sp.symbols('a') * x - 1

# Set up the equation for continuity at x = 3
equation = f_right.subs(x, 3) - f_left.subs(x, 3)

# Solve for 'a'
a = sp.solve(equation, sp.symbols('a'))[0]
print(a)
```
Code execution result: 10

Thus, the value of \( a \) that makes the function \( f(x) \) continuous is \(\boxed{10}\). This confirms that our solution is accurate.
