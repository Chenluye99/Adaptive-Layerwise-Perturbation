First, let's solve the problem step-by-step:

1. **Determine the Tip Amount:**
   - Patty ordered a pizza for $12.00.
   - She paid $15.00 and told the delivery person to keep the change as a tip.
   - Therefore, the tip amount is $15.00 - $12.00 = $3.00.

2. **Calculate the Tip Percentage:**
   - The tip percentage is calculated as \(\frac{\text{Tip Amount}}{\text{Original Bill Amount}} \times 100\).
   - Substituting the values, we get \(\frac{3.00}{12.00} \times 100\).

Let's calculate this using Python to ensure accuracy.
```python
# Given values
bill_amount = 12.00
payment_amount = 15.00

# Calculate the tip amount
tip_amount = payment_amount - bill_amount

# Calculate the tip percentage
tip_percentage = (tip_amount / bill_amount) * 100
print(tip_percentage)
```
Code execution result: 25.0

Thus, the tip percentage Patty gave is \(\boxed{25}\) percent. This is the final answer.
