To solve this problem, let's begin by setting up the equation and iterating until we find the smallest positive integer \( n \) that satisfies it.

We need to find the smallest \( n \) such that:
\[
\sum_{k=0}^n \log_2 \left( 1 + \frac{1}{2^{2^k}} \right) \ge 1 + \log_2 \frac{2014}{2015}.
\]

First, we need to compute the right-hand side of the equation:
\[ 1 + \log_2 \frac{2014}{2015}. \]

Let's start by calculating \(\log_2 \frac{2014}{2015}\):
\[ \log_2 \frac{2014}{2015} = \log_2 2014 - \log_2 2015. \]

Then we get:
\[ 1 + \log_2 \frac{2014}{2015} = 1 + \log_2 2014 - \log_2 2015. \]

Next, we need to check for different values of \( n \) and compute the left-hand side of the inequality:
\[ \sum_{k=0}^n \log_2 \left( 1 + \frac{1}{2^{2^k}} \right). \]

We can use Python to perform this computation iteratively until we find the smallest \( n \) that makes the left-hand side greater than or equal to the right-hand side.

Let's implement this step-by-step in Python.
```python
import math

# Calculate the right-hand side of the inequality
rhs = 1 + math.log2(2014 / 2015)

# Initialize variables for iteration
n = 0
lhs = 0

# Iterate until we find the smallest n such that the inequality holds
while True:
    lhs = sum(math.log2(1 + 1 / (2 ** (2 ** k))) for k in range(n + 1))
    if lhs >= rhs:
        break
    n += 1

print(n)
```
Code execution result: 3

Thus, the smallest positive integer \( n \) that satisfies the inequality is \(\boxed{3}\). This is the final answer.
