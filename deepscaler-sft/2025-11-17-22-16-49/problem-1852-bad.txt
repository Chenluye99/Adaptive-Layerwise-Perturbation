First, let's break down the problem into smaller parts.

1. **Alpha's Purchase Constraints:**
   - Alpha will not order more than 1 of the same flavor.
   - Alpha can choose from 5 different flavors of oreos and 3 different flavors of milk.
   - Alpha can purchase anywhere from 0 to 3 products, but the maximum number of different products Alpha can choose is 3 (since Alpha cannot order more than 1 of the same flavor).

2. **Beta's Purchase Constraints:**
   - Beta will only order oreos and she is willing to have repeats of flavors.
   - Beta can purchase anywhere from 0 to 3 products.

3. **Collective Purchase:**
   - Together, Alpha and Beta need to purchase 3 products in total.

We need to consider all possible scenarios where Alpha and Beta, together, purchase exactly 3 products. We will consider each possible number of products that Alpha could purchase (from 0 to 3 products) and then determine the corresponding number of products that Beta could purchase (also from 0 to 3 products) such that their sum is 3.

We will use Python to iterate through all possible combinations and count how many ways they can collectively purchase 3 products while respecting their individual constraints.

Let's write some Python code to handle this problem.
```python
import itertools

# Define the choices available for Alpha and Beta
oreo_flavors = 5  # 5 different flavors of oreos
milk_flavors = 3  # 3 different flavors of milk

# Alpha can choose from 5 oreos and 3 milks, so a possible choice for Alpha could be a combination of up to 3 items without repetition.
alpha_choices = []
for r in range(4):  # r goes from 0 to 3 because Alpha can purchase up to 3 products.
    for combo in itertools.product(range(oreo_flavors + milk_flavors), repeat=r):
        if len(set(combo)) == r:  # Ensure no more than one of the same flavor is chosen (i.e., no repetition in terms of distinct items, but each item in the combo must be considered distinctly based on the flavor availability).
            alpha_choices.append(combo)

# Beta can choose from 5 oreos, and she can repeat flavors, so a possible choice for Beta could be any combination of up to 3 items from the 5 oreo flavors.
beta_oreo_flavors = list(range(oreo_flavors))
beta_choices = []
for r in range(4):  # r goes from 0 to 3 because Beta can purchase up to 3 products.
    for combo in itertools.product(beta_oreo_flavors, repeat=r):
        beta_choices.append(combo)

# Now, we need to count the number of ways Alpha and Beta can collectively purchase exactly 3 products.
count = 0

# Check all combinations of Alpha's and Beta's choices
for alpha_choice in alpha_choices:
    num_alpha_products = len(alpha_choice)
    for beta_choice in beta_choices:
        num_beta_products = len(beta_choice)
        if num_alpha_products + num_beta_products == 3:
            count += 1

print(count)
```
