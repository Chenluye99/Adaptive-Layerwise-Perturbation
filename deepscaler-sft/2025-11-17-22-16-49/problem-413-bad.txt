First, let's extract the data from the chart and then calculate the average number of rounds played by each golfer. From the chart, we can interpret the data as follows:

- 1 round: 5 golfers
- 2 rounds: 2 golfers
- 3 rounds: 2 golfers
- 4 rounds: 3 golfers
- 5 rounds: 5 golfers

We can represent this data in a list where each element indicates the number of rounds played by a corresponding golfer. Then, we can compute the total number of rounds played and divide it by the total number of golfers to get the average. 

Let's create this list and then perform the calculation in Python.
```python
# Create a list based on the data from the chart
num_golfers_played_rounds = []

for rounds in range(1, 6):
    num_golfers = [rounds] * rounds  # Repeat the number of rounds for the number of golfers
    num_golfers_played_rounds.extend(num_golfers)

# Calculate the total number of rounds played and the total number of golfers
total_rounds_played = sum(num_golfers_played_rounds)
total_golfers = len(num_golfers_played_rounds)

# Calculate the average number of rounds played by each golfer
average_rounds = total_rounds_played / total_golfers

# Return the result, rounded to the nearest whole number
average_rounds_rounded = round(average_rounds)
print(average_rounds_rounded)
```
