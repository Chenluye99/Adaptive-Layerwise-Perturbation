To solve the problem of expanding \((x+3)(2x-4)(x-6)\), we will use symbolic computation provided by the `sympy` library in Python. Here are the steps:

1. **Import the sympy library.**
2. **Define the expression \((x+3)(2x-4)(x-6)\).**
3. **Use the `expand` function from sympy to expand the expression.**
4. **Print the result.**

Let's implement this step-by-step in Python.
```python
import sympy as sp

# Define the variable
x = sp.symbols('x')

# Define the expression (x + 3)(2x - 4)(x - 6)
expression = (x + 3) * (2 * x - 4) * (x - 6)

# Expand the expression
expanded_expression = sp.expand(expression)

# Print the result
print(expanded_expression)
```
Code execution result: 2*x**3 - 10*x**2 - 24*x + 72

Thus, the expanded form of \((x + 3)(2x - 4)(x - 6)\) is \(\boxed{2x^3 - 10x^2 - 24x + 72}\). This is our final answer.
