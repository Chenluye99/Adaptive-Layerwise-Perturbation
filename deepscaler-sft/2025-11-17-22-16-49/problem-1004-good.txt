To solve this problem, we need to determine the smallest number of tiles Emma could have such that she can form exactly ten distinct rectangular shapes (considering that a rectangle of dimensions $a \times b$ is considered the same as $b \times a$).

A rectangle of dimensions $a \times b$ is formed using $a \cdot b$ tiles. The problem then translates to finding the smallest integer $n$ such that the number of distinct pairs $(a, b)$ satisfying $a \cdot b = n$ (where $a \leq b$) is exactly 10.

We can iterate through the numbers, for each number check the number of distinct factor pairs, and stop once we find the smallest number that has exactly 10 distinct rectangular configurations.

Let's implement this step-by-step in Python.
```python
import math

def count_distinct_rectangular_forms(n):
    count = 0
    for i in range(1, int(math.sqrt(n)) + 1):
        if n % i == 0:
            j = n // i
            if i <= j:
                count += 1
    return count

# Now we will search for the smallest number that has exactly 10 distinct factor pairs.
num = 1
while True:
    if count_distinct_rectangular_forms(num) == 10:
        break
    num += 1

print(num)
```
