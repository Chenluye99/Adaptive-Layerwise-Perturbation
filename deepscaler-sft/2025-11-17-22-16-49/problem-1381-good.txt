To solve this problem, let's start with the formula for the sum of an infinite geometric series. The sum \( S \) of an infinite geometric series with the first term \( a \) and common ratio \( r \) (where \( |r| < 1 \)) is given by:

\[ S = \frac{a}{1 - r} \]

Here, we are given:
- The sum of the series, \( S = 60 \)
- The common ratio, \( r = \frac{1}{8} \)

We need to find the first term, \( a \). Substituting the given values into the formula for the sum of the infinite geometric series, we get:

\[ 60 = \frac{a}{1 - \frac{1}{8}} \]

First, let's simplify the denominator:

\[ 1 - \frac{1}{8} = \frac{8}{8} - \frac{1}{8} = \frac{7}{8} \]

So, the equation becomes:

\[ 60 = \frac{a}{\frac{7}{8}} \]

This is equivalent to:

\[ 60 = a \cdot \frac{8}{7} \]

To solve for \( a \), we can multiply both sides of the equation by \(\frac{7}{8}\):

\[ a = 60 \cdot \frac{7}{8} \]

Now, let's compute the value of \( a \) using Python to ensure accuracy.
```python
# Given values
S = 60
r = 1/8

# Calculate the first term 'a' using the formula a = S * (1 - r)
a = S * (1 - r)
print(a)
```
