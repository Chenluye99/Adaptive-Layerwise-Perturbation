First, let's solve the problem step-by-step.

1. **Understanding the Problem:**
    - We need to find all distinct remainders when \(2^n\) is divided by 1000 for nonnegative integers \( n \).
    - Let \( R \) be the set of these distinct remainders.
    - Compute the sum \( S \) of all elements in the set \( R \).
    - Finally, find the remainder when \( S \) is divided by 1000.

2. **Generating the Set of Remainders:**
    - We need to generate the remainders of \( 2^n \mod 1000 \) for increasing values of \( n \) until the remainders start repeating (since the set of remainders is finite due to the pigeonhole principle).
    - We can use a loop to compute these remainders and store them in a set to ensure all remainders are unique.

3. **Computing the Sum and Finding the Result:**
    - Once we have the set \( R \) of all distinct remainders, we compute the sum of the elements in \( R \).
    - Finally, we find the remainder when this sum is divided by 1000.

Let's implement this step-by-step in Python to get the accurate result.
```python
# Step 1: Generate the set of distinct remainders of 2^n mod 1000
remainders = set()

# We need to determine an upper limit for n such that the remainders start repeating.
# The values of 2^n grow exponentially, so we can iterate until we are confident that we have all distinct remainders.
n = 0
while True:
    remainder = (2 ** n) % 1000
    if remainder not in remainders:
        remainders.add(remainder)
    else:
        # Break the loop if we encounter a repeated remainder, indicating we have all distinct remainders so far.
        break
    n += 1

# Step 2: Compute the sum of the elements in the set R
S = sum(remainders)

# Step 3: Find the remainder when S is divided by 1000
result = S % 1000

print(result)
```
Code execution result: 7

Thus, the remainder when the sum of the elements in \( R \) is divided by 1000 is \(\boxed{7}\). This completes our solution.
