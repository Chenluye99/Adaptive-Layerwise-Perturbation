To solve this problem, we need to count the number of ways to distribute 5 indistinguishable balls into 3 distinguishable boxes. This is a classic "stars and bars" problem in combinatorics.

The formula for solving this problem is given by the "stars and bars" theorem, which states that the number of ways to distribute \(n\) indistinguishable objects into \(k\) distinguishable bins is:

\[
\binom{n+k-1}{k-1}
\]

For our specific problem, we have 5 indistinguishable balls and 3 distinguishable boxes, so \(n = 5\) and \(k = 3\). Plugging these values into the formula, we get:

\[
\binom{5 + 3 - 1}{3 - 1} = \binom{7}{2}
\]

We can calculate \(\binom{7}{2}\) as follows:

\[
\binom{7}{2} = \frac{7!}{2!(7-2)!} = \frac{7!}{2!5!} = \frac{7 \cdot 6}{2 \cdot 1} = 21
\]
