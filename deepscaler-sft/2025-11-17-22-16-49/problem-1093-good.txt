Given that \( f(x) \) is a monic polynomial of degree 2, it means that the leading coefficient is 1. So, we can express \( f(x) \) in the form:

\[ f(x) = x^2 + bx + c \]

We are also given the following conditions:

1. \( f(0) = 4 \)
2. \( f(1) = 10 \)

Let's substitute these conditions into our polynomial expression.

First, substitute \( x = 0 \) into \( f(x) \):

\[ f(0) = 0^2 + b \cdot 0 + c = c = 4 \]

So, we have:

\[ c = 4 \]

Next, substitute \( x = 1 \) into \( f(x) \):

\[ f(1) = 1^2 + b \cdot 1 + c = 1 + b + c = 10 \]

We already know that \( c = 4 \), so we substitute this into the equation:

\[ 1 + b + 4 = 10 \]

This simplifies to:

\[ 5 + b = 10 \]

Subtract 5 from both sides:

\[ b = 5 \]

Now we have determined the values of \( b \) and \( c \). Substituting these back into our polynomial, we get:

\[ f(x) = x^2 + 5x + 4 \]

Let's confirm this solution using Python to ensure accuracy by checking that both conditions \( f(0) = 4 \) and \( f(1) = 10 \) are satisfied with this polynomial.
```python
import sympy as sp

# Define the variables
x = sp.symbols('x')

# Define the polynomial in the form x^2 + bx + c and substitute the conditions
b, c = sp.symbols('b c')
f = x**2 + b*x + c

# Set up the equations based on the conditions f(0) = 4 and f(1) = 10
eq1 = f.subs(x, 0) - 4
eq2 = f.subs(x, 1) - 10

# Solve for b and c
solution = sp.solve((eq1, eq2), (b, c))
print(solution)
```
Code execution result: {b: 5, c: 4}

This confirms that the values we obtained, \( b = 5 \) and \( c = 4 \), are correct. Therefore, the polynomial \( f(x) \) is:

\[ f(x) = x^2 + 5x + 4 \]

So, the final answer is:

\(\boxed{x^2 + 5x + 4}\)
