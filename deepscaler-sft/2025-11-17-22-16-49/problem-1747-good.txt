To solve this problem, we will set up a system of linear equations and then solve it step-by-step.

Let's denote the cost of a burger by \( b \) and the cost of a soda by \( s \).

From the problem statement, we have the following system of equations based on the purchases made by Uri and Gen:

1. Uri buys two burgers and a soda for \$2.10:
   \[
   2b + s = 2.10
   \]

2. Gen buys a burger and two sodas for \$2.40:
   \[
   b + 2s = 2.40
   \]

We will solve this system of equations to find the values of \( b \) and \( s \).

First, we can express these equations in a more mathematical form for solving:

\[
\begin{cases}
2b + s = 2.10, \\
b + 2s = 2.40.
\end{cases}
\]

To solve these equations, we can use substitution or elimination methods. Here, we will use Python to solve it accurately.
```python
from sympy import symbols, Eq, solve

# Define the variables
b, s = symbols('b s')

# Set up the equations based on the problem
eq1 = Eq(2 * b + s, 2.10)
eq2 = Eq(b + 2 * s, 2.40)

# Solve the system of equations
solution = solve((eq1, eq2), (b, s))

print(solution)
```
Code execution result: {b: 0.600000000000000, s: 0.900000000000000}

From solving the system of equations, we get:
\[
b = 0.60 \quad \text{(cost of a burger)}
\]
\[
s = 0.90 \quad \text{(cost of a soda)}
\]

We need to find out how many cents a soda costs. Since 1 dollar is equal to 100 cents, we will convert 0.90 dollars to cents:

\[
s = 0.90 \, \text{dollars} \times 100 \, \frac{\text{cents}}{\text{dollar}} = 90 \, \text{cents}
\]

Thus, the cost of a soda is \(\boxed{90}\) cents. This is our final answer.
