To solve this problem, we need to determine the number of days between January 1, 1960, and January 1, 2000, and then use that to find out the day of the week for January 1, 1960. 

1. **Determine the Number of Days:**
    - We start by noting that January 1, 2000, is a Saturday.
    - We need to count the number of days from January 1, 1960, to January 1, 2000.
    - We will account for leap years because they add an extra day to the count. A leap year is a year that is divisible by 4, but years divisible by 100 are not leap years unless they are also divisible by 400. 

2. **Calculate the Leap Years:**
    - From 1960 to 1999, we need to identify the leap years.
    - Leap years in this range are 1960, 1964, 1968, ..., 1996, 1992, 1988, 1984, 1980, 1976.
    - We can use Python to get an accurate count of the leap years and calculate the total number of days between these two dates.

3. **Compute the Day of the Week:**
    - Once we have the number of days, we can use modulo 7 arithmetic to determine the day of the week starting from Saturday (2000-01-01 is given as Saturday). Each day of the week cycles every 7 days.

Let's implement this step-by-step in Python to get the accurate result.
```python
import datetime

# Get the date objects for January 1, 1960, and January 1, 2000
date_1960 = datetime.date(1960, 1, 1)
date_2000 = datetime.date(2000, 1, 1)

# Calculate the difference in days
delta = date_2000 - date_1960

# Get the number of days between the two dates
days_difference = delta.days

# January 1, 2000, is a Saturday (0=Monday, 1=Tuesday, ..., 6=Sunday)
days_of_week = ["Monday", "Tuesday", "Wednesday", "Thursday", "Friday", "Saturday", "Sunday"]

# Find out what day of the week January 1, 1960, was
day_of_week_1960 = days_of_week[(days_difference) % 7]

print(day_of_week_1960)
```
Code execution result: Tuesday

Thus, January 1, 1960, fell on a \(\boxed{\text{Tuesday}}\). This is our final answer.
