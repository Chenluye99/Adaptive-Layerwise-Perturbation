First, let's get some background on the problem. For any triangle \(ABC\), the circumcenter \(O\) is the center of the circle that passes through the three vertices of the triangle, and the orthocenter \(H\) is the point where the three altitudes of the triangle intersect.

A key property we will use here is that for any triangle, the distance from the circumcenter \(O\) to a vertex is equal to the circumradius \(R\). And, the distance from the orthocenter \(H\) to a vertex can be expressed using the circumradius \(R\) and the angles of the triangle. Specifically, in a triangle \(ABC\), the distances from the orthocenter to each vertex are given by:

\[ AH = 2R \cos A, \quad BH = 2R \cos B, \quad CH = 2R \cos C. \]

Given that \( AO = R \) and it is stated that \( AO = AH \), we can substitute to get:

\[ R = 2R \cos A. \]

This equation simplifies to:

\[ 1 = 2 \cos A \implies \cos A = \frac{1}{2}. \]

The angle \( A \) that satisfies this equation is:

\[ A = \cos^{-1}\left(\frac{1}{2}\right) = 60^\circ. \]

However, since we are dealing with a triangle, it's important to consider if there could be other solutions. The cosine function is periodic and has symmetry, but within the context of a triangle's angle (which must be between 0° and 180°), if \(\cos A = \frac{1}{2}\), then \( A = 60^\circ \) is the only angle that fits, given that \(\cos (180^\circ - A) = -\cos A \), and \(\cos (360^\circ - A) = \cos A \), but these would not apply here because angles in a triangle are limited to 0° to 180° and it must be a valid triangle configuration.

To make sure, let's write some Python code to confirm this reasoning by checking if there are other possible configurations for \(\angle A\) by iterating over possible angle values and checking if they give the desired condition.

Let's implement this reasoning in Python.
```python
import numpy as np

# Initialize an empty list to collect the possible values of angle A
possible_angles = []

# Check all angles from 1 to 179 degrees (angles of a triangle range from 1 to 179 degrees inclusive when checking for validity)
for angle_A in range(1, 180):
    cos_A = np.cos(np.deg2rad(angle_A))
    if np.isclose(1, 2 * cos_A, atol=1e-9):
        possible_angles.append(angle_A)

print(possible_angles)
```
