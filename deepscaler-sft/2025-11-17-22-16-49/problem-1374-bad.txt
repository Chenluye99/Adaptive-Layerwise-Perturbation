Let's start by finding the median, mode, and then compute the arithmetic mean of the median and the mode.

### Step 1: Finding the Median
The median is the middle value of an ordered dataset. For a dataset with 26 grades (an even number), the median is the average of the 13th and 14th values when the data is ordered.

### Step 2: Finding the Mode
The mode is the value that appears most frequently in the dataset.

### Step 3: Calculating the Arithmetic Mean of the Median and the Mode
Once we have the median and mode, we can compute their arithmetic mean.

Let's use Python to determine these values accurately.
```python
# List of exam grades based on the stem and leaf plot interpretation
grades = [41, 52, 67, 68, 68, 71, 71, 72, 73, 73, 73, 75, 76, 78, 80, 84, 84, 86, 86, 86, 86, 88, 91, 93, 95, 95, 97]

# Find the median
n = len(grades)
sorted_grades = sorted(grades)
median = (sorted_grades[n // 2 - 1] + sorted_grades[n // 2]) / 2  # 13th and 14th values

# Find the mode
from collections import Counter
count_grades = Counter(grades)
mode = count_grades.most_common(1)[0][0]  # Get the most common value (mode)

# Calculate the arithmetic mean of the median and the mode
mean_result = (median + mode) / 2

print(((median, mode, mean_result)))
```
Code execution result: (77.0, 86, 81.5)

So, we have:
- The median of the data is \( 77.0 \).
- The mode of the data is \( 86 \).

The arithmetic mean of the median and the mode is:
\[
\frac{77.0 + 86}{2} = 81.5
\]

Thus, the final answer is \(\boxed{81.5}\). This concludes the solution.
