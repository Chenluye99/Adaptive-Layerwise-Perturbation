First, let's start by listing all the steps and reasoning required to solve the problem.

1. **Identify the Problem:**
    - We need to find the probability that the two 'E's in the word "SIXTEEN" are not next to each other when the letters are randomly arranged.

2. **Formulate a Plan:**
    - **Step 1: Count the Total Number of Arrangements:**
      - The word "SIXTEEN" has 7 letters with 'E' repeating twice. The total number of distinct arrangements of "SIXTEEN" is given by:
        \[
        \frac{7!}{2!}
        \]
      - This is because there are 7 positions and 2 of the letters are identical (the 'E's).
    - **Step 2: Count the Number of Arrangements Where the Two 'E's Are Next to Each Other:**
      - To count this, we can treat the two 'E's as a single "super letter." So, we now have 6 "letters" to arrange (the "super E" plus the other 5 distinct letters: S, I, X, T, N).
      - The number of ways to arrange these 6 "letters" is \(6!\).
    - **Step 3: Calculate the Number of Arrangements Where the Two 'E's Are Not Next to Each Other:**
      - Subtract the number of arrangements where the two 'E's are next to each other from the total number of arrangements.
    - **Step 4: Calculate the Probability:**
      - The probability that the two 'E's are not next to each other is the ratio of the number of arrangements where the two 'E's are not next to each other to the total number of arrangements.

3. **Translate the Plan into Code:**
    - We will use Python to ensure calculations are accurate.

Let's implement this step-by-step in Python to get the answer.
```python
import itertools

# Get all unique permutations of the word 'SIXTEEN'
word = "SIXTEEN"
all_permutations = set(itertools.permutations(word))

# Count total number of distinct permutations
total_permutations = len(all_permutations)

# Count number of permutations where the two 'E's are next to each other
count_E_together = 0

for perm in all_permutations:
    perm_str = ''.join(perm)
    indices_of_E = [i for i, letter in enumerate(perm_str) if letter == 'E']
    
    # Check if the 'E's are next to each other
    if len(indices_of_E) == 2 and abs(indices_of_E[0] - indices_of_E[1]) == 1:
        count_E_together += 1

# Count number of permutations where the two 'E's are not next to each other
count_E_not_together = total_permutations - count_E_together

# Calculate the probability
probability_E_not_together = count_E_not_together / total_permutations
print(probability_E_not_together)
```
Code execution result: 0.7142857142857143

Thus, the probability that the two E's are not next to each other when the letters of the word "SIXTEEN" are randomly arranged is \(\boxed{0.7142857142857143}\).
