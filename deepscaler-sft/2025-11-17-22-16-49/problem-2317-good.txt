To solve this problem, we can use the distance formula. The distance formula between two points \((x_1, y_1)\) and \((x_2, y_2)\) is given by:

\[ \text{Distance} = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2} \]

In this case, the distance is 5, one endpoint is \((1, 2)\), and the other endpoint is \((4, b)\). Substituting these values into the distance formula, we get:

\[ 5 = \sqrt{(4 - 1)^2 + (b - 2)^2} \]

This simplifies to:

\[ 5 = \sqrt{3^2 + (b - 2)^2} \]
\[ 5 = \sqrt{9 + (b - 2)^2} \]

Squaring both sides of the equation, we get:

\[ 25 = 9 + (b - 2)^2 \]

Subtract 9 from both sides:

\[ 16 = (b - 2)^2 \]

Taking the square root of both sides, we obtain:

\[ b - 2 = 4 \quad \text{or} \quad b - 2 = -4 \]

So, we solve for \( b \) in each case:

\[ b - 2 = 4 \implies b = 6 \]
\[ b - 2 = -4 \implies b = -2 \]

Thus, the possible values for \( b \) are \( 6 \) and \( -2 \). Let's verify this with Python code to ensure accuracy.
```python
import sympy as sp

# Define the variables
b = sp.symbols('b')

# Set up the equation based on the distance formula
eq = sp.Eq(sp.sqrt((4 - 1)**2 + (b - 2)**2), 5)

# Solve the equation for b
solution = sp.solve(eq, b)
print(solution)
```
Code execution result: [-2, 6]

This confirms that the possible values of \( b \) are \(\boxed{6, -2}\). This is the final answer.
