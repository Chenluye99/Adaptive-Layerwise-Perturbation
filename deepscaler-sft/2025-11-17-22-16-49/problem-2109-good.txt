To solve this problem, we need to find the values of \(a\) such that the equations
\[x^2 + ax + 1 = 0 \quad \text{(1)}\]
\[x^2 - x - a = 0 \quad \text{(2)}\]
have a common real root.

1. **Assume that \(x = r\) is the common root:**
    - Substitute \(r\) into both equations.
    - From equation (1), we have:
      \[ r^2 + ar + 1 = 0 \quad \text{(3)} \]
    - From equation (2), we have:
      \[ r^2 - r - a = 0 \quad \text{(4)} \]

2. **Set up a system to solve for \(r\) and \(a\):**
    - We can solve these two equations simultaneously to get the relationship between \(r\) and \(a\).
    - First, solve equation (4) for \(a\):
      \[ a = r^2 - r \quad \text{(5)} \]
    - Substitute equation (5) into equation (3):
      \[ r^2 + (r^2 - r)r + 1 = 0 \]
      \[ r^2 + r^3 - r^2 + 1 = 0 \]
      \[ r^3 + 1 = 0 \]
      \[ r^3 = -1 \]
      \[ r = -1 \]

3. **Find the corresponding \(a\):**
    - Substitute \( r = -1 \) back into equation (5):
      \[ a = (-1)^2 - (-1) = 1 + 1 = 2 \]

We need to ensure that this is the only solution and consider if there could be other possible values for \( r \) that we may have missed.
