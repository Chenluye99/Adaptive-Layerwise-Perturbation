First, let's start by finding the six solutions of the equation \(x^6 = -64\).

1. **Express \(-64\) in Polar Form:**
   The number \(-64\) can be written in polar form as \(64 \text{cis} (180^\circ)\) or \(64 e^{i \pi}\) because \(-64 = 64 (\cos \pi + i \sin \pi)\).

2. **Find the Sixth Roots:**
   To find the sixth roots of \(-64\), we use De Moivre's Theorem. The general form for the \(n\)-th roots of a complex number \(r (\cos \theta + i \sin \theta)\) is given by:
   \[
   \sqrt[n]{r} \left( \cos \frac{\theta + 2k\pi}{n} + i \sin \frac{\theta + 2k\pi}{n} \right)
   \]
   for \( k = 0, 1, 2, \ldots, n-1 \).

   For our specific problem, \( r = 64 \), \(\theta = \pi \), and \( n = 6 \). So, the sixth roots are:
   \[
   \sqrt[6]{64} \left( \cos \frac{\pi + 2k\pi}{6} + i \sin \frac{\pi + 2k\pi}{6} \right) = 2 \left( \cos \frac{\pi + 2k\pi}{6} + i \sin \frac{\pi + 2k\pi}{6} \right)
   \]
   for \( k = 0, 1, 2, 3, 4, 5 \).

3. **Calculate Each Root:**
   We can now calculate each of these roots by plugging in \( k = 0, 1, 2, 3, 4, 5 \):
   \[
   \text{For } k = 0: \quad 2 \left( \cos \frac{\pi}{6} + i \sin \frac{\pi}{6} \right) = 2 \left( \cos \frac{\pi}{6} + i \sin \frac{\pi}{6} \right) = 2 \left( \frac{\sqrt{3}}{2} + i \frac{1}{2} \right) = \sqrt{3} + i
   \]
   \[
   \text{For } k = 1: \quad 2 \left( \cos \frac{3\pi}{6} + i \sin \frac{3\pi}{6} \right) = 2 \left( \cos \frac{\pi}{2} + i \sin \frac{\pi}{2} \right) = 2 (0 + i \cdot 1) = 2i
   \]
   \[
   \text{For } k = 2: \quad 2 \left( \cos \frac{5\pi}{6} + i \sin \frac{5\pi}{6} \right) = 2 \left( -\frac{\sqrt{3}}{2} + i \frac{1}{2} \right) = -\sqrt{3} + i
   \]
   \[
   \text{For } k = 3: \quad 2 \left( \cos \frac{7\pi}{6} + i \sin \frac{7\pi}{6} \right) = 2 \left( -\frac{\sqrt{3}}{2} - i \frac{1}{2} \right) = -\sqrt{3} - i

   \[
   \text{For } k = 4: \quad 2 \left( \cos \frac{9\pi}{6} + i \sin \frac{9\pi}{6} \right) = 2 \left( \cos \frac{3\pi}{2} + i \sin \frac{3\pi}{2} \right) = 2 (0 - i \cdot 1) = -2i
   \]
   \[
   \text{For } k = 5: \quad 2 \left( \cos \frac{11\pi}{6} + i \sin \frac{11\pi}{6} \right) = 2 \left( \frac{\sqrt{3}}{2} - i \frac{1}{2} \right) = \sqrt{3} - i
   \]

4. **List the Solutions:**
   So, the six solutions are:
   \[
   \sqrt{3} + i, \quad 2i, \quad -\sqrt{3} + i, \quad -\sqrt{3} - i, \quad -2i, \quad \sqrt{3} - i
   \]

5. **Identify Solutions with \(a > 0\):**
   We need to identify which of these solutions have a real part \(a > 0\):
   - \(\sqrt{3} + i\) has \(a = \sqrt{3} > 0\)
   - \(\sqrt{3} - i\) has \(a = \sqrt{3} > 0\)

   So, the solutions with \(a > 0\) are \(\sqrt{3} + i\) and \(\sqrt{3} - i\).

6. **Find the Product of These Solutions:**
   We need to calculate the product of \(\sqrt{3} + i\) and \(\sqrt{3} - i\):
   \[
   (\sqrt{3} + i)(\sqrt{3} - i) = (\sqrt{3})^2 - (i)^2 = 3 - (-1) = 3 + 1 = 4
