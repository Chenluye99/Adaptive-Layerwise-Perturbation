To solve this problem, we need to use properties of the greatest common divisor (GCD) and the least common multiple (LCM) of two numbers. For two integers \(a\) and \(b\), the following relationship holds:

\[
\text{GCD}(a, b) \times \text{LCM}(a, b) = a \times b
\]

We are given that

\[
\text{GCD}(a, b) \times \text{LCM}(a, b) = 180
\]

This means:

\[
a \times b = 180
\]

Let's denote \(\text{GCD}(a, b) = d\). Then we can express \(a\) and \(b\) as \(a = d \cdot m\) and \(b = d \cdot n\) where \(\text{GCD}(m, n) = 1\) (i.e., \(m\) and \(n\) are coprime). Substituting these into the equation above, we get:

\[
a \times b = (d \cdot m) \times (d \cdot n) = d^2 \cdot m \cdot n = 180
\]

This implies:

\[
d^2 \cdot m \cdot n = 180
\]

Since \(\text{GCD}(m, n) = 1\), \(m\) and \(n\) must be coprime. To find the possible values of \(d\), we need to consider all the divisors of 180 and check if the corresponding \(m \cdot n = \frac{180}{d^2}\) can be factored into two coprime numbers.

First, let's get the divisors of 180. Then we will check each divisor to see if \(\frac{180}{d^2}\) can be written as a product of two coprime numbers.

### Step-by-Step Implementation in Python
1. Get the divisors of 180.
2. For each divisor \(d\) of 180, check if \(\frac{180}{d^2}\) can be factored into two coprime numbers.

Let's implement this step-by-step in Python.
```python
import math
from sympy import gcd

# Find all the divisors of 180
divisors_of_180 = [d for d in range(1, 181) if 180 % d == 0]

# To store the valid GCD values
valid_gcd_values = set()

for d in divisors_of_180:
    quotient = 180 // (d * d)
    
    # Check if quotient can be expressed as a product of two coprime numbers
    for m in range(1, quotient + 1):
        if quotient % m == 0:
            n = quotient // m
            if gcd(m, n) == 1:
                valid_gcd_values.add(d)

# Get the distinct values of GCD
distinct_gcd_values = set(valid_gcd_values)
print((len(distinct_gcd_values), distinct_gcd_values))
```
