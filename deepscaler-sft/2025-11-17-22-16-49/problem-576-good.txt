To solve the problem, we need to find the maximum value of the function \( y = 4^x + 2^{x+1} + 5 \) over the interval \( [1, 2] \).

1. **Define the Function:**
   The function is \( y = 4^x + 2^{x+1} + 5 \). We can rewrite \( 4^x \) as \( (2^2)^x = (2^x)^2 \), so the function becomes \( y = (2^x)^2 + 2 \cdot 2^x + 5 \).

2. **Evaluate the Function over the Interval:**
   To find the maximum value, we can evaluate the function at the endpoints of the interval \( x = 1 \) and \( x = 2 \), and also check if there is a maximum within this interval by taking the derivative and setting it to zero if necessary. However, it's often simpler and sufficient to evaluate at the endpoints for a continuous function over a closed interval.

3. **Evaluate at Endpoints:**
   - When \( x = 1 \):
     \[
     y = 4^1 + 2^{1+1} + 5 = 4 + 4 + 5 = 13
     \]
   - When \( x = 2 \):
     \[
     y = 4^2 + 2^{2+1} + 5 = 16 + 8 + 5 = 29
     \]

4. **Conclusion:**
   By evaluating the function at the endpoints, we get the values 13 for \( x = 1 \) and 29 for \( x = 2 \). Since these are the only evaluations we need to make for a closed interval, the maximum value of the function over the interval \([1, 2]\) is 29.

Let's confirm this by implementing it in Python.
```python
import numpy as np

# Define the function
def f(x):
    return 4**x + 2**(x + 1) + 5

# Generate values of the function over the interval [1, 2]
x_values = np.linspace(1, 2, 1000)
y_values = f(x_values)

# Find the maximum value of the function in the interval [1, 2]
max_y = np.max(y_values)
print(max_y)
```
Code execution result: 29.0

Thus, the maximum value of the function \( y = 4^x + 2^{x+1} + 5 \) over the interval \( [1, 2] \) is \(\boxed{29}\). This confirms our analytical solution.
