To solve the problem, let's follow these steps:

1. **Define the Set and Identify Conditions for Multiples of 100:**
    - The set is \(\{ 2, 4, 10, 12, 15, 20, 50 \}\).
    - We need to check when the product of two distinct members of this set is a multiple of 100. A number is a multiple of 100 if it can be divided by both 4 and 25 (i.e., \(100 = 4 \times 25\)).

2. **Generate All Possible Pairs and Check for Multiples of 100:**
    - We'll generate all distinct pairs of the elements in the set and check if their product is divisible by 100.
    - We'll then count how many of these pairs produce a product that is divisible by 100.

3. **Calculate the Probability:**
    - The total number of ways to choose 2 distinct elements from the set of 7 elements is \(\binom{7}{2} = 21\).
    - The probability is the number of pairs that produce a product divisible by 100 divided by 21.

4. **Implement this in Python:**
    - Write Python code to implement the above steps and get the final answer.

Let's write the Python code to solve this step-by-step.
```python
import itertools

# Define the set
num_set = {2, 4, 10, 12, 15, 20, 50}

# Find all distinct pairs and check if their product is a multiple of 100
count_multiples_of_100 = 0

for a, b in itertools.permutations(num_set, 2):
    product = a * b
    if product % 100 == 0:
        count_multiples_of_100 += 1

# Total number of ways to choose 2 distinct elements from the set of 7 elements is 21
total_pairs = 21

# Calculate the probability
probability = count_multiples_of_100 / total_pairs

# Return the result as a fraction
from fractions import Fraction
probability_fraction = Fraction(count_multiples_of_100, total_pairs)

print(probability_fraction)
```
Code execution result: 2/3

Thus, the probability that the product of two randomly selected distinct members of the set \(\{ 2, 4, 10, 12, 15, 20, 50 \}\) is a multiple of 100 is \(\boxed{\frac{2}{3}}\). This is our final answer.
