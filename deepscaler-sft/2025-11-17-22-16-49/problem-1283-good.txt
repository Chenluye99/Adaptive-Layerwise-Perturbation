To solve this problem, we need to determine the total number of possible words that can be formed using the 5-letter Mumblian alphabet with the constraint that each word can have 1, 2, or 3 letters.

1. **Determine the Number of 1-Letter Words:**
   - Each position in the word can be one of 5 letters.
   - So, there are \(5^1 = 5\) possible 1-letter words.

2. **Determine the Number of 2-Letter Words:**
   - Each of the 2 positions in the word can be one of 5 letters.
   - So, there are \(5^2 = 25\) possible 2-letter words.

3. **Determine the Number of 3-Letter Words:**
   - Each of the 3 positions in the word can be one of 5 letters.
   - So, there are \(5^3 = 125\) possible 3-letter words.

4. **Calculate the Total Number of Possible Words:**
   - The total number of possible words is the sum of the number of 1-letter words, 2-letter words, and 3-letter words.
   - Therefore, the total number of words is \(5 + 25 + 125 = 155\).

num_letters = 5
