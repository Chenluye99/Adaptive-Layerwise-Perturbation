To solve this problem, we will follow these steps:

1. **Find the Divisors of 372**: Get all divisors of 372.
2. **Filter Divisors by Conditions**: Filter these divisors to find those that are smaller than 50.
3. **Find Common Factors with 72**: Further filter these results to find which of these divisors are also factors of 72.
4. **Identify the Greatest Divisor**: Determine the greatest divisor that meets all the conditions.

Let's implement this step-by-step using Python.
```python
# Step 1: Find all divisors of 372
num1 = 372
num2 = 72

# Get all divisors of 372
divisors_of_372 = [i for i in range(1, num1 + 1) if num1 % i == 0]

# Step 2: Filter divisors to get those that are smaller than 50
divisors_less_than_50 = [d for d in divisors_of_372 if d < 50]

# Step 3: Find which of these divisors are also factors of 72
common_divisors = [d for d in divisors_less_than_50 if num2 % d == 0]

# Step 4: Identify the greatest divisor that meets all the conditions
greatest_common_divisor = max(common_divisors) if common_divisors else None

print(greatest_common_divisor)
```
Code execution result: 12

Thus, the greatest divisor of 372 that is smaller than 50 and also a factor of 72 is \(\boxed{12}\). This is the final answer.
