3. **Exclude Forbidden Codes:**
    - **Two or More Matching Positions:**

4. **Count Valid Codes:**

Let's implement this step-by-step reasoning in Python to get the accurate result.
```python
# Step 1: Generate all possible three-digit codes
possible_codes = []
for i in range(1000):
    possible_codes.append(str.zfill(str(i), 3))

# Step 2: Identify and exclude forbidden codes based on problem constraints

original_code = "023"
num_digits = 3

# Create a set to store forbidden codes for efficient checking
forbidden_codes = set()

# Check for codes that match "023" in two or more digit-positions
for code in possible_codes:
    match_count = 0
    for i in range(num_digits):
        if code[i] == original_code[i]:
            match_count += 1
    if match_count >= 2:
        forbidden_codes.add(code)

# Check for codes formed by swapping two digits of "023"
for i in range(num_digits):
    for j in range(i+1, num_digits):
        swapped_code = list(original_code)
        swapped_code[i], swapped_code[j] = swapped_code[j], swapped_code[i]
        swapped_code = ''.join(swapped_code)
        if swapped_code != original_code:
            forbidden_codes.add(swapped_code)

# Get the unique forbidden codes
forbidden_codes = set(forbidden_codes)

# Step 3: Count valid codes by excluding the forbidden ones
valid_codes = [code for code in possible_codes if code not in forbidden_codes]

# Get the count of valid codes
num_valid_codes = len(valid_codes)
print(num_valid_codes)
```
