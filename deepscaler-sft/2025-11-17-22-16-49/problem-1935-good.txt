To find the value of \( x \) that gives the minimum value for the quadratic function \( f(x) = x^2 - 14x + 3 \), we can use the properties of quadratic functions.

A quadratic function of the form \( f(x) = ax^2 + bx + c \) has its minimum (if \( a > 0 \)) or maximum (if \( a < 0 \)) value at the vertex. The \( x \)-coordinate of the vertex of a parabola given by \( f(x) = ax^2 + bx + c \) is found using the formula:

\[ x = -\frac{b}{2a} \]

For the function \( f(x) = x^2 - 14x + 3 \), the coefficients are:
- \( a = 1 \)
- \( b = -14 \)
- \( c = 3 \)

Substituting \( a \) and \( b \) into the vertex formula:

\[ x = -\frac{-14}{2 \cdot 1} = \frac{14}{2} = 7 \]

So, the value of \( x \) that gives the minimum value for the function \( f(x) = x^2 - 14x + 3 \) is \( x = 7 \). 

We can confirm this by implementing it in Python to ensure accuracy.
```python
import sympy as sp

# Define the variable and the function
x = sp.symbols('x')
f = x**2 - 14*x + 3

# Find the critical points by taking the derivative and setting it to zero
f_prime = sp.diff(f, x)
critical_points = sp.solve(f_prime, x)

print(critical_points)
```
Code execution result: [7]

This confirms that the critical point, and consequently the value of \( x \) that gives the minimum value for the function \( f(x) = x^2 - 14x + 3 \), is \( x = 7 \).

Thus, the final answer is:

\(\boxed{7}\)
