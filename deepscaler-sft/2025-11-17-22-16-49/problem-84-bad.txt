Let's break down the problem step-by-step.

1. **Understand and Formulate the Problem:**

   - We have the following air pollution index values: \(90, 110, x, y, 150\).
   - The average of these 5 values is 110, so we can write the equation for the average as:
     \[
     \frac{90 + 110 + x + y + 150}{5} = 110
     \]
     Simplifying this, we get:
     \[
     90 + 110 + x + y + 150 = 550 \implies 350 + x + y = 550 \implies x + y = 200
     \]

2. **Part 1: Find the Probability that Both Selected Days Have Good Air Quality:**

   - First, determine which of the values \(90, 110, x, y, 150\) have an air quality index not greater than 100, meaning the air quality is good. Given \(90 \leq 100\) and \(110 \leq 100\) is false, only \(90\) will qualify as an index that means good air quality unless \(x\) or \(y\) is such that it falls below or equal to 100.
   - Since \(x + y = 200\), and we want to determine under what conditions both of the two selected days have good air quality, we need to consider the constraints on \(x\) and \(y\) given \(90 < x < 150\):
     - If \(90\) is the only good air quality index, then both selected days must be 90 if this is the only eligible index. But let's generalize it and check based on different valid values of \(x\) and \(y\) satisfying the equation \(x + y = 200\) and the constraints.
   
   - Based on the above considerations, more generally, to determine the validity of the relationship \(x < y\) and finding the probability that both of the 2 selected days have air quality indexes not greater than 100, we generally consider all such pairs \((x, y)\) for \((90, 110, x, y, 150)\) coming out of the 5-pick 2-pairs.
   - We need to enumerate all possible values for \(x\) and \(y\) and evaluate each case to find valid pairs and subsequently check the probability of picking 2 good air quality days out of 5 days whose list of indices could be enumerated over the possible ranges systematically. Let's evaluate it using Python now.

3. **Part 2: Find the Minimum Value of the Variance of the Air Pollution Index for These 5 Days:**

   - Variance is given by \(\text{Var}(X) = \frac{1}{N} \sum_{i=1}^N (x_i - \mu)^2\) where \( \mu \) is the mean of the dataset. For our case, \( \mu = 110 \).
   - We need to minimize the variance subject to the condition \(90 < x < 150\) and \( x + y = 200 \).

Let's implement this step-by-step using Python and SymPy:

```python
import sympy as sp
import itertools

# Part 1: Find the Probability

# We need to find all possible values of x and y such that 90 < x < 150, x + y = 200, and x < y.
x, y = sp.symbols('x y', integer=True)
solution = []

# Find all possible integer values of x and y that satisfy 90 < x < 150 and x + y = 200
for i in range(91, 150):
    j = 200 - i
    if 90 < i < 150 and 90 < j < 150 and i < j:
        solution.append((i, j))

# Create a list of 5-day pollution data sets based on the constraints for each (x, y) found in "solution" list
data_sets = []
for x_val, y_val in solution:
    data_set = [90, 110, x_val, y_val, 150]
    data_sets.append(data_set)

# Now, count the number of pairs where the air quality is good for both days from these 5 days, air quality being good if the index is not greater than 100.
good_air_quality_indices = [90, 110]
count_good_pairs = 0
num_pairs = 0

for data_set in data_sets:
    for pair in itertools.combinations(data_set, 2):
        if all(p in good_air_quality_indices for p in pair):
            count_good_pairs += 1
        num_pairs += 1

probability_good_pairs = count_good_pairs / num_pairs

# Part 2: Find the Minimum Value of the Variance

variance_values = []
for x_val, y_val in solution:
    data = [90, 110, x_val, y_val, 150]
    mean = 110
    variance = sum((val - mean) ** 2 for val in data) / len(data)
    variance_values.append(variance)

min_variance = min(variance_values)

print(probability_good_pairs, min_variance)
```
