We are given a polynomial equation of the form:

\[ 3x^3 + a_2 x^2 + a_1 x - 6 = 0 \]

We need to find all possible integer roots of this polynomial. To solve this, we can utilize the Rational Root Theorem. The Rational Root Theorem states that any rational root, expressed in its lowest terms \( \frac{p}{q} \), of the polynomial equation \(a_n x^n + a_{n-1} x^{n-1} + \ldots + a_1 x + a_0 = 0\) must be such that:

- \( p \) is a factor of the constant term \( a_0 \), and
- \( q \) is a factor of the leading coefficient \( a_n \).

For our polynomial \( 3x^3 + a_2 x^2 + a_1 x - 6 = 0 \):

- The constant term is \(-6\).
- The leading coefficient is \(3\).

First, we list the factors of the constant term \(-6\):
\[ \text{Factors of } -6: \, \pm 1, \, \pm 2, \, \pm 3, \, \pm 6 \]

Next, we list the factors of the leading coefficient \(3\):
\[ \text{Factors of } 3: \, \pm 1, \, \pm 3 \]

According to the Rational Root Theorem, the possible rational roots (and subsequently, the possible integer roots) of the polynomial are the ratios \(\frac{p}{q}\) where \( p \) is a factor of \(-6\) and \( q \) is a factor of \(3\). This means the possible integer roots are the factors of \(-6\) because the only way for \(\frac{p}{q}\) to be an integer is if \( q = 1 \) or \( q = -1 \).

So, the possible integer roots are:
\[ \pm 1, \, \pm 2, \, \pm 3, \, \pm 6 \]

Let's use Python to confirm that these are indeed the possible integer roots by checking if each of these values can satisfy the polynomial equation for some values of \(a_2\) and \(a_1\).
```python
import sympy as sp

# Define the variable and the polynomial
x = sp.symbols('x')
a2, a1 = sp.symbols('a2 a1', integer=True)

# Define the polynomial expression
polynomial = 3*x**3 + a2*x**2 + a1*x - 6

# Possible integer roots to test
possible_roots = [1, -1, 2, -2, 3, -3, 6, -6]

# Find which of these possible roots can make the polynomial equal to 0 for some integer values of a2 and a1
valid_roots = []

for root in possible_roots:
    equation = polynomial.subs(x, root)
    # Check if there exist integers a2 and a1 such that the equation equals 0
    for a2_val in range(-100, 101):
        for a1_val in range(-100, 101):
            if equation.subs({a2: a2_val, a1: a1_val}) == 0:
                valid_roots.append(root)
                break  # No need to check further for this root if we found a solution for a2 and a1

# Get distinct values for valid_roots
valid_roots = set(valid_roots)
print(valid_roots)
```
