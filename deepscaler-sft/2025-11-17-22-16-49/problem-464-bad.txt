First, let's define the problem carefully and create a plan for solving it:

1. **Initial Day (Day 1):**
    - Rabbits: 200
    - Squirrels: 18

2. **Subsequent Days:**
    - Each day, the number of rabbits caught is reduced by 3, and the number of squirrels caught is increased by 2.
    - The process continues until the number of squirrels caught is greater than the number of rabbits caught.

3. **Objective:**
    - We need to keep track of the total number of rabbits caught up through the day when the number of squirrels caught is greater than the number of rabbits caught.
    - We will iterate through each day, updating the counts of rabbits and squirrels caught, and also updating a cumulative total for the number of rabbits caught.

To implement this, we will create a loop that simulates each day and continues until the number of squirrels caught in a day exceeds the number of rabbits caught in that day. We will then return the cumulative total of rabbits caught up to that point.

Let's write the Python code to solve this problem.
```python
# Initialize variables
rabbit_caught = 200
squirrel_caught = 18
daily_rabbit_total = 0

# Loop until the number of squirrels caught is greater than the number of rabbits caught
while squirrel_caught <= rabbit_caught:
    daily_rabbit_total += rabbit_caught
    rabbit_caught -= 3
    squirrel_caught += 2

print(daily_rabbit_total)
```
Code execution result: 5402

Therefore, the total number of rabbits caught up through the day when the task force caught more squirrels than rabbits is \(\boxed{5402}\). This is the final answer.
