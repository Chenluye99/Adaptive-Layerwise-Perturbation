To solve the problem, we need to construct the numbers \(a_k\) for \(1 \leq k \leq 100\), and check for each of these numbers whether it is divisible by 9. A number is divisible by 9 if the sum of its digits is divisible by 9.

To get \(a_k\), we simply concatenate the numbers from 1 to \(k\) into a single number. Then, we check the divisibility of this number by 9.

Let's implement this step-by-step in Python.
1. Create a function that constructs the number \(a_k\) by concatenating the numbers from 1 to \(k\).
2. Check if the resulting number is divisible by 9.
3. Count how many such numbers \(a_k\) (for \(1 \leq k \leq 100\)) are divisible by 9.

Here is the Python code to solve this problem:
```python
# Initialize a counter for the numbers that are divisible by 9
count_divisible_by_9 = 0

# Check for each k from 1 to 100 if a_k is divisible by 9
for k in range(1, 101):
    # Construct a_k by concatenating numbers from 1 to k
    a_k = int(''.join(map(str, list(range(1, k + 1)))))
    # Check if a_k is divisible by 9
    if a_k % 9 == 0:
        count_divisible_by_9 += 1

print(count_divisible_by_9)
```
Code execution result: 22

Thus, the number of \(a_k\) for \(1 \le k \le 100\) that are divisible by 9 is \(\boxed{22}\). This is our final answer.
