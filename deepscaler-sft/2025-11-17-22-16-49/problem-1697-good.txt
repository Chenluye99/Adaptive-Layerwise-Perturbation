First, let's start by setting up the equation and simplifying it. We have:

\[
(x^2 - 4x + 3)(x + 5) - (x^2 + 4x - 5)(x - c) = 0
\]

We want this equation to hold for all \( x \). This means that the coefficients of corresponding powers of \( x \) on both sides of the equation must be equal.

Let's expand both products:

1. Expand \((x^2 - 4x + 3)(x + 5)\):

\[
(x^2 - 4x + 3)(x + 5) = x^3 + 5x^2 - 4x^2 - 20x + 3x + 15 = x^3 + x^2 - 17x + 15
\]

2. Expand \((x^2 + 4x - 5)(x - c)\):

\[
(x^2 + 4x - 5)(x - c) = x^3 - cx^2 + 4x^2 - 4cx - 5x + 5c = x^3 + (4 - c)x^2 - (4c + 5)x + 5c
\]

Now, substitute these expansions into the original equation:

\[
(x^3 + x^2 - 17x + 15) - (x^3 + (4 - c)x^2 - (4c + 5)x + 5c) = 0
\]

This simplifies to:

\[
x^3 + x^2 - 17x + 15 - x^3 - (4 - c)x^2 + (4c + 5)x - 5c = 0
\]

Combine like terms:

\[
x^2 - (4 - c)x^2 - 17x + (4c + 5)x + 15 - 5c = 0
\]

\[
(x^2 - (4 - c)x^2) + (- 17x + (4c + 5)x) + (15 - 5c) = 0
\]

\[
(c - 3)x^2 + (4c - 12)x + (15 - 5c) = 0
\]

For this equation to hold for all \( x \), the coefficients of \( x^2 \), \( x \), and the constant term must all be zero. So, we set up the following system of equations:

1. From the coefficient of \( x^2 \):

\[
c - 3 = 0 \implies c = 3
\]

2. From the coefficient of \( x \):

\[
4c - 12 = 0 \implies 4c = 12 \implies c = 3
\]

3. From the constant term:

\[
15 - 5c = 0 \implies 15 = 5c \implies c = 3
\]
