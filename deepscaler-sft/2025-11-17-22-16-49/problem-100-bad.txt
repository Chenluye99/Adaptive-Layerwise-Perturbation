To solve the problem, let's follow these steps:

1. **Generate Possible Values for \(x\) and \(y\):**
    - Both \(x\) and \(y\) are integers between 100 and 999, inclusive.
    - For each \(x\), generate \(y\) by reversing the digits of \(x\).

2. **Calculate \(z = |x - y|\):**
    - For each pair \((x, y)\), compute \(z = |x - y|\).

3. **Collect All Distinct Values of \(z\):**
    - Add each value of \(z\) to a set to ensure that only distinct values are stored.

4. **Count the Number of Distinct Values of \(z\):**
    - Finally, determine the number of distinct values in the set.

Let's implement this step-by-step process using Python.
```python
# Initialize a set to store distinct values of z
distinct_z = set()

# Iterate over all numbers x from 100 to 999
for x in range(100, 1000):
    # Form y by reversing the digits of x
    y = int(str(x)[::-1])
    
    # Ensure y is also between 100 and 999
    if 100 <= y <= 999:
        # Calculate z as the absolute difference between x and y
        z = abs(x - y)
        
        # Add z to the set of distinct values
        distinct_z.add(z)

# Get the number of distinct values of z
num_distinct_z = len(distinct_z)
print(num_distinct_z)
```
Code execution result: 9

Thus, the number of distinct values of \( z \) that are possible is \(\boxed{9}\). This concludes our solution.
