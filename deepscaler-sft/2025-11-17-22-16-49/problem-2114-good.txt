To solve this problem, we need to follow these steps:

1. **Find the Factors of 1000:**
   First, we need to find all the factors of 1000. The prime factorization of 1000 is \(1000 = 2^3 \cdot 5^3\). So, the factors of 1000 are all numbers of the form \(2^a \cdot 5^b\) where \(0 \leq a \leq 3\) and \(0 \leq b \leq 3\).

2. **Check Which Factors are Divisible by 20:**
   Then, we need to check which of these factors are divisible by 20. The prime factorization of 20 is \(20 = 2^2 \cdot 5\). So, a factor of 1000 is divisible by 20 if and only if it is of the form \(2^a \cdot 5^b\) such that \(a \geq 2\) and \(b \geq 1\).

3. **Generate and Count Such Factors:**
   We will generate all factors of 1000 and then check for each factor if it is divisible by 20.

Let's implement this step-by-step in Python.
```python
import numpy as np

# Step 1: Find all factors of 1000
num = 1000
factors = []

for i in range(1, num + 1):
    if num % i == 0:
        factors.append(i)

# Step 2: Check which of these factors are divisible by 20
count = 0
for factor in factors:
    if factor % 20 == 0:
        count += 1

print(count)
```
Code execution result: 6

Thus, the number of factors of 1000 that can be divided by 20 without a remainder is \(\boxed{6}\). This is our final answer.
