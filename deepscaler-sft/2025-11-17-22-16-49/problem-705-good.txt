First, let's start by recalling Pascal's identity, which states:

\[
\binom{n}{k} = \binom{n-1}{k-1} + \binom{n-1}{k}
\]

We can use this identity to find \(\binom{18}{12}\) by using values involving \(\binom{17}{k}\). From Pascal's identity, we know:

\[
\binom{18}{12} = \binom{17}{11} + \binom{17}{12}
\]

We're given \(\binom{17}{11} = 12376\), but we need \(\binom{17}{12}\). Using Pascal's identity again for \(\binom{17}{12}\):

\[
\binom{17}{12} = \binom{16}{11} + \binom{16}{12}
\]

However, another useful identity and relation for binomial coefficients is:

\[
\binom{n}{k} = \binom{n}{n-k}
\]

Thus, we know:

\[
\binom{17}{12} = \binom{17}{5}
\]

We can compute \(\binom{17}{5}\) using the identity above again or by direct computation considering that:

\[
\binom{17}{5} = \frac{17!}{5!(17-5)!} = \frac{17!}{5! \cdot 12!}
\]

But a more efficient approach is noticing that we can get \(\binom{17}{12}\) using:

\[
\binom{17}{12} = \binom{17}{5}
\]

We can use the identity:

\[
\binom{19}{12} = \binom{18}{11} + \binom{18}{12}

\binom{18}{12} = 18564
