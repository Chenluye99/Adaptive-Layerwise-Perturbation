First, let's start by considering the set \( \{1, 3, 5, 7, 9, 11, 13\} \). We need to find all distinct positive integers that can be represented as the difference of two numbers in this set.

To do this, we will compute the difference for every pair of numbers in the set, ensuring that the first number in the pair is greater than or equal to the second number (to get positive differences), and then store these differences in a set. This will ensure that we get only the distinct positive differences.

Let's proceed with implementing this step-by-step in Python.
```python
# Define the set
num_set = {1, 3, 5, 7, 9, 11, 13}

# Initialize a set to store distinct positive differences
difference_set = set()

# Compute all distinct positive differences of the numbers in the set
for num1 in num_set:
    for num2 in num_set:
        diff = abs(num1 - num2)
        if diff > 0:
            difference_set.add(diff)

# Get the number of distinct positive integers in the difference set
num_distinct_differences = len(difference_set)
print(num_distinct_differences)
```
Code execution result: 6

Thus, the number of distinct positive integers that can be represented as the difference of two numbers in the set \(\{1, 3, 5, 7, 9, 11, 13\}\) is \(\boxed{6}\). This is our final answer.

This concludes that there are 6 distinct positive integers that can be obtained as differences of any two numbers in the given set.
