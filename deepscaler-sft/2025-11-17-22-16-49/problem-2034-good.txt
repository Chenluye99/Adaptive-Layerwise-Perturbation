We need to find the intersection points of the graphs given by the equations:
1. \((x - \lfloor x \rfloor)^2 + y^2 = x - \lfloor x \rfloor\)
2. \(y = \frac{1}{5} x\)

### Step-by-Step Solution:

1. **Understand the First Equation:**
    - The term \(x - \lfloor x \rfloor\) represents the fractional part of \(x\), which we can denote as \(\{x\}\). So, the equation becomes \(\{x\}^2 + y^2 = \{x\}\).
    - Let \(\{x\} = t\) where \(0 \leq t < 1\). Then the equation becomes \(t^2 + y^2 = t\), or equivalently, \(y^2 = t - t^2\).
    - For \(y^2\) to be non-negative, we need \(t - t^2 \geq 0\), which means \(0 \leq t \leq 1\). Additionally, since \(0 \leq t < 1\), the valid range for \(t\) is \(0 < t \leq 1\).

2. **Substitute the Second Equation:**
    - Substitute \(y = \frac{1}{5} x\) into the first equation.
    - Since \(\{x\} = t\), we can write \(x = n + t\) where \(n\) is an integer.
    - Then, \(y = \frac{1}{5} (n + t)\).
    - Substitute \(y = \frac{1}{5} (n + t)\) into the equation \(\{x\}^2 + y^2 = \{x\}\), we get:
      \[
      t^2 + \left( \frac{1}{5} (n + t) \right)^2 = t
      \]
      which simplifies to:
      \[
      t^2 + \frac{1}{25} (n + t)^2 = t
      \]
      Multiplying through by 25 gives:
      \[
      25t^2 + (n + t)^2 = 25t
      \]
      Expanding and rearranging the equation:
      \[
      25t^2 + n^2 + 2nt + t^2 = 25t \implies 26t^2 + 2nt + n^2 = 25t \implies 26t^2 + 2nt + n^2 - 25t = 0
      \]
      This is a quadratic equation in \(t\):
      \[
      26t^2 + (2n - 25)t + n^2 = 0
      \]

3. **Solve the Quadratic Equation for \(t\):**
    - For this quadratic equation, the discriminant must be non-negative for \(t\) to have real solutions:
      \[
      \Delta = (2n - 25)^2 - 4 \cdot 26 \cdot n^2 \geq 0
      \]
      Simplifying the discriminant:
      \[
      \Delta = (2n - 25)^2 - 104n^2 \geq 0
      \]
      \[
      4n^2 - 100n + 625 - 104n^2 \geq 0
      \]
      \[
      -100n^2 - 100n + 625 \geq 0
      \]
      \[
      -100(n^2 + n - \frac{25}{4}) \geq 0
      \]
      \[
      n^2 + n - \frac{25}{4} \leq 0
      \]
      To solve this quadratic inequality, we find the roots of the equation \(n^2 + n - \frac{25}{4} = 0\):
      \[
      n = \frac{-1 \pm \sqrt{1 + 25}}{2} = \frac{-1 \pm \sqrt{26}}{2}
      \]
      The approximate roots are:
      \[
      n \approx \frac{-1 + 5.1}{2} \approx 2.05 \quad \text{and} \quad n \approx \frac{-1 - 5.1}{2} \approx -3.05
      \]
      So, the inequality \(n^2 + n - \frac{25}{4} \leq 0\) holds for:
      \[
      \frac{-1 - \sqrt{26}}{2} \leq n \leq \frac{-1 + \sqrt{26}}{2}
      \]
      Since \(n\) is an integer, we check for integer values of \(n\) in the range \([-3, 2]\).

4. **Check for Each Integer Value of \(n\) in the Range \([-3, 2]\):**
    - For each integer \(n\) in this range, solve the quadratic equation \(26t^2 + (2n - 25)t + n^2 = 0\) to ensure \(0 < t \leq 1\).

Let's implement this step-by-step process in Python to get the final number of intersection points.
```python
import sympy as sp

# Initialize a list to store the valid (x, y) pairs that satisfy both equations
intersection_points = []

# Check for each integer n in the range -3 to 2
for n in range(-3, 3):
    # Define the quadratic equation 26t^2 + (2n - 25)t + n^2 = 0
    t = sp.symbols('t')
    quadratic_eq = 26 * t**2 + (2 * n - 25) * t + n**2
    
    # Find the roots of the quadratic equation
    roots = sp.solve(quadratic_eq, t)
    
    # Check each root to ensure it's in the valid range for t (0 < t <= 1)
    for root in roots:
        if root.is_real:
            if 0 < root <= 1:
                # Calculate the corresponding y value for each valid t
                y = (1 / 5) * (n + root)
                intersection_points.append((n + root, y))

# Get the number of unique intersection points
num_intersection_points = len(set(intersection_points))
print(num_intersection_points)
```
