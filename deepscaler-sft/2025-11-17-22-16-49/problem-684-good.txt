To solve the problem, we need to calculate the probability that Carlos's purchase of 5 CDs includes at least one CD from each of the three categories (rap, country, and heavy metal).

1. **Define the Problem:**
    - We have 4 rap CDs, 5 country CDs, and 3 heavy metal CDs, making a total of 12 CDs.
    - Carlos randomly selects 5 CDs out of these 12.
    - We want to find the probability that the selected 5 CDs include at least one CD from each of the three categories (rap, country, and heavy metal).

2. **Plan the Solution:**
    - First, calculate the total number of ways to choose 5 CDs out of 12.
    - Then, we need to find the number of ways to choose 5 CDs such that at least one CD is from each of the three categories.
    - Use the complementary counting method to make it easier: Find the total number of ways to choose 5 CDs and then subtract the number of ways that do not include at least one CD from each of the three categories.

3. **Use Combinatorics:**
    - The total number of ways to choose 5 CDs out of 12 is given by \(\binom{12}{5}\).
    - We need to find and subtract the number of ways to choose 5 CDs that do not satisfy the condition (i.e., those selections that miss at least one of the categories).

Let's implement this step-by-step plan in Python to ensure accuracy.
```python
import itertools

# Number of CDs in each category
num_rap = 4
num_countries = 5
num_heavy_metal = 3

# Create lists of CDs for each category
rap_cds = list(range(1, num_rap + 1))
country_cds = list(range(num_rap + 1, num_rap + num_countries + 1))
heavy_metal_cds = list(range(num_rap + num_countries + 1, num_rap + num_countries + num_heavy_metal + 1))

# Combine all the CDs
all_cds = rap_cds + country_cds + heavy_metal_cds

# Get all combinations of choosing 5 CDs from 12 CDs
combinations_of_5 = list(itertools.combinations(all_cds, 5))

# Function to check if a combination includes at least one CD from each category
def has_at_least_one_from_each_category(comb):
    has_rap = any(cd in rap_cds for cd in comb)
    has_country = any(cd in country_cds for cd in comb)
    has_heavy_metal = any(cd in heavy_metal_cds for cd in comb)
    
    return has_rap and has_country and has_heavy_metal

# Count combinations that satisfy the condition of having at least one CD from each category
valid_combinations_count = sum(1 for comb in combinations_of_5 if has_at_least_one_from_each_category(comb))

# Total combinations of choosing 5 CDs from 12
total_combinations = len(combinations_of_5)

# Calculate the probability
probability = valid_combinations_count / total_combinations

print(((valid_combinations_count, total_combinations, probability)))
```
Code execution result: (590, 792, 0.7449494949494949)

Thus, we have:
- The number of ways to choose 5 CDs such that at least one CD is from each of the three categories is 590.
- The total number of ways to choose 5 CDs out of 12 is 792.
- Therefore, the probability is \(\frac{590}{792}\).

To express this as a common fraction, we should simplify \(\frac{590}{792}\).

Let's simplify this fraction.
```python
import math

# Get the greatest common divisor (GCD) of 590 and 792
gcd = math.gcd(590, 792)

# Simplify the fraction
numerator_simplified = 590 // gcd
denominator_simplified = 792 // gcd

print(((numerator_simplified, denominator_simplified)))
```
Code execution result: (295, 396)

So, the simplified fraction is \(\frac{295}{396}\).

Thus, the probability that Carlos's purchase includes at least one CD from each of the three categories is \(\boxed{\frac{295}{396}}\).
