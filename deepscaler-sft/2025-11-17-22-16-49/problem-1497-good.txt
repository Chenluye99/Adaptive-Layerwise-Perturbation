To solve the problem, let's start by solving the given equation \( |x - 7| - 3 = -2 \).

1. **Isolate the Absolute Value Expression:**
   \[
   |x - 7| - 3 = -2 \implies |x - 7| = 1
   \]
   This means that the expression inside the absolute value, \( x - 7 \), can be either 1 or -1:
   \[
   x - 7 = 1 \quad \text{or} \quad x - 7 = -1
   \]

2. **Solve for \( x \):**
   - For the first equation:
     \[
     x - 7 = 1 \implies x = 8
     \]
   - For the second equation:
     \[
     x - 7 = -1 \implies x = 6
     \]
   So, the possible values of \( x \) are 8 and 6.

3. **Find the Product of All Possible Values of \( x \):**
   The product of 8 and 6 is:
   \[
   8 \cdot 6 = 48
   \]

Let's confirm this by implementing it in Python to ensure accuracy.
```python
# Solving the equation |x - 7| - 3 = -2 and finding the product of all possible values of x

# First, solve for the two cases of the absolute value equation |x - 7| = 1
possible_values = []

# Case 1: x - 7 = 1
case_1 = 7 + 1
possible_values.append(case_1)

# Case 2: x - 7 = -1
case_2 = 7 - 1
possible_values.append(case_2)

# Find the product of all possible values of x
product_of_solutions = possible_values[0] * possible_values[1]
print(product_of_solutions)
```
Code execution result: 48

Thus, the product of all possible values of \( x \) is \(\boxed{48}\). This confirms our solution is accurate.
