1. **Initial Setup**: We need to assign 6 volunteers (let's call them A, B, C, D, E, F) to 3 different tasks, with each task requiring 2 people.
2. **Constraints**:
    - A and B must be on the same task.
    - C and D cannot be on the same task.

    - We will generate all ways to assign 6 volunteers to 3 tasks such that each task gets 2 people.
    - Then, we will filter these assignments based on the constraints provided.

### Step-by-Step Implementation

1. **Generate All Possible Assignments**:
    - Generate all ways to assign 6 volunteers to 3 tasks such that each task has exactly 2 people. This can be done using combinations.
2. **Apply Constraints**:
    - For each assignment, check if A and B are on the same task.
    - For each assignment, check if C and D are not on the same task.
3. **Count Valid Assignments**:

Let's implement this step-by-step in Python.
```python
import itertools

# Volunteers list
volunteers = ['A', 'B', 'C', 'D', 'E', 'F']

# Generate all ways to assign 6 volunteers to 3 tasks such that each task has exactly 2 people
assignments = []
for task1 in itertools.combinations(volunteers, 2):
    for task2 in itertools.combinations(set(volunteers) - set(task1), 2):
        task3 = tuple(set(volunteers) - set(task1) - set(task2))
        assignments.append((task1, task2, task3))

# Filter assignments based on constraints
valid_assignments = []

for assign in assignments:
    task1, task2, task3 = assign
    
    # Check if A and B are on the same task
    a_in_task1 = 'A' in task1 and 'B' in task1
    a_in_task2 = 'A' in task2 and 'B' in task2
    a_in_task3 = 'A' in task3 and 'B' in task3
    
    c_in_task1 = 'C' in task1 and 'D' in task1
    c_in_task2 = 'C' in task2 and 'D' in task2
    c_in_task3 = 'C' in task3 and 'D' in task3
    
    # Only consider the assignments that meet both conditions:
    # 1. A and B are on the same task.
    # 2. C and D are not on the same task.
    if (a_in_task1 or a_in_task2 or a_in_task3) and \
       not (c_in_task1 or c_in_task2 or c_in_task3):
        valid_assignments.append(assign)

# Get the count of valid assignments
num_valid_assignments = len(valid_assignments)
print(num_valid_assignments)
```
