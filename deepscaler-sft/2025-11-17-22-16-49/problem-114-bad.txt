Let's solve this step-by-step. We need to find out how many ways we can assign volleyball, basketball, and table tennis competitions to 4 different gyms under the conditions that each sport is held in only one gym and no gym hosts more than 2 sports.

1. **Define the Problem Mathematically:**
    - We have 3 sports (volleyball, basketball, table tennis) and 4 gyms.
    - Each of the 3 sports must be assigned to one of the 4 gyms.
    - No gym should host more than 2 sports. This means that if a gym hosts one sport, it cannot host any more, and if it hosts 2 sports, it cannot host a third.

2. **Enumerate All Possible Assignments:**
    - We need to check all possible ways to assign the 3 sports to the 4 gyms and then filter out the assignments that meet the condition that no gym hosts more than 2 sports.

3. **Implementation in Python:**
    - We can use Python to iterate through all permutations of assigning the 3 sports to the 4 gyms and then check the conditions for each assignment.
    - We can use the `itertools.permutations` function to get all possible assignments of gyms to the 3 sports, check the condition on the number of sports per gym, and count how many assignments meet this condition.

Let's implement this step-by-step in Python.
```python
import itertools

# Number of gyms
num_gyms = 4

# The three sports
sports = ['volleyball', 'basketball', 'table tennis']

# Store all valid assignments
valid_assignments = []

# Generate all permutations of assigning 3 sports to 4 gyms
for perm in itertools.permutations(range(num_gyms), 3):
    gym_assignment = {sport: gym for gym, sport in zip(perm, sports)}
    
    # Initialize a list to keep track of how many sports each gym is hosting
    gym_counts = [0] * num_gyms
    
    for sport, gym in gym_assignment.items():
        gym_counts[gym] += 1
    
    # Check if the assignment meets the condition that no gym hosts more than 2 sports
    if all(count <= 2 for count in gym_counts):
        valid_assignments.append(gym_assignment)

# The number of valid assignments
num_valid_assignments = len(valid_assignments)
print(num_valid_assignments)
```

Thus, the number of different ways to schedule volleyball, basketball, and table tennis competitions in 4 different gyms, ensuring that each sport is held in only one gym and no gym hosts more than 2 sports, is \(\boxed{24}\). This is our final answer.
