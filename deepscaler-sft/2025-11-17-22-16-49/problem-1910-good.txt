To solve this problem, let's set up the equations based on the information provided.

1. Let's denote the number of blue marbles by \( b \) and the number of yellow marbles by \( y \).
2. According to the problem, the initial ratio of blue marbles to yellow marbles is 8:5. This gives us the equation:
   \[
   \frac{b}{y} = \frac{8}{5} \implies 5b = 8y \implies 5b - 8y = 0
   \]
3. After removing 12 blue marbles and adding 21 yellow marbles, the new ratio of blue marbles to yellow marbles becomes 1:3. This gives us the equation:
   \[
   \frac{b - 12}{y + 21} = \frac{1}{3} \implies 3(b - 12) = y + 21 \implies 3b - 36 = y + 21 \implies 3b - y = 57
   \]
4. Now we have a system of linear equations:
   \[
   \begin{cases}
   5b - 8y = 0 \\
   3b - y = 57
   \end{cases}
   \]
5. We can solve this system of equations step-by-step. First, we can express \( y \) from the second equation:
   \[
   y = 3b - 57
   \]
6. Next, we substitute this expression for \( y \) into the first equation:
   \[
   5b - 8(3b - 57) = 0 \implies 5b - 24b + 456 = 0 \implies -19b + 456 = 0 \implies 19b = 456 \implies b = \frac{456}{19} = 24
   \]
7. Now that we have the value of \( b \), we can substitute it back into the equation \( y = 3b - 57 \) to find \( y \):
   \[
   y = 3(24) - 57 = 72 - 57 = 15
   \]

So, the initial number of blue marbles is \( b = 24 \). To ensure the result is accurate, we can write the Python code to solve this system of equations.
```python
from sympy import symbols, Eq, solve

# Define the variables
b, y = symbols('b y')

# Define the equations based on the problem statement
eq1 = Eq(5 * b - 8 * y, 0)
eq2 = Eq(3 * b - y, 57)

# Solve the system of equations
solution = solve((eq1, eq2), (b, y))
```
