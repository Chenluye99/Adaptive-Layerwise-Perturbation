To solve this problem, we need to find the maximum value of the function \( f(x) = 1 - 2x - \frac{3}{x} \) for \( x > 0 \). We can do this by following these steps:

1. **Find the First Derivative:**
   We take the first derivative of \( f(x) \) and set it equal to zero to find the critical points.
   \[
   f(x) = 1 - 2x - \frac{3}{x}
   \]
   \[
   f'(x) = \frac{d}{dx}\left(1 - 2x - \frac{3}{x}\right) = -2 + \frac{3}{x^2}
   \]
   Set the first derivative equal to zero to find the critical points:
   \[
   -2 + \frac{3}{x^2} = 0 \implies \frac{3}{x^2} = 2 \implies 3 = 2x^2 \implies x^2 = \frac{3}{2} \implies x = \sqrt{\frac{3}{2}} = \frac{\sqrt{6}}{2}
   \]
   (We only consider the positive root because \(x > 0\)).

2. **Find the Second Derivative:**
   To ensure that this critical point gives a maximum value, we take the second derivative of \( f(x) \) and evaluate it at \( x = \frac{\sqrt{6}}{2} \):
   \[
   f''(x) = \frac{d}{dx}\left(-2 + \frac{3}{x^2}\right) = \frac{d}{dx}\left(-2 + 3x^{-2}\right) = -6x^{-3} = -\frac{6}{x^3}
   \]
   Evaluate the second derivative at \( x = \frac{\sqrt{6}}{2} \):
   \[
   f''\left(\frac{\sqrt{6}}{2}\right) = -\frac{6}{\left(\frac{\sqrt{6}}{2}\right)^3} = -\frac{6}{\frac{6\sqrt{6}}{8}} = -\frac{6 \cdot 8}{6 \sqrt{6}} = -\frac{8}{\sqrt{6}} = -\frac{8 \sqrt{6}}{6} = -\frac{4 \sqrt{6}}{3}
   \]
   Since \( f''\left(\frac{\sqrt{6}}{2}\right) < 0 \), this indicates that the function \( f(x) \) has a local maximum at \( x = \frac{\sqrt{6}}{2} \).

3. **Find the Maximum Value of the Function:**
   Substitute \( x = \frac{\sqrt{6}}{2} \) back into the original function to get the maximum value:
   \[
   f\left(\frac{\sqrt{6}}{2}\right) = 1 - 2 \left(\frac{\sqrt{6}}{2}\right) - \frac{3}{\frac{\sqrt{6}}{2}} = 1 - \sqrt{6} - \frac{3 \cdot 2}{\sqrt{6}} = 1 - \sqrt{6} - \frac{6}{\sqrt{6}} = 1 - \sqrt{6} - \frac{6 \sqrt{6}}{6} = 1 - \sqrt{6} - \sqrt{6} = 1 - 2 \sqrt{6}
   \]

import sympy as sp

# Define the variable and function
x = sp.symbols('x', positive=True)
f = 1 - 2 * x - 3 / x

# Find the first derivative
f_prime = sp.diff(f, x)

# Find the critical points by setting the first derivative to 0
critical_points = sp.solve(f_prime, x)

# Evaluate the second derivative to ensure it's a maximum
f_double_prime = sp.diff(f_prime, x)

# Check the second derivative at the critical point
second_derivative_at_critical = [f_double_prime.subs(x, cp) for cp in critical_points if cp > 0]

# Find the maximum value of the function at the critical point
max_value = f.subs(x, critical_points[0])

print(f"Critical Point: {critical_points[0]}")
