Generate the currency exchange rates and convert a mixed currency amount to USD, including handling fractional amounts and multiple currencies. 

Write a Python function that takes a list of mixed currency amounts and converts them to USD. The function should also handle cases where fractional parts of the amount need to be rounded according to standard banking conventions (typically, rounding half up). Include error handling for cases where the input is not in the correct format.

For example, given a list of transactions in different currencies such as `["10 USD", "5 EUR", "20 JPY", "15 GBP"]`, your function should convert each amount to USD, assuming known exchange rates. Let's assume that:
- 1 EUR = 1.1 USD,
- 1 JPY = 0.009 USD,
- 1 GBP = 1.3 USD,

and that any fractional amounts should be rounded to two decimal places as is typical in financial transactions.

### Task Steps:
1. Define a function that takes a list of strings representing transactions in different currencies.
2. Use the provided exchange rates to convert each transaction to USD.
3. Ensure the function rounds the result to two decimal places.
4. Return a list of converted amounts in USD.
5. Provide appropriate error handling for incorrect formats or missing values.
Let's implement the solution step-by-step according to the described requirements.

1. **Define the Function:**
   - Create a function named `convert_to_usd` that takes a list of strings representing amounts in different currencies.
   - Set up a dictionary to hold the exchange rates for conversion.

2. **Implementation:**
   - Each string in the list should generally be in the format of `<amount> <currency>`.
   - Parse each string to separate the amount and the currency.
   - Use the appropriate exchange rate to convert the amount to USD.
   - Round the result to two decimal places.
   - Return a list with the converted amounts in USD.

3. **Exchange Rates:**
   - We assume the following exchange rates:
     - 1 EUR = 1.1 USD
     - 1 JPY = 0.009 USD
     - 1 GBP = 1.3 USD

4. **Error Handling:**
   - Ensure that each string is in the correct format (<amount> <currency>).
   - Validate that the currency is known (only handle the specified currencies: USD, EUR, JPY, GBP).
   - If the format or currency is incorrect, return an appropriate error message.

Let's write the Python code implementing the above steps.
```python
import re

def convert_to_usd(transactions):
    exchange_rates = {
        "USD": 1.0,
        "EUR": 1.1,
        "JPY": 0.009,
        "GBP": 1.3
    }
    
    converted_amounts = []
    
    for transaction in transactions:
        match = re.match(r"([\d\.]+)\s*([A-Z]{3})", transaction)
        if match:
            amount, currency = match.groups()
            amount = float(amount)
            
            if currency in exchange_rates:
                usd_amount = amount * exchange_rates[currency]
                converted_amounts.append(round(usd_amount, 2))
            else:
                return f"Error: Unknown currency '{currency}' in transaction '{transaction}'"
        else:
            return f"Error: Incorrect format for transaction '{transaction}'"
    
    return converted_amounts

# Example usage:
transactions = ["10 USD", "5 EUR", "20 JPY", "15 GBP"]
converted_transactions = convert_to_usd(transactions)
print(converted_transactions)
```
