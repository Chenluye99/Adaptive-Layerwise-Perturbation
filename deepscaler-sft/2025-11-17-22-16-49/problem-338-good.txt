We need to find the smallest natural number \( A \) that satisfies the following conditions:

1. The number ends with the digit 6.
2. By moving the digit 6 from the end of the number to its beginning, the resulting number is four times the original number.

Let's denote the original number as \( A \). Let's say that \( A \) has \( n+1 \) digits, and we can express it as:
\[ A = 10a + 6 \]
where \( a \) is an integer that represents the number formed by the first \( n \) digits of \( A \).

When we move the last digit 6 to the beginning, the new number becomes:
\[ B = 6 \cdot 10^n + a \]

According to the problem, this new number \( B \) is four times the original number \( A \):
\[ 6 \cdot 10^n + a = 4 \cdot (10a + 6) \]

Let's simplify the equation:
\[ 6 \cdot 10^n + a = 40a + 24 \]
\[ 6 \cdot 10^n - 24 = 39a \]
\[ 2 (10^n - 4) = 39a \]
\[ 10^n - 4 = \frac{39a}{2} \]

From the above equation, it is clear that \(\frac{39a}{2}\) must be an integer, so \( 39a \) must be even, which means \( a \) must be even. We can write a Python script to iterate through values of \( n \) and corresponding values for \( a \) and check if the equation holds.

We will start from \( n = 1 \) and check up to a reasonable number of digits until we find the solution. Let's implement this in Python.
```python
# We will iterate over possible values for n and corresponding values for a to find the correct number A.

def find_special_number():
    n = 1  # Start with the smallest possible number of digits greater than 1 (since 1-digit numbers that end in 6 don't have the right property)
    
    while True:
        for a in range(10**(n-1), 10**n):
            A = 10 * a + 6
            new_number = int(str(6) + str(a))
            if 4 * A == new_number:
                return A
        n += 1

special_number = find_special_number()
print(special_number)
```
