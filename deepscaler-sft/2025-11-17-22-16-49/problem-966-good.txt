To solve this problem, we need to check all positive integers less than 10,000 and determine how many of them have at most two different digits.

We will iterate through each number from 1 to 9999 and for each number, we will get its digits and check whether the number of distinct digits in that number is at most 2.

Let's implement this step-by-step in Python.
1. Initialize a counter to keep track of how many numbers meet the condition.
2. For each number from 1 to 9999, convert the number to a string to easily iterate over its digits.
3. Use a set to store the distinct digits of the current number and check its size.
4. If the size of the set is 1 or 2, increment the counter.
5. After checking all numbers, return the counter as the final answer.

Let's write this code to get the accurate result.
```python
count = 0

for num in range(1, 10000):
    num_str = str(num)
    distinct_digits = set(num_str)
    if len(distinct_digits) <= 2:
        count += 1

print(count)
```
Code execution result: 927

Thus, the number of positive integers less than 10,000 that have at most two different digits is \(\boxed{927}\). This is our final answer.
