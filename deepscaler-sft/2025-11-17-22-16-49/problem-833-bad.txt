To find the range of the function \( p(x) = \frac{x^2 + x + 1}{x^2 + 1} \), we need to determine all possible values that \( p(x) \) can take as \( x \) varies over all real numbers.

### Step-by-Step Solution:

1. **Express the Function:**
   The function is given by:
   \[
   p(x) = \frac{x^2 + x + 1}{x^2 + 1}
   \]

2. **Set Up the Equation:**
   To find the range, we can express \( x \) in terms of \( p \). Set \( y = p(x) \), so we have:
   \[
   y = \frac{x^2 + x + 1}{x^2 + 1}
   \]
   Rearrange this equation to:
   \[
   y (x^2 + 1) = x^2 + x + 1
   \]
   \[
   y x^2 + y = x^2 + x + 1
   \]
   \[
   y x^2 - x^2 = x + 1 - y
   \]
   \[
   x^2 (y - 1) = x + 1 - y
   \]
   This is a quadratic equation in \( x \):
   \[
   x^2 (y - 1) - x - (1 - y) = 0
   \]

3. **Form a Quadratic Equation:**
   This is a standard quadratic equation of the form \( ax^2 + bx + c = 0 \) where:
   \[
   a = y - 1, \quad b = -1, \quad c = -(1 - y)
   \]
   For this quadratic equation to have real solutions, its discriminant must be non-negative. The discriminant \( \Delta \) of \( ax^2 + bx + c = 0 \) is given by:
   \[
   \Delta = b^2 - 4ac
   \]
   Substituting \( a, b, \) and \( c \) into the discriminant formula, we get:
   \[
   \Delta = (-1)^2 - 4 (y - 1) [ -(1 - y) ] = 1 - 4 (y - 1) (1 - y) = 1 - 4 (1 - y^2)
   \]
   \[
   \Delta = 1 - 4 + 4y^2 = 4y^2 - 3
   \]
   For the quadratic equation to have real solutions, we need:
   \[
   4y^2 - 3 \geq 0
   \]
   \[
   4y^2 \geq 3
   \]
   \[
   y^2 \geq \frac{3}{4}
   \]
   \[
   |y| \geq \frac{\sqrt{3}}{2}
   \]
   Hence,
   \[
   y \leq -\frac{\sqrt{3}}{2} \quad \text{or} \quad y \geq \frac{\sqrt{3}}{2}
   \]

4. **Conclusion:**
   The range of the function \( p(x) = \frac{x^2 + x + 1}{x^2 + 1} \) is all values of \( y \) that satisfy \( y \leq -\frac{\sqrt{3}}{2} \) or \( y \geq \frac{\sqrt{3}}{2} \).
