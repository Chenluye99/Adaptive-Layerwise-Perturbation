This means that the grid must be highly symmetric.

1. **Grid Symmetry Requirements:**
    - **Rotation Symmetry:** A grid is symmetric under 90°, 180°, and 270° rotations if rotating the grid by these amounts results in the same pattern.
    - **Reflection Symmetry:** A grid is symmetric under reflection if reflecting it across the lines joining opposite corners or midpoints of opposite sides results in the same pattern.

2. **Key Symmetry Constraints:**
    - When a grid is rotated by 90°, 180°, or 270°, the color of each square must correspond to the color of another square that ends up in the same position after the rotation. For a 7x7 grid, the center square remains the same after any rotation.
    - When reflecting across the diagonals or midpoints of opposite sides, the color of a square at (i, j) must match the color of the corresponding square that appears after the reflection.

2. Check each coloring to ensure it meets the symmetry requirements described above.
3. Ensure that each coloring has at least one black square and one white square.

import numpy as np

def is_symmetric(grid):
    # Check 90°, 180°, and 270° rotations
    for i in range(4):
        rotated_grid = np.rot90(grid, i)
        if not np.array_equal(grid, rotated_grid):
            return False
    
    # Check reflections across diagonals and midpoints of opposite sides
    reflected_grid_across_main_diagonal = np.fliplr(np.transpose(grid))
    reflected_grid_across_secondary_diagonal = np.flipud(np.transpose(grid))
    reflected_grid_across_horizontal_midpoint = np.flipud(grid)
    reflected_grid_across_vertical_midpoint = np.fliplr(grid)
    
    if not np.array_equal(grid, reflected_grid_across_main_diagonal) or \
       not np.array_equal(grid, reflected_grid_across_secondary_diagonal) or \
       not np.array_equal(grid, reflected_grid_across_horizontal_midpoint) or \
       not np.array_equal(grid, reflected_grid_across_vertical_midpoint):
        return False
    
    return True

count = 0

# Generate all possible 7x7 grids with binary values (0 or 1)
for i in range(2**49):
    grid = np.array([(i >> j) & 1 for j in range(49)]).reshape(7, 7)
    
    # Ensure that the grid has at least one black and one white square
    if np.sum(grid) > 0 and np.sum(grid) < 49:
        if is_symmetric(grid):
            count += 1

print(count)
