2. Compute \(S(n)\) for each \(n\) from 1 to 1000.

```python
import numpy as np

def tau(n):
    count = 0
    for i in range(1, n + 1):
        if n % i == 0:
            count += 1
    return count

# Calculate S(n) for n from 1 to 1000
S = [0] * 1001
for n in range(1, 1001):
    S[n] = S[n - 1] + tau(n)

# Count how many times S(n) is odd and how many times it is even for 1 <= n <= 1000
c = sum(1 for s in S[1:1001] if s % 2 == 1)
d = sum(1 for s in S[1:1001] if s % 2 == 0)

# Find |c - d|
result = abs(c - d)
print(result)
```
