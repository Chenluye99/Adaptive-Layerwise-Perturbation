To solve this problem, we start with the initial term 1,000,000 and repeatedly divide it by 2 until we get an integer result.

Let's implement this in Python to ensure accuracy. We'll iterate, dividing by 2, and check the result at each step until we get the last integer in the sequence.
```python
# Initialize the first term
term = 1_000_000

# List to store the sequence
sequence = [term]

# Generate the sequence until we get the last integer
while term % 1 == 0:  # This condition ensures that term remains an integer
    term /= 2
    sequence.append(int(term))  # Append the integer result to the sequence

# The last integer in the sequence before the next division results in a non-integer
last_integer_in_sequence = sequence[-1]
print(last_integer_in_sequence)
```
Code execution result: 7812

Thus, the last integer in the sequence is \(\boxed{7812}\). This is the result of repeatedly dividing 1,000,000 by 2 until we can no longer get an integer value, and the last integer value in this sequence is 7812.
