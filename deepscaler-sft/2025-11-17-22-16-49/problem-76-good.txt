To solve this problem, let's start by understanding what it means to plant trees at a 5-foot distance from each other on a rectangular plot of land that has side lengths of 120 feet and 70 feet.

1. **Grid Formation:**
    - When trees are planted at a 5-foot distance from each other, it means the coordinates of the trees will form a grid pattern with 5 feet as the spacing between each tree along both the length and width of the plot.
    - To find out how many trees can be planted along the 120-foot side, we divide 120 by 5 and add 1 (because we need to count the starting point as well):
      \[
      \text{Number of trees along the 120-foot side} = \frac{120}{5} + 1 = 24 + 1 = 25
      \]
    - Similarly, to find out how many trees can be planted along the 70-foot side:
      \[
      \text{Number of trees along the 70-foot side} = \frac{70}{5} + 1 = 14 + 1 = 15
      \]

2. **Total Number of Trees:**
    - The total number of trees that can be planted on the rectangular plot, given that trees are planted at every 5-foot interval along both the 120-foot side and the 70-foot side, is given by the product of the number of trees along each side:
      \[
      \text{Total number of trees} = 25 \times 15 = 375
      \]

Let's confirm this by implementing it in Python to ensure accuracy.
```python
# Length and width of the rectangular plot
length = 120
width = 70

# Distance between trees
distance = 5

# Calculate the number of trees along each side, including both ends
num_trees_length = length // distance + 1
num_trees_width = width // distance + 1

# Calculate the total number of trees
total_trees = num_trees_length * num_trees_width
print(total_trees)
```
Code execution result: 375

Thus, the number of trees that can be planted at a 5-foot distance from each other on a rectangular plot of land with side lengths of 120 feet and 70 feet is \(\boxed{375}\). This result has been confirmed by both our reasoning and the Python code implementation.
