First, let's define some functions to solve the problem step-by-step:

1. **Function to Compute the Sum of Divisors of \( n \):**
   - To find the sum of the divisors of a number \( n \), we need to check for each number from 1 to \( n \) to see if it is a divisor of \( n \). The sum of all such divisors will be the result.

2. **Function to Check if a Number is Prime:**
   - We need a function that will check if a given number is a prime number. A number is prime if it is greater than 1 and has no positive divisors other than 1 and itself.

3. **Find Bouncy Primes:**
   - For each prime number n, compute \( f(n) \) (sum of the divisors of \( n \)).
   - Then, compute \( f(f(n)) \) (sum of the divisors of \( f(n) \)).
   - Check if \( f(f(n)) \) is a prime number. If it is, then \( n \) is a bouncy prime.

4. **Find the Smallest Bouncy Prime:**
   - Start checking from the smallest prime number and go upwards, using the above steps to identify bouncy primes until we find the first one.

Let's implement this step-by-step in Python.
```python
import sympy

def sum_of_divisors(n):
    """Returns the sum of the divisors of n."""
    return sum(i for i in range(1, n + 1) if n % i == 0)

def is_prime(n):
    """Checks if a number is a prime number."""
    return sympy.isprime(n)

# Now we need to identify bouncy primes and find the smallest one.
bouncy_prime = None

# Check prime numbers sequentially starting from 2
n = 2
while bouncy_prime is None:
    if sympy.isprime(n):
        f_n = sum_of_divisors(n)
        f_f_n = sum_of_divisors(f_n)
        if is_prime(f_f_n):
            bouncy_prime = n
            break
    n += 1

print(bouncy_prime)
```

Upon running the code, we get that the smallest bouncy prime is \( \boxed{3} \).

Let's confirm this by verifying the steps briefly for \( n = 3 \):

1. **Check if 3 is a prime number:**
   - 3 is indeed a prime number.

2. **Compute \( f(3) \):**
   - The divisors of 3 are 1 and 3. So, \( f(3) = 1 + 3 = 4 \).

3. **Compute \( f(f(3)) = f(4) \):**
   - The divisors of 4 are 1, 2, and 4. So, \( f(4) = 1 + 2 + 4 = 7 \).

4. **Check if 7 is a prime number:**
   - 7 is a prime number.

Since \( f(f(3)) = 7 \) is also a prime number, this confirms that 3 is a bouncy prime. Also, since we checked sequentially starting from the smallest prime numbers and found that 3 meets the condition, we can conclude that 3 is indeed the smallest bouncy prime.
