We aim to find the smallest positive integer \(n\) for which there exist real numbers \(x_1, x_2, \ldots, x_n\) satisfying these conditions. 

To solve this problem, we can consider the case where all the \(x_i\) are equal. Let's assume \(x_1 = x_2 = \cdots = x_n = x\). Then, we have:

\[nx = 1000 \implies x = \frac{1000}{n}.\]

Substituting this into the second equation, we get:

\[x_1^4 + x_2^4 + \cdots + x_n^4 = n \left(\frac{1000}{n}\right)^4 = 512000.\]

This simplifies to:

\[n \cdot \frac{1000^4}{n^4} = 512000 \implies \frac{1000^4}{n^3} = 512000.\]

Rewriting, we get:

\[n^3 = \frac{1000^4}{512000}.\]

Now, let's compute the right-hand side of the equation:

\[1000^4 = (10^3)^4 = 10^{12},\]
\[512000 = 512 \cdot 1000 = 512 \cdot 10^3 = 2^9 \cdot 10^3.\]

Thus, we have:

\[\frac{1000^4}{512000} = \frac{10^{12}}{2^9 \cdot 10^3} = \frac{10^9}{2^9} = \frac{10^9}{512}.\]

import math
