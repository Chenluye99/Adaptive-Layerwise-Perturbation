To solve this problem, we need to determine all possible ways to arrange 36 chairs into a rectangular array such that each row contains the same number of chairs and each column contains the same number of chairs, with the constraints that there must be at least 2 chairs in every row and every column.

To find valid pairs $(r, c)$, where $r$ is the number of rows and $c$ is the number of columns, we need to ensure that both $r$ and $c$ are at least 2, and $r \cdot c = 36$. We will iterate through all integer pairs $(r, c)$ that satisfy these conditions and count them.

Let's write the Python code to solve this step-by-step:

1. Initialize a counter for the number of valid arrays.
2. Check all pairs $(r, c)$ such that $r \cdot c = 36$.
3. For each pair, ensure that both $r$ and $c$ are at least 2.
4. If both conditions are satisfied, increment the counter.

Let's implement this in Python.
```python
# Initialize counter for the number of valid arrays
valid_array_count = 0

# Iterate through all possible numbers of rows (r) from 2 to 36
for r in range(2, 37):
    if 36 % r == 0:
        c = 36 // r
        if c >= 2:
            valid_array_count += 1

print(valid_array_count)
```
Code execution result: 7

Thus, the number of possible arrays that can be formed with 36 chairs, while keeping the constraints that each row and column must contain at least 2 chairs, is \(\boxed{7}\). This is our final answer.
