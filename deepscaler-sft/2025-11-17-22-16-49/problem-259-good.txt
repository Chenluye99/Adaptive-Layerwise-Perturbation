To solve the problem, let's start by simulating the daily and nightly changes in the number of bacteria over a series of days until the number of bacteria is 0 or less. We will iterate day by day, updating the number of bacteria based on the given conditions:

1. In the morning, 11 bacteria are eliminated.
2. In the evening, 5 bacteria are added.
3. We start with 50 bacteria on the morning of the first day.

We will continue this process until the number of bacteria is 0 or less, and then return the day on which this occurs. Let's implement this step-by-step in Python.
```python
# Initial number of bacteria on the morning of the first day
bacteria_count = 50
day = 1

# Loop until the number of bacteria is <= 0
while bacteria_count > 0:
    # Eliminate 11 bacteria in the morning
    bacteria_count -= 11
    
    # Add 5 bacteria in the evening
    bacteria_count += 5
    
    # Move to the next day
    day += 1

print(day)
```
Code execution result: 10

Hence, all the bacteria will be eliminated on the 10th day. The final answer is \(\boxed{10}\).
