To solve the problem, we need to determine how many integers between 0 and 8 inclusive have an inverse modulo 9. An integer \( a \) has an inverse modulo 9 if and only if there exists an integer \( b \) such that:

\[ a \cdot b \equiv 1 \pmod{9} \]

This means that \( a \) and 9 must be coprime (i.e., \(\text{gcd}(a, 9) = 1\)). If \(\text{gcd}(a, 9) \neq 1\), then \( a \) does not have an inverse modulo 9.

Let's check which integers between 0 and 8 are coprime with 9 by computing their gcd values. We will use Python to do this accurately.
```python
import math

# Initialize a counter for numbers that have an inverse modulo 9
count = 0

# Check each number from 0 to 8
for a in range(0, 9):
    if math.gcd(a, 9) == 1:
        count += 1

print(count)
```
Code execution result: 6

Thus, the number of integers between 0 and 8 inclusive that have an inverse modulo 9 is \(\boxed{6}\). This is because there are 6 numbers in this range that are coprime to 9.
