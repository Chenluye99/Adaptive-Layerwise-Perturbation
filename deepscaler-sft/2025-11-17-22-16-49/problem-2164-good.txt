To solve the problem, let's start by understanding the function \( f(x) = \arcsin x + \arccos x + \arctan x \).

1. **Properties of \(\arcsin x\) and \(\arccos x\):**
   - The \(\arcsin x\) function is defined for \( -1 \leq x \leq 1 \) and its range is \( -\frac{\pi}{2} \leq \arcsin x \leq \frac{\pi}{2} \).
   - The \(\arccos x\) function is also defined for \( -1 \leq x \leq 1 \) and its range is \( 0 \leq \arccos x \leq \pi \).
   - A known identity is \(\arcsin x + \arccos x = \frac{\pi}{2}\) for all \( x \) in the domain \([-1, 1]\).

2. **Simplify the Function:**
   - Given the identity \(\arcsin x + \arccos x = \frac{\pi}{2}\), we can substitute this into our function:
     \[
     f(x) = \frac{\pi}{2} + \arctan x
     \]
   - Now, we need to consider the range of \(\arctan x\):
     - The \(\arctan x\) function is defined for all real numbers, but for the domain of \( f(x) \) (i.e., \([-1, 1]\)), \(\arctan x\) ranges from \(\arctan(-1) = -\frac{\pi}{4}\) to \(\arctan(1) = \frac{\pi}{4}\).

3. **Determine the Range of \( f(x) \):**
   - Hence, when \( x = -1 \),
     \[
     f(-1) = \frac{\pi}{2} + \arctan(-1) = \frac{\pi}{2} - \frac{\pi}{4} = \frac{\pi}{4}
     \]
   - When \( x = 1 \),
     \[
     f(1) = \frac{\pi}{2} + \arctan(1) = \frac{\pi}{2} + \frac{\pi}{4} = \frac{3\pi}{4}
     \]

Therefore, \(\frac{\pi}{2} + \arctan x\) will take on all values between \(\frac{\pi}{4}\) and \(\frac{3\pi}{4}\).

Thus, the range of the function \( f(x) = \arcsin x + \arccos x + \arctan x \) is \(\left[ \frac{\pi}{4}, \frac{3\pi}{4} \right]\).
