1. To solve this problem, we need to determine the number of sides of the polygon first. We know that the measure of an exterior angle of a regular polygon is given by \( \frac{360^\circ}{n} \), where \( n \) is the number of sides of the polygon.

2. We are given that the exterior angle is 120 degrees. So, we can set up the equation:
    \[
    \frac{360^\circ}{n} = 120^\circ
    \]
    Solving for \( n \):
    \[
    360 = 120 \cdot n \implies n = \frac{360}{120} = 3
    \]
    Thus, the polygon has 3 sides, making it an equilateral triangle.

3. We are also given that each side of the polygon has a length of 5 units. The perimeter of a polygon is calculated by multiplying the number of sides by the length of each side. Therefore, for a polygon with 3 sides, each of length 5 units, the perimeter \( P \) is:
    \[
    P = 3 \cdot 5 = 15 \text{ units}
    \]

Let's confirm this by implementing it in Python.
```python
# Given values
side_length = 5
exterior_angle = 120

# Calculate the number of sides (n) of the polygon
n = 360 / exterior_angle

# Calculate the perimeter of the polygon
perimeter = n * side_length
print(perimeter)
```
Code execution result: 15.0

Thus, the perimeter of the polygon is \(\boxed{15}\) units. This confirms our solution is accurate.
