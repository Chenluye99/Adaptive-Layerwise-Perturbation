1. **Find the Polynomial \( p(x) \):**
    - We need to determine the coefficients of the second-degree polynomial \( p(x) = ax^2 + bx + c \) such that it satisfies the conditions \( p(1) = 1 \), \( p(2) = 3 \), and \( p(3) = 2 \).

2. **Formulate the Equation \( p(p(x)) = x \):**
    - Once we have the polynomial \( p(x) \), we need to find the solutions to the equation \( p(p(x)) = x \).

3. **Find the Non-integer Solution:**
    - We need to identify the non-integer solution among the four real solutions to the equation \( p(p(x)) = x \).

Let's start by finding the polynomial \( p(x) \). We can use the system of equations given by the conditions:
\[
\begin{cases}
p(1) = a(1)^2 + b(1) + c = 1 \\
p(2) = a(2)^2 + b(2) + c = 3 \\
p(3) = a(3)^2 + b(3) + c = 2
\end{cases}
\]
This translates to:
\[
\begin{cases}
a + b + c = 1 \\
4a + 2b + c = 3 \\
9a + 3b + c = 2
\end{cases}
\]
We can solve this system of equations to find the coefficients \( a, b, \) and \( c \).

Let's use Python to solve this system and find the polynomial \( p(x) \).
```python
import sympy as sp

# Define the variables
a, b, c = sp.symbols('a b c')

# Set up the equations based on the conditions
eq1 = a * 1**2 + b * 1 + c - 1
eq2 = a * 2**2 + b * 2 + c - 3
eq3 = a * 3**2 + b * 3 + c - 2

# Solve the system of equations
solution = sp.solve((eq1, eq2, eq3), (a, b, c))

# Extract the coefficients
a_val = solution[a]
b_val = solution[b]
c_val = solution[c]

# Form the polynomial p(x)
x = sp.symbols('x')
p = a_val * x**2 + b_val * x + c_val

print(p)
```

import sympy as sp
