First, let's set up the problem and understand what's required:

We need to find the ages of a group of teenagers such that their product is 705,600. Once we find those ages, we need to compute the mean of these ages and express it as a decimal to the nearest tenth.

To solve this, we'll iterate through all possible combinations of the ages of teenagers (i.e., ages from 13 to 19) and check if their product equals 705,600. Once we find a valid set of ages, we can compute the mean of these ages.

We can use Python to perform this task efficiently. Let's implement this step-by-step.

1. **Find the Combination:**
   We will generate all possible combinations of ages from the set \{13, 14, 15, 16, 17, 18, 19\} and check if their product equals 705,600.
   
2. **Calculate the Mean:**
   Once we find such a combination, we will calculate the mean of these ages and round it to the nearest tenth.

Let's start by implementing this in Python.
```python
import itertools
import numpy as np

# Define the possible ages of teenagers
possible_ages = list(range(13, 20))

# Find the combination of ages whose product is 705600
target_product = 705600

# We'll check combinations of ages starting from 2 up to some reasonable upper limit (e.g., 7 since the product of 8 ages, each at most 19, will be very large)
for r in range(2, 8):
    for combo in itertools.combinations_with_replacement(possible_ages, r):
        if np.prod(combo) == target_product:
            ages = list(combo)
            break

# Calculate the mean of the found ages and round it to the nearest tenth
mean_age = round(np.mean(ages), 1)
print((ages, mean_age))
```
