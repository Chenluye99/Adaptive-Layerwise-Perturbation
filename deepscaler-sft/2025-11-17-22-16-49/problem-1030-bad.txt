To solve the problem, we need to follow these steps:

1. Let's assume the total number of students is \( N \).
2. According to the problem, 60% of the students selected soda, and this number is given to be 72. So, we can set up the equation: 
\[ 0.60 \times N = 72. \]
3. Solving for \( N \):
\[ N = \frac{72}{0.60}. \]
4. Once we have the total number of students \( N \), we can find out how many students selected milk. The problem states that 20% of the students selected milk, so:
\[ \text{Number of students who selected milk} = 0.20 \times N. \]

Let's proceed by computing this step-by-step using Python to ensure accuracy.
```python
# Given data
percentage_selected_soda = 0.60
students_selected_soda = 72

# Calculate the total number of students
total_students = students_selected_soda / percentage_selected_soda

# Given that 20% of the students selected milk
percentage_selected_milk = 0.20

# Calculate the number of students who selected milk
students_selected_milk = percentage_selected_milk * total_students
print(students_selected_milk)
```
Code execution result: 24.0

Thus, the number of students who selected milk is \(\boxed{24}\). This is our final answer.
