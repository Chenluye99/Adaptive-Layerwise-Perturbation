We are given the functional equation:
\[ f(x) - 2 f \left( \frac{1}{x} \right) = 4^x. \]

To solve for \( f(2) \), we will follow these steps:

1. **Substitute \( x = 2 \) into the equation:**
   \[ f(2) - 2 f \left( \frac{1}{2} \right) = 4^2 = 16. \]
   This gives us the first equation:
   \[ f(2) - 2 f \left( \frac{1}{2} \right) = 16. \tag{1} \]

2. **Substitute \( x = \frac{1}{2} \) into the equation:**
   \[ f \left( \frac{1}{2} \right) - 2 f(2) = 4^{\frac{1}{2}} = 2. \]
   This gives us the second equation:
   \[ f \left( \frac{1}{2} \right) - 2 f(2) = 2. \tag{2} \]

3. **Solve the system of equations:**

   We have the following system of linear equations:
   \[
   \begin{cases}
   f(2) - 2 f \left( \frac{1}{2} \right) = 16, \\
   f \left( \frac{1}{2} \right) - 2 f(2) = 2.
   \end{cases}
   \]

   Let's solve these equations step-by-step using Python for accuracy.
```python
import sympy as sp

# Define the variables
f_2, f_half = sp.symbols('f_2 f_half')

# Set up the equations based on the functional equation
eq1 = sp.Eq(f_2 - 2 * f_half, 16)
eq2 = sp.Eq(f_half - 2 * f_2, 2)

# Solve the system of equations
solution = sp.solve((eq1, eq2), (f_2, f_half))

print(solution)
```
Code execution result: {f_2: -20/3, f_half: -34/3}

Thus, we have the solution:
\[ f(2) = -\frac{20}{3}, \]
\[ f \left( \frac{1}{2} \right) = -\frac{34}{3}. \]

So, the final answer is:
\[
\boxed{-\frac{20}{3}}
\]
