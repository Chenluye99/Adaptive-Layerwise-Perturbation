To solve this problem, we need to find how many integers between -100 and 100 are congruent to \(3 \pmod{11}\). This means we are looking for integers \(x\) such that:

\[ x \equiv 3 \pmod{11} \]

This is equivalent to saying that when \(x\) is divided by 11, the remainder is 3. Mathematically, this can be written as:

\[ x = 11k + 3 \]

for some integer \( k \). We need to find all such \( x \) that lie in the range from -100 to 100. To do this, we will:

1. Set up the bounds such that \(-100 \leq 11k + 3 \leq 100\).
2. Find the valid integer values of \( k \) that satisfy this inequality.
3. Generate the corresponding \( x \) values for each valid \( k \) and then count how many such \( x \) values there are.

Let's solve this step-by-step using Python to ensure accuracy.
```python
# Initialize a counter for the number of integers that meet the condition
count = 0

# List to store the integers that meet the condition
valid_numbers = []

# Iterate through the range from -100 to 100
for x in range(-100, 101):
    if x % 11 == 3:
        count += 1
        valid_numbers.append(x)

print((count, valid_numbers[:10]))  # Return count and first 10 elements of valid_numbers for verification
```
