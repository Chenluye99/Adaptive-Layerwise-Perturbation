To solve this problem, we need to find the value of \(x\) such that \(f(x) = 25\), and then use those values in the function \(g(f(x)) = x^2 + x + 1\) to find \(g(25)\). Then, we will sum all possible values of \(g(25)\).

1. **Find the values of \(x\) such that \(f(x) = 25\):**
   Given \( f(x) = 3x^2 - 2 \), we set it equal to 25:
   \[
   3x^2 - 2 = 25
   \]
   Solving for \(x\):
   \[
   3x^2 = 27 \implies x^2 = 9 \implies x = 3 \text{ or } x = -3
   \]

2. **Evaluate \( g(f(x)) = g(25) \) for both \( x = 3 \) and \( x = -3 \):**
   Given \( g(f(x)) = x^2 + x + 1 \), we substitute \( x = 3 \) and \( x = -3 \) into the expression \( x^2 + x + 1 \):
   - For \( x = 3 \):
     \[
     g(25) = 3^2 + 3 + 1 = 9 + 3 + 1 = 13
     \]
   - For \( x = -3 \):
     \[
     g(25) = (-3)^2 + (-3) + 1 = 9 - 3 + 1 = 7
     \]

3. **Sum all possible values of \( g(25) \):**
   The possible values of \( g(25) \) are 13 and 7. So, we sum these values:
   \[
   13 + 7 = 20
   \]

Let's confirm this by implementing it in Python.
```python
import sympy as sp

# Define the functions f(x) and g(f(x))
x = sp.symbols('x')
f = 3 * x**2 - 2
g_expression = x**2 + x + 1

# Find the values of x such that f(x) = 25
solution = sp.solve(f - 25, x)

# Evaluate g(25) for each solution and sum the distinct results
g_25_values = [g_expression.subs(x, sol) for sol in solution]
distinct_g_25_values = set(g_25_values)  # Ensure we have distinct values (if any duplicates)
sum_of_g_25 = sum(distinct_g_25_values)
print(sum_of_g_25)
```
Code execution result: 20

Thus, the sum of all possible values of \( g(25) \) is \(\boxed{20}\). This confirms that our solution is accurate.
