To solve this problem, we need to utilize trigonometric identities and solve the given equations step-by-step.

1. **Given Equation:**
   \[
   \sin 2\theta = \frac{21}{25}
   \]
   We know that \(\sin 2\theta = 2 \sin \theta \cos \theta\). So, we can write:
   \[
   2 \sin \theta \cos \theta = \frac{21}{25} \implies \sin \theta \cos \theta = \frac{21}{50}
   \]

2. **Inequality Condition:**
   \[
   \cos \theta - \sin \theta > 0 \implies \cos \theta > \sin \theta
   \]
   This means that in the unit circle, \(\theta\) is in either the first or fourth quadrant, but since \(\cos \theta > \sin \theta\), \(\theta\) is in the first quadrant or some equivalent angle in other periods, but the trigonometric functions have different signs in different quadrants. We will use Python to ensure we get the correct solution.

3. **Find \(\cos \theta - \sin \theta\):**
   We need to find the value of \(\cos \theta - \sin \theta\). Let's denote this value by \(x\):
   \[
   x = \cos \theta - \sin \theta
   \]
   Square both sides of this equation:
   \[
   x^2 = (\cos \theta - \sin \theta)^2 = \cos^2 \theta - 2 \sin \theta \cos \theta + \sin^2 \theta
   \]
   Since \(\sin^2 \theta + \cos^2 \theta = 1\), we substitute to get:
   \[
   x^2 = 1 - 2 \sin \theta \cos \theta
   \]
   We know from earlier that \(\sin \theta \cos \theta = \frac{21}{50}\), so substitute this in:
   \[
   x^2 = 1 - 2 \cdot \frac{21}{50} = 1 - \frac{42}{50} = 1 - \frac{21}{25} = \frac{25}{25} - \frac{21}{25} = \frac{4}{25}
   \]
   Therefore:
   \[
   x = \pm \sqrt{\frac{4}{25}} = \pm \frac{2}{5}
   \]
   Since \(\cos \theta > \sin \theta\), \(\cos \theta - \sin \theta > 0\), so we take the positive value:
   \[
   x = \frac{2}{5}
   \]

Let's confirm this by coding the solution in Python to ensure accuracy.
```python
import sympy as sp

# Define the variables
theta = sp.symbols('theta', real=True, positive=True)

# Given equation
eq1 = sp.sin(2 * theta) - 21 / 25

# Solve for theta
solutions = sp.solveset(eq1, theta, domain=sp.Interval(0, sp.pi))

# Filter solutions based on the condition cos(theta) - sin(theta) > 0
possible_solutions = []
for sol in solutions:
    if sp.cos(sol) - sp.sin(sol) > 0:
        possible_solutions.append(sol)

# Calculate cos(theta) - sin(theta) for the valid theta
cos_minus_sin = [sp.cos(sol) - sp.sin(sol) for sol in possible_solutions]

print(cos_minus_sin)
```
