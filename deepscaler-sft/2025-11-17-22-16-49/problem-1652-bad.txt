We are tasked with finding the number of three-digit integers that are congruent to \(7 \pmod{19}\).

First, let's set up what it means for a number to be congruent to \(7 \pmod{19}\). A number \( n \) is congruent to \( 7 \pmod{19} \) if there exists an integer \( k \) such that:
\[ n = 19k + 7 \]

We need to determine the range of \( k \) such that \( n \) is a three-digit integer. Three-digit integers range from 100 to 999. So, we set up the following inequalities:
\[ 100 \leq 19k + 7 \leq 999 \]

\[ 100 \leq 19k + 7 \]
\[ 100 - 7 \leq 19k \]
\[ 93 \leq 19k \]
\[ \frac{93}{19} \leq k \]
\[ 4.8947 \leq k \]
Since \( k \) is an integer, we get:
\[ k \geq 5 \]

\[ 19k + 7 \leq 999 \]
\[ 19k \leq 992 \]
\[ k \leq \frac{992}{19} \]
\[ k \leq 52.2105 \]
Since \( k \) is an integer, we get:
\[ k \leq 52 \]

So, \( k \) ranges from 5 to 52, inclusive. To find the number of integers in this range, we compute:
\[ 52 - 5 + 1 = 48 \]

Thus, there are 48 such three-digit integers. To ensure accuracy, we can write a Python code to verify this result by iterating through and checking each condition.
```python
# We initialize a counter to count the number of three-digit integers that are congruent to 7 (mod 19)
count = 0
```
