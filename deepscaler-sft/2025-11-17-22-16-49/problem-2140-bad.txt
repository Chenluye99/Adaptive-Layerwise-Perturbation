First, let's formulate the equation based on the problem statement. We need to find the smallest integer \( x \) such that its square is 48 more than its double. Mathematically, this can be written as:

\[ x^2 = 2x + 48 \]

Rearrange this equation to form a standard quadratic equation:

\[ x^2 - 2x - 48 = 0 \]

We can solve this quadratic equation using the quadratic formula:

\[ x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} \]

where \( a = 1 \), \( b = -2 \), and \( c = -48 \). Substituting these values into the quadratic formula, we get:

\[ x = \frac{-(-2) \pm \sqrt{(-2)^2 - 4 \cdot 1 \cdot (-48)}}{2 \cdot 1} = \frac{2 \pm \sqrt{4 + 192}}{2} = \frac{2 \pm \sqrt{196}}{2} = \frac{2 \pm 14}{2} \]

This gives us two potential solutions:

\[ x = \frac{2 + 14}{2} = \frac{16}{2} = 8 \]
\[ x = \frac{2 - 14}{2} = \frac{-12}{2} = -6 \]

So, the potential solutions are \( x = 8 \) and \( x = -6 \). To find the least integer, we compare these two solutions. The smaller of the two is \(-6\). To ensure that \(-6\) is the correct answer, we can substitute \(-6\) back into the original equation and check if it holds true:

\[ (-6)^2 = 2(-6) + 48 \implies 36 = -12 + 48 \implies 36 = 36 \]

This is true, so \(-6\) is indeed a solution. To ensure that \(-6\) is the least integer solution and there are no smaller integers that work, we can check the integer just lower than \(-6\), which is \(-7\), by substituting it back into the original equation:

\[ (-7)^2 = 2(-7) + 48 \implies 49 = -14 + 48 \implies 49 = 34 \]

This is false, so \(-7\) is not a solution. Therefore, the least integer that satisfies the equation is \(-6\).

Let's confirm this by implementing it in Python to ensure accuracy.
```python
import sympy as sp

# Define the variable

# Solve the equation
```
