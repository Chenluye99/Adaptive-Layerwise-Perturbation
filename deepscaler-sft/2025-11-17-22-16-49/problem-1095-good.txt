To solve this problem, we need to check the validity of each of the given mathematical statements and give a 'yes' or 'no' answer for each statement. Then, we will add up the numbers corresponding to the statements for which the answer is 'yes'.

Let's analyze each statement step-by-step and use Python to ensure the results are accurate.

1. **Is \(\frac{2}{3x}\) equivalent to \(\frac{2x}{3}\)?**
   - \(\frac{2}{3x} \neq \frac{2x}{3}\). These are not equivalent because the left-hand side would be \(\frac{2}{3x}\) and the right-hand side would be \(\frac{2x}{3}\).

2. **Is \(\frac{1-h}{2h}\) equivalent to \(\frac{h-1}{2h}\)?**
   - Notice that \(1 - h = -(h - 1)\), so \(\frac{1 - h}{2h} = \frac{-(h - 1)}{2h} = \frac{h - 1}{-2h} \neq \frac{h - 1}{2h}\). These are not equivalent.

3. **Is \(-(u + u^2)\) equivalent to \(-u - u^2\)?**
   - \(-(u + u^2) = -u - u^2\), so these are equivalent.

4. **Is \(-(3 + y)\) equivalent to \(-3 + y\)?**
   - \(-(3 + y) = -3 - y \neq -3 + y\). These are not equivalent.

5. **Is \(\frac{j}{2}\) equivalent to \(\frac{1}{2}j\)?**
   - \(\frac{j}{2} = \frac{1}{2}j\), so these are equivalent.

6. **Is \(x + y + z\) equivalent to \(y + x + z\)?**
   - The commutative property of addition states that \(x + y + z = y + x + z\), so these are equivalent.

Now, let's assign '1' to each statement that is 'yes' and '0' to each statement that is 'no', and sum up the corresponding numbers. We'll then write Python code to confirm our reasoning and get the correct answer.
```python
# We will create a list of booleans indicating whether each statement is true or false
statements = [
    False,  # 1. Is \frac{2}{3x} equivalent to \frac{2x}{3}?
    False,  # 2. Is \frac{1-h}{2h} equivalent to \frac{h-1}{2h}?
    True,   # 3. Is -(u + u^2) equivalent to -u - u^2?
    False,  # 4. Is -(3 + y) equivalent to -3 + y?
    True,   # 5. Is \frac{j}{2} equivalent to \frac{1}{2}j?
    True    # 6. Is x + y + z equivalent to y + x + z?
]

# Assign numbers to each statement (1 through 6)
numbers = list(range(1, 7))

# Create a list of numbers corresponding to the 'True' statements
resulting_numbers = [num for num, is_true in zip(numbers, statements) if is_true]

# Get the sum of these numbers
final_answer = sum(resulting_numbers)
print(final_answer)
```
