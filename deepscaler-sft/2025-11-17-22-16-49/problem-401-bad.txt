To solve this problem, we need to consider all possible ways the player could have made 5 baskets, with each basket worth either 2 or 3 points.

Let's denote:
- \( x \) as the number of 2-point baskets.
- \( y \) as the number of 3-point baskets.

We know that:
\[ x + y = 5 \]
And the total points scored, \( P \), is given by:
\[ P = 2x + 3y \]

We need to iterate through all possible values of \( x \) and \( y \) that satisfy the equation \( x + y = 5 \), compute the corresponding total points, and then determine the different values that \( P \) can take.

Here, \( x \) can range from 0 to 5, and for each value of \( x \), \( y \) is determined as \( y = 5 - x \). Then we calculate \( P = 2x + 3y \) for each pair \((x, y)\).

Let's implement this in Python to get the answer.
```python
# Create a set to store different possible total points scored
total_points_set = set()

# Iterate through all possible values of x (from 0 to 5)
for x in range(6):
    y = 5 - x
    # Calculate the total points for each (x, y) pair
    total_points = 2 * x + 3 * y
    # Add the total points to the set
    total_points_set.add(total_points)

# Get the number of different total points that can be scored
num_different_total_points = len(total_points_set)
print((num_different_total_points, total_points_set))
```
