2. **Find Coordinates of Midpoints \(D\) and \(E\):**
    - Point \(D\) is the midpoint of \(\overline{AB}\), so its coordinates are \(\left(\frac{9+0}{2}, \frac{0+0}{2}\right) = \left(\frac{9}{2}, 0\right)\).
    - Point \(E\) is the midpoint of \(\overline{AC}\), so its coordinates are \(\left(\frac{9+0}{2}, \frac{0+13}{2}\right) = \left(\frac{9}{2}, \frac{13}{2}\right)\).

3. **Find the Equations of Lines \(CD\) and \(BE\):**
    - Line \(CD\) passes through points \(C = (0, 13)\) and \(D = \left(\frac{9}{2}, 0\right)\).
    - Line \(BE\) passes through points \(B = (0, 0)\) and \(E = \left(\frac{9}{2}, \frac{13}{2}\right)\).

4. **Find the Intersection Point \(X\) of Lines \(CD\) and \(BE\):**
    - To find the intersection, we can get the equations of the lines and solve them.
    - The slope of \(CD\) is \(\frac{0 - 13}{\frac{9}{2} - 0} = -\frac{26}{9}\), so its equation is \( y = -\frac{26}{9}x + 13 \).
    - The slope of \(BE\) is \(\frac{\frac{13}{2} - 0}{\frac{9}{2} - 0} = \frac{13}{9}\), so its equation is \( y = \frac{13}{9}x \).

    Set the equations equal to each other to solve for \(x\):
    \[
    -\frac{26}{9}x + 13 = \frac{13}{9}x \implies 13 = \frac{13}{9}x + \frac{26}{9}x \implies 13 = \frac{39}{9}x \implies 13 = \frac{13}{3}x \implies x = 3
    \]
    Substitute \(x = 3\) back into \( y = \frac{13}{9}x \):
    \[
    y = \frac{13}{9} \cdot 3 = \frac{13}{3}
    \]
    So, the intersection point \(X\) is \((3, \frac{13}{3})\).

5. **Find the Areas Using Coordinates:**
    - We can use the shoelace formula (or surveyor's formula) to find the areas of the polygons and the triangle.
    - The shoelace formula for a polygon with vertices \((x_1, y_1), (x_2, y_2), \ldots, (x_n, y_n)\) is:
      \[
      \text{Area} = \frac{1}{2} \left| \sum_{i=1}^{n-1}(x_i y_{i+1} - y_i x_{i+1}) + (x_n y_1 - y_n x_1) \right|
      \]

import sympy as sp

# Define the coordinates of points

# Function to calculate the area using the shoelace formula
def area_of_polygon(vertices):
    n = len(vertices)
    sum1 = sum(vertices[i][0] * vertices[(i + 1) % n][1] for i in range(n))
    sum2 = sum(vertices[i][1] * vertices[(i + 1) % n][0] for i in range(n))
    area = abs(sum1 - sum2) / 2
    return area

# Get the coordinates for points X, A, E, D, B, C
