First, let's determine the domain for the left-hand side of the inequality, \(\sqrt{x^2 - x - 6}\). The expression inside the square root must be non-negative, i.e.,
\[x^2 - x - 6 \geq 0.\]

1. **Find the domain:**

   To solve \(x^2 - x - 6 \geq 0\), we first find the roots of the equation \(x^2 - x - 6 = 0\):
   \[
   x^2 - x - 6 = (x - 3)(x + 2) = 0.
   \]
   So, the roots are \(x = 3\) and \(x = -2\). The quadratic expression \(x^2 - x - 6\) is a parabola that opens upwards, so it is non-negative outside the interval \((-2, 3)\). Thus, the domain for \(\sqrt{x^2 - x - 6}\) is:
   \[
   x \in (-\infty, -2] \cup [3, \infty).
   \]

2. **Consider the inequality \(\sqrt{x^2 - x - 6} < 2x - 3\):**

   For the right-hand side, \(2x - 3\) to be valid under a square root on the left-hand side, it must be non-negative because the left-hand side is a square root and is always non-negative:
   \[
   2x - 3 \geq 0 \implies x \geq \frac{3}{2}.
   \]

   So, we need to consider the intersection of the domains:
   \[
   x \in [3, \infty) \quad \text{(because this is the intersection of } [3, \infty) \text{ and } [x \geq \frac{3}{2}].)
   \]

3. **Formulate and check the inequality within this domain:**

   Combine this with the requirement that \(\sqrt{x^2 - x - 6} < 2x - 3\), and let's solve it programmatically to ensure accuracy. We can use Python to check this piece by piece and make sure we get the correct interval that satisfies both the domain constraints and the inequality itself.

Let's implement this step-by-step in Python to get the accurate solution.
```python
import sympy as sp

# Define the variable
x = sp.symbols('x')

# Define the inequality
lhs = sp.sqrt(x**2 - x - 6)
rhs = 2*x - 3

# Solve the inequality
solution = sp.solve_univariate_inequality(lhs < rhs, x, relational=False)

print(solution)
```
