To solve the problem, we need to find the smallest integer \( A \) such that there exist several consecutive integers starting from \( A \) that sum up to 2014.

Consider a sequence of \( n \) consecutive integers starting from \( A \):
\[ A + (A + 1) + (A + 2) + \ldots + (A + (n - 1)) \]

This sequence of consecutive integers can be summed up as:
\[ A + (A + 1) + (A + 2) + \ldots + (A + (n - 1)) = \sum_{k=0}^{n-1} (A + k) = nA + \sum_{k=0}^{n-1} k = nA + \frac{(n-1)n}{2} \]

We want this sum to be 2014, so we set up the equation:
\[ nA + \frac{(n-1)n}{2} = 2014 \]

This can be rearranged to isolate \( A \):
\[ nA = 2014 - \frac{(n-1)n}{2} \]
\[ A = \frac{2014 - \frac{(n-1)n}{2}}{n} \]
\[ A = \frac{2014}{n} - \frac{(n-1)n}{2n} \]
\[ A = \frac{2014}{n} - \frac{(n-1)}{2} \]

# Initialize variables to keep track of the smallest yummy integer found
