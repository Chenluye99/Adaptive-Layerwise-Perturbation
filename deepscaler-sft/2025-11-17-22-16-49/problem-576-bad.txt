Let's implement this step-by-step:

1. **Define the Function:**
   Define the function $y = 4^x + 2^{x+1} + 5$.

2. **Find the Maximum Value Over the Interval:**
   Use `scipy.optimize` to find the maximum value of the function over the interval $[1, 2]$.

Let's implement this in Python.
```python
import numpy as np
from scipy.optimize import minimize_scalar

# Define the function
def func(x):
    return -(4**x + 2**(x+1) + 5)

# Use minimize_scalar to find the minimum of the negative function, which corresponds to the maximum of the original function
result = minimize_scalar(func, bounds=(1, 2), method='bounded')

# Get the maximum value of the original function
max_value = -result.fun
print(max_value)
```
