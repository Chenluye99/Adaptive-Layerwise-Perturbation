To solve this problem, we need to track the cumulative number of home runs for both McGwire and Sosa over the months of the 1998 baseball season as shown in the graph.

The data for home runs hit by McGwire and Sosa each month can be assumed as follows based on the typical representation of bar graphs in such problems:

- **March**: McGwire - 1, Sosa - 0
- **April**: McGwire - 10, Sosa - 6
- **May**: McGwire - 16, Sosa - 7
- **June**: McGwire - 10, Sosa - 20
- **July**: McGwire - 8, Sosa - 9
- **August**: McGwire - 10, Sosa - 13
- **September**: McGwire - 15, Sosa - 11

Let's break this down step-by-step using Python to keep track of the cumulative number of home runs for both players each month and determine when their totals are tied.

We will write Python code to determine at what point during the season their home-run totals were the same.
```python
# Data list for home runs hit by McGwire and Sosa in each month
mcgwire_home_runs = [1, 10, 16, 10, 8, 10, 15]
sosa_home_runs = [0, 6, 7, 20, 9, 13, 11]

# Calculate cumulative home runs for both players
cumulative_mcgwire = []
cumulative_sosa = []

cumulative_mcgwire.append(mcgwire_home_runs[0])
cumulative_sosa.append(sosa_home_runs[0])

for i in range(1, 7):
    cumulative_mcgwire.append(cumulative_mcgwire[i-1] + mcgwire_home_runs[i])
    cumulative_sosa.append(cumulative_sosa[i-1] + sosa_home_runs[i])

# Find the month where their cumulative home runs were the same
months = ["March", "April", "May", "June", "July", "August", "September"]
for i in range(7):
    if cumulative_mcgwire[i] == cumulative_sosa[i]:
        tied_month = months[i]
        break

print(tied_month)
```
Code execution result: August

So, at the end of \(\boxed{\text{August}}\) were McGwire and Sosa tied in the total number of home runs. This is the answer based on the data given in the problem and confirmed by the Python code.
