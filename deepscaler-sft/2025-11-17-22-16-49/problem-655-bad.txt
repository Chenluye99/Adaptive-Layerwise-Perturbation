To solve this problem, we need to determine for which values of \( n \) in the range \( 1 \le n \le 1000 \), the quadratic polynomial \( x^2 + x - n \) can be factored into two linear factors with integer coefficients.

A quadratic polynomial \( x^2 + x - n \) can be factored into two linear factors if and only if it has integer roots. Suppose the roots of the polynomial are \( \alpha \) and \( \beta \). By Vieta's formulas, for a polynomial of the form \( x^2 + px + q \), the sum of the roots \(\alpha + \beta = -p\) and the product of the roots \(\alpha \cdot \beta = q\). For our polynomial \( x^2 + x - n \), this means:
\[
\alpha + \beta = -1 \quad \text{(1)}
\]
\[
\alpha \cdot \beta = -n \quad \text{(2)}
\]

From equation (1), we can express \(\beta\) as:
\[
\beta = -1 - \alpha
\]

Substitute this expression for \(\beta\) into equation (2):
\[
\alpha \cdot (-1 - \alpha) = -n
\]
\[
-n = \alpha \cdot (-1 - \alpha)
\]
\[
n = \alpha \cdot (1 + \alpha)
\]

Here, both \(\alpha\) and \(1 + \alpha\) are integers, and we need \( n \) to be a positive integer such that \( 1 \le n \le 1000 \).

We can iterate over all possible integer values of \(\alpha\) and check if the resulting \( n \) is in the range \( 1 \le n \le 1000 \). We will then count how many such \( n \) satisfy this condition.

Let's implement this logic in Python to get the accurate result.
```python
count = 0

# We will iterate over possible values of \(\alpha\) and compute corresponding \( n \)
for alpha in range(-1000, 1001):
    n = alpha * (1 + alpha)
    if 1 <= n <= 1000:
        count += 1

print(count)
```
