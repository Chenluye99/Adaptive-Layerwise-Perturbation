First, let's begin with some mathematical reasoning before implementing it in Python. 

The measure of an interior angle of a regular polygon with \( n \) sides is given by the formula:
\[
\text{Interior Angle} = \frac{(n-2) \cdot 180^\circ}{n}
\]
We know from the problem that the interior angle is 162 degrees. So, we can set up the following equation:
\[
\frac{(n-2) \cdot 180}{n} = 162
\]
To solve for \( n \), we can follow these steps:

1. Multiply both sides by \( n \):
\[
(n-2) \cdot 180 = 162n
\]
2. Distribute 180 on the left side:
\[
180n - 360 = 162n
\]
3. Rearrange the equation to isolate \( n \):
\[
180n - 162n = 360 \implies 18n = 360 \implies n = \frac{360}{18} = 20
\]

So, the polygon has 20 sides. Now let's confirm this solution using Python to ensure its accuracy.
```python
# We'll set up the equation and solve for n programmatically to make sure our solution is correct.

# We know that (n-2) * 180 / n = 162
# Rearranging gives us (n-2) * 180 = 162 * n
# Which further simplifies to 180 * n - 360 = 162 * n
# Rearrange to isolate n: 180 * n - 162 * n = 360
# This simplifies to 18 * n = 360, so n = 360 / 18

n = 360 / 18
print(n)
```
Code execution result: 20.0

Thus, the solution obtained from both mathematical reasoning and code execution is \(\boxed{20}\). The polygon has 20 sides. This is our final answer.
