First, let's start by generating all possible differences of the form \(a - b\) for \(a, b \in \{1, 3, 5, 7, 9, 11, 13\}\) where \(a \geq b\). This ensures we get all possible positive differences and avoid negative differences or zero (since zero is not a positive integer in this context).

Then, we will collect these differences in a set to ensure all values are distinct. After that, we will find the number of distinct positive integers in this set. Let's execute this step-by-step in Python.
```python
# Given set
num_set = {1, 3, 5, 7, 9, 11, 13}

# To store distinct differences
distinct_differences = set()

# Generate all differences a - b for a, b in the set, ensuring a >= b to get positive differences
for a in num_set:
    for b in num_set:
        if a >= b:
            distinct_differences.add(a - b)

# Get the number of distinct positive integers in the set of differences
num_distinct_differences = len(distinct_differences)
print(num_distinct_differences)
```
Code execution result: 7

Thus, the number of distinct positive integers that can be represented as the difference of two numbers in the set \(\{1, 3, 5, 7, 9, 11, 13\}\) is \(\boxed{7}\). This is our final answer.
