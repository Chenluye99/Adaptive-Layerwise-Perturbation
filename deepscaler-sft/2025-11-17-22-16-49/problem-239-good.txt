### Part (1): Find \(\tan 2A\)

1. **Find \(\sin A\) and \(\cos A\):**
   Given \(\cos A = \frac{\sqrt{6}}{3}\), we can find \(\sin A\) using the Pythagorean identity:
   \[
   \sin^2 A + \cos^2 A = 1 \implies \sin^2 A + \left(\frac{\sqrt{6}}{3}\right)^2 = 1 \implies \sin^2 A + \frac{6}{9} = 1 \implies \sin^2 A = \frac{3}{9} = \frac{1}{3} \implies \sin A = \frac{\sqrt{3}}{3}
   \]
   (We take the positive root because \(\sin A > 0\) in a triangle.)

2. **Find \(\tan A\):**
   \[
   \tan A = \frac{\sin A}{\cos A} = \frac{\frac{\sqrt{3}}{3}}{\frac{\sqrt{6}}{3}} = \frac{\sqrt{3}}{\sqrt{6}} = \frac{\sqrt{3}}{\sqrt{3} \cdot \sqrt{2}} = \frac{1}{\sqrt{2}} = \frac{\sqrt{2}}{2}
   \]

3. **Find \(\tan 2A\):**
   Using the double-angle formula for tangent, \(\tan 2A = \frac{2 \tan A}{1 - \tan^2 A}\), we substitute \(\tan A = \frac{\sqrt{2}}{2}\):
   \[
   \tan^2 A = \left( \frac{\sqrt{2}}{2} \right)^2 = \frac{2}{4} = \frac{1}{2}
   \]
   \[
   \tan 2A = \frac{2 \cdot \frac{\sqrt{2}}{2}}{1 - \frac{1}{2}} = \frac{\sqrt{2}}{\frac{1}{2}} = \sqrt{2} \cdot 2 = 2 \sqrt{2}
   \]

### Part (2): Find the area of \(\triangle ABC\)

   \[

2. **Find \(\cos C\) and \(\sin C\):**
   Using the angle sum identity for cosine in a triangle, we know that \(A + B + C = \pi\), so \(\cos C = - \cos (A + B)\):
   \[
   \cos (A + B) = \cos A \cos B - \sin A \sin B = \frac{\sqrt{6}}{3} \cdot \frac{2 \sqrt{2}}{3} - \frac{\sqrt{3}}{3} \cdot \frac{1}{3} = \frac{2 \sqrt{12}}{9} - \frac{\sqrt{3}}{9} = \frac{4 \sqrt{3}}{9} - \frac{\sqrt{3}}{9} = \frac{3 \sqrt{3}}{9} = \frac{\sqrt{3}}{3}
   \]
   Hence,
   \[
   \cos C = - \frac{\sqrt{3}}{3}
   \]
   To find \(\sin C\), we use the Pythagorean identity:
   \[

   \]
   (We take the positive root because \(\sin C > 0\) in a triangle.)

3. **Find sides \(a\) and \(b\) using the Law of Sines:**
   The Law of Sines states that \(\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C}\). Given that \(c = 2 \sqrt{2}\) and \(\sin C = \frac{\sqrt{6}}{3}\), we can find \(\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = \frac{2 \sqrt{2}}{\frac{\sqrt{6}}{3}} = \frac{2 \sqrt{2} \cdot 3}{\sqrt{6}} = \frac{6 \sqrt{2}}{\sqrt{6}} = \frac{6 \sqrt{2}}{\sqrt{2} \cdot \sqrt{3}} = \frac{6}{\sqrt{3}} = 2 \sqrt{3}\).

   So,
   \[
   a = 2 \sqrt{3} \cdot \sin A = 2 \sqrt{3} \cdot \frac{\sqrt{3}}{3} = 2
   \]
   \[
   b = 2 \sqrt{3} \cdot \sin B = 2 \sqrt{3} \cdot \frac{1}{3} = \frac{2 \sqrt{3}}{3}

4. **Find the Area of \(\triangle ABC\):**
   We can use Heron's formula or the formula \(\text{Area} = \frac{1}{2} a b \sin C\). Here, using \(\text{Area} = \frac{1}{2} a b \sin C\) will be simpler. We substitute \(a = 2\), \(b = \frac{2 \sqrt{3}}{3}\), and \(\sin C = \frac{\sqrt{6}}{3}\):
