1. **Understand the Problem:**
    - We have a rectangle with vertices at \((0,0)\), \((3,0)\), \((3,2)\), and \((0,2)\).
    - We need to find the probability that a randomly chosen point \((x, y)\) from this rectangle satisfies the condition \(x < y\).

2. **Set Up the Rectangle and Condition:**
    - The area of the rectangle is calculated as the product of the lengths of its sides: the length along the x-axis (which is 3) and the length along the y-axis (which is 2). So, the area of the rectangle is \(3 \times 2 = 6\).
    - We need to find the area of the region within this rectangle where \(x < y\). To determine this, we need to consider the line \(x = y\).

3. **Find the Region Where \(x < y\):**
    - The line \(x = y\) starts from \((0, 0)\) and goes upwards to \((2, 2)\). However, the upper limit for \(y\) is 2 and for \(x\) is 3, so the line \(x = y\) will intersect the top boundary of the rectangle at \((2, 2)\).
    - Therefore, we need to consider the area below the line \(x = y\) but only up to \(y = 2\) and \(x = 3\).

4. **Set Up the Integral to Find the Area Where \(x < y\):**
    - This involves finding the intersection of the line \(x = y\) with the boundaries of the rectangle. From \(x = 0\) to \(x = 2\), \(y\) ranges from \(x\) to 2, and for \(x = 2\) to \(x = 3\), \(y = 2\).

Let's set up and solve this using Python to get an accurate answer.
```python
import sympy as sp

# Define the variables
x, y = sp.symbols('x y')

# Set up the double integral to find the area where x < y within the bounds of the rectangle
area_rectangle = 3 * 2

# Integrate over the region where 0 <= x <= 3 and 0 <= y <= 2, but only counting the area where x < y
integrand = 1
area_condition_satisfied = sp.integrate(integrand, (y, x, 2), (x, 0, 2)) + sp.integrate(integrand, (y, 0, 2), (x, 2, 3))

# Calculate the probability as the ratio of the area where x < y to the area of the entire rectangle

print(probability)
```
