First, let's understand the problem and the spinner:

- The spinner has 5 regions, each with an equal probability of being landed on.
- The values on the spinner are: "Bankrupt", "$1000$", "$300$", "$5000$", and "$400$".
- We need to find the probability that a person will earn exactly \$1700 in their first three spins.

To get exactly \$1700 from three spins, we need to check all possible outcomes of three spins and see which of those outcomes sum up to \$1700. We will then count the number of successful outcomes and divide by the total number of outcomes to get the probability.

Let's list out all possible outcomes of three spins and check which of these outcomes sum up to \$1700. The values on the spinner are \{0, 1000, 300, 5000, 400\} where "Bankrupt" corresponds to 0.

We will iterate through all combinations of three spins and check if their sum is 1700. We will then count how many such combinations exist and divide by the total number of possible outcomes to get the probability. 

There are 5 choices for each of the three spins, so there are \(5^3 = 125\) possible outcomes when spinning the spinner three times. We will check each of these outcomes to see if their sum is 1700.

Let's implement this using Python.
```python
import itertools

# Spinner values
spinner_values = [0, 1000, 300, 5000, 400]

# Generate all possible outcomes for three spins
outcomes = list(itertools.product(spinner_values, repeat=3))

# Count the number of outcomes that sum to 1700
count_success = sum(1 for outcome in outcomes if sum(outcome) == 1700)

# Calculate the probability
probability = count_success / len(outcomes)
print(probability)
```
