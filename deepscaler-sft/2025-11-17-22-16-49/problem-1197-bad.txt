To solve this problem, we need to use vector algebra. Given that the ratio \(AP:PB = 1:4\), we can use the section formula (or section and extension formula) to get the position vector of point \(P\).

If point \(P\) divides the line segment \(\overline{AB}\) externally in the ratio \(1:4\), then we can use the section formula for external division:

\[
P = \frac{m \cdot B - n \cdot A}{m - n}
\]

where \(m = 1\) and \(n = 4\). Substituting these values, we get:

\[
P = \frac{1 \cdot B - 4 \cdot A}{1 - 4} = \frac{B - 4A}{-3} = \frac{-1 \cdot (4A - B)}{3} = -\frac{4}{3}A + \frac{1}{3}B
\]

This means that:

\[
\overrightarrow{P} = -\frac{4}{3} \overrightarrow{A} + \frac{1}{3} \overrightarrow{B}
\]

Hence, we have \( t = -\frac{4}{3} \) and \( u = \frac{1}{3} \). Therefore, the ordered pair \((t, u)\) is:

\[
\left( -\frac{4}{3}, \frac{1}{3} \right)
\]
