First, we need to convert \(\frac{3}{1250}\) into its decimal form. Then, we will count how many zeros appear between the decimal point and the first non-zero digit in that decimal representation.

Let's start by converting \(\frac{3}{1250}\) to a decimal. We can do this by performing the division \( \frac{3}{1250} \).

After obtaining the decimal representation, we will count the zeros between the decimal point and the first non-zero digit. Let's implement this step-by-step in Python to get an accurate result.
```python
# Calculate the decimal representation of 3 / 1250
decimal_value = 3 / 1250

# Convert to string to easily inspect the decimal part
decimal_str = f"{decimal_value:.50f}"  # Using 50 decimal places should be more than sufficient

# Get the part of the string after the decimal point
decimal_part = decimal_str.split('.')[1]

# Find the position of the first non-zero digit after the decimal point
first_non_zero_index = next(i for i, digit in enumerate(decimal_part) if digit != '0')

# The number of zeros between the decimal point and the first non-zero digit is `first_non_zero_index`
num_zeros = first_non_zero_index

print(num_zeros)
```
Code execution result: 2

Thus, the number of zeros between the decimal point and the first non-zero digit in the decimal representation of \(\frac{3}{1250}\) is \(\boxed{2}\). This is our final answer.
