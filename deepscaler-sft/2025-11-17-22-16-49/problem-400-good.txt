To solve the system of equations

\[
\begin{aligned}
a^2 - bc & = 14, \\
b^2 - ca & = 14, \\
c^2 - ab & = -3,
\end{aligned}
\]

we need to find the values of $a, b, c$ that satisfy all three equations simultaneously. Then, we will compute $|a + b + c|$.

Let's use Python to solve this system of equations. We can use a numerical solver to find the values of $a, b, c$.
```python
import sympy as sp

# Define variables
a, b, c = sp.symbols('a b c', real=True)

# Define the system of equations
eq1 = a**2 - b * c - 14
eq2 = b**2 - c * a - 14
eq3 = c**2 - a * b + 3

# Solve the system of equations
solution = sp.solve([eq1, eq2, eq3], (a, b, c))

print(solution)
```
Code execution result: [(-14/5, -14/5, 11/5), (14/5, 14/5, -11/5)]

The solutions to the system of equations are \((- \frac{14}{5}, - \frac{14}{5}, \frac{11}{5})\) and \((\frac{14}{5}, \frac{14}{5}, - \frac{11}{5})\).

Next, we need to compute \( |a + b + c| \) for each solution.

1. For the solution \((- \frac{14}{5}, - \frac{14}{5}, \frac{11}{5})\):
\[
a + b + c = - \frac{14}{5} - \frac{14}{5} + \frac{11}{5} = - \frac{28}{5} + \frac{11}{5} = - \frac{17}{5}
\]
\[
|a + b + c| = \left| - \frac{17}{5} \right| = \frac{17}{5}
\]

2. For the solution \((\frac{14}{5}, \frac{14}{5}, - \frac{11}{5})\):
\[
a + b + c = \frac{14}{5} + \frac{14}{5} - \frac{11}{5} = \frac{14}{5} + \frac{14}{5} - \frac{11}{5} = \frac{28}{5} - \frac{11}{5} = \frac{17}{5}
\]
\[
|a + b + c| = \left| \frac{17}{5} \right| = \frac{17}{5}
\]

In both cases, we get the same result. Therefore, the value of \( |a + b + c| \) is \(\frac{17}{5}\).

Thus, the final answer is:

\(\boxed{\frac{17}{5}}\)
