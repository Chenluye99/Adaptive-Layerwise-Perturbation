To solve this problem, we need to generate all possible three-digit numbers using the digits {1, 2, 3, 4, 5} with the constraints that:

1. The number must be even.
2. The number must be less than 500.
3. Each digit can be used more than once.

Let's implement this step-by-step:

1. **Generate All Possible Three-Digit Numbers:**
   We need to generate all three-digit numbers that can be formed using the digits {1, 2, 3, 4, 5}. Each digit in the number can be any of the 5 choices, so there are \(5 \times 5 \times 5 = 125\) possible three-digit numbers.

2. **Apply Constraints:**
   - The number must be even, so the last digit must be either 2 or 4.
   - The number must be less than 500, so the first digit must be either 1, 2, 3, or 4.

3. **Check and Count Valid Numbers:**
   We need to check each generated number to see if it meets both of these constraints, and then count how many such numbers exist.

Let's write Python code to solve this step-by-step.
```python
count = 0

# We will generate all three-digit numbers with digits from the set {1, 2, 3, 4, 5}
for num in range(100, 600):
    num_str = str(num)
    
    # Extract the digits
    hundreds_digit = int(num_str[0])
    tens_digit = int(num_str[1])
    units_digit = int(num_str[2])
    
    # Check if the number is even (units digit must be 2 or 4)
    if units_digit not in {2, 4}:
        continue
    
    # Check if the number is less than 500 (hundreds digit must be 1, 2, 3, or 4)
    if hundreds_digit not in {1, 2, 3, 4}:
        continue
    
    # If both conditions are satisfied, count this number
    count += 1

print(count)
```
Code execution result: 80
