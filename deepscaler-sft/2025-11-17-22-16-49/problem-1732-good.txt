To solve this problem, we need to use the formula for the sum of the interior angles of a polygon. The sum of the interior angles of an $n$-sided polygon is given by:

\[
\text{Sum of interior angles} = (n - 2) \cdot 180^\circ
\]

### Step-by-Step Solution:

1. **Find the Number of Sides of the Original Polygon:**
    - We know that for a polygon with $n$ sides, the sum of the interior angles is $1800^\circ$. So, we can set up the equation:
      \[
      (n - 2) \cdot 180 = 1800
      \]
    - Solving this equation for $n$:
      \[
      n - 2 = \frac{1800}{180} = 10 \implies n = 12
      \]

2. **Find the Sum of the Interior Angles of a Polygon with \(n + 2\) Sides:**
    - If the original polygon has $n = 12$ sides, then the new polygon will have $n + 2 = 12 + 2 = 14$ sides.
    - The sum of the interior angles of a polygon with 14 sides is:
      \[
      (14 - 2) \cdot 180 = 12 \cdot 180 = 2160
      \]

Thus, the degree measure of the sum of the interior angles of a convex polygon with \(n + 2\) sides is \(2160^\circ\).

Let's write the Python code to confirm this reasoning.
```python
# We start by solving for n using the equation (n - 2) * 180 = 1800

from sympy import symbols, Eq, solve

# Define the equation
n = symbols('n')
eq = Eq((n - 2) * 180, 1800)

# Solve for n
n_value = solve(eq, n)[0]

# Now, we find the sum of the interior angles for a polygon with (n + 2) sides
n_plus_2 = n_value + 2
sum_of_interior_angles_n_plus_2 = (n_plus_2 - 2) * 180

print(sum_of_interior_angles_n_plus_2)
```
Code execution result: 2160

Thus, the degree measure of the sum of the interior angles of a convex polygon with \(n + 2\) sides is \(\boxed{2160}\). This confirms our solution is accurate.
