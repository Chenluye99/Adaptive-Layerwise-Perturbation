To solve the problem, let's denote the roots of the quadratic equation \(x^2 + bx + 48 = 0\) as \(3k\) and \(k\) since they are in the ratio of 3 to 1. By Vieta's formulas, we know the following relationships for the roots of the equation \(x^2 + bx + 48 = 0\):

1. The sum of the roots is equal to \(-b\):
   \[
   3k + k = -b \implies 4k = -b \implies b = -4k
   \]
2. The product of the roots is equal to 48:
   \[
   (3k) \cdot (k) = 48 \implies 3k^2 = 48 \implies k^2 = 16 \implies k = 4 \text{ or } k = -4
   \]

So, we have two possible values for \(k\):

- If \(k = 4\), then \(b = -4 \cdot 4 = -16\).
- If \(k = -4\), then \(b = -4 \cdot (-4) = 16\).

The largest possible value of \(b\) is 16. Let's verify this by coding the solution to ensure its accuracy.
```python
import sympy as sp

# Define the variables
k = sp.symbols('k', real=True)

# Equation derived from the product of the roots
eq = 3 * k**2 - 48

# Solve for k
k_solutions = sp.solve(eq, k)

# Calculate the corresponding b values
b_values = [-4 * k_val for k_val in k_solutions]

# Get the maximum value of b
max_b = max(b_values)
print(max_b)
```
Code execution result: 16

Thus, the largest possible value of \( b \) is \(\boxed{16}\). This confirms our solution is accurate.
