First, let's start by using trigonometric identities and properties. We know that:

\[
\sin (a + b) = \sin a \cos b + \cos a \sin b = \frac{3}{4}
\]

and

\[
\sin (a - b) = \sin a \cos b - \cos a \sin b = \frac{1}{2}.
\]

To solve for \(\frac{\tan a}{\tan b}\), let's introduce \(x = \tan a\) and \(y = \tan b\), hence \(\frac{\tan a}{\tan b} = \frac{x}{y}\). We can use the identities for sine and cosine in terms of tangent:

\[
\sin a = \frac{\tan a}{\sqrt{1 + \tan^2 a}} = \frac{x}{\sqrt{1 + x^2}},
\]

\[
\cos a = \frac{1}{\sqrt{1 + \tan^2 a}} = \frac{1}{\sqrt{1 + x^2}},
\]

\[
\sin b = \frac{\tan b}{\sqrt{1 + \tan^2 b}} = \frac{y}{\sqrt{1 + y^2}},
\]

\[
\cos b = \frac{1}{\sqrt{1 + \tan^2 b}} = \frac{1}{\sqrt{1 + y^2}}.
\]

Substitute these into the equations for \(\sin (a + b)\) and \(\sin (a - b)\):

\[
\sin (a + b) = \sin a \cos b + \cos a \sin b = \frac{x}{\sqrt{1 + x^2}} \cdot \frac{1}{\sqrt{1 + y^2}} + \frac{1}{\sqrt{1 + x^2}} \cdot \frac{y}{\sqrt{1 + y^2}} = \frac{x + y}{\sqrt{1 + x^2} \sqrt{1 + y^2}} = \frac{3}{4},
\]

\[
\sin (a - b) = \sin a \cos b - \cos a \sin b = \frac{x}{\sqrt{1 + x^2}} \cdot \frac{1}{\sqrt{1 + y^2}} - \frac{1}{\sqrt{1 + x^2}} \cdot \frac{y}{\sqrt{1 + y^2}} = \frac{x - y}{\sqrt{1 + x^2} \sqrt{1 + y^2}} = \frac{1}{2}.
\]

We can set up the following equations based on the above expressions:

\[
\frac{x + y}{\sqrt{1 + x^2} \sqrt{1 + y^2}} = \frac{3}{4},
\]

\[
\frac{x - y}{\sqrt{1 + x^2} \sqrt{1 + y^2}} = \frac{1}{2}.
\]

Let's denote \(\sqrt{1 + x^2} \sqrt{1 + y^2} = k\). Then we have:

\[
\frac{x + y}{k} = \frac{3}{4} \implies x + y = \frac{3k}{4},
\]

\[
\frac{x - y}{k} = \frac{1}{2} \implies x - y = \frac{k}{2}.
\]

Now, we can solve these two equations simultaneously:

1. \(x + y = \frac{3k}{4},\)
2. \(x - y = \frac{k}{2}.\)

Add these two equations:

\[
(x + y) + (x - y) = \frac{3k}{4} + \frac{k}{2} \implies 2x = \frac{3k}{4} + \frac{2k}{4} \implies 2x = \frac{5k}{4} \implies x = \frac{5k}{8}.
\]

Subtract the second equation from the first:

\[
(x + y) - (x - y) = \frac{3k}{4} - \frac{k}{2} \implies 2y = \frac{3k}{4} - \frac{2k}{4} \implies 2y = \frac{k}{4} \implies y = \frac{k}{8}.
\]

Now, substitute \(x\) and \(y\) back in terms of \(k\):

\[
x = \frac{5k}{8}, \quad y = \frac{k}{8}.
\]

Thus, we have:

\[
\frac{\tan a}{\tan b} = \frac{x}{y} = \frac{\frac{5k}{8}}{\frac{k}{8}} = \frac{5k}{8} \cdot \frac{8}{k} = 5.
\]

So, the final answer is \(\frac{\tan a}{\tan b} = 5\). Let's verify this solution by coding it to ensure its accuracy.
