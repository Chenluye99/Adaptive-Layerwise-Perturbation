To determine the slope angle of the tangent line to the curve \(y = \frac{1}{2}x^2 + 2\) at the point \((-1, \frac{5}{2})\), we can follow these steps:

1. **Find the Derivative of the Function:**
   The slope of the tangent line at any point on the curve is given by the derivative of the function \(y = \frac{1}{2}x^2 + 2\). So, let's compute its derivative:
   \[
   \frac{dy}{dx} = \frac{d}{dx}\left(\frac{1}{2}x^2 + 2\right) = x
   \]
   This means that the slope of the tangent line at any point \(x\) on the curve is \(x\).

2. **Find the Slope at the Given Point:**
   We need to find the slope at the point \((-1, \frac{5}{2})\). Substituting \(x = -1\) into the derivative, we get:
   \[
   \text{slope} = -1
   \]
   So, the slope of the tangent line at the point \((-1, \frac{5}{2})\) is \(-1\).

3. **Find the Angle of the Tangent Line:**
   The angle \(\theta\) that the tangent line makes with the positive direction of the x-axis is given by:
   \[
   \theta = \arctan(\text{slope}) = \arctan(-1)
   \]
   We know that \(\arctan(-1) = -\frac{\pi}{4}\), but since angles in geometry are usually considered in the range from 0 to \(\pi\), we can add \(\pi\) to \(-\frac{\pi}{4}\) to get the equivalent positive angle if needed. However, \(-\frac{\pi}{4}\) is often considered directly if we are looking for the angle that the line makes with the positive x-axis considering the standard mathematical context (i.e., \(\theta\) is typically taken in the range \([- \frac{\pi}{2}, \frac{\pi}{2}]\)).

```python
import sympy as sp

# Define the variables and function

# Calculate the derivative of the function
dy_dx = sp.diff(y, x)

# Evaluate the derivative at the point (-1, 5/2)
slope_at_point = dy_dx.subs(x, -1)

# Calculate the angle of the tangent line
angle = sp.atan(slope_at_point)
print(angle)
```
