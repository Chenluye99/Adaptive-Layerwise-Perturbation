First, let's start by setting up the problem using mathematical equations.

1. **Formulate the Problem:**
    - Let the length and width of the rectangle be \( l \) and \( w \) respectively.
    - The perimeter of the rectangle is given by the formula: 
      \[
      2l + 2w = 100 \implies l + w = 50
      \]
    - The area of the rectangle is given by:
      \[
      \text{Area} = l \cdot w
      \]
    - We need to find the least possible area for integer values of \( l \) and \( w \) such that \( l + w = 50 \).

2. **Iterate Through Possible Values:**
    - We can express \( w \) in terms of \( l \) as:
      \[
      w = 50 - l
      \]
    - Substitute this into the area formula:
      \[
      \text{Area} = l \cdot (50 - l)
      \]
    - We need to check all possible integer values for \( l \) and compute the corresponding area, then determine the minimum area.

3. **Set Up the Code to Find the Solution:**
    - We'll iterate through all possible integer values for \( l \) (from 1 to 49, because both \( l \) and \( w \) must be positive integers and \( l \leq w \) or \( w \leq l \) without loss of generality).
    - For each value of \( l \), compute \( w = 50 - l \) and then compute the area \( l \cdot w \).
    - Track the minimum area encountered during this process.

Let's implement this in Python to get the accurate result.
```python
# Initialize variables to keep track of the minimum area and the corresponding length and width
min_area = float("inf")
best_pair = (0, 0)

# Iterate through possible values of length l
for l in range(1, 50):
    w = 50 - l
    area = l * w
    if area < min_area:
        min_area = area
        best_pair = (l, w)

print((min_area, best_pair))
```
Code execution result: (49, (1, 49))

This result tells us that the least possible area of the rectangle is 49 square units, which occurs when the dimensions of the rectangle are 1 and 49.

Thus, the number of square units in the least possible area is \(\boxed{49}\). This is our final answer.
