First, let's start by defining the constraints for the Zuminglish-Advanced language, as described in the problem statement:

1. **Constraints**:
    - An occurrence of 'M' must be immediately followed by 'P' before any 'O' can occur again.
    - Between any two 'O's, there must appear at least two consonants ('M' or 'P').

2. **Formulate the Problem**:
    - We need to generate all possible 8-letter words using the letters 'M', 'O', and 'P' that satisfy these constraints.
    - Then, we need to count such valid words and return the count modulo 100.

3. **Implement with Python**:
    - We can use Python to generate all possible 8-letter combinations of 'M', 'O', and 'P', and then check each combination to see if it meets the constraints.

Let's write the code to solve this step by step.
```python
import itertools

count = 0

# Generate all 8-letter combinations of 'M', 'O', and 'P'
for word in itertools.product('MOP', repeat=8):
    word_str = ''.join(word)
    
    # Check the first constraint: an 'M' must be followed by a 'P' before an 'O' can occur again
    m_index = [i for i, letter in enumerate(word_str) if letter == 'M']
    for i in m_index:
        if i + 1 < len(word_str) and word_str[i + 1] != 'P':
            continue  # Skip this word if we find a 'M' not immediately followed by 'P'
    
    # Check the second constraint: between any two 'O's, there must appear at least two consonants ('M' or 'P')
    o_indices = [i for i, letter in enumerate(word_str) if letter == 'O']
    for i in range(len(o_indices) - 1):
        o1, o2 = o_indices[i], o_indices[i + 1]
        consonants_between = word_str[o1 + 1:o2]
        if len(consonants_between) < 2 or 'M' not in consonants_between or 'P' not in consonants_between:
            continue  # Skip this word if we find a violation of this condition
    
    # If both constraints are satisfied, increment the counter
    count += 1

X = count
result = X % 100
print(result)
```
