We will then use `networkx` to build this graph and find the largest connected component. This involves:

1. Generating all three-digit perfect squares.
2. Creating a graph where each node is a three-digit perfect square.
3. Add an edge between two nodes if their digits can be rearranged to form each other.

Let's implement this step-by-step solution in Python.
```python
import itertools
import networkx as nx

# Step 1: Generate all three-digit perfect squares
three_digit_squares = []

for i in range(10, 32):
    square = i * i
    if 100 <= square <= 999:
        three_digit_squares.append(square)

# Step 2: Create a graph where each node is a three-digit perfect square
G = nx.Graph()

# Add nodes
G.add_nodes_from(three_digit_squares)

# Add edges if one number can be rearranged to another
for i in range(len(three_digit_squares)):
    for j in range(i + 1, len(three_digit_squares)):
        if set(str(three_digit_squares[i])) == set(str(three_digit_squares[j])):
            G.add_edge(three_digit_squares[i], three_digit_squares[j])

# Step 3: Find the largest connected component
largest_cc = max(nx.connected_components(G), key=len)
print((len(largest_cc), list(largest_cc)))
```
