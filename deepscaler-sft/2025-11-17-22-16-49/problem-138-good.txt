To solve the problem, we need to determine the electronic configuration of a ground state iron atom and then count the number of orbitals that contain one or more electrons.

1. **Find the Electron Configuration of Iron:**
    - Iron (Fe) has an atomic number (Z) of 26, which means it has 26 electrons.
    - The electron configuration of iron in its ground state is: \(1s^2 2s^2 2p^6 3s^2 3p^6 4s^2 3d^6\).

2. **Identify Orbitals Containing Electrons:**
    - Each of the above sets of occupied orbitals should be considered:
        - \(1s^2\) (1 orbital, \(s\))
        - \(2s^2 2p^6\) (3 orbitals: \(2s\) and 3 orbitals from \(2p\))
        - \(3s^2 3p^6\) (3 orbitals: \(3s\) and 3 orbitals from \(3p\))
        - \(4s^2 3d^6\) (1 orbital from \(4s\) and 5 orbitals from \(3d\))
    - Therefore, the total number of orbitals containing electrons is the sum of all these orbitals.

Let's count each orbital group mentioned above:

- 1 orbital from \(1s^2\)
- 1 orbital from \(2s^2\) and 3 orbitals from \(2p^6\) (total 1 + 3 = 4)
- 1 orbital from \(3s^2\) and 3 orbitals from \(3p^6\) (total 1 + 3 = 4)
- 1 orbital from \(4s^2\) and 5 orbitals from \(3d^6\) (total 1 + 5 = 6)

So, the total number of orbitals containing one or more electrons is \(1 + 4 + 4 + 6 = 15\).

Let's confirm this by implementing it in Python as well.
```python
# Function to get electron configurations and count orbitals with electrons
def count_orbitals_with_electrons(atom):
    # Atomic number for iron
    atomic_number = 26
    
    # Construct the electron configuration for iron
    electron_configuration = [
        (1, 's', 2),         # 1s^2
        (2, 's', 2),         # 2s^2
        (2, 'p', 6),         # 2p^6
        (3, 's', 2),         # 3s^2
        (3, 'p', 6),         # 3p^6
        (4, 's', 2),         # 4s^2
        (3, 'd', 6)          # 3d^6
    ]
    
    # Get unique orbitals used by the electron configuration
    orbitals_with_electrons = set()
    
    for level, orbital_type, electrons in electron_configuration:
        if electrons > 0:
            if orbital_type == 's':
                orbitals_with_electrons.add(f"{level}{orbital_type}")
            elif orbital_type == 'p':
                for i in range(3):
                    orbitals_with_electrons.add(f"{level}{orbital_type}{i+1}")
            elif orbital_type == 'd':
                for i in range(5):
                    orbitals_with_electrons.add(f"{level}{orbital_type}{i+1}")
    
    return len(orbitals_with_electrons)

# Count the number of orbitals containing one or more electrons for iron
num_orbitals_with_electrons = count_orbitals_with_electrons('Fe')
print(num_orbitals_with_electrons)
```
