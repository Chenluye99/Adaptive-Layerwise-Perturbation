We start by considering the function $f(x) = x^3 + ax^2 + bx + a^2$. We know that $f(x)$ has an extremum at $x=1$ and that this extremum is 10. To solve for the constants $a$ and $b$, we need to follow these steps:

1. **Find the first derivative of \( f(x) \):**
   \[
   f'(x) = \frac{d}{dx}(x^3 + ax^2 + bx + a^2) = 3x^2 + 2ax + b
   \]
   Since $f(x)$ has an extremum at $x=1$, it means that $f'(1) = 0$:
   \[
   f'(1) = 3(1)^2 + 2a(1) + b = 3 + 2a + b = 0 \implies 2a + b = -3 \quad \text{(1)}
   \]

2. **Evaluate the function at the extremum point \( x=1 \) and set it equal to 10:**
   \[
   f(1) = (1)^3 + a(1)^2 + b(1) + a^2 = 1 + a + b + a^2 = 10 \implies a^2 + a + b = 9 \quad \text{(2)}
   \]

3. **Solve the system of equations:**
   We need to solve the system of equations given by (1) and (2):
   \[
   \begin{cases}
   2a + b = -3 \\
   a^2 + a + b = 9
   \end{cases}
   \]
   Substitute \( b = -3 - 2a \) from the first equation into the second equation:
   \[
   a^2 + a + (-3 - 2a) = 9 \implies a^2 + a - 3 - 2a = 9 \implies a^2 - a - 3 = 9 \implies a^2 - a - 12 = 0
   \]
   Now, solve the quadratic equation \( a^2 - a - 12 = 0 \) using the quadratic formula \( a = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} \):
   \[
   a = \frac{-(-1) \pm \sqrt{(-1)^2 - 4(1)(-12)}}{2(1)} = \frac{1 \pm \sqrt{1 + 48}}{2} = \frac{1 \pm \sqrt{49}}{2} = \frac{1 \pm 7}{2}
   \]
   This gives us two solutions for \( a \):
   \[
   a = \frac{1 + 7}{2} = 4 \quad \text{or} \quad a = \frac{1 - 7}{2} = -3
   \]

4. **Find the corresponding values of \( b \) for each of these \( a \) values:**
   - For \( a = 4 \):
     \[
     2(4) + b = -3 \implies 8 + b = -3 \implies b = -3 - 8 = -11
     \]
   - For \( a = -3 \):
     \[
     2(-3) + b = -3 \implies -6 + b = -3 \implies b = -3 + 6 = 3
     \]

So, the possible values for \( b \) are \( -11 \) and \( 3 \). Next, we need to check if both these values make sense in the context of the original problem. However, it's also important to make sure we substitute back and double-check the conditions to ensure correctness.
