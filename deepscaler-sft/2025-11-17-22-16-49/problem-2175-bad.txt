1. **Properties of an Arithmetic Sequence:**
    - The \(n\)-th term of an arithmetic sequence can be written as:
      \[
      a_n = a_1 + (n-1)d
      \]
      where \(a_1\) is the first term and \(d\) is the common difference.
    
2. **Given Conditions:**
    - The first term of the arithmetic sequence equals the third minus the second term:
      \[
      a_1 = a_3 - a_2
      \]
      Using the formula for the \(n\)-th term:
      \[
      a_3 = a_1 + 2d \quad \text{and} \quad a_2 = a_1 + d
      \]
      Substituting these into the equation gives:
      \[
      a_1 = (a_1 + 2d) - (a_1 + d) \implies a_1 = a_1 + 2d - a_1 - d \implies a_1 = d
      \]
      So, we have:
      \[
      d = a_1
      \]
    - The fourth term of the sequence is 8:
      \[
      a_4 = 8
      \]
      Using the formula for the fourth term:
      \[
      a_4 = a_1 + 3d
      \]
      Substituting the value of \(d = a_1\) into this equation, we get:
      \[
      a_1 + 3a_1 = 8 \implies 4a_1 = 8 \implies a_1 = 2
      \]

So, the first term \(a_1\) of the arithmetic sequence is 2. Let's confirm this by coding it to ensure accuracy.
```python
from sympy import symbols, Eq, solve

# Define the variables
```
