1. **Generate All Binary Strings of Length 11:**
   We can generate all possible binary strings of length 11. Each string will be of the form of a list or a string composed of 0's and 1's.

2. **Check the Condition:**
   For each generated binary string, we need to check that every set of three consecutive digits sums to at least 1. That is, for a string of length 11, we need to check the following sets: (string[0], string[1], string[2]), (string[1], string[2], string[3]), ..., (string[9], string[10], string[11]).

3. **Count Valid Strings:**
   We count how many of these strings meet the condition and store them in the set $\mathcal{S}_{11}$.

Let's implement this using Python to ensure accuracy.
```python
import itertools

# Initialize a counter for the number of valid strings
count = 0

# Generate all binary strings of length 11
for i in range(2**11):
    s = format(i, '011b')
    if all(int(s[i]) + int(s[i+1]) + int(s[i+2]) >= 1 for i in range(9)):
        count += 1

print(count)
```
