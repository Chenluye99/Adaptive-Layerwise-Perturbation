First, let's rewrite the equation of the ellipse in the standard form \(\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1\).

Starting with the given equation:

\[
\frac{x^2}{20} + \frac{y^2}{4} = 7,
\]

we can divide through by 7 to get:

\[
\frac{x^2}{140} + \frac{y^2}{28} = 1.
\]

From this, we can identify that \(a^2 = 140\) and \(b^2 = 28\). Here, \(a^2\) and \(b^2\) are the denominators of the standard form, and they correspond to the semi-major and semi-minor axis squares. 

For an ellipse, the distance between the foci is given by \(2c\), where \(c\) is calculated using the relationship:

\[
c^2 = a^2 - b^2.
\]

Substitute \(a^2 = 140\) and \(b^2 = 28\) into the equation:

\[
c^2 = 140 - 28 = 112.
\]

Thus,

\[
c = \sqrt{112} = \sqrt{16 \cdot 7} = 4\sqrt{7}.
\]

The distance between the foci is \(2c\):

\[
2c = 2 \cdot 4\sqrt{7} = 8\sqrt{7}.
\]

Let's verify this by implementing it in Python to ensure that the result is accurate.
```python
import sympy as sp

# Given constants
a_squared = 140
b_squared = 28

# Calculate c
c = sp.sqrt(a_squared - b_squared)

# Distance between the foci is 2c
distance_between_foci = 2 * c
print(distance_between_foci)
```
Code execution result: 8*sqrt(7)

Thus, the distance between the foci of the ellipse is \(\boxed{8\sqrt{7}}\). This confirms our analytical solution is accurate.
