To find the greatest common factor (GCF) of the numbers 84, 112, and 210, we can use the `math.gcd` function from the Python `math` module. However, that function only takes two arguments directly. To get the GCF for more than two numbers, we can iteratively compute it.

First, let's define a function that takes a list of numbers and computes their GCF. We can use the `math.gcd` function in a loop to achieve this.

Here is the step-by-step plan:

1. Import the `math` module.
2. Define a function that takes a list of numbers and computes their GCF by iteratively applying `math.gcd`.
3. Use this function to compute the GCF of the list [84, 112, 210].

Let's implement this in Python:
```python
import math

# List of numbers
numbers = [84, 112, 210]

# Compute the GCF of the list of numbers
def compute_gcf(numbers):
    gcf = numbers[0]
    for num in numbers[1:]:
        gcf = math.gcd(gcf, num)
    return gcf

gcf_result = compute_gcf(numbers)
print(gcf_result)
```
Code execution result: 14

Thus, the greatest common factor of 84, 112, and 210 is \(\boxed{14}\).
