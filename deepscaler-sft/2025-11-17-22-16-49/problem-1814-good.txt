To solve this problem, we need to model it as a graph theory problem. We can represent the attendees at the party as vertices of a graph, and a handshake between two people as an edge connecting two vertices.

1. **Graph Theory Interpretation**:
    - We have 22 vertices (one for each person).
    - Each vertex can be connected to at most 20 other vertices (since each person can shake hands with at most 20 other people).

2. **Maximizing Handshakes**:
    - To maximize the number of handshakes, we want to maximize the number of edges in the graph.
    - A graph where each vertex is connected to 20 other vertices is a 20-regular graph (each vertex has a degree of 20).
    - The maximum number of edges in a 20-regular graph with 22 vertices can be calculated as follows:
      \[
      \text{Number of Edges} = \frac{22 \times 20}{2}
      \]
      Since each edge connects two vertices, we need to divide by 2 to avoid double-counting each edge.

3. **Formulate the Calculation**:
    - We can write some Python code to ensure our calculation is accurate.
Let's compute this step-by-step.
```python
# Number of attendees
num_attendees = 22

# Each person can shake hands with a maximum of 20 other people
max_handshakes_per_person = 20

# Calculate the maximum possible number of handshakes
max_possible_handshakes = (num_attendees * max_handshakes_per_person) // 2
print(max_possible_handshakes)
```
