First, let's identify the problem clearly:

1. A standard 6-sided die has faces numbered from 1 to 6.
2. We need to paint two faces of the die red in such a way that the sum of the numbers on the red faces is not 7.
3. We have to find the number of ways to do this by iterating through all possible pairs of faces and then check if their numbers add up to 7 or not.

First, let's list the pairs of faces and their corresponding numbers:

- Face 1 pairs with faces 2, 3, 4, 5, 6
- Face 2 pairs with faces 1, 3, 4, 5, 6
- Face 3 pairs with faces 1, 2, 4, 5, 6
- Face 4 pairs with faces 1, 2, 3, 5, 6
- Face 5 pairs with faces 1, 2, 3, 4, 6
- Face 6 pairs with faces 1, 2, 3, 4, 5

We need to avoid counting a pair like (1, 6) and (6, 1) separately, because they are the same pair. We just need to ensure that each unique pair is considered only once. Also, note that a face can't be paired with itself, so we should avoid that as well.

We can use Python to check for each pair that their sum is not 7 and then count all such valid pairs.

Let's implement this step-by-step in code:
```python
import itertools

# The numbers on a 6-sided die's faces
faces = [1, 2, 3, 4, 5, 6]

# Get all possible pairs of distinct faces we can paint red
pairs = list(itertools.combinations(faces, 2))

# Now, we need to check which of these pairs have numbers that don't add up to 7
valid_pairs = []

for pair in pairs:
    if pair[0] + pair[1] != 7:
        valid_pairs.append(pair)

# The number of ways to paint two faces red such that the numbers on them don't add up to 7
num_valid_ways = len(valid_pairs)
print(num_valid_ways)
```
Code execution result: 12

Thus, the number of ways to paint two faces of a die red, so that the numbers on the red faces don't add up to 7, is \(\boxed{12}\). This is the final answer.
