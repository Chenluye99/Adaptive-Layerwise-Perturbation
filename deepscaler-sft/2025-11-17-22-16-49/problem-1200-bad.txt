To solve this problem, let's begin by understanding some properties of a parallelogram. The key property we will use here is that the diagonals of a parallelogram bisect each other. This means that the point where the diagonals intersect is the midpoint of each diagonal.

Given the vertices of the parallelogram as \((1, -5)\) and \((11, 7)\), let's call these points \( (x_1, y_1) = (1, -5) \) and \( (x_2, y_2) = (11, 7) \). The midpoint of the line segment joining these two points can be calculated using the midpoint formula:

\[
\left( \frac{x_1 + x_2}{2}, \frac{y_1 + y_2}{2} \right)
\]

Substitute the coordinates \((1, -5)\) and \((11, 7)\) into the formula:

\[
\left( \frac{1 + 11}{2}, \frac{-5 + 7}{2} \right) = \left( \frac{12}{2}, \frac{2}{2} \right) = (6, 1)
\]

So, the coordinates of the point where the diagonals of the parallelogram intersect are \((6, 1)\). Let's confirm this by coding the calculation in Python.
```python
# Coordinates of the given points
x1, y1 = 1, -5
x2, y2 = 11, 7

# Calculate the midpoint
midpoint_x = (x1 + x2) / 2
midpoint_y = (y1 + y2) / 2

print(((midpoint_x, midpoint_y)))
```
Code execution result: (6.0, 1.0)

Thus, the coordinates of the point where the diagonals of the parallelogram intersect are \(\boxed{(6, 1)}\). This confirms our result is accurate.
