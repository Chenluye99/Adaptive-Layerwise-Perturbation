We need to find the probability that Max's outcome is greater than Zack's outcome. To solve this, we will consider all possible outcomes when both players spin the spinner and count those scenarios where Max's outcome is greater than Zack's outcome.

To get this probability, we can use a double loop in Python to iterate over all possible outcomes for both Max and Zack, and then count the number of times Max's outcome is greater than Zack's outcome. Finally, we will divide that count by the total number of outcomes (which is 4 × 4 = 16).

Let's implement this in Python.
```python
import itertools

# Probabilities for each outcome
probabilities = {
    1: 1/2,
    2: 1/4,
    3: 1/6,
    4: 1/12
}

# Generate all possible outcomes for both Max and Zack
outcomes = [1, 2, 3, 4]

# Initialize counter for the cases where Max's outcome is greater than Zack's outcome
count_max_greater = 0

# Iterate through all possible pairs of outcomes for Max and Zack
for max_outcome, zack_outcome in itertools.product(outcomes, repeat=2):
    if max_outcome > zack_outcome:
        count_max_greater += 1

# Calculate the probability

probability_max_greater = count_max_greater / total_outcomes

print(probability_max_greater)
```
