First, let's start by breaking down the problem:

1. We know that there are 160 aliens in total on Planet Q.
2. \(\frac{3}{8}\) of these 160 aliens have 3 eyes. So, we can calculate the number of aliens that have 3 eyes as follows:
   \[
   \text{Number of aliens with 3 eyes} = \frac{3}{8} \times 160
   \]
3. The rest of the aliens have 5 eyes. To find out how many aliens have 5 eyes, we subtract the number of aliens with 3 eyes from the total number of aliens:
   \[
   \text{Number of aliens with 5 eyes} = 160 - \text{Number of aliens with 3 eyes}
   \]
4. To get the total number of eyes, we calculate the contribution of the aliens with 3 eyes and the aliens with 5 eyes separately and then sum them up:
   \[
   \text{Total eyes from aliens with 3 eyes} = \text{Number of aliens with 3 eyes} \times 3
   \]
   \[
   \text{Total eyes from aliens with 5 eyes} = \text{Number of aliens with 5 eyes} \times 5
   \]
   \[
   \text{Total number of eyes} = \text{Total eyes from aliens with 3 eyes} + \text{Total eyes from aliens with 5 eyes}
   \]

Let's go ahead and compute this step-by-step using Python to ensure accuracy.
```python
# Given data
total_aliens = 160
fraction_with_3_eyes = 3 / 8

# Step 1: Calculate the number of aliens with 3 eyes
num_aliens_with_3_eyes = fraction_with_3_eyes * total_aliens

# Step 2: Calculate the number of aliens with 5 eyes
num_aliens_with_5_eyes = total_aliens - num_aliens_with_3_eyes

# Step 3: Calculate the total number of eyes
total_eyes_from_aliens_with_3_eyes = num_aliens_with_3_eyes * 3
total_eyes_from_aliens_with_5_eyes = num_aliens_with_5_eyes * 5

# Step 4: Calculate the total number of eyes on Planet Q
total_number_of_eyes = total_eyes_from_aliens_with_3_eyes + total_eyes_from_aliens_with_5_eyes
```
