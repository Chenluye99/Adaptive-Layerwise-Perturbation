To solve the given problem, we need to analyze and solve the equation \(7 \lfloor x \rfloor + 2 \lceil x \rceil = c\) for different values of \(x\) and then determine for how many values of \(c\) in the interval \([0, 1000]\) this equation holds true.

1. **Understand the Equation:**
    - \(\lfloor x \rfloor\) is the greatest integer less than or equal to \(x\).
    - \(\lceil x \rceil\) is the smallest integer greater than or equal to \(x\).
    - For any real number \(x\), \(\lfloor x \rfloor \leq x < \lfloor x \rfloor + 1\) and \(\lceil x \rceil - 1 < x \leq \lceil x \rceil\). Therefore, \(\lfloor x \rfloor \leq x < \lceil x \rceil\).

2. **Relate \(\lfloor x \rfloor\) and \(\lceil x \rceil\):**
    - If \(\lfloor x \rfloor = n\) (where \(n\) is an integer), then \(n \leq x < n+1\).
    - Consequently, \(\lceil x \rceil = n\) or \(\lceil x \rceil = n+1\).

3. **Set Up the Equation Based on the Cases for \(\lceil x \rceil\):**
    - **Case 1: \(\lceil x \rceil = n\):**
      - Then, \(n \leq x < n+1\) and \(\lceil x \rceil = n\).
      - Substituting into the equation, we get:
        \[
        7 \lfloor x \rfloor + 2 \lceil x \rceil = 7n + 2n = 9n = c.
        \]
        So, \(c = 9n\).
    - **Case 2: \(\lceil x \rceil = n+1\):**
      - Then, \(n < x \leq n+1\) and \(\lceil x \rceil = n+1\).
      - Substituting into the equation, we get:
        \[
        7 \lfloor x \rfloor + 2 \lceil x \rceil = 7n + 2(n+1) = 7n + 2n + 2 = 9n + 2 = c.
        \]
        So, \(c = 9n + 2\).

5. **Determine the Range of \(n\) for Which \(c\) is in \([0, 1000]\):**
