To find John's number, we need to iterate through the numbers between 800 and 2000 and check which of these numbers satisfy all three clues:

1. The number has 125 as a factor.
2. The number is a multiple of 30.
3. The number is between 800 and 2000, inclusive.

First, let's describe the steps in code:

1. Iterate through all numbers from 800 to 2000.
2. Check if the number is a multiple of 125.
3. Check if the number is a multiple of 30.
4. If both conditions are satisfied, that is John's number.

Let's implement this step-by-step in Python:
```python
# Initialize a variable to store John's number
johns_number = None

# Iterate through the numbers between 800 and 2000 (inclusive)
for num in range(800, 2001):
    if num % 125 == 0 and num % 30 == 0:
        johns_number = num
        break  # As soon as we find the number that satisfies all conditions, we can stop the loop

print(johns_number)
```
Code execution result: 1500

Thus, John's number is \(\boxed{1500}\). This is the number that satisfies all three of the given conditions.
