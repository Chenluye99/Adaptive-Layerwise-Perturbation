To solve this problem, we first need to understand and set up the arithmetic sequence formula. The general form of the \(n\)-th term of an arithmetic sequence is given by:

\[a_n = a_1 + (n-1)d\]

where:
- \(a_n\) is the \(n\)-th term of the sequence,
- \(a_1\) is the first term,
- \(d\) is the common difference,
- \(n\) is the term number.

Given:
- The first term \(a_1 = 5\),
- The thirteenth term \(a_{13} = 29\).

Using the formula for the thirteenth term, we have:

\[a_{13} = a_1 + 12d = 29\]

Substitute \(a_1 = 5\) into the equation:

\[5 + 12d = 29\]

Now, solve for \(d\):

\[12d = 29 - 5\]
\[12d = 24\]
\[d = 2\]

Now that we have the common difference \(d = 2\), we can find the fiftieth term \(a_{50}\) using the formula for the \(n\)-th term:

\[a_{50} = a_1 + 49d\]

Substitute \(a_1 = 5\) and \(d = 2\) into the equation:

\[a_{50} = 5 + 49 \cdot 2 = 5 + 98 = 103\]

Let's confirm this by implementing it in Python to ensure the accuracy.
```python
# Given values
a1 = 5

# Calculate the common difference, d

# Calculate the 50th term, a50
n = 50

```
