1. **Understand the Equations:**
    - \(\log_{10} (PQ) + \log_{10} (PS) = 2\)
    - \(\log_{10} (QS) + \log_{10} (QR) = 3\)
    - \(\log_{10} (RP) + \log_{10} (RS) = 5\)

2. **Simplify the Equations Using Logarithm Properties:**
    - Recall that \(\log_{10} (ab) = \log_{10} a + \log_{10} b\).
    - Thus, \(\log_{10} (PQ) = \log_{10} P + \log_{10} Q\) and \(\log_{10} (PS) = \log_{10} P + \log_{10} S\).
    - The first equation becomes: \((\log_{10} P + \log_{10} Q) + (\log_{10} P + \log_{10} S) = 2 \implies 2 \log_{10} P + \log_{10} Q + \log_{10} S = 2\).
    - Similarly, \(\log_{10} (QS) = \log_{10} Q + \log_{10} S\) and \(\log_{10} (QR) = \log_{10} Q + \log_{10} R\), so the second equation becomes: \((\log_{10} Q + \log_{10} S) + (\log_{10} Q + \log_{10} R) = 3 \implies 2 \log_{10} Q + \log_{10} S + \log_{10} R = 3\).
    - And, \(\log_{10} (RP) = \log_{10} R + \log_{10} P\) and \(\log_{10} (RS) = \log_{10} R + \log_{10} S\), so the third equation becomes: \((\log_{10} R + \log_{10} P) + (\log_{10} R + \log_{10} S) = 5 \implies 2 \log_{10} R + \log_{10} P + \log_{10} S = 5\).

3. **Set Up the System of Equations:**
    - Let's set \( \log_{10} P = a \), \( \log_{10} Q = b \), \( \log_{10} R = c \), and \( \log_{10} S = d \).
    - The system of equations becomes:
      \[
      \begin{cases}
      2a + b + d = 2, \\
      2b + c + d = 3, \\
      2c + a + d = 5.
      \end{cases}
      \]

4. **Solve the System of Equations:**
    - We can solve this system step-by-step or by using a tool like Python to get the values of \(a, b, c, d\).
