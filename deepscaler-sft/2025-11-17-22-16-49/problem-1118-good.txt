To solve the problem, let's start by understanding the given series. The series is \(1 + 2x + 3x^2 + 4x^3 + \dotsb\).

This is an arithmetico-geometric series. To find the sum of this series, we can use the following approach:

1. Let the sum of the series be \(S\):
   \[
   S = 1 + 2x + 3x^2 + 4x^3 + \dotsb
   \]

2. Multiply \(S\) by \(x\):
   \[
   xS = x + 2x^2 + 3x^3 + 4x^4 + \dotsb
   \]

3. Subtract the second equation from the first:
   \[
   S - xS = (1 + 2x + 3x^2 + 4x^3 + \dotsb) - (x + 2x^2 + 3x^3 + 4x^4 + \dotsb)
   \]
   This simplifies to:
   \[
   S(1 - x) = 1 + x + x^2 + x^3 + \dotsb
   \]

4. The right-hand side of the equation is an infinite geometric series with the first term 1 and common ratio \(x\). The sum of this geometric series is \(\frac{1}{1 - x}\) for \(|x| < 1\):
   \[
   S(1 - x) = \frac{1}{1 - x}
   \]

5. Solving for \(S\):
   \[
   S = \frac{1}{(1 - x)^2}
   \]

We are given that the sum of this series is 9, so we can set up the equation:
   \[
   \frac{1}{(1 - x)^2} = 9
   \]

6. Take the square root of both sides:
   \[
   \frac{1}{1 - x} = 3 \quad \text{or} \quad \frac{1}{1 - x} = -3
   \]

7. Solving these equations for \(x\):
   \[
   1 - x = \frac{1}{3} \quad \text{or} \quad 1 - x = -\frac{1}{3}
   \]

   This gives us two potential solutions:
   \[
   1 - x = \frac{1}{3} \implies x = 1 - \frac{1}{3} = \frac{2}{3}
   \]
   \[
   1 - x = -\frac{1}{3} \implies x = 1 + \frac{1}{3} = \frac{4}{3}
   \]

Since the series \(1 + 2x + 3x^2 + 4x^3 + \dotsb\) converges only for \(|x| < 1\), we must have \(| \frac{4}{3} | \geq 1\), so \(\frac{4}{3}\) is not a valid solution because it is not in the interval of convergence. Therefore, the only valid solution is:
   \[
   x = \frac{2}{3}
   \]
