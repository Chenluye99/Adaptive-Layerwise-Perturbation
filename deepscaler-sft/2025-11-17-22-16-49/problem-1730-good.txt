To solve this problem, let's start by setting up the equations based on the information given.

1. **Formulate the Problem Mathematically:**
    - Let the radius of the cylinder be \( r \).
    - The height of the cylinder is then \( 2.5r \).
    - The surface area \( S \) of a cylinder is given by the formula:
      \[
      S = 2\pi r^2 + 2\pi r h
      \]
    - Substituting \( h = 2.5r \) into the formula, we get:
      \[
      S = 2\pi r^2 + 2\pi r (2.5r) = 2\pi r^2 + 5\pi r^2 = 7\pi r^2
      \]
    - We are given that the surface area of the cylinder is \( 112\pi \) square centimeters. So we can set up the equation:
      \[
      7\pi r^2 = 112\pi
      \]
    - We can cancel \(\pi\) from both sides of the equation:
      \[
      7 r^2 = 112
      \]
    - Divide both sides by 7:
      \[
      r^2 = 16
      \]
    - Taking the square root of both sides, we get:
      \[
      r = \sqrt{16} = 4
      \]

2. **Implement the Solution in Python to Verify:**
Let's write the Python code to verify this result.
```python
import sympy as sp

# Define the variable
r = sp.symbols('r', positive=True)

# Set up the equation based on the problem statement
equation = 7 * sp.pi * r**2 - 112 * sp.pi

# Solve the equation for r
solution = sp.solve(equation, r)

print(solution)
```
Code execution result: [4]

Thus, the solution obtained from solving the equation is \( r = 4 \). Therefore, the radius of the cylinder is \(\boxed{4}\) centimeters. This confirms that our solution is correct.
