To solve this problem, we need to determine when the height \( y \) of the ball is 0, because that will be the moment when the ball hits the ground. The equation given is:

\[ y = -16t^2 + 22t + 45 \]

We set \( y = 0 \) to find the time \( t \) when the ball hits the ground:

\[ -16t^2 + 22t + 45 = 0 \]

This is a quadratic equation of the form \( at^2 + bt + c = 0 \), where \( a = -16 \), \( b = 22 \), and \( c = 45 \). We can solve this quadratic equation using the quadratic formula:

\[ t = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} \]

Let's substitute \( a \), \( b \), and \( c \) into the quadratic formula:

\[ t = \frac{-22 \pm \sqrt{22^2 - 4(-16)(45)}}{2(-16)} \]

First, calculate the discriminant:

\[ \Delta = 22^2 - 4(-16)(45) = 484 + 2880 = 3364 \]

Next, take the square root of the discriminant:

\[ \sqrt{3364} = 58 \]

Now substitute back into the quadratic formula:

\[ t = \frac{-22 \pm 58}{-32} \]

This gives us two potential solutions:

\[ t_1 = \frac{-22 + 58}{-32} = \frac{36}{-32} = -\frac{9}{8} \]
\[ t_2 = \frac{-22 - 58}{-32} = \frac{-80}{-32} = \frac{5}{2} \]

Since time \( t \) cannot be negative, we discard \( t_1 = -\frac{9}{8} \). Therefore, the only valid solution is:

\[ t = \frac{5}{2} \]
