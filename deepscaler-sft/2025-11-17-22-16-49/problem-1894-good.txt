To solve this problem, we need to determine the probability that the numbers rolled on two standard 6-sided dice are relatively prime. Two numbers are relatively prime if their greatest common divisor (GCD) is 1.

We can follow these steps:

1. **Enumerate All Possible Outcomes:**
   - A pair of 6-sided dice has 6 × 6 = 36 possible outcomes.

2. **Check for Relative Primality:**
   - For each of these 36 outcomes, check if the two numbers are relatively prime by using the `math.gcd` function to determine if their GCD is 1.

3. **Count Favorable Outcomes:**
   - Count how many of these outcomes have a GCD of 1.

4. **Calculate the Probability:**
   - The probability is the number of favorable outcomes divided by the total number of outcomes (36).

Let's implement this step by step using Python.
```python
import math

# Initialize a counter for the number of outcomes where the two numbers are relatively prime
rel_prime_count = 0

# Iterate through all possible outcomes of rolling two 6-sided dice
for i in range(1, 7):
    for j in range(1, 7):
        if math.gcd(i, j) == 1:
            rel_prime_count += 1

# Total possible outcomes when rolling two 6-sided dice
total_outcomes = 6 * 6

# Calculate the probability
probability = rel_prime_count / total_outcomes

print(((probability, rel_prime_count, total_outcomes)))
```
Code execution result: (0.6388888888888888, 23, 36)

This means that out of the 36 possible outcomes, there are 23 pairs of numbers that are relatively prime. Therefore, the probability that the two numbers rolled are relatively prime is \(\frac{23}{36}\).

So, the final answer is:

\(\boxed{\frac{23}{36}}\)
