Given the polynomial $P(x) = 6x^4 - 14x^3 - 4x^2 + 2x - 26$, we need to find the remainder when it is divided by $2x - 6$.

To solve this problem, we can use polynomial long division, but a more efficient method in this context is to use the Remainder Theorem for polynomials, which states that the remainder of the division of a polynomial \(P(x)\) by a linear divisor \(x - c\) is \(P(c)\).

For a divisor of the form \(2x - 6\), we can rewrite it as \(2(x - 3)\). This means we can substitute \(x = 3\) into the polynomial \(P(x)\) and find the value, because the remainder when \(P(x)\) is divided by \(2x - 6\) will be the same as the remainder when \(P(3)\) is evaluated, considering the factor 2.

Let's substitute \(x = 3\) into \(P(x)\):

\[ P(3) = 6(3)^4 - 14(3)^3 - 4(3)^2 + 2(3) - 26 \]

We will compute this step-by-step using Python to ensure accuracy.
```python
import sympy as sp

# Define the polynomial P(x)
x = sp.symbols('x')
P = 6*x**4 - 14*x**3 - 4*x**2 + 2*x - 26

# Substitute x = 3 into the polynomial
remainder = P.subs(x, 3)
print(remainder)
```
Code execution result: 52

Thus, the remainder when \(6x^4 - 14x^3 - 4x^2 + 2x - 26\) is divided by \(2x - 6\) is \(\boxed{52}\). This is our final answer.
