To solve this problem, let's start by understanding and outlining the conditions:

1. We have a set of integers from 1 to 2009.
2. We need to choose \( k \) pairs \(\{a_i, b_i\}\) from this set, where \( a_i < b_i \) and no two pairs share a common element.
3. The sums \( a_i + b_i \) for each pair must be distinct and each sum must be less than or equal to 2009.

To solve this problem, we want to find the maximum possible value of \( k \). 

First, we should realize that if we choose a pair \(\{a_i, b_i\}\) with \( a_i + b_i = s \), then we must ensure that no other pair in our selection can have the same sum \( s \).

A straightforward approach is to systematically construct such pairs in a way that maximizes \( k \). We'll start by selecting pairs in increasing order of their sums, ensuring that the constraints about distinct sums and no common elements between pairs are satisfied.

Let's implement this step-by-step using Python. We can use a greedy algorithm to build such a set of pairs, starting from the smallest possible sums and ensuring no conflicts.

We will implement this as follows:

1. Initialize an empty list to keep track of chosen pairs.
2. Iterate through each number from 1 to 2009 and check if it can be paired with another number such that the conditions are satisfied.
3. For each valid pair \(\{a_i, b_i\}\), check if adding this pair to our list of chosen pairs results in a conflict (either the numbers are reused or the sum is not distinct).
4. Continue this process until it is no longer possible to add another valid pair while maintaining the conditions.

Let's implement this in Python.
```python
# Initialize a set for the numbers that have been used
used_numbers = set()

# Initialize a list to store the pairs
pairs = []

# Initialize a counter for the number of pairs we can form
k = 0

# Iterate through each number and try to form pairs
for num1 in range(1, 2010):
    for num2 in range(num1 + 1, 2010):
        if num1 not in used_numbers and num2 not in used_numbers:
            if (num1 + num2) <= 2009:
                if all((num1 + num2) != (x + y) for (x, y) in pairs):
                    pairs.append((num1, num2))
                    used_numbers.add(num1)
                    used_numbers.add(num2)
                    k += 1

print(k)
```
