Let's solve the problem step-by-step using a combination of logical reasoning and Python code.

1. **Understand the Problem:**
    - There are 20 players in total.
    - All 20 players are taking at least one of biology or chemistry.
    - There are 8 players taking biology.
    - There are 4 players taking both biology and chemistry.

2. **Use the Principle of Inclusion and Exclusion:**
    - Let \( B \) be the set of players taking biology.
    - Let \( C \) be the set of players taking chemistry.
    - We need to find the number of players taking chemistry, i.e., \( |C| \).

    Using the principle of inclusion and exclusion, we have:
    \[
    |B \cup C| = |B| + |C| - |B \cap C|
    \]
    Where:
    - \( |B \cup C| = 20 \) (since all 20 players are taking at least one of the two subjects)
    - \( |B| = 8 \) (players taking biology)
    - \( |B \cap C| = 4 \) (players taking both biology and chemistry)

    Substituting these values into the equation, we get:
    \[
    20 = 8 + |C| - 4
    \]

3. **Solve for \( |C| \):**
    - Simplify the equation to solve for \( |C| \):
    \[
    20 = 4 + |C| \implies |C| = 20 - 4 = 16
    \]

So, the number of players taking chemistry is 16. Let's confirm this with Python code.
```python
# Given values
total_players = 20
players_biology = 8
players_both = 4

# Using the inclusion-exclusion principle formula to find players taking chemistry
players_chemistry = total_players - players_biology + players_both

print(players_chemistry)
```
Code execution result: 16

Thus, the number of players taking chemistry is \(\boxed{16}\). This confirms our solution is accurate.
