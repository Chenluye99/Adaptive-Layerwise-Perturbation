To solve this problem, we need to determine the side length of the square using the coordinates of the given vertices, and then compute the area of the square.

1. **Calculate the Distance Between the Given Points:**
   The distance between the points \((-1, 4)\) and \((2, -3)\) is the length of one of the sides of the square or the length of the diagonal, depending on the arrangement of the points.

   The formula to calculate the distance between two points \((x_1, y_1)\) and \((x_2, y_2)\) is:
   \[
   \text{Distance} = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}
   \]
   Substituting \((-1, 4)\) and \((2, -3)\) into the formula, we get:
   \[
   \text{Distance} = \sqrt{(2 - (-1))^2 + (-3 - 4)^2} = \sqrt{(2 + 1)^2 + (-3 - 4)^2} = \sqrt{3^2 + (-7)^2} = \sqrt{9 + 49} = \sqrt{58}
   \]

2. **Determine if This Distance is the Side Length or the Diagonal:**
   The distance calculated above, \(\sqrt{58}\), could either be the side length of the square or the length of the diagonal of the square. To determine which it is, we need to consider the properties of a square. The length of the diagonal of a square with side length \(s\) is given by \(s \sqrt{2}\). Hence, if \(\sqrt{58}\) is the side length of the square, then it should be equal to \(s\), but if it's the diagonal, it should be equal to \(s \sqrt{2}\).

   Let's check both possibilities:
   - If \(\sqrt{58} = s\), then the side length of the square would be \(\sqrt{58}\).
   - If \(\sqrt{58} = s \sqrt{2}\), then the side length of the square would be \(\frac{\sqrt{58}}{\sqrt{2}} = \sqrt{\frac{58}{2}} = \sqrt{29}\).

   We can verify which of these is correct by checking if \((\sqrt{29})^2 \cdot 2 = 58\) because the square of the diagonal of a square with side length \(s\) is \(s^2 \cdot 2\).

   Let's check both possibilities by squaring them:
   - If \( s = \sqrt{58} \), then the area of the square would be \( (\sqrt{58})^2 = 58 \).
   - If \( s = \sqrt{29} \), then the area of the square would be \( (\sqrt{29})^2 = 29 \), and the length of the diagonal would be \( \sqrt{29} \cdot \sqrt{2} = \sqrt{58} \), which matches our earlier calculation.

   Since the length of the diagonal of a square is \( s \sqrt{2} \), and we know that the distance between the points \((-1, 4)\) and \((2, -3)\) is \(\sqrt{58}\), we can set up the equation:
   \[
   s \sqrt{2} = \sqrt{58}
   \]
   Solving for \( s \):
   \[
   s = \frac{\sqrt{58}}{\sqrt{2}} = \sqrt{\frac{58}{2}} = \sqrt{29}
   \]
   The side length of the square is \(\sqrt{29}\), and the area of the square is \( s^2 = (\sqrt{29})^2 = 29 \).

3. **Conclusion:**
   The area of the square is \(\boxed{29}\). We can confirm this by coding the solution in Python to ensure accuracy.
```python
import sympy as sp

# Coordinates of the points
x1, y1 = -1, 4
x2, y2 = 2, -3

# Calculate the distance between the points
distance = sp.sqrt((x2 - x1)**2 + (y2 - y1)**2)

# The side length 's' of the square can be derived from the relationship
# Distance = s * sqrt(2) if it's the diagonal of the square, thus
# s = Distance / sqrt(2) = sqrt(58) / sqrt(2) = sqrt(29)
side_length = distance / sp.sqrt(2)

# Calculate the area of the square
area_of_square = side_length ** 2
print(area_of_square)
```
