First, let's start by understanding the problem: We need to find how many integer values of \(a\) make the quadratic equation \(x^2 + ax + 12a = 0\) have integer solutions for \(x\).

For the quadratic equation \(x^2 + ax + 12a = 0\) to have integer solutions, its roots, say \(r_1\) and \(r_2\), must satisfy both Vieta's formulas:
1. \( r_1 + r_2 = -a \)
2. \( r_1 \cdot r_2 = 12a \)

From the second equation, we get:
\[ r_1 \cdot r_2 = 12a \implies a = \frac{r_1 \cdot r_2}{12} \]

For \(a\) to be an integer, \(\frac{r_1 \cdot r_2}{12}\) must be an integer, meaning \(r_1 \cdot r_2\) must be divisible by 12. 

We will iterate through all pairs of integers \((r_1, r_2)\) and check whether \(\frac{r_1 \cdot r_2}{12}\) is an integer. For each valid pair, we will get a corresponding value for \(a\) and ensure that this value of \(a\) results in integer solutions for the quadratic equation.

We can iterate over a reasonable range for \(r_1\) and \(r_2\) because, in a quadratic equation, the roots typically aren't too large or too small in practical scenarios like this unless otherwise stated. We can test plausible ranges and check accordingly.

Let's write the code to find all such integer values of \(a\).
```python
import sympy as sp

# Initialize a set to store unique values of 'a'
a_values = set()

# We will test a reasonable range for the roots r1 and r2, say from -100 to 100, because larger values would likely make the product not divisible by 12 or just not typical for such equations.
for r1 in range(-100, 101):
    for r2 in range(-100, 101):
        product = r1 * r2
        if product % 12 == 0:
            a = product // 12
            # Now, check if r1 and r2 are indeed solutions to the quadratic equation x^2 + ax + 12a = 0
            if r1 + r2 == -a and r1 * r2 == 12 * a:
                a_values.add(a)

# Get the distinct values of 'a' and their count
distinct_a_values = list(set(a_values))
num_distinct_a_values = len(distinct_a_values)
print(num_distinct_a_values)
```

Thus, the number of integer values of \(a\) that make the equation \(x^2 + ax + 12a = 0\) have integer solutions for \(x\) is \(\boxed{14}\).
