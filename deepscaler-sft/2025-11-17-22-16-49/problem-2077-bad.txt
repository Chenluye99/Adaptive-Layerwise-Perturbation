First, let's start by using the concept that the slope between any two points on a line is constant. 

Given three points \((-1, 6)\), \((6, k)\), and \((20, 3)\), we can set up equations based on the fact that the slope between \((-1, 6)\) and \((6, k)\) is the same as the slope between \((-1, 6)\) and \((20, 3)\).

The formula for the slope between two points \((x_1, y_1)\) and \((x_2, y_2)\) is given by:

\[
\text{slope} = \frac{y_2 - y_1}{x_2 - x_1}
\]

First, we calculate the slope between \((-1, 6)\) and \((20, 3)\):

\[
\text{slope}_{1} = \frac{3 - 6}{20 - (-1)} = \frac{3 - 6}{20 + 1} = \frac{-3}{21} = -\frac{1}{7}
\]

Next, we calculate the slope between \((-1, 6)\) and \((6, k)\):

\[
\text{slope}_{2} = \frac{k - 6}{6 - (-1)} = \frac{k - 6}{6 + 1} = \frac{k - 6}{7}
\]

Since these points lie on the same line, their slopes must be equal:

\[
\text{slope}_{1} = \text{slope}_{2} \implies -\frac{1}{7} = \frac{k - 6}{7}
\]

Now, we solve for \( k \):

\[
-\frac{1}{7} = \frac{k - 6}{7}
\]

By cross-multiplying or simply multiplying both sides by 7, we get:

\[
-1 = k - 6
\]

Then, adding 6 to both sides:

\[
k = 5
\]

Let's confirm this by coding it to ensure our answer is accurate.
```python
from sympy import symbols, Eq, solve

# Define the variables
k = symbols('k')

# Coordinates of the points
x1, y1 = -1, 6
x2, y2 = 6, k
x3, y3 = 20, 3

# Calculate the slopes and set them equal to each other
slope1 = (y3 - y1) / (x3 - x1)
slope2 = (y2 - y1) / (x2 - x1)

# Set up the equation
equation = Eq(slope1, slope2)

# Solve for k
solution = solve(equation, k)[0]
print(solution)
```
