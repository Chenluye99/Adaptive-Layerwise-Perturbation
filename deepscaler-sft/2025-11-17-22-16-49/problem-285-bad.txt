To solve the problem, let's start by setting up the coordinates for the points \(A, B, C,\) and \(G\):

1. **Setting up Coordinates:**
    - Place point \(B\) at \((0, 0)\) and point \(C\) at \((\sqrt{2}, 0)\).
    - Place point \(A\) at \((x, y)\).

2. **Find Centroid \(G\):**
    - The centroid \(G\) of \(\triangle ABC\) is given by:
      \[
      G = \left( \frac{x + 0 + \sqrt{2}}{3}, \frac{y + 0 + 0}{3} \right) = \left( \frac{x + \sqrt{2}}{3}, \frac{y}{3} \right)
      \]

3. **Conditions Given:**
    - \(BG \perp CG \): The dot product of the vectors \(\overrightarrow{BG}\) and \(\overrightarrow{CG}\) is zero.
      \[
      \overrightarrow{BG} = \left( \frac{x + \sqrt{2}}{3}, \frac{y}{3} \right)
      \]
      \[
      \overrightarrow{CG} = \left( \frac{x + \sqrt{2}}{3} - \sqrt{2}, \frac{y}{3} \right) = \left( \frac{x + \sqrt{2} - 3\sqrt{2}}{3}, \frac{y}{3} \right) = \left( \frac{x - 2\sqrt{2}}{3}, \frac{y}{3} \right)
      \]
      The dot product of \(\overrightarrow{BG}\) and \(\overrightarrow{CG}\) is:
      \[
      \left( \frac{x + \sqrt{2}}{3} \right) \cdot \left( \frac{x - 2\sqrt{2}}{3} \right) + \left( \frac{y}{3} \right) \cdot \left( \frac{y}{3} \right) = 0
      \]
      \[
      \frac{(x + \sqrt{2})(x - 2\sqrt{2}) + y^2}{9} = 0 \implies (x + \sqrt{2})(x - 2\sqrt{2}) + y^2 = 0
      \]
      \[
      x^2 - 2\sqrt{2}x + \sqrt{2}x - 2 \cdot 2 + y^2 = 0 \implies x^2 - \sqrt{2}x - 2 + y^2 = 0
      \]

4. **Distance Constraints:**
    - We know that \( BC = \sqrt{2} \), so this condition is already satisfied by our placement of points \( B \) and \( C \).
    - We want to maximize \( AB + AC \). The distances \( AB \) and \( AC \) can be expressed as:
      \[
      AB = \sqrt{(x - 0)^2 + (y - 0)^2} = \sqrt{x^2 + y^2}
      \]
      \[
      AC = \sqrt{(x - \sqrt{2})^2 + (y - 0)^2} = \sqrt{(x - \sqrt{2})^2 + y^2}
      \]
      Therefore, we need to maximize:
      \[
      f(x, y) = \sqrt{x^2 + y^2} + \sqrt{(x - \sqrt{2})^2 + y^2}
      \]
      Under the constraint:
      \[
      x^2 - \sqrt{2}x - 2 + y^2 = 0
      \]

Let's solve this problem programmatically using Python.
```python
import sympy as sp

# Define the variables
x, y = sp.symbols('x y', real=True, positive=True)

# Define the constraint equation
constraint = x**2 - sp.sqrt(2)*x - 2 + y**2

# Define the function to maximize: AB + AC
f = sp.sqrt(x**2 + y**2) + sp.sqrt((x - sp.sqrt(2))**2 + y**2)

# Use Lagrange multipliers to find the maximum value
lambda_ = sp.symbols('lambda')
L = f - lambda_ * constraint

# Take the partial derivatives
partial_x = sp.diff(L, x)
partial_y = sp.diff(L, y)
partial_lambda = sp.diff(L, lambda_)

# Solve the system of equations given by setting the partial derivatives to 0
solutions = sp.solve([partial_x, partial_y, partial_lambda], (x, y, lambda_))

# Find the maximum value of f for valid solutions
max_value = 0
for sol in solutions:
    x_val, y_val, lambda_val = sol
    if x_val.is_real and y_val.is_real and x_val > 0 and y_val > 0:
        value = f.subs({x: x_val, y: y_val})
        if value > max_value:
            max_value = value

print(max_value)
```

We can employ the `scipy.optimize` library to solve this optimization problem. We will use the `minimize` function from `scipy.optimize` to solve this problem by minimizing the negative of the function (since `minimize` attempts to minimize the objective function, we will minimize the negative of \( \sqrt{x^2 + y^2} + \sqrt{(x - \sqrt{2})^2 + y^2} \) to get its maximum).

Let's set this up in code.
```python
import numpy as np
from scipy.optimize import minimize

# Define the function to maximize: -(AB + AC)
def objective(vars):
    x, y = vars
    return -(np.sqrt(x**2 + y**2) + np.sqrt((x - np.sqrt(2))**2 + y**2))

# Define the constraint: x^2 - sqrt(2)*x - 2 + y^2 = 0
def constraint(vars):
    x, y = vars
    return x**2 - np.sqrt(2)*x - 2 + y**2

# Initial guess for (x, y)
initial_guess = [1, 1]

# Define bounds for x and y (they should be real numbers but we will keep them reasonably unbounded)
bounds = [(-10, 10), (-10, 10)]

# Define the constraint in the form required by `minimize`
cons = ({'type': 'eq', 'fun': constraint})

# Perform the optimization
solution = minimize(objective, initial_guess, bounds=bounds, constraints=cons)

# Get the maximum value of AB + AC by taking the negative of the minimized negative value
max_value = -solution.fun
print(max_value)
```
