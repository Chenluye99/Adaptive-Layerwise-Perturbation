To solve this problem, we need to find the smallest positive integer \( x \) that satisfies all of the given conditions simultaneously. These conditions can be stated as:

1. When divided by 2, the remainder is 1: \( x \equiv 1 \pmod{2} \)
2. When divided by 3, the remainder is 2: \( x \equiv 2 \pmod{3} \)
3. When divided by 4, the remainder is 3: \( x \equiv 3 \pmod{4} \)
4. When divided by 5, the remainder is 4: \( x \equiv 4 \pmod{5} \)

We can observe that each of these congruences can be rewritten in a more uniform form by noting that \( x \) is one less than a multiple of the respective divisor:

1. \( x \equiv 1 \pmod{2} \) can be written as \( x = 2k + 1 \) for some integer \( k \), which means \( x \) is an odd number.
2. \( x \equiv 2 \pmod{3} \) can be written as \( x = 3m + 2 \) for some integer \( m \).
3. \( x \equiv 3 \pmod{4} \) can be written as \( x = 4n + 3 \) for some integer \( n \).
4. \( x \equiv 4 \pmod{5} \) can be written as \( x = 5p + 4 \) for some integer \( p \).

We can solve this system of congruences using the method of iteration or using the Chinese Remainder Theorem (if all the moduli are pairwise coprime, which is not the case here as 2, 3, 4, and 5 are not pairwise coprime, but we can still solve it by brute force). We will implement this using a Python script to iterate through the positive integers and check which is the smallest number that meets all the conditions.
```python
# We will iterate through the positive integers and check for each condition.

def find_special_number():
    x = 1
    while True:
        if (x % 2 == 1) and (x % 3 == 2) and (x % 4 == 3) and (x % 5 == 4):
            return x
        x += 1

special_number = find_special_number()
print(special_number)
```
Code execution result: 59

Thus, the least positive integer that satisfies all the given conditions is \(\boxed{59}\). This is our final answer.
