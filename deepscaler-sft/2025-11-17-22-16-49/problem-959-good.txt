To solve this problem, we will follow these steps:

1. **Understand and Manipulate the Given Equation:**
    \[
    \frac{x + y}{x - y} + \frac{x - y}{x + y} = 1
    \]
   - Let us set \( a = \frac{x + y}{x - y} \) and \( b = \frac{x - y}{x + y} \). Then, we have \( a + b = 1 \) and \( ab = \frac{(x + y)(x - y)}{(x - y)(x + y)} = 1 \).

2. **Formulate a Relationship Between \(x\) and \(y\):**
   - Substitute and solve for \(x\) and \(y\):
     \[
     a \cdot b = \left( \frac{x + y}{x - y} \right) \cdot \left( \frac{x - y}{x + y} \right) = 1
     \]
     This is consistent, but we'll need another equation or condition to solve for \(x\) and \(y\) more precisely. Observe that:
     \[
     a + b = 1
     \]
     Substituting \( b = \frac{1}{a} \) into the above condition gives:
     \[
     a + \frac{1}{a} = 1
     \]
     Multiplying through by \(a\) gives:
     \[
     a^2 + 1 = a \implies a^2 - a + 1 = 0
     \]
     Solving this quadratic equation:
     \[
     a = \frac{1 \pm \sqrt{1 - 4}}{2} = \frac{1 \pm \sqrt{-3}}{2} = \frac{1 \pm i \sqrt{3}}{2}
     \]
     Therefore, \( a \) and \( b \) are complex numbers. Let's denote these roots as \( \omega = \frac{1 + i \sqrt{3}}{2} \) (a primitive third root of unity) and its conjugate \( \omega^2 = \frac{1 - i \sqrt{3}}{2} \), because:
     \[
     \omega + \omega^2 = 1 \quad \text{and} \quad \omega \cdot \omega^2 = 1
     \]

3. **Relate Back to the Desired Expression:**
    We need to find:
    \[
    \frac{x^4 + y^4}{x^4 - y^4} + \frac{x^4 - y^4}{x^4 + y^4}
    \]
   - Let us set \( u = \frac{x^4 + y^4}{x^4 - y^4} \) and \( v = \frac{x^4 - y^4}{x^4 + y^4} \). Then, we have \( u + v = \frac{x^4 + y^4}{x^4 - y^4} + \frac{x^4 - y^4}{x^4 + y^4} \).

4. **Leverage SymPy to Solve and Simplify:**
   - We will use symbolic computation with `sympy` to solve for \(x\) and \(y\) and then evaluate the desired expression.
```python
import sympy as sp

# Define variables
x, y = sp.symbols('x y', complex=True)

# Define the equation given in the problem
eq = ( (x + y) / (x - y) ) + ( (x - y) / (x + y) ) - 1

# Solve the equation for x and y
solution = sp.solve(eq, (x, y))

# Define the expression we want to find
expression = ( (x**4 + y**4) / (x**4 - y**4) ) + ( (x**4 - y**4) / (x**4 + y**4) )

# Evaluate the expression for the solutions of the equation
results = []
for sol in solution:
    try:
        expr_value = expression.subs({x: sol[0], y: sol[1]})
        results.append(expr_value)
    except:
        continue

# Return the results
print(results)
```
