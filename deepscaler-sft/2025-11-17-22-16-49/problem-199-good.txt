First, let's set up the problem with some variables and equations.

1. Let's say there are \( c \) chairs and one table in the clubroom.
2. Each chair has 4 legs, so the total number of legs from the chairs is \( 4c \).
3. The table has 3 legs.
4. The total number of legs initially in the room is \( 4c + 3 \).
5. When scouts come into the clubroom, each occupies a chair. So, if there are \( s \) scouts, they will each sit on one of the chairs, and only \( s \) chairs out of the \( c \) chairs will be occupied.
6. Since there are 2 unoccupied chairs, the number of scouts \( s \) is equal to the number of occupied chairs, so \( s = c - 2 \).
7. Every scout has 2 legs, so the total number of legs from the scouts is \( 2s \).
8. The total number of legs in the room when the scouts are present is the sum of the legs of the chairs, the legs of the table, and the legs of the scouts. This gives us the equation: 
\[ 4c + 3 + 2s = 101. \]

9. Substitute \( s = c - 2 \) into the above equation:
\[ 4c + 3 + 2(c - 2) = 101. \]

10. Simplify and solve for \( c \):
\[ 4c + 3 + 2c - 4 = 101, \]
\[ 6c - 1 = 101, \]
\[ 6c = 102, \]
\[ c = 17. \]

Hence, the number of chairs in the clubroom is 17. Let's use Python to verify this solution.
