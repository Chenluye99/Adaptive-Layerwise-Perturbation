Given the quadratic function \( f(x) = ax^2 + bx + c \):

1. **Zeros of the Function:**
   The zeros of the function (roots of the equation \(ax^2 + bx + c = 0\)) can be found using the quadratic formula:
   \[
   x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
   \]
   Let the zeros be \(\alpha\) and \(\beta\). By Vieta's formulas, we have:
   \[
   \alpha + \beta = -\frac{b}{a} \quad \text{(Sum of the zeros)}
   \]
   \[
   \alpha \beta = \frac{c}{a} \quad \text{(Product of the zeros)}
   \]

2. **Sum and Product Conditions:**
   We are given that the sum of the zeros, the product of the zeros, and the sum of the coefficients of the function are equal. The sum of the coefficients of \( f(x) = ax^2 + bx + c \) is:
   \[
   a + b + c
   \]
   Therefore, we have:
   \[
   \alpha + \beta = \alpha \beta = a + b + c
   \]
   Substituting Vieta's formulas, this becomes:
   \[
   -\frac{b}{a} = \frac{c}{a} = a + b + c
   \]
