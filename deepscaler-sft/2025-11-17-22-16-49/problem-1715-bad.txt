To solve this problem, we need to follow these steps:

1. **Find all the two-digit prime numbers less than 40.**
    - The two-digit prime numbers less than 40 are: 11, 13, 17, 19, 23, 29, 31, 37.

2. **Generate all possible four-digit combinations of these two-digit primes.**
    - We need to consider all pairs of these primes and check if combining them forms a valid four-digit number (i.e., it should be in the range 1000 to 9999).
    - For each pair (formed by concatenating the two primes), form a four-digit number and ensure that the digits of the four-digit number are valid digits (i.e., 0 through 9, but in this context, we only need to ensure that no zeroes are used and check that the formed number by concatenating two primes is a valid house number).

3. **Check for distinct digits condition.**
    - Ensure that the four-digit number formed by concatenating the two primes has no zeroes and that all digits are valid (i.e., between 1 and 9).

4. **Count the valid combinations.**
    - Count how many such four-digit numbers meet the criteria described above.

Let's write the Python code to perform the above steps and get the solution.
```python
from sympy import isprime

# Step 1: Find all two-digit prime numbers less than 40
two_digit_primes = [num for num in range(10, 40) if isprime(num)]

# Step 2 and 3: Generate and validate four-digit house numbers
house_numbers = []

for prime1 in two_digit_primes:
    for prime2 in two_digit_primes:
        # Concatenate the two primes to form a four-digit number
        str_num = f"{prime1}{prime2}"
        num = int(str_num)
        
        # Step 4: Check if the resulting number is a valid house number
        if 1000 <= num <= 9999:
            str_num = str(num)
            has_zero = '0' in str_num
            
            # Ensure no digit is 0
            if not has_zero:
                house_numbers.append(num)

# Step 4: Remove duplicates and get unique house numbers
unique_house_numbers = set(house_numbers)

# Get the count of such house numbers
num_possible_house_numbers = len(unique_house_numbers)
print(num_possible_house_numbers)
```
