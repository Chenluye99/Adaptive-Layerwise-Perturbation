\[x^3 + 3x^2 \sqrt{2} + 7x + (2 \sqrt{2} + \sqrt{2}) = 0\]

\[x^3 + 3x^2 \sqrt{2} + 7x + 3 \sqrt{2} = 0\]

```python
import sympy as sp

# Define the variable
x = sp.symbols('x')

# Define the equation
equation = x**3 + 3*x**2 * sp.sqrt(2) + 7*x + 3 * sp.sqrt(2)

# Solve the equation
```
