To solve for \(A\) and \(B\) in the given equation

\[
\frac{3x+5}{x^2 - x - 42} = \frac{A}{x-7} + \frac{B}{x+6},
\]

we start by factoring the denominator on the left-hand side:

\[ x^2 - x - 42 = (x - 7)(x + 6). \]

This allows us to rewrite the original equation as:

\[
\frac{3x+5}{(x-7)(x+6)} = \frac{A}{x-7} + \frac{B}{x+6}.
\]

Next, we combine the right-hand side over a common denominator:

\[
\frac{A}{x-7} + \frac{B}{x+6} = \frac{A(x+6) + B(x-7)}{(x-7)(x+6)}.
\]

Since the denominators are the same, we can equate the numerators:

\[
3x + 5 = A(x + 6) + B(x - 7).
\]

Expanding the right-hand side, we get:

\[
3x + 5 = Ax + 6A + Bx - 7B.
\]

Combining like terms on the right-hand side gives:

\[
3x + 5 = (A + B)x + (6A - 7B).
\]

For the two polynomials to be equal, their corresponding coefficients must be equal. This gives us the following system of equations by comparing the coefficients of \(x\) and the constant terms:

1. \( A + B = 3 \)
2. \( 6A - 7B = 5 \)

We can solve this system of linear equations using Python.
```python
from sympy import symbols, Eq, solve

# Define the variables
A, B = symbols('A B')

# Set up the equations based on the coefficients comparison
eq1 = Eq(A + B, 3)
eq2 = Eq(6 * A - 7 * B, 5)

# Solve the system of equations
solution = solve((eq1, eq2), (A, B))
print(solution)
```
Code execution result: {A: 2, B: 1}

Thus, the solution to the system of equations is:

\[
A = 2, \quad B = 1
\]

So, the answer in the form \((A, B)\) is:

\(\boxed{(2, 1)}\)
