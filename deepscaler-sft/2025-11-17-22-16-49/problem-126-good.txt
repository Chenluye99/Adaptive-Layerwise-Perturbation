We need to place ping-pong balls into 10 boxes, ensuring certain conditions for each box:

1. Each box must contain at least 11 balls.
2. Each box must not contain 17 balls.
3. Each box must not contain a number of balls that is a multiple of 6.
4. Each box must contain a different number of balls.

First, let's identify numbers that meet the conditions. We can start with the smallest possible numbers that meet the condition of being at least 11, but excluding 17 and multiples of 6. We then ensure no numbers repeat as we place them into the 10 boxes.

We will use a Python code to ensure that we get the minimum number of ping pong balls to fill the 10 boxes while adhering to these conditions. Let's generate and check numbers sequentially, making sure each criterion is satisfied and counting the total number of balls used.
```python
# Initialize variables and an empty list to store the unique quantities of balls for each box
min_balls_needed = 0
used_quantities = []

# Start checking from 11 onward and apply the conditions
quantity = 11

while len(used_quantities) < 10:
    if quantity == 17:
        quantity += 1
        continue
    if quantity % 6 == 0:
        quantity += 1
        continue
    if quantity not in used_quantities:
        used_quantities.append(quantity)
        min_balls_needed += quantity
        quantity += 1
    else:
        quantity += 1

print(min_balls_needed)
```
Code execution result: 174

Thus, the minimum number of ping pong balls needed to fulfill all the given conditions is \(\boxed{174}\). This ensures that the 10 boxes each have a different number of balls, with each number being at least 11, not 17, not a multiple of 6, and no repetition of numbers in the boxes.
