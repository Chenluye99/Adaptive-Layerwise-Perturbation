To solve this problem, we need to keep track of the cumulative amount of money Krista has deposited into her bank each day, starting from Sunday, and then check when this cumulative amount first exceeds \$2 (which is 200 cents). We need to continue this process for 14 days because there are 14 days in two weeks.

We start with 1 cent on Sunday, 2 cents on Monday, 4 cents on Tuesday, and so on, doubling the amount deposited each subsequent day. We'll then sum the deposits to get the cumulative total each day and check when this cumulative total exceeds 200 cents.

Let's implement this step-by-step process using Python.
```python
# Initialize variables
initial_deposit = 1  # First deposit on Sunday
day_of_week = ["Sunday", "Monday", "Tuesday", "Wednesday", "Thursday", "Friday", "Saturday"]
current_deposit = initial_deposit
cumulative_amount = 0
day_index = 0  # Starting with Sunday as index 0

# List to store the daily deposits
daily_deposits = []

# Run for 14 days (two weeks)
for _ in range(14):
    cumulative_amount += current_deposit
    daily_deposits.append(current_deposit)
    if cumulative_amount > 200:
        break
    current_deposit *= 2
    day_index += 1

day_of_week_when_threshold_exceeded = day_of_week[day_index]
print((day_of_week_when_threshold_exceeded, cumulative_amount))
```
