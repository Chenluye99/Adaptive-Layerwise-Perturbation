To solve this problem, let's start by considering the constraints and requirements:

1. We have a 3x3 grid, and the numbers 1 through 9 need to be placed in these squares such that if two numbers are consecutive, the squares they occupy share an edge.
2. The numbers in the four corners add up to 18.
3. We need to find the number in the center of the grid.

Let's denote the 3x3 grid as follows:

\[
\begin{array}{|c|c|c|}
\hline
a & b & c \\
\hline
d & e & f \\
\hline
g & h & i \\
\hline
\end{array}
\]

The four corners of this grid are \( a, c, g, i \), and their sum is 18. That is:

\[ a + c + g + i = 18 \]

We also know that consecutive numbers must be placed in adjacent cells (sharing an edge). We will use Python to iterate through all possible permutations of the numbers 1 through 9 and check these conditions. For each valid permutation that satisfies the adjacency condition for consecutive numbers, we will then check if the sum of the corner numbers is 18. Once we find such a configuration, we will determine the number in the center, which is \( e \).

Let's implement this step-by-step in Python.
```python
import itertools

# Function to check if the consecutive numbers are adjacent
def is_valid_grid(grid):
    number_to_index = {num: (i, j) for i, row in enumerate(grid) for j, num in enumerate(row)}
    
    for num in range(1, 9):
        i1, j1 = number_to_index[num]
        for next_num in [num + 1]:
            if next_num in number_to_index:
                i2, j2 = number_to_index[next_num]
                if abs(i1 - i2) + abs(j1 - j2) != 1:
                    return False
    return True

# Find the correct grid configuration
for perm in itertools.permutations(range(1, 10)):
    grid = [list(perm[i:i+3]) for i in range(0, 9, 3)]
    
    if (grid[0][0] + grid[0][2] + grid[2][0] + grid[2][2] == 18) and is_valid_grid(grid):
        center_number = grid[1][1]
        break

print(center_number)
```
