To find the roots of the polynomial equation \(2x^4 + x^3 - 6x^2 + x + 2 = 0\), we can use numerical methods or symbolic computation provided by libraries such as `sympy` in Python. Let's implement this step-by-step.

1. **Set Up the Equation:**
   We need to solve the equation \(2x^4 + x^3 - 6x^2 + x + 2 = 0\).

2. **Use `sympy` to Find the Roots:**
   The `sympy` library has a function `solve` that can find the roots of polynomial equations. We'll use this function to get the roots of our equation.

Let's implement this in Python.
```python
import sympy as sp

# Define the variable and the equation
x = sp.symbols('x')
equation = 2*x**4 + x**3 - 6*x**2 + x + 2

# Find the roots of the equation
roots = sp.solve(equation, x)
print(roots)
```
Code execution result: [-2, -1/2, 1]
