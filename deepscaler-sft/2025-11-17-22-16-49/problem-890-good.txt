To solve the problem, we need to compute the value of \(\sin 6^\circ \sin 42^\circ \sin 66^\circ \sin 78^\circ\).

We can use the `math` library in Python to get the values of the sine function for the given angles in degrees. The steps are as follows:

1. Convert the angles from degrees to radians because the `math.sin` function in Python expects the angle in radians.
2. Compute the sine values for each of the angles: \(6^\circ, 42^\circ, 66^\circ, 78^\circ\).
3. Compute the product of these sine values.
4. Print the result.

Let's implement this step-by-step in Python.
```python
import math

# Convert degrees to radians
angles_degrees = [6, 42, 66, 78]
angles_radians = [math.radians(angle) for angle in angles_degrees]

# Compute sine values for each angle
sin_values = [math.sin(angle) for angle in angles_radians]

# Compute the product of the sine values
product_of_sines = sin_values[0] * sin_values[1] * sin_values[2] * sin_values[3]
print(product_of_sines)
```
