To solve this problem, let's begin by analyzing the geometric properties and using the Angle Bisector Theorem. 

The Angle Bisector Theorem states that if a point \(X\) is on the angle bisector of \(\angle ACB\), then the ratio of the lengths of the two segments created on the opposite side of the vertex is equal to the ratio of the other two sides of the triangle. Mathematically, it states:

\[
\frac{AX}{BX} = \frac{AC}{BC}
\]

From the problem, we have:
- \( AC = 21 \)
- \( BC = 28 \)

Let \( AX = x \) and \( BX = 24 \). According to the Angle Bisector Theorem:

\[
\frac{AX}{BX} = \frac{AC}{BC} \implies \frac{x}{24} = \frac{21}{28}
\]

We can simplify \(\frac{21}{28}\) to \(\frac{3}{4}\):

\[
\frac{x}{24} = \frac{3}{4}
\]

Cross-multiply to solve for \( x \):

\[
4x = 3 \cdot 24 \implies 4x = 72 \implies x = \frac{72}{4} \implies x = 18
\]

Thus, the length of \( AX \) is 18. We will confirm this by coding the solution to ensure accuracy. We can write a simple Python code to confirm this step-by-step calculation.
```python
# Given lengths
AC = 21
BC = 28
BX = 24

# Calculate AX using the Angle Bisector Theorem: (AX / BX) = (AC / BC)
ratio = AC / BC
AX = ratio * BX

print(AX)
```
Code execution result: 18.0

Thus, the length of \( AX \) is \(\boxed{18}\). This confirms that our solution is accurate and correct.
