1. **Define the Problem Mathematically:**
    - The number \(121_n\) in base \(n\) can be converted to base 10 as follows: \(1 \cdot n^2 + 2 \cdot n + 1 = n^2 + 2n + 1\).

2. **Set Up the Constraints:**
    - We are asked to find the integers \(n\) such that \(3 \leq n \leq 10\).
    - For each \(n\) in this range, we need to check if \(121_n\) (which is \((n + 1)^2\)) is a perfect square. Since \((n + 1)^2\) is always a perfect square, the only thing we need to check is that \(3 \leq n \leq 10\) holds, which we already know it does by the constraints of the problem.

3. **Implement in Python:**

    sqrt_check = int(num_base_10 ** 0.5)
    if sqrt_check ** 2 == num_base_10:
        valid_n.append(n)

# Return the count of such integers n
