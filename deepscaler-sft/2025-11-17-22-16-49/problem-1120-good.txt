To solve this problem, we need to determine how many different ways we can distribute six identical copies of a book between the library and being checked out, with the constraints that at least one book is in the library and at least one is checked out.

Let's break down the problem:

1. **Define the Constraints:**
    - We have 6 identical books.
    - We need to find how many books are in the library and how many are checked out, with the constraints that at least one book is in the library and at least one book is checked out.

2. **Enumerate Possible Distributions:**
    - If there are \(i\) books in the library, there will be \(6 - i\) books checked out.
    - We need to ensure \(1 \leq i \leq 5\) because if \(i = 0\), there are no books in the library, and if \(i = 6\), there are no books checked out. Both of these cases are not allowed according to the problem.

3. **Count Valid Distributions:**
    - For each valid value of \(i\) (from 1 to 5), there is exactly one corresponding way to have \(6 - i\) books checked out.
    - So, we need to count the number of valid values for \(i\).

Let's implement this step-by-step reasoning in Python to get the answer.
```python
# We need to count the ways for the books to be in the library or checked out with the constraints that at least one book is in the library and at least one book is checked out.

count = 0

# We will iterate through all possible numbers of books from 1 to 5 because if 0 books are in the library, that is not allowed, and if 6 books are in the library, then no books are checked out, which is also not allowed.
for i in range(1, 6):
    count += 1  # For each valid i, there is exactly one corresponding way to have 6 - i books checked out.

print(count)
```
Code execution result: 5

Thus, the number of different ways to have some of the books in the library and the rest checked out, with the constraints that at least one book is in the library and at least one is checked out, is \(\boxed{5}\). This is our final answer.
