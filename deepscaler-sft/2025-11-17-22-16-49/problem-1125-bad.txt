To solve the problem, we start by solving the logarithmic equation \(\log_{25}(x-4) = \frac{1}{2}\).

1. **Rewrite the Logarithmic Equation in Exponential Form:**
   \[
   \log_{25}(x-4) = \frac{1}{2} \implies 25^{\frac{1}{2}} = x - 4
   \]
   Since \(25 = 5^2\), we have \(25^{\frac{1}{2}} = (5^2)^{\frac{1}{2}} = 5\). Therefore,
   \[
   5 = x - 4 \implies x = 9
   \]

2. **Find \(\frac{1}{\log_{x} 3}\):**
   We need to find \(\frac{1}{\log_{9} 3}\). By properties of logarithms, we know that \(\log_{9} 3 = \frac{\log_{3} 3}{\log_{3} 9} = \frac{1}{2}\), because \(\log_{3} 3 = 1\) and \(\log_{3} 9 = \log_{3} (3^2) = 2\).

   Therefore,
   \[
   \log_{9} 3 = \frac{1}{2}
   \]
   So,
   \[
   \frac{1}{\log_{9} 3} = \frac{1}{\frac{1}{2}} = 2
   \]

Let's verify this step-by-step solution using Python to ensure accuracy.
```python
import sympy as sp

# Step 1: Solve for x in the equation log_{25}(x - 4) = 1/2
x = sp.symbols('x')
equation = sp.log(x - 4, 25) - 1/2
solution = sp.solve(equation, x)[0]

# Step 2: Calculate 1 / log_x(3)
log_x_3 = sp.log(3, solution)
result = 1 / log_x_3

print(result)
```
