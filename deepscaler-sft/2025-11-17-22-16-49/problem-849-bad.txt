To solve the problem, we need to find out how many rectangles with an area of 3 square units can be formed on a 6x6 grid.

1. **Grid Description:**
   - A 6x6 grid contains unit squares, and any rectangle drawn on the grid will have its sides defined by the grid lines.
   - When we draw a rectangle, its dimensions will be \((x_2 - x_1) \times (y_2 - y_1)\), where \((x_1, y_1)\) and \((x_2, y_2)\) are grid points.

2. **Constraints for Rectangles with Area 3:**
   - For the area of the rectangle to be 3 square units, the product of its height and width should be 3. Hence, the possible dimensions of such rectangles are \((1 \times 3)\) or \((3 \times 1)\).

3. **Enumerating Possible Rectangles:**
   - We will check every combination of top-left and bottom-right points to determine all possible rectangles that could be formed.
   - For each potential combination, we will check if its area is 3.

4. **Implementation:**
   - Use two nested loops to consider all possible pairs of opposite corners of potential rectangles.
   - For each pair, compute the dimensions of the rectangle and check if its area is 3.
   - Count those that meet the condition.

Let's implement this step-by-step in Python to ensure accuracy.
```python
# We'll create a function to count the number of rectangles with area 3 in a 6x6 grid.

count = 0

# We need to iterate through every pair of left and right bounds and every pair of top and bottom bounds
# of potential rectangles within the 6x6 grid. The grid indices range from 0 to 5 for both x and y.

for x1 in range(6):
    for y1 in range(6):
        for x2 in range(x1+1, 6):
            for y2 in range(y1+1, 6):
                width = x2 - x1
                height = y2 - y1
                if width * height == 3:
                    count += 1

print(count)
```
Code execution result: 30

Thus, the number of rectangles of area 3 square units that can be formed using only the line segments of the grid as the sides of the rectangles is \(\boxed{30}\). This is our final answer.
