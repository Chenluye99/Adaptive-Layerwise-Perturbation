\[ f(x) = ax^2 + bx + c \]
where \( a \), \( b \), and \( c \) are constants, and \( a \) is the leading coefficient we are trying to find.

First, we substitute \( x+1 \) into \( f(x) \):
\[ f(x+1) = a(x+1)^2 + b(x+1) + c. \]
Expanding this, we get:
\[ f(x+1) = a(x^2 + 2x + 1) + b(x + 1) + c = ax^2 + 2ax + a + bx + b + c = ax^2 + (2a + b)x + (a + b + c). \]

We also have:
\[ f(x) = ax^2 + bx + c. \]

According to the problem, we know that:
\[ f(x+1) - f(x) = 6x + 4. \]

Substituting the expressions for \( f(x+1) \) and \( f(x) \), we get:
\[ (ax^2 + (2a + b)x + (a + b + c)) - (ax^2 + bx + c) = 6x + 4. \]

Simplifying the left side, we obtain:
\[ ax^2 + (2a + b)x + (a + b + c) - ax^2 - bx - c = 6x + 4, \]
which simplifies to:
\[ (2a + b - b)x + (a + b + c - c) = 6x + 4, \]
and further simplifies to:
\[ 2ax + a + b = 6x + 4. \]

By comparing the coefficients of the polynomials on both sides of the equation, we get two equations:
1. The coefficient of \( x \): \( 2a = 6 \)
2. The constant term: \( a + b = 4 \)

First, solve for \( a \) from the first equation:
\[ 2a = 6 \implies a = 3. \]

Now substitute \( a = 3 \) into the second equation to solve for \( b \):
\[ 3 + b = 4 \implies b = 1. \]

The value of \( c \) is not needed to find the leading coefficient of \( f(x) \), but it is important to note that the leading coefficient of \( f(x) = ax^2 + bx + c \) is \( a \), and we have determined that \( a = 3 \).
