To solve this problem, let's start by understanding the setup.

1. **Determine the Total Number of Unique Chess Matches:**
   - With 10 members, each member plays against every other member. The number of unique pairs (and hence unique matches if each pair only plays once) is given by the combination formula \( \binom{10}{2} \), which equals \( \frac{10 \times 9}{2} = 45 \).
   - So, if each pair of members only played once, there would be 45 matches in total.

2. **Account for Multiple Matches:**
   - Each pair of members actually plays \( N \) times. Therefore, since each of the 45 unique matches is played \( N \) times, the total number of games played is \( 45 \times N \).

3. **Set Up the Equation:**
   - We are given that the total number of games played is 900. So, we can write the equation:
     \[
     45 \times N = 900
     \]

4. **Solve for \( N \):**
   - To find \( N \), we solve the equation by isolating \( N \):
     \[
     N = \frac{900}{45}
     \]

Let's compute this step-by-step using Python to ensure accuracy.
```python
# Given total number of games played
total_games = 900

# Calculate the number of unique pairs (combinations of 10 players taken 2 at a time)
num_pairs = 10 * 9 // 2

# Solve for N
N = total_games / num_pairs
print(N)
```
