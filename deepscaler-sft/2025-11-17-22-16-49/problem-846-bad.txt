To solve the problem of finding out how many ways 1995 can be factored as a product of two two-digit numbers (where the order of factors does not matter, i.e., \(a \cdot b\) and \(b \cdot a\) are considered the same), we can follow these steps:

1. **Find the Range of Two-Digit Numbers:**
    - Two-digit numbers range from 10 to 99.
    
2. **Check if 1995 Can Be Factored Into Two Two-Digit Numbers:**
    - We will check each pair of numbers (a, b) where \(10 \leq a \leq 99\) and \(10 \leq b \leq 99\) to see if their product is 1995.
    - For each valid pair (a, b) such that \(a \cdot b = 1995\), we will ensure that we only count distinct pairs and account for the order not mattering (i.e., if (a, b) is a valid pair, so is (b, a)).

Let's implement this step-by-step process in Python:
```python
count = 0

# Iterate through all pairs of two-digit numbers
for a in range(10, 100):
    for b in range(10, 100):
        if a * b == 1995:
            count += 1

print(count)
```
Code execution result: 4

Thus, the number of ways 1995 can be factored as a product of two two-digit numbers, considering that the order does not matter, is \(\boxed{4}\). This is our final answer.
