To solve this problem, we need to determine the equation of the straight line that passes through the given points and then use that equation to find the values of \( p \) and \( q \).

1. **Extract the Points:**
   From the table, we have the following points: \((2, -5)\), \((p, -14)\), and \((p + 2, -17)\).

2. **Find the Slope of the Line:**
   The slope \( m \) of a line passing through two points \((x_1, y_1)\) and \((x_2, y_2)\) is given by:
   \[
   m = \frac{y_2 - y_1}{x_2 - x_1}
   \]
   We can use the points \((2, -5)\) and \((p, -14)\) to find the slope:
   \[
   m = \frac{-14 - (-5)}{p - 2} = \frac{-9}{p - 2}
   \]
   We can also use the points \((2, -5)\) and \((p + 2, -17)\) to get another expression for the slope:
   \[
   m = \frac{-17 - (-5)}{(p + 2) - 2} = \frac{-12}{p}
   \]

3. **Set the Slopes Equal:**
   Since both expressions represent the slope of the same line, we can set them equal to each other:
   \[
   \frac{-9}{p - 2} = \frac{-12}{p}
   \]
   Cross-multiply to solve for \( p \):
   \[
   -9p = -12(p - 2)
   \]
   Simplify and solve:
   \[
   -9p = -12p + 24 \implies 3p = 24 \implies p = 8
   \]

4. **Find the Equation of the Line:**
   Now that we have \( p = 8 \), we can substitute it back into the equation of the line. We can use the point \((2, -5)\) and the slope \( m = \frac{-12}{8} = -\frac{3}{2} \) to get the equation of the line in the form \( y = mx + c \):
   \[
   y = -\frac{3}{2}x + c
   \]
   Substitute the point \((2, -5)\) into this equation to find \( c \):
   \[
   -5 = -\frac{3}{2}(2) + c \implies -5 = -3 + c \implies c = -2
   \]
   So, the equation of the line is:
   \[
   y = -\frac{3}{2}x - 2
   \]

5. **Find the Value of \( q \):**
   We are given that the point \((13, q)\) lies on this line. Substitute \( x = 13 \) into the equation to find \( q \):
   \[
   q = -\frac{3}{2}(13) - 2 = -\frac{39}{2} - 2 = -\frac{39}{2} - \frac{4}{2} = -\frac{43}{2} = -21.5
   \]

6. **Find \( p + q \):**
   We have \( p = 8 \) and \( q = -21.5 \), so:
   \[
   p + q = 8 - 21.5 = -13.5
   \]
