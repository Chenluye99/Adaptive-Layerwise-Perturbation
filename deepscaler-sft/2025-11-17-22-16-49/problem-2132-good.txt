\[

a - 7b + 8c = 4, \\
8a + 4b - c = 7.

\]

1. Define the variables.
2. Set up the equations.
3. Use `sympy.solve` to solve for \(a, b, c\).
4. Substitute these solutions into the expression \(a^2 - b^2 + c^2\) and compute the result.

a, b, c = sp.symbols('a b c')

# Define the equations
eq1 = a - 7*b + 8*c - 4

# Solve the system of equations

print(solution)
