To solve the equation \(\sqrt{3x + 6} = x + 2\), let's follow these steps:

1. **Square Both Sides:**
   Start by squaring both sides of the equation to eliminate the square root:
   \[
   (\sqrt{3x + 6})^2 = (x + 2)^2 \implies 3x + 6 = (x + 2)^2.
   \]

2. **Expand and Form a Quadratic Equation:**
   Expand the right-hand side:
   \[
   3x + 6 = x^2 + 4x + 4.
   \]
   Move all terms to one side of the equation to set it to zero:
   \[
   0 = x^2 + 4x + 4 - 3x - 6 \implies 0 = x^2 + x - 2.
   \]
   This gives us a standard quadratic equation:
   \[
   x^2 + x - 2 = 0.
   \]

3. **Solve the Quadratic Equation:**
   We can solve the quadratic equation \(x^2 + x - 2 = 0\) by factoring, completing the square, or using the quadratic formula \(x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}\), where \(a = 1\), \(b = 1\), and \(c = -2\).

   Factoring the quadratic equation:
   \[
   x^2 + x - 2 = (x + 2)(x - 1) = 0.
   \]
   So, we get:
   \[
   x + 2 = 0 \implies x = -2,
   \]
   and
   \[
   x - 1 = 0 \implies x = 1.
   \]

4. **Verify Solutions:**
   We must verify these solutions by substituting them back into the original equation \(\sqrt{3x + 6} = x + 2\) to ensure that they are valid.

   - For \(x = -2\):
     \[
     \sqrt{3(-2) + 6} = \sqrt{-6 + 6} = \sqrt{0} = 0,
     \]
     and
     \[
     -2 + 2 = 0.
     \]
     Since both sides are equal (0 = 0), \(x = -2\) is a solution.

   - For \(x = 1\):
     \[
     \sqrt{3(1) + 6} = \sqrt{3 + 6} = \sqrt{9} = 3,
     \]
     and
     \[
     1 + 2 = 3.
     \]
     Since both sides are equal (3 = 3), \(x = 1\) is a solution.

Both \(x = -2\) and \(x = 1\) are solutions to the original equation. Since the problem asks to order the solutions from least to greatest, we have:

\[
-2, 1
