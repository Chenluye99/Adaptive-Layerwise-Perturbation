### Part 1: Find Angle \( B \)

1. **Given Equation:**
   The equation provided is \( c \sin \frac{A + C}{2} = b \sin C \).
   
2. **Use trigonometric identities:**
   - Notice that \( A + B + C = \pi \), so \( \frac{A + C}{2} = \frac{\pi - B}{2} \).
   - Using the identity \( \sin \frac{\pi - B}{2} = \cos \frac{B}{2} \), we can rewrite the given equation as:
     \[
     c \cos \frac{B}{2} = b \sin C
     \]
   - By the Law of Sines, we know that \( \frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R \), where \( R \) is the circumradius of the triangle. This implies \( c = 2R \sin C \) and \( b = 2R \sin B \). Substituting these into our equation, we get:
     \[
     2R \sin C \cdot \cos \frac{B}{2} = 2R \sin B \cdot \sin C
     \]
   - Simplifying this by dividing through by \( 2R \sin C \) (assuming \(\sin C \neq 0\)), we get:
     \[
     \cos \frac{B}{2} = \sin B
     \]
   - Recall the double-angle identity for sine: \(\sin B = 2 \sin \frac{B}{2} \cos \frac{B}{2}\). So, we have:
     \[
     \cos \frac{B}{2} = 2 \sin \frac{B}{2} \cos \frac{B}{2}
     \]
   - Assuming \(\cos \frac{B}{2} \neq 0\), we can divide both sides by \(\cos \frac{B}{2}\) to get:
     \[
     1 = 2 \sin \frac{B}{2}
     \]
     \[
     \sin \frac{B}{2} = \frac{1}{2}
     \]
   - This implies:
     \[
     \frac{B}{2} = \frac{\pi}{6} \implies B = \frac{\pi}{3}
     \]

So, angle \( B = \frac{\pi}{3} \).

### Part 2: Find the Perimeter of \(\triangle ABC\)

1. **Given Conditions:**
   - \( BD = 1 \) is the altitude from \( B \) to side \( AC \).
   - \( b = \sqrt{3} \).
   - Angle \( B = \frac{\pi}{3} \).

2. **Area Relationship:**
   - The area of \(\triangle ABC\) can be expressed in two ways:
     1. Using the altitude: \[ \text{Area} = \frac{1}{2} \times AC \times BD = \frac{1}{2} \times AC \times 1 = \frac{1}{2} \times AC \]
     2. Using the formula involving the sides and sine of the angle: \[ \text{Area} = \frac{1}{2} \times a \times c \times \sin B = \frac{1}{2} \times a \times c \times \sin \frac{\pi}{3} = \frac{1}{2} \times a \times c \times \frac{\sqrt{3}}{2} = \frac{\sqrt{3}}{4} \times a \times c \]
   - Equating the two expressions for the area, we get:
     \[
     \frac{1}{2} \times AC = \frac{\sqrt{3}}{4} \times a \times c
     \]
     Since \( AC = b = \sqrt{3} \), we can substitute it:
     \[
     \frac{1}{2} \times \sqrt{3} = \frac{\sqrt{3}}{4} \times a \times c \implies \frac{\sqrt{3}}{2} = \frac{\sqrt{3}}{4} \times a \times c \implies \frac{1}{2} = \frac{1}{4} \times a \times c \implies 2 = a \times c
     \]
     So, we have:
     \[
     a \times c = 2
     \]

3. **Using the Law of Cosines:**
   - The Law of Cosines states that:
     \[
     b^2 = a^2 + c^2 - 2ac \cos B
     \]
     Substituting \( b = \sqrt{3} \) and \( \cos \frac{\pi}{3} = \frac{1}{2} \), we get:
     \[
     (\sqrt{3})^2 = a^2 + c^2 - 2 \cdot a \cdot c \cdot \frac{1}{2} \implies 3 = a^2 + c^2 - a \cdot c
     \]
     We already know that \( a \cdot c = 2 \), so we substitute this into the equation:
     \[
     3 = a^2 + c^2 - 2
     \]
     This simplifies to:
     \[
     5 = a^2 + c^2
     \]

4. **Solve for \( a \) and \( c \):**
   - We have the following system of equations:
     \[
     \begin{cases}
     a \cdot c = 2 \\
     a^2 + c^2 = 5
     \end{cases}
     \]
   - We can substitute \( c = \frac{2}{a} \) into the second equation:
     \[
     a^2 + \left( \frac{2}{a} \right)^2 = 5 \implies a^2 + \frac{4}{a^2} = 5
     \]
   - Let's solve this equation step-by-step using Python to ensure accuracy.
```python
import sympy as sp

# Define variables
a, c = sp.symbols('a c', positive=True)

# Define equations
eq1 = sp.Eq(a * c, 2)
eq2 = sp.Eq(a**2 + c**2, 5)

# Solve the system of equations
solution = sp.solve((eq1, eq2), (a, c))
print(solution)
```
Code execution result: [(1, 2), (2, 1)]

So, the solutions to the system of equations are \((a, c) = (1, 2)\) or \((a, c) = (2, 1)\). This means that the lengths of \(a\) and \(c\) can be switched, but the values will be the same either way. We can choose \(a = 1\) and \(c = 2\) without loss of generality.
