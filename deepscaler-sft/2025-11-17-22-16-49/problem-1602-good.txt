To solve this problem, we need to use Vieta's formulas. Vieta's formulas relate the coefficients of a polynomial to sums and products of its roots.

Given the polynomial $ax^3 + bx^2 + cx + d = 0$ with roots 1, 2, and 3, we can express the polynomial in its factored form:
\[ a(x - 1)(x - 2)(x - 3) = 0. \]

First, let's expand the product $(x - 1)(x - 2)(x - 3)$:

1. Expand $(x - 1)(x - 2)$:
\[ (x - 1)(x - 2) = x^2 - 3x + 2. \]

2. Now, expand the result with $(x - 3)$:
\[ (x^2 - 3x + 2)(x - 3) = x^3 - 3x^2 - 3x^2 + 9x + 2x - 6 = x^3 - 6x^2 + 11x - 6. \]

So, we have:
\[ a(x^3 - 6x^2 + 11x - 6) = ax^3 - 6ax^2 + 11ax - 6a. \]

By comparing this with the standard form $ax^3 + bx^2 + cx + d = 0$, we can identify the coefficients:
\[ b = -6a, \]
\[ c = 11a, \]
\[ d = -6a. \]

We need to compute $\frac{c}{d}$. Substituting the expressions for $c$ and $d$:

\[
\frac{c}{d} = \frac{11a}{-6a} = \frac{11}{-6} = -\frac{11}{6}.
\]
