To determine how much Bob has to spend in U.S. dollars to buy a coffee that costs 200 yen, given that 1 USD is worth 108 yen, we can use the following steps:

1. Set up the conversion formula:
   \[
   \text{Amount in USD} = \frac{\text{Amount in Yen}}{\text{Exchange Rate (Yen per USD)}}
   \]
   Here, the amount in yen is 200, and the exchange rate is 108 yen per USD.

2. Plug in the values:
   \[
   \text{Amount in USD} = \frac{200}{108}
   \]

3. Compute the value and round it to the nearest hundredth.

Let's execute this calculation using Python to ensure accuracy.
```python
# Given values
yen_amount = 200
exchange_rate_yen_per_usd = 108

# Calculate the amount in USD
usd_amount = yen_amount / exchange_rate_yen_per_usd

# Round to the nearest hundredth
usd_amount_rounded = round(usd_amount, 2)
print(usd_amount_rounded)
```
Code execution result: 1.85

Thus, Bob has to spend \(\boxed{1.85}\) USD to buy the coffee that costs 200 yen. This result was obtained by dividing 200 by 108 and then rounding the result to the nearest hundredth.
