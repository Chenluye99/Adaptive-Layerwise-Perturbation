First, let's calculate the distances between all pairs of adjacent vertices of the quadrilateral. The vertices are given as \((0,1)\), \((3,4)\), \((4,3)\), and \((3,0)\). We can use the distance formula to find the lengths of the sides of the quadrilateral. The distance formula between two points \((x_1, y_1)\) and \((x_2, y_2)\) is given by:

\[
\text{Distance} = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}
\]

We will calculate the distances for each of the sides of the quadrilateral:

1. Distance between \((0,1)\) and \((3,4)\)
2. Distance between \((3,4)\) and \((4,3)\)
3. Distance between \((4,3)\) and \((3,0)\)
4. Distance between \((3,0)\) and \((0,1)\)

Let's compute these step-by-step using Python to ensure accuracy.
```python
import sympy as sp

# Define the vertices
vertices = [(0, 1), (3, 4), (4, 3), (3, 0)]

# Function to calculate the distance between two points
def distance(p1, p2):
    return sp.sqrt((p2[0] - p1[0]) ** 2 + (p2[1] - p1[1]) ** 2)

# Calculate the distances for each side of the quadrilateral
d1 = distance(vertices[0], vertices[1])
d2 = distance(vertices[1], vertices[2])
d3 = distance(vertices[2], vertices[3])
d4 = distance(vertices[3], vertices[0])

# Get the perimeter by summing the distances
perimeter = d1 + d2 + d3 + d4

print((d1, d2, d3, d4, perimeter))
```
Code execution result: (3*sqrt(2), sqrt(2), sqrt(10), sqrt(10), 4*sqrt(2) + 2*sqrt(10))

So, we have the distances as follows:
1. Distance between \((0, 1)\) and \((3, 4)\) is \(3\sqrt{2}\)
2. Distance between \((3, 4)\) and \((4, 3)\) is \(\sqrt{2}\)
3. Distance between \((4, 3)\) and \((3, 0)\) is \(\sqrt{10}\)
4. Distance between \((3, 0)\) and \((0, 1)\) is \(\sqrt{10}\)

Thus, the perimeter of the quadrilateral is:
\[ 3 \sqrt{2} + \sqrt{2} + \sqrt{10} + \sqrt{10} = 4 \sqrt{2} + 2 \sqrt{10} \]

We can see that the perimeter is in the form \( a \sqrt{2} + b \sqrt{10} \), where \( a = 4 \) and \( b = 2 \). 

Therefore, the sum of \( a \) and \( b \) is:
\[ a + b = 4 + 2 = 6 \]

The final answer is \(\boxed{6}\)
