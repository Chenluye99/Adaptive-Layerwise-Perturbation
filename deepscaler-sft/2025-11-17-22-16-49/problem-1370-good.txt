Let's start by using the tools and properties of polynomials, particularly Vieta's formulas and properties related to the sums and products of the roots of a polynomial.

Given that we have a monic polynomial of degree \( n \):

\[ P(x) = x^n + a_{n-1}x^{n-1} + a_{n-2}x^{n-2} + \ldots \]

We know from the problem statement that:

\[ a_{n-1} = -a_{n-2} \]

We want to find the sum of the squares of the roots of this polynomial. Let's denote the roots of the polynomial by \( r_1, r_2, \ldots, r_n \). By Vieta's formulas, we have:

1. The sum of the roots (taken one at a time) is \(-a_{n-1}\):
   \[
   r_1 + r_2 + \ldots + r_n = -a_{n-1}
   \]
2. The sum of the product of the roots taken two at a time is \(a_{n-2}\):
   \[
   \sum_{1 \leq i < j \leq n} r_i r_j = a_{n-2}
   \]

We are asked to find the sum of the squares of the roots, which can be expressed using the identity:

\[
r_1^2 + r_2^2 + \ldots + r_n^2 = (r_1 + r_2 + \ldots + r_n)^2 - 2 \sum_{1 \leq i < j \leq n} r_i r_j
\]

Substituting the values from Vieta's formulas, we get:

\[
r_1^2 + r_2^2 + \ldots + r_n^2 = (-a_{n-1})^2 - 2 a_{n-2}
\]

Given the condition \( a_{n-1} = -a_{n-2} \), let's substitute \( a_{n-2} = -a_{n-1} \):

\[
r_1^2 + r_2^2 + \ldots + r_n^2 = (-a_{n-1})^2 - 2 (-a_{n-1}) = a_{n-1}^2 + 2 a_{n-1}
\]

We need to find the minimum value of the expression \( a_{n-1}^2 + 2 a_{n-1} \). To do this, we can consider the function \( f(a_{n-1}) = a_{n-1}^2 + 2 a_{n-1} \) and find its minimum value. This is a standard quadratic function, and its minimum value can be found by completing the square or using derivatives.

To complete the square, we write:

\[
a_{n-1}^2 + 2 a_{n-1} = (a_{n-1} + 1)^2 - 1
\]

The minimum value of \((a_{n-1} + 1)^2\) is 0, which occurs when \(a_{n-1} = -1\). Substituting this, we get:

\[
(a_{n-1} + 1)^2 - 1 = 0 - 1 = -1
\]

So, the minimum value of \(a_{n-1}^2 + 2 a_{n-1}\) is \(-1\). Therefore, the greatest lower bound for the sum of the squares of the roots is \(-1\).

Finally, the absolute value of that lower bound is:

\[
|-1| = 1
\]

Let's confirm this with Python code by checking if there are any other possible values and ensuring that \(-1\) is indeed the lowest possible value for \(a_{n-1}^2 + 2 a_{n-1}\).

# Find the critical points by taking the derivative and setting it to 0
critical_points = sp.solve(sp.diff(expression, a_n1), a_n1)

# Evaluate the expression at the critical points to find the minimum value
min_value = min(expression.subs(a_n1, cp) for cp in critical_points)
