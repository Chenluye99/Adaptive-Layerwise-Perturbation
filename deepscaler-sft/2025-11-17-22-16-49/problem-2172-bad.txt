To solve this problem, we need to follow these steps:

1. **Find the Divisors of 252:**
    - First, determine all the positive divisors of 252.
  
2. **Identify the Even Divisors:**
    - From the list of positive divisors, select the even ones.

3. **Count the Even Divisors:**
    - Count how many even divisors there are.

Let's start by implementing this step-by-step in Python.
```python
# Step 1: Find all positive divisors of 252

number = 252
divisors = []

for i in range(1, number + 1):
    if number % i == 0:
        divisors.append(i)

# Step 2: Identify the even divisors

even_divisors = [d for d in divisors if d % 2 == 0]

# Step 3: Count the even divisors

num_even_divisors = len(even_divisors)

print(num_even_divisors)
```
Code execution result: 12

Thus, the number of the positive divisors of 252 that are even is \(\boxed{12}\). This is our final answer.
