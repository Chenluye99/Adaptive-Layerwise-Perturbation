To solve this problem, let's follow these steps:

### Part 1: Find the value of $m$ such that $\overrightarrow{a}$ is perpendicular to $\overrightarrow{a} - \overrightarrow{b}$

1. **Express the Vectors:**
   - $\overrightarrow{a} = (1, -3)$
   - $\overrightarrow{b} = (-2, m)$
   - Therefore, $\overrightarrow{a} - \overrightarrow{b} = (1 - (-2), -3 - m) = (3, -3 - m)$

2. **Condition for Perpendicularity:**
   - Two vectors $\overrightarrow{u}$ and $\overrightarrow{v}$ are perpendicular if their dot product is zero.
   - So, $\overrightarrow{a} \cdot (\overrightarrow{a} - \overrightarrow{b}) = 0$
   - Substituting the vectors, we get:
     \[
     (1, -3) \cdot (3, -3 - m) = 1 \cdot 3 + (-3) \cdot (-3 - m) = 3 + 9 + 3m = 12 + 3m = 0
     \]
   - Solving for $m$:
     \[
     12 + 3m = 0 \implies 3m = -12 \implies m = -4
     \]

### Part 2: Find the value of $k$ such that $k \overrightarrow{a} + \overrightarrow{b}$ is parallel to $\overrightarrow{a} - \overrightarrow{b}$

1. **Express the Vectors in Question:**
   - $k \overrightarrow{a} + \overrightarrow{b} = k (1, -3) + (-2, m) = (k - 2, -3k + m)$
   - From Part 1, we know $m = -4$, so substituting $m = -4$:
     \[
     k \overrightarrow{a} + \overrightarrow{b} = (k - 2, -3k - 4)
     \]
   - We also have:
     \[
     \overrightarrow{a} - \overrightarrow{b} = (3, -3 - m) = (3, -3 - (-4)) = (3, 1)
     \]

2. **Condition for Parallelism:**
   - Two vectors $\overrightarrow{u} = (u_1, u_2)$ and $\overrightarrow{v} = (v_1, v_2)$ are parallel if there exists a scalar $\lambda$ such that $\overrightarrow{u} = \lambda \overrightarrow{v}$, or equivalently, if $\frac{u_1}{v_1} = \frac{u_2}{v_2}$ (as long as $v_1$ and $v_2$ are non-zero).
   - So, we set up the proportion:
     \[
     \frac{k - 2}{3} = \frac{-3k - 4}{1}
     \]
   - Cross-multiply to solve for $k$:
     \[
     k - 2 = -3(-3k - 4) \implies k - 2 = 9k + 12 \implies k - 9k = 12 + 2 \implies -8k = 14 \implies k = -\frac{14}{8} = -\frac{7}{4}
     \]

```python
import sympy as sp

# Part 1: Find the value of m
m = sp.symbols('m')
a = [1, -3]
b = [-2, m]
a_minus_b = [a[0] - b[0], a[1] - b[1]]

# Dot product of a and (a - b) must be zero
dot_product = a[0] * a_minus_b[0] + a[1] * a_minus_b[1]
m_value = sp.solve(dot_product, m)[0]

# Part 2: Find the value of k such that k * a + b is parallel to a - b

# Solve the system of equations
```

```python
import sympy as sp

# Part 1: Find the value of m
m = sp.symbols('m')
a = [1, -3]
b = [-2, m]
a_minus_b = [a[0] - b[0], a[1] - b[1]]

# Dot product of a and (a - b) must be zero
dot_product = a[0] * a_minus_b[0] + a[1] * a_minus_b[1]
m_value = sp.solve(dot_product, m)[0]

# Part 2: Find the value of k such that k * a + b is parallel to a - b
k = sp.symbols('k')
m = -4  # From Part 1, we know m = -4
k_a_plus_b = [k * a[0] + b[0], k * a[1] + b[1]]
a_minus_b = [3, 1]  # From above, we know a - b = (3, 1) when m = -4

# Condition for parallelism: (k * a + b) = lambda * (a - b)
# Which implies, (k - 2, -3k - 4) = lambda * (3, 1)
# So, we get two equations:
eq1 = sp.Eq(k - 2, 3 * sp.symbols('lambda'))
eq2 = sp.Eq(-3 * k - 4, sp.symbols('lambda'))

# Solve the system of equations
solution = sp.solve((eq1, eq2), (k, sp.symbols('lambda')))

print(f"Value of m: {m_value}")
print(f"Value of k: {solution[k]}")
```
