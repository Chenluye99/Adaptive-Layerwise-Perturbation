First, we need to set up equations for the cost of printing shirts at both Acme T-Shirt Company and Beta T-Shirt Company.

1. **Cost Equation for Acme T-Shirt Company:**
   - Acme has a set-up fee of \$50 and charges \$9 per shirt.
   - So, the cost for printing \( n \) shirts at Acme, \( C_{\text{Acme}}(n) \), can be represented as:
     \[
     C_{\text{Acme}}(n) = 50 + 9n
     \]

2. **Cost Equation for Beta T-Shirt Company:**
   - Beta has no set-up fee and charges \$14 per shirt.
   - So, the cost for printing \( n \) shirts at Beta, \( C_{\text{Beta}}(n) \), can be represented as:
     \[
     C_{\text{Beta}}(n) = 14n
     \]

To find the minimum number of shirts for which a customer saves money by using Acme, we need to determine the smallest value of \( n \) such that the cost of using Acme is less than the cost of using Beta:
\[
C_{\text{Acme}}(n) < C_{\text{Beta}}(n)
\]

Substitute the cost equations into the inequality:
\[
50 + 9n < 14n
\]

Rearrange the inequality to solve for \( n \):
\[
50 < 14n - 9n \implies 50 < 5n \implies 10 < n \implies n > 10
\]

This means \( n \) must be greater than 10. So, the smallest integer value for \( n \) that satisfies this inequality is 11. To ensure accuracy, we can check this by evaluating both cost functions at \( n = 11 \) and \( n = 10 \).

Let's compute this using Python to ensure accuracy.
```python
import sympy as sp

# Define the variables
n = sp.symbols('n', positive=True, integer=True)

# Define the cost functions
C_acme = 50 + 9 * n
C_beta = 14 * n

# Find the minimum number of shirts for which the cost of using Acme is less than the cost of using Beta
solution = sp.solve(C_acme - C_beta, n)

print(solution)
```
Code execution result: [10]
