To solve the problem, let's start by understanding what an icosahedron is and how we can find the number of interior diagonals.

1. **Understanding the Icosahedron:**
    - An icosahedron has 12 vertices.
    - Any two vertices of the icosahedron can be connected by either an edge or a diagonal.
    - The total number of ways to connect any two vertices of a 12-vertex figure is given by the combination formula \( \binom{12}{2} \), which is the number of ways to choose 2 vertices out of 12. This is calculated as:
      \[
      \binom{12}{2} = \frac{12 \times 11}{2} = 66
      \]
    - This 66 counts all possible line segments connecting any two vertices, which includes both the edges of the icosahedron and the interior diagonals.

2. **Counting the Edges of the Icosahedron:**
    - An icosahedron has 30 edges. (This is a known geometric property of an icosahedron.)

3. **Counting the Interior Diagonals:**
    - The total number of line segments connecting any two vertices (which is 66) minus the number of edges of the icosahedron (which is 30) will give the number of interior diagonals.
    - Therefore, the number of interior diagonals is:
      \[
      66 - 30 = 36
      \]

Let's confirm this by coding the solution.
```python
# Calculate the combination of 12 choose 2 which is the total ways to connect any 2 vertices out of 12
from math import comb

num_vertices = 12
total_segments = comb(num_vertices, 2)

# Number of edges in an icosahedron
num_edges = 30

# Number of interior diagonals is the total number of segments connecting any 2 vertices minus the number of edges
num_interior_diagonals = total_segments - num_edges
print(num_interior_diagonals)
```
Code execution result: 36

Thus, the number of interior diagonals in an icosahedron is \(\boxed{36}\). This result has been confirmed both by reasoning and by coding the solution.
