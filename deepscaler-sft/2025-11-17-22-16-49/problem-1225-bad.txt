To solve the problem, we need to determine the probability that a randomly selected integer from the set of integers from 0 through 99, inclusive, is in the range from 10 through 20, inclusive.

1. **Determine the Total Number of Integers:**
   - The integers range from 0 to 99, inclusive. Therefore, the total number of integers is \(99 - 0 + 1 = 100\).

2. **Determine the Number of Integers in the Range 10 through 20:**
   - The integers in the range from 10 through 20, inclusive, are 10, 11, 12, ..., 20. Therefore, the number of integers in this range is \(20 - 10 + 1 = 11\).

3. **Calculate the Probability:**
   - The probability that a randomly selected integer is in the range 10 through 20 is the ratio of the number of integers in the range 10 through 20 to the total number of integers. So, the probability is \(\frac{11}{100}\).

Let's confirm this with Python to ensure accuracy.
```python
# Total number of integers from 0 to 99, inclusive
total_integers = 100

# Number of integers from 10 to 20, inclusive
integers_in_range = list(range(10, 21))
num_integers_in_range = len(integers_in_range)

# Probability calculation
probability = num_integers_in_range / total_integers

# Output the result as a fraction
from fractions import Fraction
probability_fraction = Fraction(num_integers_in_range, total_integers)

print(probability_fraction)
```
Code execution result: 11/100

Thus, the probability that a randomly selected integer from the integers 0 through 99, inclusive, is in the range 10 through 20, inclusive, is \(\boxed{\frac{11}{100}}\). This confirms our reasoning and calculation are accurate.
