To solve this problem, we need to find the value of \( x \) that satisfies the equation \(\sqrt{5 + x} + \sqrt{20 - x} = 7\), and then use that value to compute \((5 + x)(20 - x)\).

1. **Set up the equation:**
   \[
   \sqrt{5 + x} + \sqrt{20 - x} = 7
   \]
   
2. **Find the value of \( x \):**
   We can solve this equation by isolating one of the square roots and then squaring both sides to eliminate the square roots. However, it's often more efficient to solve it numerically using Python to ensure accuracy.

3. **Compute \((5 + x)(20 - x)\):**
   Once we have the correct value of \( x \), we substitute it into the expression \((5 + x)(20 - x)\) to get the result.

Let's implement this step-by-step in Python.
```python
import sympy as sp

# Define the variable
x = sp.symbols('x')

# Define the equation
equation = sp.sqrt(5 + x) + sp.sqrt(20 - x) - 7

# Solve the equation
solution = sp.solve(equation, x)

# Filter out any non-real solutions (if any)
solution = [sol.evalf() for sol in solution if sol.is_real]

print(solution)
```

4. **Verify the solutions:**

   - For \( x = 4 \):
     \[
     \sqrt{5 + 4} + \sqrt{20 - 4} = \sqrt{9} + \sqrt{16} = 3 + 4 = 7
     \]
     This solution works.

   - For \( x = 11 \):
     \[
     \sqrt{5 + 11} + \sqrt{20 - 11} = \sqrt{16} + \sqrt{9} = 4 + 3 = 7
     \]
     This solution also works.

So, both \( x = 4 \) and \( x = 11 \) are valid solutions. We can now compute \((5 + x)(20 - x)\) for both values of \( x \) to ensure we get the same consistent result, or we can verify which gives a reasonable answer by substituting back into the original problem context.

Let's compute \((5 + x)(20 - x)\) for both solutions.

  \[
  (5 + 4)(20 - 4) = 9 \cdot 16 = 144

- For \( x = 11 \):
