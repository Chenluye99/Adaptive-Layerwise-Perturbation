To solve this problem, we need to find how many seven-digit phone numbers beginning with "336" have the property that the three-digit prefix "336" equals the product of the last four digits.

1. **Understand the Problem:**
    - A phone number is a seven-digit number that starts with "336".
    - Let the last four digits of the phone number be \(a, b, c, d\).
    - The product of these last four digits is \(a \times b \times c \times d\).
    - The three-digit prefix "336" should be equal to this product, i.e., \(336 = a \times b \times c \times d\).

2. **Set Up the Constraints:**
    - Each of \(a, b, c, d\) is a digit, so they range from 0 to 9.
    - We need to check all possible combinations of \(a, b, c, d\) to see if their product equals 336.

3. **Iterate and Check:**
    - We will iterate through all combinations of \(a, b, c, d\) and check if their product is 336.
    - For each valid combination, we form the complete phone number as "336abcd" and count it as a valid phone number.

Let's implement this step-by-step in Python.
```python
count = 0

# We need to check all combinations of the last four digits (a, b, c, d) where each digit ranges from 0 to 9.
for a in range(10):
    for b in range(10):
        for c in range(10):
            for d in range(10):
                if 336 == a * b * c * d:
                    count += 1

print(count)
```
Code execution result: 84

Thus, the number of seven-digit phone numbers beginning with "336" that have the property that the three-digit prefix "336" equals the product of the last four digits is \(\boxed{84}\). This is our final answer.
