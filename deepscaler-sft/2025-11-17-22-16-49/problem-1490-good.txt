To solve the problem, we need to find the number of triples \((a, b, c)\) of positive integers satisfying the equation:
\[ a^2 + b^2 + c^2 = ab + ac + bc \]
with the constraints \(1 \le a, b, c \le 100\).

First, let's rewrite the equation:
\[ a^2 + b^2 + c^2 = ab + ac + bc. \]

We can rearrange this equation as:
\[ a^2 + b^2 + c^2 - ab - ac - bc = 0. \]

To solve this, we will iterate over all possible values of \(a, b, c\) from 1 to 100 and check whether the equation holds for each triple \((a, b, c)\). If it does, we will count that triple as a solution.

Let's implement this step-by-step in Python.
```python
# Initialize a counter for the number of solutions
count = 0

# Iterate over all possible values of a, b, c in the range 1 to 100
for a in range(1, 101):
    for b in range(1, 101):
        for c in range(1, 101):
            if a**2 + b**2 + c**2 == a*b + a*c + b*c:
                count += 1

print(count)
```
Code execution result: 100

Thus, the number of triples \((a, b, c)\) of positive integers satisfying the equation \(a^2 + b^2 + c^2 = ab + ac + bc\) with the constraints \(1 \le a, b, c \le 100\) is \(\boxed{100}\). This is the final answer.
