To solve this problem, we need to generate the sequence and find the 100th number.

The sequence is formed by starting at 1 and then adding 3 repeatedly. So, the sequence is:

\[1, 4, 7, 10, \ldots\]

This is an arithmetic sequence where the first term \(a_1 = 1\) and the common difference \(d = 3\).

The general formula for the \(n\)-th term of an arithmetic sequence is given by:

\[ a_n = a_1 + (n-1) \cdot d \]

We want to find the 100th term (\(a_{100}\)) of this sequence. Substituting \(a_1 = 1\), \(d = 3\), and \(n = 100\) into the formula, we get:

\[ a_{100} = 1 + (100-1) \cdot 3 = 1 + 99 \cdot 3 = 1 + 297 = 298 \]

Let's confirm this by writing some Python code to generate the sequence and get the 100th element.
```python
# Generate the sequence by starting with 1 and adding 3 repeatedly until we get the 100th element

sequence = []
current = 1

# Generate the first 100 terms of the sequence
for i in range(100):
    sequence.append(current)
    current += 3

# Get the 100th number in the sequence (index 99)
hundreds_term = sequence[99]
print(hundreds_term)
```
Code execution result: 298

Thus, the 100th number in the sequence is \(\boxed{298}\). This confirms our analytical solution is correct.
