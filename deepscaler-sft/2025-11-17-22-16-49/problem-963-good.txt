To solve this problem, we need to determine the probability that a randomly chosen point \( P = (x, y) \) in the rectangular region closer to the origin \((0, 0)\) than to the point \((3, 1)\).

The steps to solve this problem are as follows:

1. **Define the Region:**
   The rectangular region has vertices at \((0, 0)\), \((2, 0)\), \((2, 1)\), and \((0, 1)\). So, \(x\) ranges from 0 to 2, and \(y\) ranges from 0 to 1.

2. **Distance Condition:**
   A point \( P = (x, y) \) is closer to \((0, 0)\) than to \((3, 1)\) if the Euclidean distance from \( P \) to \((0, 0)\) is less than the Euclidean distance from \( P \) to \((3, 1)\):
   \[
   \sqrt{x^2 + y^2} < \sqrt{(x - 3)^2 + (y - 1)^2}
   \]
   Squaring both sides, we get:
   \[
   x^2 + y^2 < (x - 3)^2 + (y - 1)^2
   \]
   Expanding and simplifying:
   \[
   x^2 + y^2 < x^2 - 6x + 9 + y^2 - 2y + 1
   \]
   This simplifies to:
   \[
   0 < -6x - 2y + 10
   \]
   Which can be further simplified to:
   \[
   6x + 2y < 10 \implies 3x + y < 5
   \]

3. **Set Up the Integral:**
   We need to integrate over the region defined by \(0 \leq x \leq 2\) and \(0 \leq y \leq 1\) where \(3x + y < 5\) and then divide by the area of the rectangle (which is 2) to get the probability.

4. **Implement in Python:**
   We'll use Python to set up and solve this integral.
```python
import sympy as sp

# Define the variables
x, y = sp.symbols('x y')

# Define the inequalities that define our region
inequality = 3 * x + y < 5

# Set up the double integral over the specified bounds
integral = sp.integrate(sp.Piecewise((1, inequality), (0, True)), (x, 0, 2), (y, 0, 1))

# The area of the rectangle is 2 (since it ranges from 0 to 2 in the x-direction and 0 to 1 in the y-direction)
area_of_rectangle = 2

# The probability is the ratio of the integrated area where the condition holds to the total area of the rectangle
probability = integral / area_of_rectangle

print(probability)
```
Code execution result: 3/4

Thus, the probability that a randomly selected point \( P \) from the rectangular region with vertices \((0, 0)\), \((2, 0)\), \((2, 1)\), and \((0, 1)\) is closer to the origin \((0, 0)\) than to the point \((3, 1)\) is \(\boxed{\frac{3}{4}}\). This is our final answer.
