Given the conditions \(a < 0\), \(a < b < c\), we need to determine which of the following statements must be true:

1. \(ab < bc\)
2. \(ac < bc\)
3. \(ab < ac\)
4. \(a + b < b + c\)
5. \(\frac{c}{a} < 1\)

Let's analyze each statement one by one.

1. **Statement: \(ab < bc\)**

    - Since \(a < b\) and both are multiplied by \(b\) (which is a common factor in both terms), we can compare just \(a\) and \(c\). Given \(a < c\) and \(b > 0\) (because \(a < b < c\) and \(a < 0\), so \(b\) and \(c\) must be positive), it is not necessarily true that \(ab < bc\) because if \(|a|\) is large enough, it can make \(ab\) greater than \(bc\). For example, if \(a = -2\), \(b = 1\), and \(c = 2\), then \(ab = -2 \cdot 1 = -2\) and \(bc = 1 \cdot 2 = 2\), so \(ab < bc\) is true in this case. But if \(a = -2\), \(b = -1\), and \(c = 1\), then \(ab = -2 \cdot -1 = 2\) and \(bc = -1 \cdot 1 = -1\), so \(ab > bc\), meaning this statement is not always true.

2. **Statement: \(ac < bc\)**

    - Since \(a < c\) and both are multiplied by \(c\) (which is positive because \(c > 0\)), it is clear that \(ac < bc\) must be true because any negative number times a smaller positive number is less than that negative number times a larger positive number. For example, if \(a = -2\), \(b = 1\), and \(c = 2\), then \(ac = -2 \cdot 2 = -4\) and \(bc = 1 \cdot 2 = 2\), so \(ac < bc\) is true. This holds for any \(a < 0\) and \(c > 0\).

3. **Statement: \(ab < ac\)**

    - Since \(b < c\) and both are multiplied by the negative number \(a\), it follows that \(ab > ac\) because a negative number times a smaller positive number is greater than a negative number times a larger positive number. For example, if \(a = -2\), \(b = 1\), and \(c = 2\), then \(ab = -2 \cdot 1 = -2\) and \(ac = -2 \cdot 2 = -4\), so \(ab > ac\), meaning this statement is not always true.

4. **Statement: \(a + b < b + c\)**

    - By subtracting \(b\) from both sides, we get \(a < c\), which is true by the condition \(a < b < c\). So, this statement is always true.

5. **Statement: \(\frac{c}{a} < 1\)**

    - Since \(a < 0\) and \(c > 0\), \(\frac{c}{a}\) is negative (because a positive number divided by a negative number is negative). Any negative number is less than 1, so \(\frac{c}{a} < 1\) is always true.
