To solve this problem, we need to find the minimum possible value of \(a_1 + a_2\) such that the sequence \(a_n\) defined by the recurrence relation \(a_{n + 2} = \frac{a_n + 2009}{1 + a_{n + 1}}\) produces only positive integers for all terms.

Let's break this down step-by-step:

1. **Initialize Variables and Recurrence Relation:**
    - Start with initial values \(a_1 = a_1\) and \(a_2 = a_2\).
    - Use the recurrence relation to compute the next terms of the sequence.
    - Check if all terms of the sequence up to a reasonable number of terms (say, up to \(a_{20}\)) are positive integers.

2. **Check for Integer Conditions:**
    - For each candidate pair \((a_1, a_2)\), generate the sequence and check if all the terms are integers.
    - We will iterate over possible values of \(a_1\) and \(a_2\) and check the conditions.

3. **Minimize \(a_1 + a_2\):**
    - Among all valid pairs \((a_1, a_2)\) that make the sequence consist of positive integers, find the pair that gives the minimum value of \(a_1 + a_2\).

Let's implement this step-by-step plan in Python.

import sympy as sp

def is_valid_sequence(a1, a2, terms_to_check=20):
    # Initialize the sequence with the first two terms
    sequence = [a1, a2]
    
    for n in range(terms_to_check - 1):
        a_n = sequence[n]
        a_np1 = sequence[n + 1]
        
        # Calculate the next term according to the recurrence relation
        a_np2 = (a_n + 2009) / (1 + a_np1)
        
        # Check if the next term is a positive integer
        if not a_np2.is_integer() or a_np2 <= 0:
            return False
        
        # Append the next term to the sequence
        sequence.append(int(a_np2))
    
    return True

# Initialize minimum sum as a large number, and store the pair (a1, a2) that gives this minimum
min_sum = float("inf")
best_pair = (0, 0)

# We will check a reasonable range for a1 and a2, say from 1 to 1000, because larger values might make it more difficult for (a_n + 2009) / (1 + a_{n+1}) to produce an integer.
for a1 in range(1, 1001):
    for a2 in range(1, 1001):
        if is_valid_sequence(a1, a2):
            current_sum = a1 + a2
            if current_sum < min_sum:
                min_sum = current_sum
                best_pair = (a1, a2)

print(((min_sum, best_pair)))
