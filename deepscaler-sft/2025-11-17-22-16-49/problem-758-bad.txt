First, let's identify the positive divisors of each of the given numbers: 36, 72, 114, and 96. Then, we need to find the common divisors of these numbers. The negative number -12 does not need to be considered separately for divisors since we are only considering the positive divisors.

### Step-by-Step Solution:

1. **Find the Positive Divisors of Each Number:**
    - Find the divisors of 36.
    - Find the divisors of 72.
    - Find the divisors of 114.
    - Find the divisors of 96.

2. **Find the Common Divisors:**
    - Identify the positive integers that are divisors of all the numbers 36, 72, 114, and 96.

3. **Sum the Common Divisors:**
    - Once we have the common divisors, sum them up.

Let's start by implementing this step-by-step in Python.
```python
import math

# Given numbers
numbers = [36, 72, 114, 96]

# Function to get the divisors of a number
def get_divisors(n):
    divisors = []
    for i in range(1, n + 1):
        if n % i == 0:
            divisors.append(i)
    return divisors

# Get divisors for each number in the list
divisors_36 = get_divisors(36)
divisors_72 = get_divisors(72)
divisors_114 = get_divisors(114)
divisors_96 = get_divisors(96)

# Find the common divisors
common_divisors = list(set(divisors_36) & set(divisors_72) & set(divisors_114) & set(divisors_96))

# Get the sum of these common divisors
sum_of_common_divisors = sum(common_divisors)
print((sum_of_common_divisors, common_divisors))
```
Code execution result: (12, [1, 2, 3, 6])

The common positive divisors of 36, 72, 114, and 96 are \(1, 2, 3, \) and \(6\). The sum of these common divisors is:

\[1 + 2 + 3 + 6 = 12\]
