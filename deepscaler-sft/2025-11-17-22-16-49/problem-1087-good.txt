To solve this problem, we need to determine constants \(a\) and \(b\) such that the relationship \(G_n = a G_{n-1} + b G_{n-2}\) holds for every third Fibonacci number \(G_n = F_{3n}\), for every integer \( n \ge 2 \). 

First, let's generate some values for \(G_n, G_{n-1},\) and \(G_{n-2}\), and then solve for \(a\) and \(b\) by forming a system of equations.

1. **Generate Fibonacci Numbers:**
   We need to generate enough Fibonacci numbers to get several values of \(G_n = F_{3n}, G_{n-1} = F_{3(n-1)}, G_{n-2} = F_{3(n-2)}\).

2. **Set Up the Equations:**
   For each triplet \((G_n, G_{n-1}, G_{n-2})\), we substitute into the equation \(G_n = a G_{n-1} + b G_{n-2}\) and solve for \(a\) and \(b\).

Let's start by coding this step-by-step.

We will use Python to generate the Fibonacci numbers and then use those to solve for \(a\) and \(b\).
```python
import sympy as sp

# Generate enough Fibonacci numbers
fib = [0, 1]  # Initialize Fibonacci sequence with F_0 = 0 and F_1 = 1

for i in range(2, 101):
    fib.append(fib[-1] + fib[-2])

# Get G_n values, i.e., F_3n
G = [fib[3 * n] for n in range(1, 31)]

# Create a system of equations to solve for a and b
a, b = sp.symbols('a b')

# We will use the first few values of G_n, G_{n-1}, G_{n-2} to set up equations
eqns = []

for n in range(3, len(G)):
    G_n = G[n]
    G_n1 = G[n-1]
    G_n2 = G[n-2]
    
    eq = sp.Eq(G_n, a * G_n1 + b * G_n2)
    eqns.append(eq)

# Solve the system of equations
solution = sp.solve(eqns[:2], (a, b))
print(solution)
```
Code execution result: {a: 4, b: 1}

Thus, the solution to the system of equations gives us the constants \(a = 4\) and \(b = 1\). Therefore, the values of \((a, b)\) that satisfy the equation \(G_n = a G_{n-1} + b G_{n-2}\) for every integer \(n \ge 2\) are:

\(\boxed{(4, 1)}\)
