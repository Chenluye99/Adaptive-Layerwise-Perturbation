To solve the problem, let’s first outline the steps needed:

1. **People to Select from:**
    - Each department (mathematics, statistics, and computer science) has 2 male and 2 female professors, so each department has 4 professors in total.
    - We need to form a committee of 6 professors such that there are 3 men and 3 women, and the committee must also contain 2 professors from each of the three departments.

2. **Break Down into Steps:**
    - Since we need 2 professors from each department, and we need 3 men and 3 women in total, we must ensure that the selection respects both of these constraints simultaneously. That means, across the three departments, we need to select professors in such a way that we pick 2 professors from each department and meet the 3 men and 3 women requirement.
    - To meet these criteria, we need to consider all possible ways to choose 2 professors from each department and then find which of those combinations give us 3 men and 3 women in total.

3. **Combinatorial Analysis:**
    - For each department, there are \(\binom{4}{2} = 6\) ways to choose 2 professors out of 4.
    - However, not all ways of choosing 2 professors from each department will satisfy the condition of having 3 men and 3 women in the full committee of 6 professors. We need to ensure that exactly three of the chosen professors are men and three are women.

Let's implement this step-by-step in Python. We'll use `itertools.combinations` to generate all ways of picking 2 professors each from the 3 departments and then check which of these combinations meet the criteria of having 3 men and 3 women in total.
```python
import itertools

# Define the professors in each department
professors_math = [('M1', 'M'), ('M2', 'M'), ('F1', 'F'), ('F2', 'F')]
professors_stats = [('M1', 'M'), ('M2', 'M'), ('F1', 'F'), ('F2', 'F')]
professors_cs = [('M1', 'M'), ('M2', 'M'), ('F1', 'F'), ('F2', 'F')]

# Get all ways to choose 2 professors from each department
combs_math = list(itertools.combinations(professors_math, 2))
combs_stats = list(itertools.combinations(professors_stats, 2))
combs_cs = list(itertools.combinations(professors_cs, 2))

# Now, we need to evaluate all possible ways to form a committee of 6 professors, one way from each list above, and check if it meets the conditions of having 3 men and 3 women.
count_valid_committees = 0

# Iterate over all combinations of choosing 2 professors from each department
for comb_math in combs_math:
    for comb_stats in combs_stats:
        for comb_cs in combs_cs:
            committee = list(comb_math + comb_stats + comb_cs)
            
            # Count the number of men and women in the committee
            num_men = sum(1 for _, gender in committee if gender == 'M')
            num_women = sum(1 for _, gender in committee if gender == 'F')
            
            # Check if the committee has exactly 3 men and 3 women
            if num_men == 3 and num_women == 3:
                count_valid_committees += 1

print(count_valid_committees)
```
