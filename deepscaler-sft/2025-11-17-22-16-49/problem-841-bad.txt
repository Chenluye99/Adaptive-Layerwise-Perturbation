Let's start by understanding the relationship between the number of sides of a polygon and the number of its diagonals. A polygon with \( n \) sides has \(\frac{n(n-3)}{2}\) diagonals. We are given that the polygon has 9 diagonals, so we can set up the following equation:

\[
\frac{n(n-3)}{2} = 9
\]

To solve for \( n \), we can follow these steps:

1. Multiply both sides by 2 to clear the fraction:
\[
n(n-3) = 18
\]

2. Rearrange this into a standard quadratic equation form:
\[
n^2 - 3n - 18 = 0
\]

3. Solve this quadratic equation using the quadratic formula, \( n = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} \), where \( a = 1 \), \( b = -3 \), and \( c = -18 \):

\[
n = \frac{-(-3) \pm \sqrt{(-3)^2 - 4 \cdot 1 \cdot (-18)}}{2 \cdot 1} = \frac{3 \pm \sqrt{9 + 72}}{2} = \frac{3 \pm \sqrt{81}}{2} = \frac{3 \pm 9}{2}
\]

This gives us two potential solutions:

\[
n = \frac{3 + 9}{2} = \frac{12}{2} = 6
\]
\[
n = \frac{3 - 9}{2} = \frac{-6}{2} = -3
\]

Since the number of sides of a polygon must be a positive integer, we discard \( n = -3 \) and accept \( n = 6 \).

To ensure the accuracy, we can implement this solution in Python and confirm our result.
```python
import sympy as sp

# Define the variable
n = sp.symbols('n', positive=True, integer=True)

# Define the equation based on the formula for the number of diagonals
equation = sp.Eq(n * (n - 3) / 2, 9)

# Solve the equation
solution = sp.solve(equation, n)
print(solution)
```
Code execution result: [6]

Thus, the solution obtained from both our reasoning and the code execution confirms that the polygon has \(\boxed{6}\) sides. This is the final answer.
