To solve the problem, we need to find the least common multiple (LCM) of 9999 and 100001. The LCM of two numbers can be computed using the formula:

\[
\text{LCM}(a, b) = \frac{|a \cdot b|}{\text{GCD}(a, b)}
\]

where GCD is the greatest common divisor. We will use Python to perform these calculations accurately. Let's start by finding the GCD of 9999 and 100001 using `math.gcd` function from the Python standard library, and then use the formula above to get the LCM.
```python
import math

# Define the numbers
a = 9999
b = 100001

# Calculate the GCD
gcd_ab = math.gcd(a, b)

# Calculate the LCM using the formula LCM(a, b) = |a * b| / GCD(a, b)
lcm_ab = abs(a * b) // gcd_ab
print(lcm_ab)
```
Code execution result: 90900909

Thus, the least common multiple of 9999 and 100001 is \(\boxed{90900909}\). This is our final answer.
