To solve the problem, we need to find the distance between the points \((-3, -4)\) and \((4, -5)\). The formula for the distance \(d\) between two points \((x_1, y_1)\) and \((x_2, y_2)\) in a Cartesian plane is given by:

\[ d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2} \]

Substituting the coordinates of the points \((-3, -4)\) and \((4, -5)\) into the formula, we get:

\[ d = \sqrt{(4 - (-3))^2 + (-5 - (-4))^2} = \sqrt{(4 + 3)^2 + (-5 + 4)^2} = \sqrt{7^2 + (-1)^2} = \sqrt{49 + 1} = \sqrt{50} = \sqrt{25 \cdot 2} = 5\sqrt{2} \]

Let's write the Python code to confirm this result.
```python
import sympy as sp

# Coordinates of the points
x1, y1 = -3, -4
x2, y2 = 4, -5

# Calculate the distance using the distance formula
distance = sp.sqrt((x2 - x1)**2 + (y2 - y1)**2)
print(distance)
```
Code execution result: 5*sqrt(2)

Thus, the distance between the points \((-3, -4)\) and \((4, -5)\) is \(\boxed{5\sqrt{2}}\). This confirms our previous calculation.
