To solve this problem, we need to find the roots of the quadratic equation \(54 - 15x - x^2 = 0\), and then determine the sum of its solutions.

First, let's rewrite the equation in the standard quadratic form, which is \(ax^2 + bx + c = 0\):

\[ -x^2 - 15x + 54 = 0 \]

This is equivalent to:

\[ x^2 + 15x - 54 = 0 \]

For a quadratic equation of the form \(ax^2 + bx + c = 0\), the sum of the roots is given by \(-\frac{b}{a}\). In our equation, \(a = 1\), \(b = 15\), and \(c = -54\). Therefore, the sum of the roots is:

\[ -\frac{b}{a} = -\frac{15}{1} = -15 \]

Let's verify this by solving the quadratic equation using Python and finding its roots explicitly.
```python
import sympy as sp

# Define the variable and the equation
x = sp.symbols('x')
equation = 54 - 15 * x - x ** 2

# Solve the equation
solutions = sp.solve(equation, x)

# Calculate the sum of the solutions
sum_of_solutions = sum(solutions)
print(sum_of_solutions)
```
Code execution result: -15

This confirms that the sum of the two solutions to the equation \(54 - 15x - x^2 = 0\) is \(\boxed{-15}\). Our analytical solution was accurate, and the code has verified this result.
