First, let's use our knowledge of right triangles and the Pythagorean theorem. In a right triangle, the square of the hypotenuse (the side opposite the right angle) is equal to the sum of the squares of the other two sides.

In this problem, we have side lengths \(x\), \(x + y\), and \(x - y\). To determine which of these is the hypotenuse, we need to compare their magnitudes. Since \(0 < y < x\), it follows that \(x + y > x > x - y\). Therefore, \(x + y\) is the hypotenuse because it is the largest side.

Using the Pythagorean theorem, we can write the following equation:
\[ (x + y)^2 = x^2 + (x - y)^2. \]

Expanding and simplifying this equation, we get:
\[ x^2 + 2xy + y^2 = x^2 + x^2 - 2xy + y^2, \]
\[ x^2 + 2xy + y^2 = 2x^2 - 2xy + y^2. \]

We can cancel out \(y^2\) from both sides of the equation:
\[ x^2 + 2xy = 2x^2 - 2xy. \]

Rearrange terms to isolate \(x\) and \(y\):
\[ 2xy + 2xy = 2x^2 - x^2, \]
\[ 4xy = x^2, \]
\[ 4y = x, \]
\[ \frac{y}{x} = \frac{1}{4}. \]

So, the value of \(\frac{y}{x}\) is \(\frac{1}{4}\). Let's confirm this by coding it to make sure our solution is accurate.
```python
import sympy as sp

# Define the variables
x, y = sp.symbols('x y', positive=True)

# Set up the equation based on the Pythagorean theorem
eq = (x + y)**2 - (x**2 + (x - y)**2)

# Solve the equation for y in terms of x
solution = sp.solve(eq, y)

print(solution)
```
Code execution result: [x/4]

This confirms our solution. So, the value of \(\frac{y}{x}\) is \(\frac{1}{4}\).
