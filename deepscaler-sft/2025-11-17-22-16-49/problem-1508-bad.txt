We need to maximize the expression \(2ab \sqrt{2} + 2bc\) under the constraint \(a^2 + b^2 + c^2 = 1\).

To solve this, we will use the method of Lagrange multipliers. Define the function we want to maximize as:

\[ f(a, b, c) = 2ab \sqrt{2} + 2bc \]

and the constraint function as:

\[ g(a, b, c) = a^2 + b^2 + c^2 - 1 = 0 \]

The method of Lagrange multipliers introduces a new variable \(\lambda\) (the Lagrange multiplier) and sets up the following system of equations:

\[
\nabla f = \lambda \nabla g
\]

where \(\nabla f\) is the gradient of \(f\) and \(\nabla g\) is the gradient of \(g\). The gradients are:

\[
\nabla f = \left( \frac{\partial f}{\partial a}, \frac{\partial f}{\partial b}, \frac{\partial f}{\partial c} \right) = \left( 2b \sqrt{2}, 2a \sqrt{2} + 2c, 2b \right)
\]

\[
\nabla g = \left( \frac{\partial g}{\partial a}, \frac{\partial g}{\partial b}, \frac{\partial g}{\partial c} \right) = \left( 2a, 2b, 2c \right)
\]

Equating the gradients, we get:

\[
(2b \sqrt{2}, 2a \sqrt{2} + 2c, 2b) = \lambda (2a, 2b, 2c)
\]

This gives us the following system of equations:

1. \(2b \sqrt{2} = \lambda \cdot 2a \implies b \sqrt{2} = \lambda a \)
2. \(2a \sqrt{2} + 2c = \lambda \cdot 2b \implies a \sqrt{2} + c = \lambda b \)
3. \(2b = \lambda \cdot 2c \implies b = \lambda c \)

We also have the constraint:

\[ a^2 + b^2 + c^2 = 1 \]

import sympy as sp

# Define the function to maximize and the constraint

solution = sp.solve([eq1, eq2, eq3, eq4], (a, b, c, lambd), dict=True)
