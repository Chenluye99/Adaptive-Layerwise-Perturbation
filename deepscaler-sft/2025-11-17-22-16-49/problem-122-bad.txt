To solve the problem, let's first place the equilateral triangle \( \triangle ABC \) in a coordinate system for simplicity. We can place \( A \) at \((0, 0)\), \( B \) at \((1, 0)\), and \( C \) at \(\left(\frac{1}{2}, \frac{\sqrt{3}}{2}\right)\).

1. **Find the coordinates of point \( P \):**
   \[
   \overrightarrow{AP} = \frac{1}{3} \left( \overrightarrow{AB} + \overrightarrow{AC} \right)
   \]
   \[
   \overrightarrow{AB} = (1, 0) - (0, 0) = (1, 0)
   \]
   \[
   \overrightarrow{AC} = \left( \frac{1}{2}, \frac{\sqrt{3}}{2} \right) - (0, 0) = \left( \frac{1}{2}, \frac{\sqrt{3}}{2} \right)
   \]
   \[
   \overrightarrow{AB} + \overrightarrow{AC} = \left( 1 + \frac{1}{2}, 0 + \frac{\sqrt{3}}{2} \right) = \left( \frac{3}{2}, \frac{\sqrt{3}}{2} \right)
   \]
   \[
   \overrightarrow{AP} = \frac{1}{3} \left( \frac{3}{2}, \frac{\sqrt{3}}{2} \right) = \left( \frac{1}{2}, \frac{\sqrt{3}}{6} \right)
   \]
   So, the coordinates of \( P \) are:
   \[
   P = \left( \frac{1}{2}, \frac{\sqrt{3}}{6} \right)
   \]

2. **Find the coordinates of point \( Q \):**
   \[
   \overrightarrow{AQ} = \overrightarrow{AP} + \frac{1}{2} \overrightarrow{BC}
   \]
   \[
   \overrightarrow{BC} = \left( \frac{1}{2}, \frac{\sqrt{3}}{2} \right) - (1, 0) = \left( \frac{1}{2} - 1, \frac{\sqrt{3}}{2} - 0 \right) = \left( -\frac{1}{2}, \frac{\sqrt{3}}{2} \right)
   \]
   \[
   \frac{1}{2} \overrightarrow{BC} = \frac{1}{2} \left( -\frac{1}{2}, \frac{\sqrt{3}}{2} \right) = \left( -\frac{1}{4}, \frac{\sqrt{3}}{4} \right)
   \]
   \[
   \overrightarrow{AQ} = \left( \frac{1}{2}, \frac{\sqrt{3}}{6} \right) + \left( -\frac{1}{4}, \frac{\sqrt{3}}{4} \right) = \left( \frac{1}{2} - \frac{1}{4}, \frac{\sqrt{3}}{6} + \frac{\sqrt{3}}{4} \right) = \left( \frac{1}{4}, \frac{4 \sqrt{3} + 3 \sqrt{3}}{12} \right) = \left( \frac{1}{4}, \frac{7 \sqrt{3}}{12} \right)
   \]
   So, the coordinates of \( Q \) are:
   \[
   Q = \left( \frac{1}{4}, \frac{7 \sqrt{3}}{12} \right)
   \]

3. **Find the coordinates of point \( A \):**
   We already know the coordinates of \( A \) are \( (0, 0) \).

4. **Find the area of \( \triangle APQ \):**
   To find the area of a triangle with vertices at \((x_1, y_1)\), \((x_2, y_2)\), and \((x_3, y_3)\), we can use the determinant formula:
   \[
   \text{Area} = \frac{1}{2} \left| x_1(y_2 - y_3) + x_2(y_3 - y_1) + x_3(y_1 - y_2) \right|
   \]
   Substituting in the coordinates of \( A \), \( P \), and \( Q \):
   \[
   A = (0, 0), \quad P = \left( \frac{1}{2}, \frac{\sqrt{3}}{6} \right), \quad Q = \left( \frac{1}{4}, \frac{7 \sqrt{3}}{12} \right)
   \]
   \[
   \text{Area} = \frac{1}{2} \left| 0 \left( \frac{\sqrt{3}}{6} - \frac{7 \sqrt{3}}{12} \right) + \frac{1}{2} \left( \frac{7 \sqrt{3}}{12} - 0 \right) + \frac{1}{4} \left( 0 - \frac{\sqrt{3}}{6} \right) \right|
   \]
   \[
   = \frac{1}{2} \left| \frac{1}{2} \cdot \frac{7 \sqrt{3}}{12} + \frac{1}{4} \cdot \left( -\frac{\sqrt{3}}{6} \right) \right|
   \]
   \[
   = \frac{1}{2} \left| \frac{7 \sqrt{3}}{24} - \frac{\sqrt{3}}{24} \right|
   \]
   \[
   = \frac{1}{2} \left| \frac{6 \sqrt{3}}{24} \right|
   \]
   \[
   = \frac{1}{2} \left| \frac{\sqrt{3}}{4} \right|
   \]
   \[
   = \frac{1}{2} \cdot \frac{\sqrt{3}}{4} = \frac{\sqrt{3}}{8}
   \]

P = tuple(AP)

# Calculate the coordinates of point Q

AQ = sp.Matrix(P) + (1/2) * sp.Matrix(BC)
Q = tuple(AQ)

# Extract the coordinates of A, P, and Q
x1, y1 = A
x2, y2 = P
x3, y3 = Q

# Calculate the area using the determinant formula
area = sp.Rational(1, 2) * abs(x1 * (y2 - y3) + x2 * (y3 - y1) + x3 * (y1 - y2))
print(area)
