To find the minimum height, we need to determine the critical points of the function \( h(t) \). The critical points are found by taking the derivative of \( h(t) \) with respect to \( t \) and setting it to zero.

1. Find the derivative of \( h(t) \):
\[ h'(t) = \frac{d}{dt}(2t^2 - 5t + 29) = 4t - 5. \]

2. Set the derivative equal to zero to find the critical points:
\[ 4t - 5 = 0 \implies 4t = 5 \implies t = \frac{5}{4}. \]

3. To ensure that this critical point gives a minimum, we can check the second derivative:
\[ h''(t) = \frac{d}{dt}(4t - 5) = 4. \]
Since \( h''(t) = 4 > 0 \), the function has a minimum at \( t = \frac{5}{4} \).

4. Substitute \( t = \frac{5}{4} \) back into the height function \( h(t) \) to get the minimum height:
\[ h\left(\frac{5}{4}\right) = 2\left(\frac{5}{4}\right)^2 - 5\left(\frac{5}{4}\right) + 29. \]

```python
import sympy as sp

# Define the function
t = sp.symbols('t')
h = 2*t**2 - 5*t + 29

# Find the critical points by taking the derivative and setting it to 0
h_prime = sp.diff(h, t)
critical_points = sp.solve(h_prime, t)

# Evaluate the function at the critical points to find the minimum height
min_height = min(h.subs(t, cp) for cp in critical_points)

# Get the minimum height to the nearest foot
min_height_rounded = round(min_height)
```
