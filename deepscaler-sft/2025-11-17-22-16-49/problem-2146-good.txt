To solve this problem, we need to determine the greatest common divisor (GCD) of two consecutive terms of the sequence \(a_n = n! + n\). Specifically, we want to find the maximum possible value of \(\text{GCD}(a_n, a_{n+1})\).

1. **Define the Sequence:**
   - The \(n\)-th term of the sequence is given by \(a_n = n! + n\).
   - The \((n+1)\)-th term of the sequence is given by \(a_{n+1} = (n+1)! + (n+1)\).

2. **Set Up the GCD:**
   - We need to compute \(\text{GCD}(a_n, a_{n+1}) = \text{GCD}(n! + n, (n+1)! + (n+1))\).
   - Notice that \((n+1)! = (n+1) \cdot n!\), so \((n+1)! + (n+1) = (n+1) \cdot n! + (n+1) = (n+1)(n! + 1)\).

3. **Formulate the Problem:**
   - We need to find \(\text{GCD}(n! + n, (n+1)(n! + 1))\).

Let's write some Python code to help us explore this. We will compute \(\text{GCD}(a_n, a_{n+1})\) for several values of \(n\) and look for the maximum value.

We'll use Python's `math.gcd` function to compute the GCD of consecutive terms of the sequence and then iterate through several values of \(n\) to find the maximum GCD value.
```python
import math

max_gcd = 0
max_n = 100  # We'll check for n from 0 to 99 initially (a reasonable range to start with)

for n in range(1, max_n):
    a_n = math.factorial(n) + n
    a_n1 = math.factorial(n + 1) + (n + 1)
    current_gcd = math.gcd(a_n, a_n1)
    if current_gcd > max_gcd:
        max_gcd = current_gcd

print(max_gcd)
```
Code execution result: 2
