To determine the range of the function \( p(x) = \frac{x^2 + x + 1}{x^2 + 1} \), we can follow these steps:

1. **Express the Function in a Useful Form:**
   To find the range, it might be helpful to express \( y = p(x) \) and then solve for \( x \) in terms of \( y \):
   \[
   y = \frac{x^2 + x + 1}{x^2 + 1}
   \]
   Rearrange this equation to:
   \[
   y (x^2 + 1) = x^2 + x + 1 \implies yx^2 + y = x^2 + x + 1 \implies yx^2 - x^2 = x + 1 - y \implies x^2 (y - 1) = x + 1 - y
   \]
   This can be written as:
   \[
   x^2 (y - 1) - x + (y - 1) = 0
   \]
   This is a quadratic equation in \( x \):
   \[
   (y - 1) x^2 - x + (y - 1) = 0
   \]
   For \( x \) to be a real number, the discriminant of this quadratic equation must be non-negative:
   \[
   \Delta = b^2 - 4ac \geq 0
   \]
   where \( a = y - 1 \), \( b = -1 \), and \( c = y - 1 \). So, the discriminant is:
   \[
   (-1)^2 - 4 (y - 1) (y - 1) \geq 0 \implies 1 - 4 (y - 1)^2 \geq 0 \implies 1 - 4 (y^2 - 2y + 1) \geq 0 \implies 1 - 4y^2 + 8y - 4 \geq 0 \implies -4y^2 + 8y - 3 \geq 0 \implies 4y^2 - 8y + 3 \leq 0
   \]

2. **Solve the Inequality:**
   To solve \( 4y^2 - 8y + 3 \leq 0 \), we first find the roots of the equation \( 4y^2 - 8y + 3 = 0 \) using the quadratic formula:
   \[
   y = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} = \frac{8 \pm \sqrt{64 - 4 \cdot 4 \cdot 3}}{2 \cdot 4} = \frac{8 \pm \sqrt{64 - 48}}{8} = \frac{8 \pm \sqrt{16}}{8} = \frac{8 \pm 4}{8}
   \]
   This gives two solutions:
   \[
   y = \frac{12}{8} = \frac{3}{2} \quad \text{and} \quad y = \frac{4}{8} = \frac{1}{2}
   \]
   So, the quadratic \( 4y^2 - 8y + 3 \leq 0 \) holds for:
   \[
   \frac{1}{2} \leq y \leq \frac{3}{2}
   \]
   Therefore, the range of \( p(x) \) is \(\left[ \frac{1}{2}, \frac{3}{2} \right]\).

```python
import sympy as sp

# Define the variable and the function
x = sp.symbols('x')
p = (x**2 + x + 1) / (x**2 + 1)

# Find the critical points and the limits of the function
p_critical = sp.solve(sp.diff(p, x), x)

# Evaluate the function at critical points to determine the range
p_values = [p.subs(x, point) for point in p_critical]

# Also consider the limits as x approaches positive and negative infinity
limit_pos_inf = sp.limit(p, x, sp.oo)
limit_neg_inf = sp.limit(p, x, -sp.oo)

p_values.append(limit_pos_inf)
p_values.append(limit_neg_inf)

# Get the minimum and maximum values of the function
min_value = min(p_values)
max_value = max(p_values)

print(((min_value, max_value)))
```
