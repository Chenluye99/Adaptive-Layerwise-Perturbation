First, let's start by calculating the squares of 101 and 99:

\[ 101^2 = 10201 \]
\[ 99^2 = 9801 \]

Next, we find the difference between these squares:

\[ 101^2 - 99^2 = 10201 - 9801 = 400 \]

Then, we need to find the absolute value of this difference. Since 400 is already a positive number, its absolute value is 400.

To ensure accuracy, we can use Python to perform these calculations.
```python
# Calculate the squares of 101 and 99
square_101 = 101 ** 2
square_99 = 99 ** 2

# Find the difference between the squares
difference = square_101 - square_99

# Get the absolute value of the difference
absolute_difference = abs(difference)
print(absolute_difference)
```
Code execution result: 400

So, the absolute value of the difference between the squares of 101 and 99 is \(\boxed{400}\). This confirms our solution is accurate.
