To solve this problem, we need to determine the smallest positive integer \( n \) such that \(\frac{n}{2010}\) is a terminating decimal.

A fraction in its simplest form \(\frac{a}{b}\) is a terminating decimal if and only if the prime factorization of \( b \) (after simplifying the fraction) contains no prime factors other than 2 and 5. 

First, let's get the prime factorization of 2010:

\[ 2010 = 2 \times 3 \times 5 \times 67 \]

This means that \(\frac{n}{2010}\) will be a terminating decimal only if the numerator \( n \) "cancels out" all prime factors of 2010 other than 2 and 5 when the fraction is in its simplest form. Therefore, \( n \) must be a multiple of \( 3 \times 67 = 201 \) so that the 3 and 67 factors from 2010 are eliminated from the denominator.

So, let's start checking from \( n = 1 \) and go upwards until we find the smallest \( n \) such that \(\frac{n}{2010}\) is a terminating decimal.

We can write some Python code to check this condition iteratively.
```python
import math

def is_terminating(denominator, n):
    # Simplify the fraction n / denominator
    gcd = math.gcd(n, denominator)
    reduced_denominator = denominator // gcd
    
    # Factorize the reduced denominator and check if it only contains 2 and 5
    while reduced_denominator % 2 == 0:
        reduced_denominator //= 2
    while reduced_denominator % 5 == 0:
        reduced_denominator //= 5
    
    return reduced_denominator == 1

# Find the smallest positive integer n such that n / 2010 is a terminating decimal
denominator = 2010
n = 1

while True:
    if is_terminating(denominator, n):
        result = n
        break
    n += 1

print(result)
```
Code execution result: 201

Thus, the smallest positive integer \( n \) such that \(\frac{n}{2010}\) is a terminating decimal is \(\boxed{201}\). This is confirmed by the code's execution which verified that 201 is the correct answer.
