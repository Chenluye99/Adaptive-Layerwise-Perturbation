Let's solve this problem using Python to ensure accuracy. We need to find all ways to allocate 8 students to two companies (denoted as Company A and Company B) such that:

1. Each company gets 4 students.
2. Two particular students (let's call them Student 1 and Student 2) cannot be in the same company.
3. Three other particular students (let's call them Student 3, Student 4, and Student 5) cannot be in the same company.

To solve this problem, we can use the following steps:

1. Generate all ways to split 8 students into two groups of 4.
2. Check each of these ways for the constraints mentioned above.
3. Count how many of these ways satisfy all constraints.

Let's assume the students are labeled from 1 to 8. We can implement this step-by-step process in Python.

First, we need to generate all ways to split 8 students into two groups of 4, and then check against the constraints. We can use `itertools.combinations` to generate the groupings.

Let's start by coding this.
```python
import itertools

# Let's label students from 1 to 8.
students = list(range(1, 9))

# Constraints: Two specific students (say student 1 and student 2) cannot be in the same group,
# and three specific students (say student 3, student 4, and student 5) cannot be in the same group.
# Let's assume students 1 and 2 are the specific students that cannot be in the same group,
# and students 3, 4, and 5 are the specific students that cannot be in the same group.

def is_valid_allocation(group1, group2):
    # Check if students 1 and 2 are not in the same group
    if any(student in group1 for student in [1, 2]) and any(student in group2 for student in [1, 2]):
        return False
    
    # Check if students 3, 4, and 5 are not all in the same group
    group1_count = sum(1 for student in [3, 4, 5] if student in group1)
    group2_count = sum(1 for student in [3, 4, 5] if student in group2)
    
    if group1_count == 3 or group2_count == 3:
        return False
    
    return True

count = 0

# Generate all ways to split 8 students into two groups of 4
for combo in itertools.combinations(students, 4):
    group1 = list(combo)
    group2 = [student for student in students if student not in group1]
    
    if len(group2) == 4:
        if is_valid_allocation(group1, group2):
            count += 1

print(count)
```
