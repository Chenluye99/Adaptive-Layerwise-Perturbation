According to the pigeonhole principle, if we want to ensure that the same sum is rolled twice, then the number of times we need to roll the dice must be one more than the number of distinct possible sums. This is because if we roll the dice 16 times, it's possible that each of the 16 distinct sums appears once, but on the 17th roll, we are guaranteed that at least one of the sums will repeat.

Thus, the minimum number of times we need to roll the dice to ensure that the same sum is rolled twice is 17. Let's confirm this by writing some Python code to illustrate the point (though it is more of a theoretical problem rather than a computational one).
