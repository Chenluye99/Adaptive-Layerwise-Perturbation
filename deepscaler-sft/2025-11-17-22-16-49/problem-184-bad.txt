First, let's start by establishing some properties of the right triangle \(ABC\):

- \(AB = 4\)
- \(AC = 3\)
- Since \(\triangle ABC\) is a right triangle, we can find \(BC\) using the Pythagorean theorem:
  \[
  BC = \sqrt{AB^2 + AC^2} = \sqrt{4^2 + 3^2} = \sqrt{16 + 9} = \sqrt{25} = 5
  \]

Point \(D\) is the midpoint of the hypotenuse \(BC\). The midpoint formula for \(BC\) will give us the coordinates of \(D\). Let's place \(A\) at the origin \((0, 0)\), \(B\) at \((4, 0)\), and \(C\) at \((0, 3)\). The midpoint formula for \(BC\) is:
\[
D = \left( \frac{4 + 0}{2}, \frac{0 + 3}{2} \right) = \left( 2, \frac{3}{2} \right)
\]

Next, we'll find the incenter (the center of the incircle) of triangles \(ADC\) and \(ABD\).

The incenter of a triangle can be found using the formula for the incenter coordinates \((x_i, y_i)\) of a triangle with vertices at \((x_1, y_1)\), \((x_2, y_2)\), and \((x_3, y_3)\):
\[
x_i = \frac{ax_1 + bx_2 + cx_3}{a + b + c}, \quad y_i = \frac{ay_1 + by_2 + cy_3}{a + b + c}
\]
where \(a, b, c\) are the lengths of the sides opposite the respective vertices.

We will calculate the incenter for both \(\triangle ADC\) and \(\triangle ABD\) and then find the distance between these incenter points.

### Step-by-Step Calculation:

1. **Calculate the side lengths of \(\triangle ADC\) and \(\triangle ABD\):**

   - For \(\triangle ADC\):
     - \(AD = \sqrt{(2 - 0)^2 + \left(\frac{3}{2} - 0\right)^2} = \sqrt{2^2 + \left(\frac{3}{2}\right)^2} = \sqrt{4 + \frac{9}{4}} = \sqrt{\frac{16}{4} + \frac{9}{4}} = \sqrt{\frac{25}{4}} = \frac{5}{2}\)
     - \(DC = \sqrt{(2 - 0)^2 + \left(\frac{3}{2} - 3\right)^2} = \sqrt{2^2 + \left(-\frac{3}{2}\right)^2} = \sqrt{4 + \frac{9}{4}} = \sqrt{\frac{16}{4} + \frac{9}{4}} = \sqrt{\frac{25}{4}} = \frac{5}{2}\)
     - \(AC = 3\)

   - For \(\triangle ABD\):
     - \(AD = \frac{5}{2}\) (already calculated)
     - \(BD = \frac{BC}{2} = \frac{5}{2}\)

2. **Find the incenter of \(\triangle ADC\):**

   - The side lengths opposite to \(A, D, C\) are \(DC, AD, AC\), respectively.
   - Using the incenter formula:
     - Let \(a = DC = \frac{5}{2}\), \(b = AD = \frac{5}{2}\), \(c = AC = 3\)
     - Then,
       \[
       x_{i_{ADC}} = \frac{a \cdot 0 + b \cdot 2 + c \cdot 0}{a + b + c} = \frac{\frac{5}{2} \cdot 0 + \frac{5}{2} \cdot 2 + 3 \cdot 0}{\frac{5}{2} + \frac{5}{2} + 3} = \frac{5}{5 + 3} = \frac{5}{8}

       \]
     - So, the incenter of \(\triangle ADC\) is \(\left( \frac{5}{8}, \frac{15}{32} \right)\).

3. **Find the incenter of \(\triangle ABD\):**

   - The side lengths opposite to \(A, B, D\) are \(BD, AD, AB\), respectively.
   - Using the incenter formula:
     - Let \(a = BD = \frac{5}{2}\), \(b = AD = \frac{5}{2}\), \(c = AB = 4\)
