To solve this problem, we need to compute the units digit of the sum of the sequence \(1! + 1, 2! + 2, 3! + 3, \ldots, 8! + 8, 9! + 9\).

1. First, let's generate the sequence.
2. Then, compute the factorial for each number from 1 to 9 and add the number to its factorial to get the terms of the sequence.
3. Sum all the terms in the sequence.
4. Finally, get the units digit of this sum.

We will use Python to carry out these calculations accurately. Let's start by coding this step-by-step.
```python
import math

# Generate the sequence and compute the sum
sequence = [(i + 1) + math.factorial(i) for i in range(9)]

# Get the sum of the sequence
sum_of_sequence = sum(sequence)

# Get the units digit of the sum
units_digit = sum_of_sequence % 10
print(units_digit)
```
Code execution result: 9

Thus, the units digit of the sum of the nine terms of the sequence \(1! + 1, \, 2! + 2, \, 3! + 3, \, \ldots, \, 8! + 8, \, 9! + 9\) is \(\boxed{9}\). This completes our solution.
