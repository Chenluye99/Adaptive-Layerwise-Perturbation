To solve the problem, we need to follow these steps:

1. **Identify Relevant Primes and Natural Numbers:**
    - We need to consider all integers \( n \) from 1 to 2012.
    - For each integer \( n \), find its least prime divisor \( p \).
    - Check if \( p^2 + p + 1 \) divides \( n \).

2. **Find Least Prime Divisor:**
    - To find the least prime divisor of \( n \), we need a helper function that checks for the smallest prime number that divides \( n \).

3. **Check the Condition:**
    - For each \( n \), compute \( p^2 + p + 1 \).
    - Check if this value divides \( n \).

4. **Count Valid \( n \):**
    - Count those \( n \) that satisfy both conditions mentioned above.

Let's implement this step-by-step process in Python to ensure accuracy. We'll start by defining functions to find the least prime divisor and check the divisibility condition, and then iterate through all numbers from 1 to 2012 to count the valid ones.
```python
import sympy

def count_valid_n(max_n):
    count = 0
    
    for n in range(1, max_n + 1):
        # Find the least prime divisor of n
        least_prime_divisor = 2
        for i in range(2, n + 1):
            if n % i == 0 and sympy.isprime(i):
                least_prime_divisor = i
                break
        
        # Calculate p^2 + p + 1 where p is the least prime divisor of n
        p = least_prime_divisor
        divisor_check = p**2 + p + 1
        
        # Check if p^2 + p + 1 divides n
        if n % divisor_check == 0:
            count += 1
    
    return count

# Now we run this function for the range up to 2012
result = count_valid_n(2012)
print(result)
```
