To solve the problem, we can use Apollonius's theorem, which relates the length of a median of a triangle to the lengths of its sides. The theorem states:

\[ AB^2 + AC^2 = 2AM^2 + 2BM^2 \]

where $BM$ is half of $BC$ because $M$ is the midpoint of $BC$. Let's denote the side $BC$ by $a$, so $BM = MC = \frac{a}{2}$.

Given:
\[ AB = 7, \quad AC = 15, \quad AM = 10 \]

Substitute these values into Apollonius's theorem:

\[ 7^2 + 15^2 = 2 \cdot 10^2 + 2 \left( \frac{a}{2} \right)^2 \]

This simplifies to:

\[ 49 + 225 = 2 \cdot 100 + 2 \cdot \frac{a^2}{4} \]

\[ 274 = 200 + \frac{a^2}{2} \]

Subtract 200 from both sides:

\[ 74 = \frac{a^2}{2} \]

Multiply both sides by 2:

\[ 148 = a^2 \]

Taking the square root of both sides, we get:

\[ a = \sqrt{148} = 2 \sqrt{37} \]

Now we have the lengths of all three sides of triangle $ABC$: $AB = 7$, $AC = 15$, and $BC = 2 \sqrt{37}$. To find the area of triangle $ABC$, we will use Heron's formula. Heron's formula states that the area of a triangle with side lengths $a$, $b$, and $c$ is:

\[ \text{Area} = \sqrt{s(s - a)(s - b)(s - c)} \]

where $s$ is the semi-perimeter of the triangle:

\[ s = \frac{a + b + c}{2} \]

Substitute $a = 2 \sqrt{37}$, $b = 7$, and $c = 15$ into the formula:

\[ s = \frac{2 \sqrt{37} + 7 + 15}{2} = \frac{2 \sqrt{37} + 22}{2} = \sqrt{37} + 11 \]

Now, substitute $s$, $a$, $b$, and $c$ into Heron's formula:

\[ \text{Area} = \sqrt{s(s - a)(s - b)(s - c)} = \sqrt{ (\sqrt{37} + 11) \left( (\sqrt{37} + 11) - 2 \sqrt{37} \right) \left( (\sqrt{37} + 11) - 7 \right) \left( (\sqrt{37} + 11) - 15 \right) } \]

\[ \text{Area} = \sqrt{ (\sqrt{37} + 11) (11 - \sqrt{37}) ( \sqrt{37} + 4 ) ( \sqrt{37} - 4 ) } \]

We can simplify the expression inside the square root by pairing the terms:

\[ ( \sqrt{37} + 11 ) ( 11 - \sqrt{37} ) = 11^2 - (\sqrt{37})^2 = 121 - 37 = 84 \]

\[ ( \sqrt{37} + 4 ) ( \sqrt{37} - 4 ) = (\sqrt{37})^2 - 4^2 = 37 - 16 = 21 \]

So we get:

\[ \text{Area} = \sqrt{ 84 \cdot 21 } = \sqrt{ 1764 } = 42 \]

Let's confirm this by coding the solution in Python.
```python
import sympy as sp

# Given lengths
AB = 7
AC = 15
AM = 10

# Find the length of BC using the equation derived from Apollonius's theorem
a = sp.symbols('a', positive=True)
eq = sp.Eq(AB**2 + AC**2, 2 * AM**2 + 2 * (a / 2)**2)
solution = sp.solve(eq, a)[0]

# Get the side lengths
BC = solution

# Calculate the semi-perimeter
s = (AB + AC + BC) / 2

# Calculate the area using Heron's formula
area = sp.sqrt(s * (s - AB) * (s - AC) * (s - BC))
print(area)
```
