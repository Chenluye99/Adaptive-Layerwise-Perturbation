First, let's set up the problem.

1. **Problem Understanding:**
    - The bacteria in the jar triple every 20 seconds.
    - After three minutes (which is 180 seconds), the number of bacteria is 275,562.
    - We need to find out how many bacteria were in the jar at the beginning of the experiment.

2. **Formulate the Relationship Mathematically:**
    - Since the bacteria triple every 20 seconds, we need to determine how many 20-second intervals there are in three minutes (180 seconds).
    - There are \( \frac{180}{20} = 9 \) intervals of 20 seconds in 180 seconds.
    - Let's call the initial number of bacteria \( N \). After 9 intervals, the number of bacteria will be \( N \cdot 3^9 \).
    - We know that after 180 seconds, the number of bacteria is 275,562, so we can set up the equation:
      \[
      N \cdot 3^9 = 275,562
      \]
    - We know that \( 3^9 = 19683 \), so the equation becomes:
      \[
      N \cdot 19683 = 275,562
      \]
    - Solving for \( N \):
      \[
      N = \frac{275,562}{19683}
      \]

3. **Implement in Python to Find the Answer:**
Let's implement this step-by-step in Python to ensure accuracy.
```python
# Given values
final_population = 275562
tripling_interval = 3  # because the population triples each 20 seconds
time_intervals = 180 / 20  # calculating the number of 20-second intervals in 180 seconds

# Calculate the exponent (number of 20-second intervals)
num_intervals = int(time_intervals)

# Compute 3^num_intervals
tripled_factor = tripling_interval ** num_intervals

# Calculate the initial population (N)
initial_population = final_population / tripled_factor
print(initial_population)
```
Code execution result: 14.0

Hence, the initial number of bacteria in the jar at the beginning of the experiment is \(\boxed{14}\). This is our final answer.
