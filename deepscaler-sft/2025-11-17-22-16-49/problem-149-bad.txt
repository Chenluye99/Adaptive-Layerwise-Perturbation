To solve this problem, let's denote the number of pieces of candy in each one-pound bag as \( n \).

Here are the given conditions:

1. Mike bought 4 one-pound bags, so he had \( 4n \) pieces of candy initially. After giving 15 pieces of candy to each person in his class, he had 23 pieces of candy left over. Let's say Mike's class has \( m \) people. Therefore, the equation for Mike is:
\[ 4n - 15m = 23 \]

2. Betsy bought 5 one-pound bags, so she had \( 5n \) pieces of candy initially. After giving 23 pieces of candy to each teacher in her school, she had 15 pieces of candy left over. Let's say Betsy's school has \( t \) teachers. Therefore, the equation for Betsy is:
\[ 5n - 23t = 15 \]

So, we have the following system of equations:
\[
\begin{cases}
4n - 15m = 23, \\
5n - 23t = 15.
\end{cases}
\]

We need to find the smallest positive integer value for \( n \) that satisfies both of these equations for some integers \( m \) and \( t \). We can implement this by iterating over possible values of \( n \) and checking if there exist integers \( m \) and \( t \) that satisfy both equations.

Let's write the Python code to solve this.
```python
import sympy as sp

# We will iterate over a reasonable range of values for n, m, and t to check for solutions.
solution = None

for n in range(1, 1000):  # We choose an arbitrary upper bound of 1000 for n to start with
    for m in range(1, 1000):
        if (4 * n - 23) % 15 == 0:
            if 4 * n - 15 * m == 23:
                for t in range(1, 1000):
                    if (5 * n - 15) % 23 == 0:
                        if 5 * n - 23 * t == 15:
                            solution = n
                            break
                else:
                    continue
                break
        
print(solution)
```
