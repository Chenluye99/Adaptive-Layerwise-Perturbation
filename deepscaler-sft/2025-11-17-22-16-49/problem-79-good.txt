To solve this problem, we need to reverse the process described in the problem, because the tree's height doubles every year.

Let's assume that the height of the tree at the end of 6 years is 32 feet. Each year, the tree's height is half of its height the previous year because its height doubles every year. Hence:

1. At the end of 6 years, the height of the tree is 32 feet.
2. At the end of 5 years, the height of the tree would have been \( \frac{32}{2} = 16 \) feet.
3. At the end of 4 years, the height of the tree would have been \( \frac{16}{2} = 8 \) feet.
4. At the end of 3 years, the height of the tree would have been \( \frac{8}{2} = 4 \) feet.

So, the height of the tree at the end of 3 years is 4 feet. Let's confirm this by implementing it in Python.
```python
# Initial height at the end of 6 years
height_at_end_of_6_years = 32

# Calculate the height at the end of 3 years by reversing the doubling process
height_at_end_of_5_years = height_at_end_of_6_years / 2
height_at_end_of_4_years = height_at_end_of_5_years / 2
height_at_end_of_3_years = height_at_end_of_4_years / 2

print(height_at_end_of_3_years)
```
Code execution result: 4.0

Thus, the height of the tree at the end of 3 years is \(\boxed{4}\) feet. This confirms that our solution is accurate.
