We will analyze each statement one by one.

1. **Statement 1: \( ab < bc \)**
   - Since \( a < b \) and both are multiplied by \( b \), this would be true if \( a \) and \( c \) had the same sign. But because \( a < 0 \) and \( c > 0 \), \( ac < 0 \) and \( bc > 0 \), so \( ab \) could be either positive or negative, while \( bc \) is always positive. So this statement is not necessarily always true because if \( b \) is positive and \( |a| > |c| \), then \( ab \) could be greater than \( bc \).

2. **Statement 2: \( ac < bc \)**
   - Since \( a < c \) and both are multiplied by \( c \), and \( a \) is negative while \( c \) is positive, \( ac \) is negative and \( bc \) is positive, so this statement is always true.

3. **Statement 3: \( ab < ac \)**
   - Since \( a < 0 \) and both are multiplied by \( a \), and because \( b < c \), if we multiply both sides of the inequality \( b < c \) by the negative number \( a \), the direction of the inequality is reversed, so the statement \( ab > ac \) is true, and not \( ab < ac \). So, this statement is not always true.

4. **Statement 4: \( a + b < b + c \)**
   - By canceling \( b \) on both sides, we get \( a < c \). Since we know \( a < 0 \), \( a < b < c \), hence \( a < c \) is always true, so this statement is always true.

5. **Statement 5: \( \frac{c}{a} < 1 \)**
   - Since \( a < 0 \) and \( c > 0 \), \(\frac{c}{a}\) is negative (because a positive number divided by a negative number is negative). Any negative number is always less than 1, so this statement is always true.
