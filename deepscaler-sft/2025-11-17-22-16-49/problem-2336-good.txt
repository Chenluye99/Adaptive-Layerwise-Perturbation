To solve this problem, we need to find all the ordered triples \((x, y, z)\) that satisfy the system of equations:

\[
\begin{align*}
x + yz &= 7, \\
y + xz &= 10, \\
z + xy &= 10.
\end{align*}
\]

We will use Python to solve this system of equations and find all the solutions. After getting the solutions, we will then sum up all the \(x\) values from these solutions.

Let's implement this step-by-step using Python.

1. **Set up the Equations:**
   We can use a symbolic solver to solve the system of equations. We'll use `sympy` to get all solutions.

2. **Find All Solutions:**
   We will use `solve` from the `sympy` library to get all solutions to the system of equations.

3. **Extract and Sum the \(x\) Values:**
   Once we have all solutions, we will extract the \(x\) values and sum them up.

Let's write the Python code to get the solution.
```python
import sympy as sp

# Define variables
x, y, z = sp.symbols('x y z', complex=True)

# Define the system of equations
eq1 = x + y * z - 7
eq2 = y + x * z - 10
eq3 = z + x * y - 10

# Solve the system of equations
solutions = sp.solve([eq1, eq2, eq3], (x, y, z))

# Extract all distinct x values and sum them up
x_values = [sol[0] for sol in solutions]
x_sum = sum(set(x_values))  # Use set to ensure we are summing distinct x values only

print(x_sum)
```
