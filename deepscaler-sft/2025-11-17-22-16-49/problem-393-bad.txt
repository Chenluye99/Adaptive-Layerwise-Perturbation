To solve this problem, we need to determine how many shower heads can be accommodated within a reasonable period of time, considering both the preheating time and the shower time.

1. **Problem Understanding:**
    - **Preheating Time:** The preheating takes 3 minutes per shower head.
    - **Shower Time:** Each shower takes 12 minutes.
    - **Constraints on Time:** We need to find out how many shower heads can supply showers for all 100 students within a reasonable period of time, such as a typical shower room scheduling period, say, one hour (60 minutes).

2. **Formulating the Problem Mathematically:**
    - For each shower head, the total time taken for one student to have a shower is the preheating time plus the shower time, i.e., \(3 + 12 = 15\) minutes.
    - If we have \(n\) shower heads, in one hour (60 minutes), each shower head will allow (\(\frac{60}{15} = 4\)) students to take a shower.
    - Therefore, with \(n\) shower heads, a total of \(4 \times n\) students can take showers in one hour.
    - We need to accommodate 100 students within this time. So, we need to find the smallest integer \(n\) such that \(4 \times n \geq 100\).

3. **Finding the Solution:**
    - Rearrange the inequality to find \(n\): \(n \geq \frac{100}{4} = 25\).
    - Therefore, the minimum number of shower heads required is 25. We'll write Python code to confirm this result and ensure it's accurate by checking if 24 shower heads would suffice, and if 25 shower heads would work.

Let's implement this step-by-step in Python to get the confirmation.

# Now, calculate how many shower heads are needed to serve 100 students in one hour
min_shower_heads_needed = 100 / students_per_shower_head
