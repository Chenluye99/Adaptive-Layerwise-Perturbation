To solve this problem, we need to find the units digit of the sum of the nine terms in the sequence \(1! + 1, 2! + 2, 3! + 3, \ldots, 9! + 9\).

1. **Calculate Each Term:**
   Each term in the sequence is of the form \( n! + n \). We need to calculate \( n! \) for \( n = 1, 2, \ldots, 9 \), then add \( n \) to each factorial, and store these values.

2. **Find the Units Digit:**
   To get the units digit of the sum, we can sum up all the values and then find the units digit of this sum. The units digit of a number is the remainder when the number is divided by 10.

Let's implement this step-by-step in Python to ensure accuracy.
```python
import math

# Calculate each term in the sequence and store them
sequence_terms = []

for n in range(1, 10):
    term = math.factorial(n) + n
    sequence_terms.append(term)

# Calculate the sum of these terms
sum_of_terms = sum(sequence_terms)

# Get the units digit of this sum
units_digit = sum_of_terms % 10
print(units_digit)
```
Code execution result: 8

Thus, the units digit of the sum of the nine terms of the sequence \(1! + 1, \, 2! + 2, \, 3! + 3, \, \ldots, \, 8! + 8, \, 9! + 9\) is \(\boxed{8}\). This is our final answer.
