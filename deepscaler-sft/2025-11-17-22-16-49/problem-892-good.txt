If a quadratic polynomial \(x^2 + ax + b\) can be factored into two linear factors, it must be of the form \((x - r_1)(x - r_2)\) where \(r_1\) and \(r_2\) are integers. Expanding \((x - r_1)(x - r_2)\), we get:

\[x^2 - (r_1 + r_2)x + r_1 r_2.\]

By comparing this with \(x^2 + ax + b\), we get:

\[a = - (r_1 + r_2),\]
\[b = r_1 r_2.\]

Given the constraints \(1 \leq a \leq 100\) and \(b \geq 0\), we need to find all pairs of integers \((r_1, r_2)\) such that when substituted into the above equations, we get valid values for \(a\) and \(b\) that meet the conditions.

2. **Check Conditions:** For each valid pair \((r_1, r_2)\), compute \(a = - (r_1 + r_2)\) and \(b = r_1 r_2\). Check if \(1 \leq a \leq 100\) and \(b \geq 0\). If both conditions are satisfied, then consider \((a, b)\) as a valid ordered pair.

3. **Count Unique Ordered Pairs:** Use a set to store unique ordered pairs \((a, b)\) that meet the conditions.

Let's implement this step-by-step plan in Python to ensure accuracy.
```python
# Initialize a set to store unique (a, b) pairs
valid_pairs = set()
```
