### Steps for Solution in Python:
1. **Generate Coordinates of Vertices:**
    - Start with an initial coordinate, such as \((3, 0)\), and move along according to the conditions given until we complete the polygon and get back to the start.
    - Each side has a length of 2 and is perpendicular to the next, so for each step, we'll modify the coordinates by either adding or subtracting 2 in the x or y directions alternatively.

2. **Calculate the Area Using Shoelace Formula:**
    - Once the coordinates for all vertices are generated, we can use the shoelace formula (also known as Gauss's area formula for polygons) to compute the area of the polygon accurately.

Let's implement this step-by-step in Python now.
```python
import numpy as np

# Generate the coordinates of the vertices of the polygon
num_sides = 28
side_length = 2
coords = [(3, 0)]  # Start at (3, 0)

# Generate the rest of the coordinates
for i in range(1, num_sides):
    if i % 4 == 1:
        coords.append((coords[i-1][0], coords[i-1][1] + side_length))
    elif i % 4 == 2:
        coords.append((coords[i-1][0] + side_length, coords[i-1][1]))
    elif i % 4 == 3:
        coords.append((coords[i-1][0], coords[i-1][1] - side_length))
    elif i % 4 == 0:
        coords.append((coords[i-1][0] - side_length, coords[i-1][1]))

# Ensure we close the polygon by adding the start point to the end of the list
coords.append(coords[0])

# Extract the x and y coordinates for use in Shoelace formula
x = [coord[0] for coord in coords]
y = [coord[1] for coord in coords]

# Use the shoelace formula to compute the area
n = len(coords)  # number of vertices
area = 0.5 * np.abs(sum(x[i] * y[(i + 1) % n] - y[i] * x[(i + 1) % n] for i in range(n)))

print(area)
```
