To solve this problem, we need to use the functional relationship in the transformation of the graphs. If $(-2, 3)$ is on the graph of $y = f(x)$, it means that $f(-2) = 3$.

We want to find a point on the graph of $y = f(2x + 1) + 3$. To do that, we need to determine the conditions under which $f(2x + 1)$ maps to $f(-2)$ because we know the value of $f(-2) = 3$.

1. Set up the equation $2x + 1 = -2$ to find the appropriate $x$ that makes $f(2x + 1) = f(-2)$.
2. Once we get the corresponding $x$, we can substitute it into $y = f(2x + 1) + 3$ to get the $y$-coordinate.

Let's solve this step-by-step.

### Step 1: Determine the appropriate \( x \)
We set up the equation:
\[ 2x + 1 = -2 \]
Solving for $x$:
\[ 2x + 1 = -2 \implies 2x = -3 \implies x = -\frac{3}{2} \]

### Step 2: Get the corresponding \( y \)-coordinate
Now, substitute $x = -\frac{3}{2}$ into the equation $y = f(2x + 1) + 3$:
\[ y = f(2 \cdot -\frac{3}{2} + 1) + 3 = f(-3 + 1) + 3 = f(-2) + 3 \]
Since we know that $f(-2) = 3$, we substitute this in:
\[ y = 3 + 3 = 6 \]

So, the point on the graph of $y = f(2x + 1) + 3$ corresponding to $f(-2) = 3$ is $\left( -\frac{3}{2}, 6 \right)$.
