1. **Find the Roots of the Polynomial:**
    - First, let's introduce a substitution to simplify solving the polynomial. Let \( w = z^4 \). Then the equation becomes:
      \[
      w^2 + (4\sqrt{3} + 6)w - (4\sqrt{3} + 7) = 0.
      \]
    - We can solve this quadratic equation for \( w \) using the quadratic formula:
      \[
      w = \frac{-(4\sqrt{3} + 6) \pm \sqrt{(4\sqrt{3} + 6)^2 + 4(4\sqrt{3} + 7)}}{2}.
      \]
    - Once we have the values for \( w \), we can solve for \( z \) by taking the fourth roots of these values of \( w \).

2. **Find the Zeros of the Polynomial:**
    - Plug the solutions back to get the values of \( z \). For each solution of \( w \), we get four values of \( z \) because \( z^4 = w \) has four solutions (the fourth roots of \( w \)).
    - The roots of the original polynomial \( P(z) \) will be the 8 solutions obtained from the fourth roots of the two values of \( w \).

3. **Form the 8-Sided Polygon:**
    - The roots of \( P(z) \) will be the vertices of the 8-sided polygon in the complex plane. We need to compute these roots and then determine the minimum perimeter of all possible 8-sided polygons formed by these roots.

Let's implement this step-by-step in Python to ensure accuracy.
```python
import sympy as sp

# Define the variable and the polynomial
z = sp.symbols('z')
P = z**8 + (4 * sp.sqrt(3) + 6) * z**4 - (4 * sp.sqrt(3) + 7)

# Find the roots of the polynomial
roots = sp.solve(P, z)

# Get the numerical values of the roots
roots = [complex(root.evalf()) for root in roots]

# Function to compute the perimeter of an 8-sided polygon formed by the roots
def compute_perimeter(roots):
    n = 8
    perimeter = 0
    for i in range(n):
        perimeter += abs(roots[i] - roots[(i + 1) % n])
    return perimeter

# Find the minimum perimeter by considering all possible rotations and combinations of the roots
min_perimeter = float("inf")

for i in range(8):
    curr_perimeter = compute_perimeter(roots[i:][:] + roots[:i])
    if curr_perimeter < min_perimeter:
        min_perimeter = curr_perimeter

print(min_perimeter)
```
