To determine the average daily high temperature over these days, we need to compute the average of these high temperatures. The formula for the average is given by:

\[
\text{Average} = \frac{\sum \text{High Temperatures}}{\text{Number of Days}}
\]

Let's calculate it step-by-step using Python to ensure accuracy.
```python
# List of high temperatures from September 15, 2008, to September 19, 2008
high_temperatures = [49, 62, 58, 57, 46]

# Calculate the average of the high temperatures
average_high_temperature = sum(high_temperatures) / len(high_temperatures)

# Return the result rounded to the nearest tenth
average_high_temperature_rounded = round(average_high_temperature, 1)
print(average_high_temperature_rounded)
```
