To solve this problem, we need to generate all seven-digit numbers using the digits 7, 8, and 9, and then check which of these numbers are palindromes.

### Steps:

1. **Generate Seven-Digit Numbers:**
   A seven-digit number using the digits 7, 8, and 9 can be represented as a list or tuple of seven elements, where each element is one of 7, 8, or 9.
   
2. **Check for Palindromes:**
   A number is a palindrome if it reads the same forward and backward. For a seven-digit number, this means that the first digit has to match the seventh digit, the second digit has to match the sixth digit, and the third digit has to match the fifth digit. The fourth digit can be anything because it is in the middle and doesn't need to match any other digit.

3. **Count Valid Palindromes:**
   We need to generate all possible seven-digit numbers composed of the digits 7, 8, and 9, check if they are palindromes, and then count how many of them are.

Let's implement this step-by-step in Python.
```python
import itertools

count = 0

# Generate all possible 7-digit combinations using only the digits 7, 8, 9
for combo in itertools.product([7, 8, 9], repeat=7):
    number_str = ''.join(map(str, combo))
    num = int(number_str)
    
    # Check if the number is a palindrome
    if str(num) == str(num)[::-1]:
        count += 1

print(count)
```
Code execution result: 81

Thus, the number of positive seven-digit integers that can be made using only the digits 7, 8, and 9 and are palindromes is \(\boxed{81}\). This is the final answer.
