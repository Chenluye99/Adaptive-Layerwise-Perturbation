Let's define the number of cups of tea each merchant drank as follows:
- Let \( S \) be the number of cups Sosipatra Titovna drank.
- Let \( O \) be the number of cups Olympiada Karpovna drank.
- Let \( P \) be the number of cups Poliksena Uvarovna drank.

According to the problem, we have the following equations based on the given information:
1. \( S + O = 11 \)
2. \( P + O = 15 \)
3. \( S + P = 14 \)

To find out how many cups of tea all three merchants drank together, we need to find the values of \( S \), \( O \), and \( P \), and then compute \( S + O + P \).

We can solve this system of equations step by step.

First, we can add all three equations:
\[ (S + O) + (P + O) + (S + P) = 11 + 15 + 14 \]
This simplifies to:
\[ 2S + 2O + 2P = 40 \]
Dividing through by 2, we get:
\[ S + O + P = 20 \]

So, the total number of cups of tea that all three merchants drank together is 20. We can confirm this by solving for \( S \), \( O \), and \( P \) individually if needed, but given that our solution is derived from the equations, we can conclude our answer directly. However, let's write the Python code to make sure this is accurate.
```python
from sympy import symbols, Eq, solve

# Define the variables
S, O, P = symbols('S O P')

# Set up the equations based on the problem statement
eq1 = Eq(S + O, 11)
eq2 = Eq(P + O, 15)
eq3 = Eq(S + P, 14)

# Solve the system of equations
solution = solve((eq1, eq2, eq3), (S, O, P))

# Get the values for S, O, P
S_val = solution[S]
O_val = solution[O]
P_val = solution[P]

# Calculate the total number of cups of tea that all three merchants drank together
total_cups = S_val + O_val + P_val
print(total_cups)
```
Code execution result: 20

Thus, the total number of cups of tea that Sosipatra Titovna, Olympiada Karpovna, and Poliksena Uvarovna drank together is \(\boxed{20}\). This confirms our solution is accurate.
