First, let's start by setting up the equation \((x + 2)(x - 3) = 14\) and solving for \(x\).

1. **Set up the equation:**
   \[
   (x + 2)(x - 3) = 14
   \]

2. **Expand and rearrange the equation:**
   \[
   (x + 2)(x - 3) = x^2 - 3x + 2x - 6 = x^2 - x - 6
   \]
   So, the equation becomes:
   \[
   x^2 - x - 6 = 14 \implies x^2 - x - 20 = 0
   \]

3. **Solve the quadratic equation:**
   We can solve the quadratic equation \(x^2 - x - 20 = 0\) using the quadratic formula \(x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}\), where \(a = 1\), \(b = -1\), and \(c = -20\).

   Alternatively, we can factorize the quadratic equation if possible. Let's factorize \(x^2 - x - 20 = 0\):
   \[
   x^2 - x - 20 = (x - 5)(x + 4) = 0
   \]
   So, we get:
   \[
   x - 5 = 0 \quad \text{or} \quad x + 4 = 0 \implies x = 5 \quad \text{or} \quad x = -4
   \]

4. **Find the sum of the possible values of \(x\):**
   The possible values of \(x\) are 5 and -4. The sum of these values is:
   \[
   5 + (-4) = 1
   \]

Let's confirm this by using Python to solve the quadratic equation and get the values of \(x\).
```python
import sympy as sp

# Define the variable
x = sp.symbols('x')

# Define the equation (x + 2)(x - 3) = 14
equation = (x + 2) * (x - 3) - 14

# Solve the equation
solutions = sp.solve(equation, x)

# Calculate the sum of the solutions
sum_of_solutions = sum(solutions)
print(sum_of_solutions)
```
Code execution result: 1

Thus, the sum of the possible values of \( x \) is \(\boxed{1}\). This confirms that our solution is accurate.
