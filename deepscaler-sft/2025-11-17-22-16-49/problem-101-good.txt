To solve this problem, let's begin by generating all possible 3-word sentences using the words "splargh", "glumph", and "amr". Then, we will filter out those sentences where "splargh" directly precedes "glumph".

1. **Generate All Possible 3-Word Sentences:**
   Each position in a 3-word sentence can be filled by any of the 3 words, so there are \(3^3 = 27\) possible 3-word sentences.

2. **Check for the Constraint:**
   We need to ensure that "splargh" does not come directly before "glumph" in any of these sentences. We will iterate through each of these 27 sentences and check if the constraint is violated.

3. **Count Valid Sentences:**
   Count only those sentences that do not contain "splargh" directly preceding "glumph".

Let's implement this step-by-step process in Python.
```python
import itertools

# Define the words in the Gnollish language
words = ["splargh", "glumph", "amr"]

# Generate all possible 3-word sentences
all_sentences = list(itertools.product(words, repeat=3))

# Function to check if a sentence is valid (i.e., "splargh" does not come directly before "glumph")
def is_valid_sentence(sentence):
    for i in range(len(sentence) - 1):
        if sentence[i] == "splargh" and sentence[i + 1] == "glumph":
            return False
    return True

# Filter out the invalid sentences
valid_sentences = [sentence for sentence in all_sentences if is_valid_sentence(sentence)]

# Return the count of valid sentences
num_valid_sentences = len(valid_sentences)
print(num_valid_sentences)
```

Thus, the number of valid 3-word sentences in the Gnollish language, where "splargh" does not come directly before "glumph", is \(\boxed{21}\). This is our final answer.
