1. **Properties and Formulas:**
    - The perimeter of \(\triangle ABC\) is given as 20. Let \(a = BC = 7\), \(b = CA\), and \(c = AB\). Then, \(a + b + c = 20\).
    - The radius of the inscribed circle (inradius) is given as \(\sqrt{3}\). The formula for the inradius \(r\) of a triangle is:
      \[
      r = \frac{A}{s}
      \]
      where \(A\) is the area of the triangle and \(s\) is the semiperimeter of the triangle. For \(\triangle ABC\), the semiperimeter \(s\) is:
      \[
      s = \frac{a + b + c}{2} = \frac{20}{2} = 10
      \]
      Given that the inradius \(r = \sqrt{3}\), we can write:
      \[
      \sqrt{3} = \frac{A}{10} \implies A = 10 \sqrt{3}
      \]
      where \(A\) is the area of the triangle.
    - The area \(A\) of a triangle can also be given by:
      \[
      A = \sqrt{s(s - a)(s - b)(s - c)} = \sqrt{10 (10 - 7) (10 - b) (10 - c)} = \sqrt{10 \cdot 3 \cdot (10 - b) \cdot (10 - c)} = \sqrt{30 (10 - b) (10 - c)}
      \]
      Equating this to the earlier expression for the area, we get:
      \[
      \sqrt{30 (10 - b) (10 - c)} = 10 \sqrt{3}
      \]
      Squaring both sides, we obtain:
      \[
      30 (10 - b) (10 - c) = 300 \implies (10 - b) (10 - c) = 10
      \]
    - We also know that \(a + b + c = 20\), so substituting \(a = 7\), we get:
      \[
      7 + b + c = 20 \implies b + c = 13
      \]
      Now we have a system of equations:
      \[
      (10 - b)(10 - c) = 10
      \]
      \[
      b + c = 13
      \]

2. **Solve for \(b\) and \(c\):**
    - We can solve for \(b\) and \(c\) by substituting \(c = 13 - b\) into the equation \((10 - b)(10 - c) = 10\):
      \[
      (10 - b)(10 - (13 - b)) = 10 \implies (10 - b)(b - 3) = 10
      \]
      This expands to:
      \[
      10b - 30 - b^2 + 3b = 10 \implies -b^2 + 13b - 40 = 0 \implies b^2 - 13b + 40 = 0
      \]
      We solve this quadratic equation using the quadratic formula \(b = \frac{-B \pm \sqrt{B^2 - 4AC}}{2A}\), where \(A = 1\), \(B = -13\), and \(C = 40\):
      \[
      b = \frac{13 \pm \sqrt{169 - 160}}{2} = \frac{13 \pm \sqrt{9}}{2} = \frac{13 \pm 3}{2}
      \]
      This gives us two solutions:
      \[
      b = \frac{16}{2} = 8 \quad \text{or} \quad b = \frac{10}{2} = 5
      \]
      If \(b = 8\), then \(c = 13 - 8 = 5\). If \(b = 5\), then \(c = 13 - 5 = 8\). So, the sides of the triangle are \(a = 7\), \(b = 8\), and \(c = 5\).

3. **Find \(\tan A\):**
    - To find \(\tan A\), we can use the Law of Cosines to find \(\cos A\) and \(\sin A\):
      \[
      \cos A = \frac{b^2 + c^2 - a^2}{2bc}
      \]
      \[
      \sin A = \frac{\text{opposite}}{\text{hypotenuse}} = \frac{\text{area of triangle}}{s \cdot \cos \frac{A}{2}}
      \]
      But a more straightforward method is to use the formula \(\tan A = \frac{2 \cdot \text{area}}{b^2 + c^2 - a^2}\).

Let's implement this step-by-step in Python to verify and get the accurate value of \(\tan A\).
```python
import sympy as sp

# Given values
a = 7
s = 10
r = sp.sqrt(3)
A = 10 * sp.sqrt(3)

# Calculate the area of the triangle using A = r * s

# Now, using Heron's formula to verify and ensure accuracy
b, c = sp.symbols('b c', positive=True)

# Equation derived from (10 - b)(10 - c) = 10 and b + c = 13
eq1 = (10 - b) * (10 - c) - 10

solution = sp.solve([eq1, eq2], (b, c))

# Now we have the sides of the triangle: a = 7, b, c
# Using Law of Cosines to find cos(A)
cos_A = (b**2 + c**2 - a**2) / (2 * b * c)

# Using sin(A) = sqrt(1 - cos^2(A))
sin_A = sp.sqrt(1 - cos_A**2)

# Calculate tan(A) = sin(A) / cos(A)
tan_A = sin_A / cos_A
print(tan_A)
```
