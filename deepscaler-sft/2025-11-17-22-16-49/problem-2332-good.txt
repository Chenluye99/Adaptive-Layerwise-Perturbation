First, let's start by calculating the dimensions and areas involved:

1. **Tile Dimensions and Area:**
    - Each tile measures 3 inches by 4 inches.

2. **Region Dimensions and Area:**
    - The rectangular region measures 2 feet by 5 feet.
    - Since 1 foot equals 12 inches, we convert the dimensions of the region to inches:
      - 2 feet = \(2 \times 12 = 24\) inches
      - 5 feet = \(5 \times 12 = 60\) inches
    - Therefore, the area of the rectangular region is \(24 \, \text{inches} \times 60 \, \text{inches} = 1440 \, \text{square inches}\).

3. **Determine the Number of Tiles Needed:**
    - To find out the fewest number of tiles needed to completely cover the rectangular region, we divide the area of the region by the area of one tile:
      \[
      \text{Number of tiles} = \frac{1440 \, \text{square inches}}{12 \, \text{square inches/tile}} = 120
      \]
    - However, just considering the area might not guarantee an efficient tiling without considering the arrangement of the tiles. We need to ensure that the tiles fit perfectly along both the length and the width without any slack or gaps.

4. **Check Feasibility of Tiling Arrangement:**
    - Let's consider how the tiles can be arranged in terms of their length and width to fit the dimensions of the rectangular region.

  - If we place the 3-inch side of the tile along the 24-inch side of the region:

Both arrangements require 120 tiles, so let's confirm this using code to ensure accuracy and check if a smaller number of tiles could be used if there was a more optimal way to place them.
```python
# Function to check the minimum number of tiles needed to cover the rectangular region
def find_min_tiles_needed():
    # Dimensions in inches
    tile_length = 3
    tile_width = 4
    region_length = 2 * 12  # 2 feet converted to inches
    region_width = 5 * 12   # 5 feet converted to inches
    
    min_tiles = float("inf")  # Start with an infinitely large number for comparison
    
    # Check different possible arrangements of tiling the region
    for i in range(1, region_length // tile_length + 1):
        for j in range(1, region_width // tile_width + 1):
            if i * tile_length == region_length and j * tile_width == region_width:
                num_tiles = i * j
                if num_tiles < min_tiles:
                    min_tiles = num_tiles
    
    return min_tiles

min_tiles_needed = find_min_tiles_needed()
print(min_tiles_needed)
```
