To determine how many positive 3-digit numbers are divisible by 7, we can follow these steps:

1. **Identify the Range of 3-Digit Numbers:**
    - The smallest 3-digit number is 100.
    - The largest 3-digit number is 999.

2. **Find the Smallest 3-Digit Number Divisible by 7:**
    - We need to find the smallest number greater than or equal to 100 that is divisible by 7.
    - We can do this by checking the remainder when 100 is divided by 7, and then adjusting 100 accordingly.

3. **Find the Largest 3-Digit Number Divisible by 7:**
    - We need to find the largest number less than or equal to 999 that is divisible by 7.
    - We can do this by checking the remainder when 999 is divided by 7, and then adjusting 999 accordingly.

4. **Count the Numbers Between the Smallest and Largest 3-Digit Numbers that are Divisible by 7:**
    - Once we have the smallest and largest 3-digit numbers that are divisible by 7, we can generate a list of all such numbers and then count them.

Let's implement this step-by-step process in Python.
```python
# Step 1: Find the smallest 3-digit number that is divisible by 7
smallest_3_digit = 100
while smallest_3_digit % 7 != 0:
    smallest_3_digit += 1

# Step 2: Find the largest 3-digit number that is divisible by 7
largest_3_digit = 999
while largest_3_digit % 7 != 0:
    largest_3_digit -= 1

# Step 3: Count the numbers between the smallest and largest 3-digit numbers that are divisible by 7
count = 0
for num in range(smallest_3_digit, largest_3_digit + 1):
    if num % 7 == 0:
        count += 1

print(count)
```
Code execution result: 128

Thus, the number of positive 3-digit numbers that are divisible by 7 is \(\boxed{128}\). This is our final answer.
