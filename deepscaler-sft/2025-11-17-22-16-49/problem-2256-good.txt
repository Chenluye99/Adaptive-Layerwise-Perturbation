The final digit of a number in a given base is simply the remainder when that number is divided by the base. We'll iterate through each base and determine if the final digit of 576 in that base is 1.

Let's create a function to get the base-b representation of a number and then check its final digit. We'll then count how many of these bases from 2 to 9 have this property. Let's implement this step by step.
```python
# Function to get the last digit of a number in a given base
def last_digit_in_base(n, base):
    return n % base

# Initialize a counter for the number of bases that have a final digit of 1 for the representation of 576
count = 0

# Check for each base from 2 to 9
for base in range(2, 10):
    last_digit = last_digit_in_base(576, base)
    if last_digit == 1:
        count += 1

print(count)
```
