First, let's place the regular tetrahedron \(ABCD\) in a coordinate system for simplicity. We can place the vertices of the tetrahedron as follows:

- \(A = (1, 1, 1)\)
- \(B = (1, -1, -1)\)
- \(C = (-1, 1, -1)\)
- \(D = (-1, -1, 1)\)

1. **Find the Midpoint \(N\) of \(\overline{AB}\):**

   The midpoint \(N\) of \(\overline{AB}\) is given by:
   \[
   N = \left( \frac{1+1}{2}, \frac{1+(-1)}{2}, \frac{1+(-1)}{2} \right) = (1, 0, 0)
   \]

2. **Find the Centroid \(G\) of Triangle \(ACD\):**

   The centroid \(G\) of a triangle with vertices \((x_1, y_1, z_1)\), \((x_2, y_2, z_2)\), and \((x_3, y_3, z_3)\) is given by:
   \[
   G = \left( \frac{x_1 + x_2 + x_3}{3}, \frac{y_1 + y_2 + y_3}{3}, \frac{z_1 + z_2 + z_3}{3} \right)
   \]
   For triangle \(ACD\) with vertices \(A = (1, 1, 1)\), \(C = (-1, 1, -1)\), and \(D = (-1, -1, 1)\):
   \[
   G = \left( \frac{1 + (-1) + (-1)}{3}, \frac{1 + 1 + (-1)}{3}, \frac{1 + (-1) + 1}{3} \right) = \left( \frac{-1}{3}, \frac{1}{3}, \frac{1}{3} \right) = \left( -\frac{1}{3}, \frac{1}{3}, \frac{1}{3} \right)
   \]

3. **Find the Vectors \(\overrightarrow{BN}\) and \(\overrightarrow{NG}\):**

   - Vector \(\overrightarrow{BN}\) is from \(B = (1, -1, -1)\) to \(N = (1, 0, 0)\):
     \[
     \overrightarrow{BN} = N - B = (1 - 1, 0 - (-1), 0 - (-1)) = (0, 1, 1)
     \]
   - Vector \(\overrightarrow{NG}\) is from \(N = (1, 0, 0)\) to \(G = \left( -\frac{1}{3}, \frac{1}{3}, \frac{1}{3} \right)\):
     \[
     \overrightarrow{NG} = G - N = \left( -\frac{1}{3} - 1, \frac{1}{3} - 0, \frac{1}{3} - 0 \right) = \left( -\frac{4}{3}, \frac{1}{3}, \frac{1}{3} \right)
     \]

4. **Find the Cosine of the Angle Between \(\overrightarrow{BN}\) and \(\overrightarrow{NG}\):**

   The cosine of the angle \(\theta\) between two vectors \(\overrightarrow{u}\) and \(\overrightarrow{v}\) is given by:
   \[
   \cos \theta = \frac{\overrightarrow{u} \cdot \overrightarrow{v}}{\| \overrightarrow{u} \| \| \overrightarrow{v} \|}
   \]
   where \(\overrightarrow{u} \cdot \overrightarrow{v}\) is the dot product of \(\overrightarrow{u}\) and \(\overrightarrow{v}\), and \(\| \overrightarrow{u} \|\) and \(\| \overrightarrow{v} \|\) are the magnitudes of \(\overrightarrow{u}\) and \(\overrightarrow{v}\), respectively.

   For \(\overrightarrow{BN} = (0, 1, 1)\) and \(\overrightarrow{NG} = \left( -\frac{4}{3}, \frac{1}{3}, \frac{1}{3} \right)\):
   - Dot product \(\overrightarrow{BN} \cdot \overrightarrow{NG}\):
     \[
     \overrightarrow{BN} \cdot \overrightarrow{NG} = 0 \cdot \left( -\frac{4}{3} \right) + 1 \cdot \frac{1}{3} + 1 \cdot \frac{1}{3} = \frac{1}{3} + \frac{1}{3} = \frac{2}{3}
     \]
   - Magnitude of \(\overrightarrow{BN}\):
     \[
     \| \overrightarrow{BN} \| = \sqrt{0^2 + 1^2 + 1^2} = \sqrt{2}
     \]
   - Magnitude of \(\overrightarrow{NG}\):
     \[
     \| \overrightarrow{NG} \| = \sqrt{\left( -\frac{4}{3} \right)^2 + \left( \frac{1}{3} \right)^2 + \left( \frac{1}{3} \right)^2} = \sqrt{\frac{16}{9} + \frac{1}{9} + \frac{1}{9}} = \sqrt{\frac{18}{9}} = \sqrt{2}
     \]

   Therefore:
   \[
   \cos \angle BNG = \frac{\frac{2}{3}}{\sqrt{2} \cdot \sqrt{2}} = \frac{\frac{2}{3}}{2} = \frac{2}{3} \cdot \frac{1}{2} = \frac{1}{3}
   \]

Let's confirm this by coding it in Python to ensure accuracy.
```python
import numpy as np

# Define the coordinates of the vertices
A = np.array([1, 1, 1])
B = np.array([1, -1, -1])
C = np.array([-1, 1, -1])
D = np.array([-1, -1, 1])

# Calculate the midpoint N of AB
N = (A + B) / 2

# Calculate the centroid G of triangle ACD
G = (A + C + D) / 3

# Calculate the vectors BN and NG
BN = N - B
NG = G - N

# Calculate the cosine of the angle between vectors BN and NG
cos_angle_BNG = np.dot(BN, NG) / (np.linalg.norm(BN) * np.linalg.norm(NG))
print(cos_angle_BNG)
```
