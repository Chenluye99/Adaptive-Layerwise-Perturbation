First, let's analyze the problem step-by-step:

1. **Given Information:**
    - A stack of eight quarters is exactly half an inch high.
    - We need to determine how many quarters are needed to make a stack that is one foot high.

2. **Convert Units:**
    - First, we know that one foot is equal to 12 inches.
    - If eight quarters make up half an inch, then we can determine how many quarters make up one inch by scaling up from half an inch.

3. **Find the Number of Quarters Needed for One Inch:**
    - Since eight quarters make up half an inch, to make one full inch, we would need twice as many quarters:
      \[
      \text{Number of quarters needed for 1 inch} = 8 \times 2 = 16
      \]

4. **Find the Number of Quarters Needed for Twelve Inches (One Foot):**
    - Now that we know it takes 16 quarters to make a stack that is one inch high, we need to find out how many quarters are needed to make a stack that is 12 inches high:
      \[
      \text{Number of quarters needed for 12 inches} = 16 \times 12
      \]

Let's implement this step-by-step reasoning in Python to ensure the result is accurate.
```python
# Given data
quarters_for_half_an_inch = 8
height_of_half_an_inch = 0.5  # in inches
height_of_one_foot = 12  # in inches

# Calculate the number of quarters needed to make a stack that is 1 inch high
quarters_for_one_inch = quarters_for_half_an_inch * (2 / height_of_half_an_inch)

# Now calculate the number of quarters needed to make a stack that is 12 inches (one foot) high
quarters_for_one_foot = quarters_for_one_inch * height_of_one_foot
print(quarters_for_one_foot)
```
Code execution result: 384.0

Thus, the number of quarters needed to make a stack one foot high is \(\boxed{384}\). This completes our solution.
