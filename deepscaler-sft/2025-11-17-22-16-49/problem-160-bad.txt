Let's solve the problem step-by-step.

1. **Understand the Problem:**
    - We have 3 horizontal strips in a flag.
    - Each strip can be one of 5 colors: red, white, blue, green, or yellow.
    - No two adjacent strips can be the same color.
    - No color can be used more than twice across the flag.

2. **Set Up the Solution:**
    - We will generate all possible ways to color the 3 strips with the 5 colors.
    - We will then filter these ways based on the conditions:
        - No two adjacent strips can be the same color.
        - No color can be used more than twice.

3. **Implement the Solution Using Python:**
    - We can use Python to iterate through all possible color combinations for the 3 strips and then check the conditions.
    - For each valid combination, we will count it as a distinct flag.

Let's write the Python code to solve this step-by-step.
```python
import itertools

# Define the list of possible colors
colors = ['red', 'white', 'blue', 'green', 'yellow']

# Initialize a counter for distinct flags
distinct_flags = []

# Generate all possible ways to color the 3 strips with the 5 colors
for comb in itertools.product(colors, repeat=3):
    strip1, strip2, strip3 = comb
    
    # Check the conditions
    if strip1 != strip2 and strip2 != strip3 and strip1 != strip3:
        color_count = {color: 0 for color in colors}
        
        for color in comb:
            color_count[color] += 1
        
        if all(count <= 2 for count in color_count.values()):
            distinct_flags.append(comb)

# Get the count of distinct flags
num_distinct_flags = len(distinct_flags)
print(num_distinct_flags)
```
Code execution result: 60

Thus, the number of distinct flags that can be made, given the constraints, is \(\boxed{60}\). This is our final answer.
