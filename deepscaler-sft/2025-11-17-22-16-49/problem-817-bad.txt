To solve this problem, we need to follow these steps:

1. **Generate All Permutations:**
   - First, generate all the permutations of the digits in 1150. Note that the digit 1 is repeated.
   - Convert these permutations into integers to filter out the four-digit numbers.

2. **Filter Conditions:**
   - Filter out the four-digit numbers only.
   - Check if these numbers are multiples of 5. A number is a multiple of 5 if its last digit is either 0 or 5.

3. **Count Valid Numbers:**
   - Count how many such numbers meet both conditions.

Let's implement this step-by-step in Python:
```python
import itertools

# Get all unique permutations of the digits in 1150
digits = [1, 1, 5, 0]
permutations = set()

for perm in set(itertools.permutations(digits)):
    num = int(''.join(map(str, perm)))
    
    # Only consider numbers that are four digits long (i.e., do not start with 0)
    if 1000 <= num <= 9999 and perm[-1] != 0:
        permutations.add(num)

# Filter to keep only the numbers that are multiples of 5
multiples_of_5 = [num for num in permutations if num % 5 == 0]

# Get the count of such numbers
result = len(multiples_of_5)
print(result)
```
Code execution result: 2

Thus, the number of ways to arrange the digits of 1150 to get a four-digit multiple of 5 is \(\boxed{2}\). This is our final answer.
