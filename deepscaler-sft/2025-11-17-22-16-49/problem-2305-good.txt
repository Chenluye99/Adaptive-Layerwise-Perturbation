First, let's start by setting up the problem and breaking it down into steps.

1. **Combine the Girls Condition:**
    - We need to ensure that all 3 daughters sit next to each other. We can treat the 3 daughters as a single "super unit" or block. This "block" can be in different positions, but internally, the 3 daughters can be arranged in \(3!\) ways.
    
2. **Formulate the Problem with the "Super Unit":**
    - This "super unit" of 3 daughters can be considered as a single entity, so we now have 5 entities to arrange: the "super unit" (which internally has 3 elements) and the 4 sons, making it 5 entities in total.
    - These 5 entities can be arranged in \(5!\) ways.
    - For each of these \(5!\) arrangements, the 3 daughters within their "super unit" can be arranged among themselves in \(3!\) ways.

3. **Calculate the Result:**
    - The total number of ways to arrange the 7 people such that the 3 daughters are always together is given by:
      \[
      5! \times 3!
      \]

Let's implement this using Python to ensure we get an accurate result.
```python
import math

# Calculate 5! (factorial of 5) and 3! (factorial of 3)
factorial_5 = math.factorial(5)
factorial_3 = math.factorial(3)

# Multiply the two results to get the final answer
total_ways = factorial_5 * factorial_3
print(total_ways)
```
Code execution result: 720

Thus, the number of ways the Smith family can seat their 4 sons and 3 daughters in a row of 7 chairs such that all 3 girls sit next to each other is \(\boxed{720}\). This is our final answer.
