First, let's summarize the problem requirements and setup:

We need to find integers \( k \) such that when expressed in base \(-3 + i\), they have a four-digit expansion, i.e., \( k = (a_3 a_2 a_1 a_0)_{-3 + i} \) where \( a_3, a_2, a_1, a_0 \) are digits chosen from \{0, 1, 2, \ldots, 9\} with \( a_3 \neq 0 \).

To solve this problem, we need to convert from the base \(-3 + i\) representation back to the decimal (base 10) representation and check if the result is an integer. We'll iterate over all combinations of \( a_3, a_2, a_1, a_0 \) under the given constraints, convert each combination to its decimal equivalent, and then check if the resulting number \( k \) is an integer.

### Step-by-Step Plan:

1. **Set Up Base Conversion Function:**
    - Create a function to convert a number from base \(-3 + i\) to its decimal (base 10) equivalent.

2. **Iterate Over Possible Digits:**
    - Loop through all possible values of \( a_3, a_2, a_1, a_0 \) from 0 to 9, ensuring \( a_3 \neq 0 \).
    - For each combination, form the base \(-3 + i\) number and convert it to a decimal number.

3. **Check and Collect Valid \( k \):**
    - Check if the decimal number is an integer.
    - Collect all such integers \( k \) that meet the criteria.

4. **Find the Sum of All Valid \( k \):**
    - Compute the sum of all distinct integers \( k \) that satisfied the condition above.

### Implementation in Python

Let's implement this step by step in Python:
```python
import itertools

# Define the base
base = -3 + 1j

# Initialize a set to store valid k values
valid_k = set()

# Try all combinations of a_3, a_2, a_1, a_0 from 0 to 9, with a_3 != 0
for a_3, a_2, a_1, a_0 in itertools.product(range(10), repeat=4):
    if a_3 != 0:
        # Form the complex number in base -3 + i
        num_base = a_3 * (base ** 3) + a_2 * (base ** 2) + a_1 * base + a_0
        
        # Check if this corresponds to an integer k
        if num_base.imag == 0:
            k = int(num_base.real)
            valid_k.add(k)

# Find the sum of all such valid k
sum_of_k = sum(valid_k)
print(sum_of_k)
```
