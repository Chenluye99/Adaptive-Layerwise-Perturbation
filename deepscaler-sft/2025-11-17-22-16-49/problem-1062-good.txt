First, let's start by introducing a substitution to simplify the equation. Let:

\[ y = z^2 - 3z + 1 \]

Then, the given equation

\[ (z^2 - 3z + 1)^2 - 3(z^2 - 3z + 1) + 1 = z \]

can be rewritten as:

\[ y^2 - 3y + 1 = z. \]

Now, we substitute back \( y = z^2 - 3z + 1 \):

\[ (z^2 - 3z + 1)^2 - 3(z^2 - 3z + 1) + 1 = z. \]

This gives us a system of two equations:

1. \( y = z^2 - 3z + 1 \)
2. \( y^2 - 3y + 1 = z \)

We can substitute the first equation into the second:

\[ (z^2 - 3z + 1)^2 - 3(z^2 - 3z + 1) + 1 = z. \]

We will use Python to solve this equation because it involves solving a polynomial equation, which can be quite complex and difficult to solve manually.

Let's implement this step-by-step in Python.
```python
import sympy as sp

# Define the variable
z = sp.symbols('z')

# Define the equation
equation = (z**2 - 3*z + 1)**2 - 3 * (z**2 - 3*z + 1) + 1 - z

# Solve the equation
solutions = sp.solve(equation, z)
print(solutions)
```
