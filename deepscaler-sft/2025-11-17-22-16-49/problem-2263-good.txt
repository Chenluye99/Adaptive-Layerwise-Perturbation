This gives us:
\[
\cos 5^\circ = \sin 25^\circ + \sin \theta \implies \sin 85^\circ = \sin 25^\circ + \sin \theta.
\]

Next, we can isolate \(\sin \theta\):
\[
\sin \theta = \sin 85^\circ - \sin 25^\circ.
\]

We can use Python to calculate \(\sin 85^\circ\) and \(\sin 25^\circ\), and then find \(\sin \theta\). Once we have \(\sin \theta\), we can determine the angle \(\theta\) that satisfies this equation and find the least positive angle that works.

Let's start by computing \(\sin 85^\circ\) and \(\sin 25^\circ\) and then find \(\sin \theta\).
```python
import math

# Calculate sin(85°) and sin(25°)
sin_85 = math.sin(math.radians(85))
sin_25 = math.sin(math.radians(25))

# Calculate sin(θ)
sin_theta = sin_85 - sin_25

# Find the angle θ such that sin(θ) = sin_theta
# We need to find the angle θ in degrees that corresponds to sin(θ)
theta_rad = math.asin(sin_theta)
theta = math.degrees(theta_rad)

print(theta)
```
