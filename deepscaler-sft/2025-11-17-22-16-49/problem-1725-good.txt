Let's start by coding this in Python to ensure all valid configurations and their counts are properly handled and returned.
```python
import itertools

# The set of letters that remain after 8 has already been typed
remaining_letters = [1, 2, 3, 4, 5, 6, 7, 9]

# Generate all permutations of the remaining letters, as each permutation represents a different possible order in which
# the remaining letters could be typed after lunch.
permutations = list(itertools.permutations(remaining_letters))

# The number of distinct after-lunch typing orders is simply the number of permutations of the list [1, 2, 3, 4, 5, 6, 7, 9].
```
