Let's start by defining the variables and understanding the problem.

1. Let's assume the length of \(AB\) and \(BC\) to be \(a\) and \(b\) respectively.
2. Point \(E\) is on \(\overline{AB}\) and point \(F\) is on \(\overline{CD}\) such that \(AEFD\) forms a square. This means that \(AE = EF = FD = AD = b\).
3. Therefore, if \(AE = b\), then \(BE = a - b\) because \(E\) is on \(\overline{AB}\).
4. Given that \(\frac{AB}{BE} = \frac{BE}{BC}\), we substitute \(AB = a\), \(BE = a - b\), and \(BC = b\) into this equation:
   \[
   \frac{a}{a - b} = \frac{a - b}{b}
   \]
5. We can solve this equation for the ratio \(\frac{a}{b}\).

Let's set up the equation and solve it step-by-step using Python to ensure accuracy.
```python
import sympy as sp

# Define variables
a, b = sp.symbols('a b', positive=True)

# Set up the equation based on the given condition
equation = sp.Eq(a / (a - b), (a - b) / b)

# Solve the equation for the ratio a/b
solution = sp.solve(equation, a)

print(solution)
```
