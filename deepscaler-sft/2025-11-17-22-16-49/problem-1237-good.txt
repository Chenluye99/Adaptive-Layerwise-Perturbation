First, let's start by understanding the problem:

1. Each of the 4 dice rolled can show a number from 1 to 12.
2. A "one-digit number" is any number from 1 to 9, and a "two-digit number" is any number from 10 to 12.
3. We need to find the probability that the number of dice showing a two-digit number is equal to the number of dice showing a one-digit number. Since we have 4 dice, the only way this can happen is if exactly 2 of the dice show a one-digit number and exactly 2 of the dice show a two-digit number.

Next, let's set up the solution with Python to ensure accuracy.

1. **Identify the ranges:**
    - One-digit numbers: 1 through 9 (9 possibilities)
    - Two-digit numbers: 10 through 12 (3 possibilities)

2. **Enumerate all outcomes:**
    - Each die has 12 faces, so there are \(12^4\) possible outcomes when 4 dice are rolled.

3. **Count the desired outcomes:**
    - We need to count how many of these outcomes have exactly 2 dice showing one-digit numbers and exactly 2 dice showing two-digit numbers.

4. **Calculate the probability:**
    - The probability is the ratio of the number of desired outcomes to the total number of outcomes.

Let's implement this step-by-step in Python.
```python
import itertools

# Define the possible outcomes for each die
sides = list(range(1, 13))

# Generate all possible outcomes for rolling 4 dice
all_rolls = list(itertools.product(sides, repeat=4))

# Count the number of desired outcomes
desired_count = 0

for roll in all_rolls:
    one_digit_count = sum(1 for x in roll if 1 <= x <= 9)
    two_digit_count = sum(1 for x in roll if 10 <= x <= 12)
    
    if one_digit_count == 2 and two_digit_count == 2:
        desired_count += 1

# Calculate total number of outcomes
total_outcomes = len(all_rolls)

# Calculate the probability
probability = desired_count / total_outcomes

# Return the result as a fraction
from fractions import Fraction
probability_fraction = Fraction(desired_count, total_outcomes)

print(probability_fraction)
```
Code execution result: 27/128

Thus, the probability that the number of dice showing a two-digit number is equal to the number of dice showing a one-digit number is \(\boxed{\frac{27}{128}}\). This is our final answer.
