Let's start by setting up the problem. We know that 0.5 liters is approximately 1.05 pints. To find out how many pints are in one liter, we can set up a proportion and solve for the unknown quantity.

1. We know:
\[ 0.5 \text{ liters} \approx 1.05 \text{ pints} \]

2. To find out how many pints are in 1 liter, we can set up the following equation:
\[ 1 \text{ liter} = \frac{1.05 \text{ pints}}{0.5} \]

3. Performing the division:
\[ 1 \text{ liter} \approx \frac{1.05}{0.5} \text{ pints} \]

Let's calculate this value using Python to ensure accuracy, and then round it to the nearest tenth.
```python
# Given values
liters = 0.5
pints = 1.05

# Calculate pints per liter
pints_per_liter = pints / liters

# Round the result to the nearest tenth
pints_per_liter_rounded = round(pints_per_liter, 1)
print(pints_per_liter_rounded)
```
Code execution result: 2.1

Thus, the number of pints in one liter is \(\boxed{2.1}\). This is the final answer, obtained by reasoning and computation.
