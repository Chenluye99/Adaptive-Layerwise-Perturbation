First, let's start by solving the equation \(2 \sin^3 x - 5 \sin^2 x + 2 \sin x = 0\) in the range \(0 \le x \le 2 \pi\).

1. **Factor the Equation:**
   We can factor out \(\sin x\) from the equation:
   \[
   \sin x (2 \sin^2 x - 5 \sin x + 2) = 0
   \]
   This gives us two parts to solve:
   - \(\sin x = 0\)
   - \(2 \sin^2 x - 5 \sin x + 2 = 0\)

2. **Solve \(\sin x = 0\):**
   \(\sin x = 0\) when \(x = 0\) or \(x = \pi\) or \(x = 2 \pi\) in the range \(0 \le x \le 2 \pi\).

3. **Solve \(2 \sin^2 x - 5 \sin x + 2 = 0\):**
   Let \(y = \sin x\). Then the equation becomes a quadratic equation in terms of \(y\):
   \[
   2 y^2 - 5 y + 2 = 0
   \]
   We solve this quadratic equation using the quadratic formula \(y = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}\), where \(a = 2\), \(b = -5\), and \(c = 2\):
   \[
   y = \frac{-(-5) \pm \sqrt{(-5)^2 - 4 \cdot 2 \cdot 2}}{2 \cdot 2} = \frac{5 \pm \sqrt{25 - 16}}{4} = \frac{5 \pm \sqrt{9}}{4} = \frac{5 \pm 3}{4}
   \]
   This gives us two solutions:
   \[
   y = \frac{5 + 3}{4} = 2 \quad \text{and} \quad y = \frac{5 - 3}{4} = \frac{1}{2}
   \]
   Since \(\sin x = 2\) is not a valid solution (as the sine function only takes values between -1 and 1), we are left with:
   \[
   \sin x = \frac{1}{2}
   \]
   \(\sin x = \frac{1}{2}\) when \(x = \frac{\pi}{6}\) or \(x = \frac{5 \pi}{6}\) in the range \(0 \le x \le 2 \pi\).

4. **Combine All Solutions:**
   Now, we have the solutions from both parts:
   - From \(\sin x = 0\), we get \(x = 0, \pi, 2 \pi\).
   - From \(\sin x = \frac{1}{2}\), we get \(x = \frac{\pi}{6}, \frac{5 \pi}{6}\).

   Therefore, the distinct solutions in the interval \(0 \le x \le 2 \pi\) are:
   \[
   x = 0, \frac{\pi}{6}, \pi, \frac{5 \pi}{6}, 2 \pi
   \]
   This gives us a total of 5 distinct solutions.

Let's confirm this by implementing it in Python.
```python
import sympy as sp

# Define the variable
x = sp.symbols('x')

# Define the equation
equation = 2 * sp.sin(x)**3 - 5 * sp.sin(x)**2 + 2 * sp.sin(x)

# Solve the equation in the range 0 <= x <= 2 * pi
solutions = sp.solveset(equation, x, domain=sp.Interval(0, 2 * sp.pi))

# Get the list of solutions
solution_list = list(solutions)

# Get the number of distinct solutions
num_solutions = len(solution_list)
print(num_solutions)
```
