To solve the problem of finding the smallest odd number with four different prime factors, we can follow these steps:

1. **Generate Prime Numbers:**
   We need a way to generate a list of prime numbers because we'll need to check for prime factors.

2. **Check for Different Prime Factors:**
   We need to check whether a given number has four different prime factors.

3. **Ensure the Number is Odd:**
   We need to ensure that the number we check is odd.

4. **Find the Smallest Number:**
   We will start checking from the smallest odd number (3) and go upwards, checking each odd number to see if it meets the conditions above.

Let's implement this step-by-step in Python.
```python
import sympy

def find_smallest_odd_number_with_four_prime_factors():
    n = 3  # Start checking from the smallest odd number
    
    while True:
        # Factorize the number and get the prime factors
        prime_factors = list(sympy.primefactors(n))
        
        # Check if the number has exactly four different prime factors
        if len(prime_factors) == 4:
            return n
        
        # Move to the next odd number
        n += 2  # Increment by 2 to ensure we only check odd numbers

smallest_odd_number = find_smallest_odd_number_with_four_prime_factors()
print(smallest_odd_number)
```
