5. **Finding Vectors \(\overrightarrow{NB}\), \(\overrightarrow{NG}\):**

    - \(\overrightarrow{NG} = G - N = \left(\frac{1}{3}, \frac{2\sqrt{3}}{9}, \frac{\sqrt{6}}{9}\right) - \left(\frac{1}{2}, 0, 0\right) = \left(\frac{1}{3} - \frac{1}{2}, \frac{2\sqrt{3}}{9}, \frac{\sqrt{6}}{9}\right) = \left(-\frac{1}{6}, \frac{2\sqrt{3}}{9}, \frac{\sqrt{6}}{9}\right)\)

6. **Finding \(\cos \angle BNG\):**
    - The cosine of the angle between two vectors \(\overrightarrow{u}\) and \(\overrightarrow{v}\) is given by:
      \[
      \cos \theta = \frac{\overrightarrow{u} \cdot \overrightarrow{v}}{\|\overrightarrow{u}\| \|\overrightarrow{v}\|}

import numpy as np

# Define the vertices of the tetrahedron

# Find N (midpoint of AB)
N = (A + B) / 2

# Find G (centroid of triangle ACD)
G = (A + C + D) / 3

# Calculate vectors NB and NG
NB = B - N
NG = G - N

# Calculate the dot product of NB and NG
dot_product = np.dot(NB, NG)

# Calculate the magnitudes of NB and NG
magnitude_NB = np.linalg.norm(NB)
magnitudeNG = np.linalg.norm(NG)

# Calculate cos(angle BNG)
cos_BNG = dot_product / (magnitude_NB * magnitudeNG)
