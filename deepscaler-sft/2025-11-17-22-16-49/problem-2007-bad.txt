To solve this problem, we need to find the smallest possible value of \( n \) that satisfies the following conditions:

1. When Ray climbs the stairs 4 steps at a time, there are 3 steps left at the top, which translates to:
   \[
   n \equiv 3 \pmod{4}
   \]
2. When Ray climbs the stairs 5 steps at a time, there are 2 steps left at the top, which translates to:
   \[
   n \equiv 2 \pmod{5}
   \]
3. \( n \) must be greater than 10.

We will iterate through the numbers greater than 10 and check if they satisfy both of these conditions. Let's write some Python code to find the smallest possible value of \( n \).
```python
# We will start from 11 and go upwards, checking each number to see if it satisfies both congruences.
def find_smallest_n():
    n = 11
    while True:
        if n % 4 == 3 and n % 5 == 2:
            return n
        n += 1

# Find and print the result
result = find_smallest_n()
print(result)
```
Code execution result: 27

Thus, the smallest possible value of \( n \) that is greater than 10 and satisfies both conditions is \(\boxed{27}\). This means that 27 is the smallest number that, when climbed 4 steps at a time, leaves 3 steps at the top, and when climbed 5 steps at a time, leaves 2 steps at the top.
